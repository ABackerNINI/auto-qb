交互口径(与落地实现一致)
  • 按钮 = 当前 UI 名 + 图标 + ▾; 点开下拉, 再点收起; 点页面空白处 / Esc 收起(走既有浮层关闭链)。
  • 菜单行 = 图标 + UI 名 + 一句话描述; 当前行带「当前」标记 + ✓, 点击不动作(仅收起); 其余行点击整页跳转直达。
  • 面板复用既有弹层族 .pop-menu / .pop-item(与列选择器、筛选器同族, 静态 flip-x 右对齐), 三套皮肤各自出样式 —— 新增 CSS 为 0 行(atlas components.css 已顶满 700 行上限)。
  • 棱镜的「主题」按钮不受影响(主题是棱镜内部的另一维度); 控制台菜单选中态用左侧发光条(方角语言)。
