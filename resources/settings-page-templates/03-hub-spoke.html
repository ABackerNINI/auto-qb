/连接 qBittorrent

连接 qBittorrent

auto-qb 通过 qBittorrent 的 Web UI 读取和修改种子。把地址和登录信息填对，它就能接管种子管理。

已连接
地址和登录qB 的「设置 → Web UI」里都能查到
主机*

装 qBittorrent 的那台机器。auto-qb 和 qB 装在同一台电脑上就填 127.0.0.1。

端口*

qB Web UI 监听的端口，默认是 8080。

用户名

qB 里没设用户名就留空。

密码

qB Web UI 的登录密码。

保存后会以明文写进配置文件，别把配置文件发给别人。

多久检查一次一般不用改
检查间隔
秒

每隔多久看一次所有种子的状态，并处理到期的任务。不能填 0。

每轮最多处理
个任务

一轮里最多执行多少个自动化任务。太大单轮耗时长，界面反应会变钝。

内置任务间隔
秒

清理、限速曲线这类周期性任务的间隔，从上一次结束开始算。

运行状态存在哪
数据目录

运行状态、日志、跳检备份放在哪。可以写相对路径或绝对路径。

改了要重启 auto-qb 才生效。

状态文件

记录「上次做到哪了」，重启后接着上次的进度继续。

/自动化

自动化

种子加入之后自动做什么。每一项都是可选的，不想要就关掉。

标签
清理相似标签

自动去掉只有大小写不同的重复标签，比如 HHan 和 hhan 只留一个。

跳检标签

跳过哈希校验的种子会被打上这个标签。留空 = 不启用。

辅种分组已启用
启用分组

把原种和它的辅种看成一组，统一检查、统一暂停。

检查文件是否还在

核对组里的文件是否还在磁盘上，发现少了就整组暂停。

缺文件标签

发现缺文件时给组里每个种子加上这个标签。

集数标签未启用
启用

从新种子的文件名里解析集数，自动打上 zE01 这样的标签。只对刚加入的种子生效。

单集模板

${episode_first} 会替换成集数。

多集模板

分别是首集和末集，例如 zE01-12。

清理标签
彻底删除标签
未配置

把匹配的标签从所有种子上摘掉并注销。支持 regex:、:ignore_case、@站点标签。

标签定义会一起删掉，依赖它的自动化跟着失效。

删除无人使用的标签
2 条

只删已经没有种子在用的标签，可以放心配。

通知

出错或者做了有风险的操作时，用电脑的系统通知提醒你。不用额外装任何东西。
