连接 qBittorrent

auto-qb 通过 qB 的 Web UI 管理种子。点任意一行，右侧会说明这一项。

地址和登录
主机* 装 qBittorrent 的那台机器。和 auto-qb 同一台电脑就填 127.0.0.1，在别的机器上就填那台机器的内网 IP，比如 192.168.1.20。
端口* qB Web UI 监听的端口，默认是 8080。注意别和「界面与日志 → 端口」搞混，那是 auto-qb 自己的界面端口。
用户名 qB Web UI 的登录用户名。qB 里没设就留空。
密码 qB Web UI 的登录密码。保存后会以明文写进配置文件。
多久检查一次
检查间隔 秒 每隔多久看一次所有种子的状态，并处理到期的任务。默认 2 秒，不能填 0。
每轮最多处理 个 一轮里最多执行多少个自动化任务。太大单轮耗时长，界面反应会变钝。
内置任务间隔 秒 清理、限速曲线这类周期性任务的间隔，从上一次结束开始算。
运行状态存在哪
数据目录 运行状态、日志、跳检备份放在哪个目录。改了要重启 auto-qb 才生效。
状态文件 记录「上次做到哪了」，重启后接着上次的进度继续。

自动化

种子加入之后自动做什么。每一项都是可选的。

标签
清理相似标签 自动去掉只有大小写不同的重复标签，比如 HHan 和 hhan 只留一个。某个站点想例外可以到「站点」里单独关掉。
跳检标签 跳过哈希校验的种子会被打上这个标签。留空 = 不启用跳检。
辅种分组
启用分组 把原种和它的辅种看成一组，统一检查、统一暂停。
检查文件是否还在 核对组里的文件是否还在磁盘上，发现少了就整组暂停。
缺文件标签 发现缺文件时给组里每个种子加上这个标签。
集数标签
启用 从新种子的文件名里解析集数，自动打上 zE01 这样的标签。只对刚加入的种子生效。
单集模板 ${episode_first} 会替换成集数，例如 zE01。
多集模板 分别是首集和末集，例如 zE01-12。
清理标签
彻底删除标签 未配置 把匹配的标签从所有种子上摘掉并注销。标签定义会一起删掉，依赖它的自动化跟着失效。
删除无人使用的标签 2 条 只删已经没有种子在用的标签，可以放心配。

站点

用 tracker 域名判断种子来自哪个站点，再套用这个站点的设置。

HHan
站点域名 用 tracker 地址里的域名匹配，一行一个，子域名也算命中。
自动打的标签 命中这个站点的种子会自动带上这些标签。
自动归到的分类 qB 里的分类。留空表示不改分类。
上传限速 MiB/s 只对这个站点的种子生效。留空 = 不限速。
要跑哪些规则 @规则集 跑整个规则集，@规则集.规则名 只跑一条。留空 = 不跑规则。

规则

一条规则就是「当满足条件时执行动作」。条件全部满足才执行，动作按顺序执行。

做种满 7 天后删除含风险动作
条件 · 全部满足才执行
1做种时间 至少 7 天
动作 · 按顺序执行
1删除种子（同时删除文件）
上传率低就暂停
条件 · 全部满足才执行
1分享率 小于 0.5
2做种时间 至少 2 天
动作 · 按顺序执行
1暂停种子

通知

出错或者做了有风险的操作时，用电脑的系统通知提醒你。

主动通知
启用通知 关掉之后消息只出现在界面里，不会再弹系统通知。
最低提醒级别 达到哪个严重程度才提醒你。默认 WARNING，日常信息不打扰。
免打扰时段 这段时间里不弹通知，可以跨午夜。留空 = 全天都弹。
每小时上限 条 一小时内最多弹多少条，超出的直接丢掉。
重复合并窗口 分钟 这段时间里内容相同的通知只弹第一条。填 0 = 不合并。

界面与日志

这个浏览器界面怎么开、谁能访问，以及日志记在哪、留多久。

WEB 界面
启用界面 关掉之后只能直接改配置文件。
监听地址 保持 127.0.0.1 表示只有这台电脑能打开。改成 0.0.0.0 会暴露给局域网。
端口 auto-qb 自己界面的端口，和 qB 的 Web UI 端口是两回事。
访问密钥 留空 = 第一次启动时随机生成，并打印在启动日志里。
跳过本机验证 开着的话本机不用输密钥，别的机器访问仍然要。
日志
日志等级 DEBUG 会把每一步都记下来，排查问题时再开。
单个日志上限 MiB 写满就另起新文件，最多留 5 个旧文件。

端口qbittorrent.port

必填整数 1–65535

它是什么

qBittorrent 的 Web UI 监听在哪个端口。auto-qb 就是从这个端口去读种子、改种子的。

默认值

8080

什么时候需要改

  • 你在 qB 里把 Web UI 端口改过（改过就以 qB 里显示的为准）。
  • 一台机器上跑多个 qB 实例，端口被占用。

容易和它搞混的
