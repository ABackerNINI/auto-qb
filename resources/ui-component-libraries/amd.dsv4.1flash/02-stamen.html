Stamen

信息建筑派让数据成为可触摸的风景

数据不该被锁进图表，而该像一张等高线地图：每一层都是可探索的风景，色彩是温度，层次是地形。

以地图学思维组织界面。暖色赭石点燃焦点，鼠尾草绿安定正文，深蓝提供纵深；柔软的圆角与投影让数字界面也带着手工的温度。适合数据产品、地理信息、气候与公共数据叙事。

扩展你的组件

  1. 色调：延续"暖焦点 + 冷纵深"的法则——主操作与数据强调用赭石，正文与背景用暖中性，信息层级用深蓝。三个主色已定，语义色可再取邻近色相。
  2. 圆角：内容卡片 10px、小控件 6px、标签与开关胶囊；保持"纸张可触摸"的一致手感。
  3. 阴影：统一 浅投影，浮起感靠投影而非描边；弹窗可加深投影以拉开层级。
  4. 字体：衬线标题（Georgia/宋体）表人文，无衬线正文（Avenir/Segoe）保可读；比例固定 42/24/17/15/13。
  5. 质感：背景用暖纸白 #f7f4ee，卡片用 #fbfaf6；配色一律取自然界已有色相，不凭空造色。
