扩展你的组件

  1. 色调：结构全用中性灰，权威用海军蓝 #1d3a54，唯一强调色赭橙 #b3562f 只点结论与关键数据。
  2. 数字：所有数字与度量用等宽字体 JetBrains Mono 并右对齐，保证列内精确对齐。
  3. 圆角：直角 + 发丝线是科学期刊的纪律；仅数字徽章保留胶囊。
  4. 层级：信息密度可以高，但每层都用 1px 线 + 留白分隔，做到密集而不杂乱。
  5. 叙事：新增区块前自问"这段承载了什么结论"——不承载信息的像素都应删除。
