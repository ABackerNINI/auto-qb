Information Architects

信息建筑派设计不是装饰，是内容的建筑

少即是多的信息版本：去掉一切装饰，只保留内容自身的建筑感。字体即结构，链接即道路，性能即美学。

只使用系统字体以保证在任何设备上都极速加载。唯一的"设计"是清晰的内容层级：标题、正文、标签各司其职，经典蓝色链接贯穿始终。适合文档、写作工具、笔记应用与一切以阅读为第一要务的产品。

扩展你的组件

  1. 色调：灰阶承担全部层级（墨 #1a1a1a → 次墨 → 弱墨）。唯一彩色是链接蓝 #0000ee（已访问 #551a8b）；状态色只用于告警。
  2. 字体：只用系统字体栈 system-ui；代码/数字用等宽 ui-monospace。不引入任何 web 字体——性能即美学。
  3. 圆角：几乎不用圆角（2px 内），唯一胶囊保留在数字徽章。
  4. 行宽：正文统一 max-width: 66ch，这是阅读优化的硬约束。
  5. 链接：所有可点击文字用经典下划线蓝链接；按钮仅用于明确的动作。
