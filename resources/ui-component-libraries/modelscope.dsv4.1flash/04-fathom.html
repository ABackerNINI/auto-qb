01

风格介绍

适合：研究报告 / 数据产品 / 金融与科研仪表盘

这套组件库按科学期刊的规矩来：冷静的灰蓝底 + 海军蓝 + 单一琥珀色高亮；表格用细线分栏，数字一律等宽并右对齐；图表、图注（图 1）与脚注系统都是版面的正式成员。信息密度高于其他风格，但每条线都有存在的理由。

特征 01期刊式版式

分区标题配顶部规则线，图注与脚注编号成体系，像一篇论文。

特征 02冷静配色

灰蓝底 + 海军蓝主色 + 单一琥珀高亮（#B0761A），不用第二强调色。

特征 03数据精密

所有数字列使用等宽字体 + tabular-nums 右对齐，小数点对齐。

特征 04注释即设计

注释、单位、来源行全部纳入版式，而不是事后补充。

提示词 DNA（用于扩展 AI 生成素材）

Fathom Information Design style:
- Scientific journal aesthetic meets modern design
- Precise data visualization (charts, timelines, scatter plots)
- Neutral scheme (grays, navy, one highlight color)
- Footnote/citation design integrated into layout
- Clean sans-serif (GT America / Graphik)
- Information density without clutter

标志性做法（延续这套风格时保留）

  • 图表带编号图注（图 1 / 图 2），按正文顺序排列。
  • 面板顶部有 2px 规则线，像期刊的栏线。
  • 高亮色（琥珀）只用于需要读者注意的单个数据点。
  • 脚注区使用小号字 + 上标编号，与正文严格对应。

灵感来源

参考 Fathom Information Design（波士顿）：盖茨基金会年度报告、科学出版物的数据叙事。科学期刊的严谨 + 现代设计的优雅，注释与引用系统被设计进版面，信息密度高但不杂乱。

03

扩展指南

新增组件或页面时, 按这四步走即可保持风格统一。

  1. 新增组件先确定它的「图注编号」，版面上所有可见信息都应有出处或单位。
  2. 颜色只从灰蓝 / 海军蓝 / 琥珀三组里取；琥珀一屏最多出现两处。
  3. 数字与单位统一等宽字体 + 右对齐；百分比保留一位小数。
  4. 提高信息密度时优先用分栏与细线，而不是缩小字号（正文不小于 13px）。

延续与扩展时应做

  • 为图表加编号图注与来源
  • 数字右对齐 + 等宽字体
  • 用细线分栏提高密度
  • 琥珀色标记关键数据

会破坏这套风格的做法

  • 用大面积色块做视觉冲击
  • 省略单位与数据来源
  • 正文小于 13px
  • 引入第二高亮色

想要第 21 套风格? 复制任意一套文件, 只替换 :root 变量块与该风格专属的组件覆写即可 —— 骨架、组件标记与交互脚本都可原样复用。

折叠面板

为什么「每天一次」要靠状态文件去重?
窗口语义不能依赖循环频率: 程序可能重启、循环周期可能调整。把执行记录写进 state_file, 重复执行同一动作才会是幂等的。
校验之后的代码为什么不做防御性检查?
配置在 validate_config 一次性全量校验并聚合报错, 之后的代码假定配置正确 —— 这样错误只有一个出口, 不会散落在各分支里。
