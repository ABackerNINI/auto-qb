# UI 组件库 20 式

> 按 [设计哲学风格库](../../../.agents/skills/aesthetic-preset-library/SKILL.md) 的 **5 大流派 × 20 位设计师/工作室** 体系，
> 各产出一套完整、可直接展示的 UI 组件库。20 套共用同一套语义化组件标记与结构，
> 但视觉语汇（配色 / 字体 / 形状 / 光影 / 交互 / 装饰）由每套风格独立覆写 —— 便于横向比较与挑选。

## 快速开始

1. 双击打开 **[index.html](index.html)** —— 挑选索引页：20 套实时缩略预览、按流派筛选、速查表。
2. 打开任意单套页面（如 [01-pentagram.html](01-pentagram.html)）—— 完整组件库：风格介绍 / 设计变量 / 扩展指南 / 常用组件 / 组合示例。
3. 所有文件**单文件自包含**：无外部 CSS / JS / 字体 / 图片依赖，离线可开、可直接发给人看。

## 每套页面包含什么

- **风格介绍** —— 哲学内核、4 条核心特征、关键词、灵感来源、标志性做法，以及可直接复制使用的**提示词 DNA**（用于扩展 AI 生成素材）。
- **设计变量** —— 色板（含 hex 与用途）、字体排印样张、形状 / 层级刻度、完整 token 清单；全部定义在该页 `:root`，扩展时引用变量即可。
- **扩展指南** —— 四步扩展流程 + 「应做 / 会破坏风格」清单；文末说明「如何长出第 21 套」。
- **常用组件** —— 按钮（6 变体 / 3 尺寸 / 4 状态）、表单（输入 / 选择 / 复选 / 单选 / 开关 / 滑块 / 校验态）、数据展示（徽章 / 标签 / 头像 / 进度 / 指标 / 骨架屏）、表格、导航（标签页 / 面包屑 / 分页 / 步骤条 / 折叠面板）、反馈（提示 / Toast / Tooltip / 对话框 / 空状态），以及一屏**组合示例**。
- **交互可试用** —— 标签页切换、对话框、表单聚焦 / 校验态、悬停与按下反馈均为原生实现，无需构建。

## 如何扩展

**加一个新组件（保持某套风格）**

1. 打开对应页面，从「设计变量」区复制 `:root` 变量块（或直接复制该文件的 `<style>` 第二段）。
2. 新组件的所有颜色 / 圆角 / 间距 / 字体只引用变量（如 `var(--primary)`、`var(--radius)`），不要写死数值。
3. 对照该页「扩展指南」的应做 / 禁止清单自查（例如 Pentagram 禁圆角与阴影、Kenya Hara 只用发丝线）。

**加第 21 套风格**

1. 复制任意一套 HTML，替换 `<style>` 中的 `:root` 变量块与该风格专属的组件覆写规则。
2. 替换页面首部的风格介绍、提示词 DNA、扩展指南文案（结构不必动）。
3. 在 `index.html` 的卡片列表与速查表中登记新的一套。

**换品牌字体**：每套 `:root` 的 `--font-display / --font-body / --font-mono` 是纯系统字体栈（离线可用）。若要换成品牌字体，只需替换这三个变量的字族列表（无需其它改动）。

## 实现说明

- 单文件自包含：CSS 内联、交互用少量原生 JS（标签页 / 对话框 / 复制），无构建步骤、无 CDN。
- 无 emoji 装饰；图标为内联 SVG 线性图标（1.7px stroke、currentColor）。
- 无障碍基础：语义化标签、表单 label / `aria-invalid`、对话框 `dialog` 元素、可见聚焦态、装饰图形 `role`/`aria-label`。
- 响应式：≥1020px / 700–1020px / <700px 三档；表格横向滚动；`prefers-reduced-motion` 下关闭动效。
- 示例数据均为演示用途（页面内已标注），不代表真实统计数据。
