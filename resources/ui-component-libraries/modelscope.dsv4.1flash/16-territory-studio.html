01

风格介绍

适合：科幻与游戏项目 / 数据监控大屏 / 叙事型产品展示

这套组件库模拟一块船载终端屏幕：琥珀单色（#FFB000）打在近黑底上、细网格与扫描线、面板四角带支架（corner brackets）、表格用虚线构成数据矩阵。信息层叠出现 —— 底网格、中面板、前景读数，像全息投影的三层。青色 #5FE0FF 只用于「信息态」。

特征 01琥珀单色

除青色信息态外全部使用琥珀色系；单色是 FUI 可信度的核心。

特征 02支架角标

面板四角有 2px 支架，像固定在屏幕上的硬件模块。

特征 03层叠全息

底网格 / 中面板 / 前景读数三层叠放，层间用透明度区分。

特征 04数据矩阵

表格与列表使用虚线行分隔，像扫描出来的数据流。

提示词 DNA（用于扩展 AI 生成素材）

Territory Studio FUI (Fantasy User Interface):
- Fantasy User Interface design
- Holographic projection aesthetics
- Orange/amber monochrome or cyan accents
- Multiple overlapping data layers
- Believable future technology
- Technical readouts and data streams

标志性做法（延续这套风格时保留）

  • 支架角标出现在所有面板的四角。
  • 扫描线/网格底纹贯穿页面，像 CRT 的余晖。
  • 所有读数使用等宽字体 + 琥珀色，青色仅用于信息状态。
  • 数字时刻对齐（tabular-nums），像仪表盘。

灵感来源

参考 Territory Studio 的 FUI（Fantasy User Interface）工作：《银翼杀手 2049》《攻壳机动队》等影片中的屏幕图形。琥珀单色、全息层叠、技术读数与数据流、可信的未来感 —— 让观众相信那是真的系统。

03

扩展指南

新增组件或页面时, 按这四步走即可保持风格统一。

  1. 新增面板时加上四角支架；没有支架的「屏幕感」会立刻消失。
  2. 琥珀色系打底，青色只用在信息/成功态；两者不要平分画面。
  3. 读数、编号、状态统一等宽字体并保持右对齐；上标英文缩写用大写。
  4. 需要层次时叠加透明度层（底网格 / 面板 / 读数），不要引入新色相。

延续与扩展时应做

  • 所有面板带四角支架
  • 单色琥珀 + 青色信息态
  • 表格用虚线分隔
  • 读数等宽 + 右对齐

会破坏这套风格的做法

  • 使用彩虹或多色相
  • 放弃网格与扫描线
  • 把青色用成主色
  • 圆角与柔和阴影

想要第 21 套风格? 复制任意一套文件, 只替换 :root 变量块与该风格专属的组件覆写即可 —— 骨架、组件标记与交互脚本都可原样复用。

折叠面板

为什么「每天一次」要靠状态文件去重?
窗口语义不能依赖循环频率: 程序可能重启、循环周期可能调整。把执行记录写进 state_file, 重复执行同一动作才会是幂等的。
校验之后的代码为什么不做防御性检查?
配置在 validate_config 一次性全量校验并聚合报错, 之后的代码假定配置正确 —— 这样错误只有一个出口, 不会散落在各分支里。
