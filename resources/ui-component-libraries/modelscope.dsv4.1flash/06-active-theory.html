01

风格介绍

适合：技术产品官网 / 数据平台展示 / 沉浸式演示

这套组件库把界面放进一间数据粒子室里：深空底色 + 青→品红撞色渐变、磨砂玻璃面板（backdrop-filter）、悬浮感的大圆角。粒子场与数据流线是主视觉，玻璃卡片浮在其上。强调色采用渐变而非纯色，让每个交互都有「能量」的方向感。

特征 01粒子即数据

主视觉是确定性生成的粒子场 + 数据流线，表达数据流动。

特征 02玻璃层 UI

面板使用 14px 模糊 + 白色薄膜，浮在粒子背景之上。

特征 03撞色渐变

青 #3BE8FF → 品红 #FF4FD8，用于主按钮、进度与关键数字。

特征 04悬浮节奏

Hero 图形有缓慢浮动动画，界面像漂浮在空间中。

提示词 DNA（用于扩展 AI 生成素材）

Active Theory WebGL aesthetic:
- Particle systems representing data flow
- 3D visualization in depth space
- Neon gradients (cyan/magenta/electric blue) on dark
- Mouse-reactive environment
- Depth of field and bokeh effects
- Floating UI with glassmorphism

标志性做法（延续这套风格时保留）

  • 主按钮使用青→品红渐变，纯色按钮不存在于这套体系。
  • 所有面板半透明 + 模糊，能透出背后的粒子。
  • 标题用白→淡青渐隐，与背景空间连成一体。
  • 粒子场每次生成位置不同但种子固定，可复现。

灵感来源

参考 Active Theory（洛杉矶）的 WebGL 作品：NASA Prospect、为品牌构建的三维交互世界。粒子系统代表数据流、霓虹撞色、悬浮玻璃层 UI、鼠标可交互的环境感。

03

扩展指南

新增组件或页面时, 按这四步走即可保持风格统一。

  1. 新增面板时保持半透明 + 模糊；如果面板完全不透明，粒子房间就消失了。
  2. 渐变只允许一个方向（120°）：青 → 紫 → 品红，不要自造第二组渐变。
  3. 粒子类图形用 SVG 生成并固定随机种子，保证可复现、零外部资源。
  4. 文字永远放在玻璃层或底色上，不直接压在密集粒子上（对比度优先）。

延续与扩展时应做

  • 面板保持玻璃态（模糊 + 薄膜）
  • 渐变统一青→品红方向
  • 粒子图形固定种子
  • 给悬浮元素留出光晕空间

会破坏这套风格的做法

  • 使用纯色主按钮
  • 把粒子堆到文字后面
  • 叠加第二种渐变方向
  • 让面板完全不透明

想要第 21 套风格? 复制任意一套文件, 只替换 :root 变量块与该风格专属的组件覆写即可 —— 骨架、组件标记与交互脚本都可原样复用。

折叠面板

为什么「每天一次」要靠状态文件去重?
窗口语义不能依赖循环频率: 程序可能重启、循环周期可能调整。把执行记录写进 state_file, 重复执行同一动作才会是幂等的。
校验之后的代码为什么不做防御性检查?
配置在 validate_config 一次性全量校验并聚合报错, 之后的代码假定配置正确 —— 这样错误只有一个出口, 不会散落在各分支里。
