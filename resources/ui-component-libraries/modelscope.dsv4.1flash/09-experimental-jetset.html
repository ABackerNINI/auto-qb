01

风格介绍

适合：文化机构 / 品牌识别系统 / 展览与活动页面

这套组件库把「字体即图形」推到前台：主视觉是重复的单词条带（像海报上的字阵），按钮是色块，标签是高对比描边。颜色严格限定在三原色 + 黑白，几何形状只有方、圆、条。所有组件都在 3px 黑色结构线上生长，像一张被精确裁切的印刷品。

特征 01字体即图形

重复单词条带作为主视觉与分区装饰，字号即图形力度。

特征 02三原色规则

红 #E42313 / 蓝 #1D4ED8 / 黄 #FFD400 + 黑白，不引入第四色。

特征 03结构黑线

3px 黑色结构线定义所有区块边界，圆角一律为 0。

特征 04色块交互

悬停与选中即填充色块（黄 → 蓝 → 红），不做阴影与位移。

提示词 DNA（用于扩展 AI 生成素材）

Experimental Jetset conceptual minimalism:
- Single visual metaphor for entire design
- Primary colors only (red/blue/yellow) + black/white
- Typography as main graphic element
- Grid-based with deliberate rule-breaking
- No photography, only type and geometry
- Anti-commercial, honest aesthetic

标志性做法（延续这套风格时保留）

  • 重复单词条带是签名元素，出现在 Hero 与页脚上方。
  • 选中态填充黄色 #FFD400，悬停填充黑色或蓝色。
  • 所有编号使用等宽数字并与结构线对齐。
  • 一屏只用一种原色作为动作色，其余留白。

灵感来源

参考 Experimental Jetset（阿姆斯特丹）的概念极简：Whitney Museum 的「Responsive W」识别、大量以字体本身作为图形的海报。三原色（红/蓝/黄）+ 黑白的蒙德里安色系，反商业的诚实感。

03

扩展指南

新增组件或页面时, 按这四步走即可保持风格统一。

  1. 新增组件先选它的「形式」：条带、色块还是描边框？只能三选一。
  2. 颜色从三原色池里取；同一屏内动作色只用一种，其余用黑白灰。
  3. 所有描边统一 3px 黑色；圆角保持 0，不用渐变与阴影。
  4. 需要装饰时重复文字，而不是加图形 —— 字阵是这套风格唯一的插画。

延续与扩展时应做

  • 用重复文字做装饰
  • 保持 3px 黑色结构线
  • 选中态用三原色色块
  • 编号与结构线对齐

会破坏这套风格的做法

  • 引入第四种颜色
  • 使用圆角或阴影
  • 添加照片或插画
  • 用渐变做任何过渡

想要第 21 套风格? 复制任意一套文件, 只替换 :root 变量块与该风格专属的组件覆写即可 —— 骨架、组件标记与交互脚本都可原样复用。

折叠面板

为什么「每天一次」要靠状态文件去重?
窗口语义不能依赖循环频率: 程序可能重启、循环周期可能调整。把执行记录写进 state_file, 重复执行同一动作才会是幂等的。
校验之后的代码为什么不做防御性检查?
配置在 validate_config 一次性全量校验并聚合报错, 之后的代码假定配置正确 —— 这样错误只有一个出口, 不会散落在各分支里。
