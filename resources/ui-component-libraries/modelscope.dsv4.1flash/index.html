怎么用这份索引

1 · 先看再挑

每张卡片的预览是真实页面缩放（非截图），风格辨识度主要看标题字体、色板与主视觉。点击标题或「打开完整组件库」进入完整页面。

2 · 在页面里核对

完整页面自上而下是：风格介绍 → 设计变量（色板 / 字体 / 形状）→ 扩展指南（该做的 / 会破坏风格的）→ 常用组件 → 组合示例。可现场试用交互态。

3 · 交给开发

每套页面的 :root 变量块 + 组件覆写规则就是一份可直接落地的样式说明；扩展新组件时引用同一批变量即可保持风格。
