01

风格介绍

适合：品牌官网 / 高端产品 / 内容精选与作品集

这套组件库用留白说话：区块间距 40–88px 起步，正文行距舒展，字号大而字重轻。颜色只比全白暖一度，唯一强调色是青铜 #8C7A5B，用得非常吝啬。组件几乎没有边界感 —— 1px 发丝线 + 漫射阴影，像奢侈品纸盒的折痕。

特征 01奢侈留白

70% 以上面积留白；痛点是「太空」而不是「太挤」。

特征 02轻字重层级

标题 300 字重、正文 400；层级靠字重差与字距，不靠颜色。

特征 03漫射阴影

阴影大范围低透明度（40px 模糊 / 18% 黑），像自然光下的纸盒。

特征 04克制强调

青铜色只用于进度、选中与一个关键数字，一屏不超过两处。

提示词 DNA（用于扩展 AI 生成素材）

Build studio luxury minimalism:
- Generous whitespace (70%+ of area)
- Subtle typography weight shifts (200 to 600)
- Single accent color used sparingly
- High-end product photography aesthetic
- Soft shadows and subtle gradients
- Golden ratio proportions

标志性做法（延续这套风格时保留）

  • 标题使用 300 字重与 -0.01em 字距，安静而有分量。
  • 卡片只有 1px 发丝线 + 大范围漫射阴影，没有第二层边框。
  • 分区标题刻意小于区块内容，让内容成为主角。
  • 所有交互过渡使用 0.24s 缓动，慢半拍反而更高级。

灵感来源

参考 Build（伦敦）的奢侈极简品牌工作：70% 以上留白、200–600 的细微字重差、单一强调色的战略使用、呼吸般的排版节奏与金色比例版式。

03

扩展指南

新增组件或页面时, 按这四步走即可保持风格统一。

  1. 新增区块时先把上下留白加到 56px 以上，再考虑内容是否需要那么多。
  2. 字重只用 300 / 400 / 600 三档；不要用 700 以上，声音会太大。
  3. 青铜色一屏最多两处；需要更多强调时增加留白，而不是增加颜色。
  4. 阴影只有一档漫射值；不要叠加第二层阴影或描边。

延续与扩展时应做

  • 把留白当作信息层级
  • 用 300 字重做标题
  • 只用一条青铜强调
  • 过渡放慢到 0.24s

会破坏这套风格的做法

  • 用粗字重与大色块制造冲击
  • 给卡片加第二层边框
  • 增加第三种颜色
  • 压缩行距塞内容

想要第 21 套风格? 复制任意一套文件, 只替换 :root 变量块与该风格专属的组件覆写即可 —— 骨架、组件标记与交互脚本都可原样复用。

折叠面板

为什么「每天一次」要靠状态文件去重?
窗口语义不能依赖循环频率: 程序可能重启、循环周期可能调整。把执行记录写进 state_file, 重复执行同一动作才会是幂等的。
校验之后的代码为什么不做防御性检查?
配置在 validate_config 一次性全量校验并聚合报错, 之后的代码假定配置正确 —— 这样错误只有一个出口, 不会散落在各分支里。
