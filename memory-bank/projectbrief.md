# Project Brief — 项目纲领

> Memory Bank 核心文件之一: 所有其它文档的上游。定义项目的核心需求与目标, 是范围 (scope) 的唯一权威; 项目目标变更时先改这里, 再同步其它文档。

## 项目是什么

**auto-qb** — 基于 qBittorrent WebUI API 的 PT (Private Tracker) 种子自动化管理工具。单机常驻 Python 程序, 每 2 秒一个 tick, 通过 `/api/v2/sync/maindata` **增量同步**打理种子 (只取变化种子与字段, 几乎不增加 qB 负载)。

## 核心目标

1. **省心保种** — 自动打站点标签、跟踪 HR (Hit & Run) 触发与达标状态, 做种达标自动标记。
2. **辅种安全** — 指向相同文件的种子自动归组; 缺文件 / 大小不一致 / 下载冲突时**整组暂停**, 防止误传垃圾数据被站点封号。
3. **灵活自动化** — 15 种筛选条件 × 12 种动作的自由规则引擎, 周期/事件触发、去重冷却、错误处理齐备。
4. **智能限速** — tracker 级单种限速 + 规则动作限速 + 基于流量统计的全局限速曲线, 到量自动降速。
5. **可视可控** — 内置 Web UI (辅种分组视图、种子搜索、配置图形化增删改) + `--tray` 托盘常驻 + 桌面通知。
6. **安全第一** — 高风险动作 (跳检/强制汇报/移动) 默认关闭; `--dry-run` 试运行; 启动全量配置校验。

## 范围边界

- 与 qBittorrent 的通信**只走 WebUI API** (`qbittorrent-api` 库), 不直接操作 qB 内部数据/文件。
- 不做通用下载器; 只服务 PT 场景 (tracker 语义、HR、辅种分组)。
- 运行主平台 Windows (托盘/通知), Linux 可跑核心 (CI 覆盖 3.12/3.13)。
