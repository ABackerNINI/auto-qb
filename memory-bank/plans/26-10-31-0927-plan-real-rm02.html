03① 本片用例清单(8 条, docstring 首行 [RM02-nn] …)

位置 tests-real/rm02_loop/, 跑法 commands run real.suite -- --slice RM02 --yes(-n 0)。真实种子全程 paused, 全部条目不需要活跃种子。四行要点按规程 §09, 供执行代理照写 docstring。

RM02-01interval 真节拍: 同步线/任务线周期与配置一致L2L0/L1 种子层(零种子即可)

起非 dry-run 产品进程连 36596, 中间垫本地 TCP 代理(新建 tests-real/lib/proxy.py, 仅转发+记录请求时间戳, 与 RM02-07 共用; 见 §07 风险 1)。

  • 前置: 36596 在线 firewalled、空库; 代理 listen 39000-39999 探空端口(不复用); 配置 schema_version: 5、qB 地址指代理端口、main_tick=2/sync_interval=1.5。
  • 副作用: 无(对 qB 零写; 只读快照请求)。
  • 回滚: 停进程 + 关代理 + 删用例目录。
  • 失败判据: 同步线请求间隔众数偏离 1.5s >±20%; 或出现无请求的死段; 或请求频率达到 _throttle 回归特征(数百次/秒)。
RM02-02优雅退出落盘: state_file 立即落盘 + 锁清理L2L0(零种子)

graceful_after=N 跑壳进程内自投 SIGTERM(RM01-07 同法), 但非 dry-run —— dry-run 退出不落盘是设计口径, 本条验的正是落盘。

  • 前置: 同 RM02-01 基座(不经代理也行, 直连 36596); 启动前记 state_file mtime。
  • 副作用: 用例目录写 state.json / state.lock(随目录清理); 36596 零写。
  • 回滚: 停进程 + 删用例目录。
  • 失败判据: 日志无「收到停止信号, 退出主循环」/ 退出码非 0 / state.json mtime 未前进 / 锁 meta 残留(与 RM01-07 口径一致)。红验对照(升 L3 通道): 同法 dry-run 跑一遍, state.json 必须不被写 —— 否则「落盘」断言恒绿。
RM02-03非优雅终止丢失窗口 ≤ state_save_intervalL2(带负向对照, L3 潜力)L0(零种子)

周期落盘 maybe_flush 的外部可观测面就是 state_file 的 mtime 序列。

  • 前置: 配置 state_save_interval=30(校验下限, 不得更低); 非 dry-run 运行 ≥70s。
  • 副作用: 用例目录 state.json 多次改写; 进程被 taskkill /F /T 强杀。
  • 回滚: 删用例目录(强杀进程已死, 无需停)。
  • 失败判据: 运行期内 mtime 推进次数 <1; taskkill 后最后写入距 kill 时刻 > interval+裕量; 负向对照: state_save_interval=0 时运行期内 mtime 不前进(0=关)必须成立 —— 对照不红则本条按 L3 验收不合格。
RM02-04热重载: L0 键即时生效 + R 闸拒绝L2L0(零种子)

经 WEB 命令线提交新配置触发 apply_new_config(端点细节属 RM09 写侧, 本条只断言内核生效面)。

  • 前置: 同 RM02-01 基座(带代理, 便于观测节拍); WEB 启用(不带 dry-run)。
  • 副作用: 运行期改写用例目录的临时配置文件。
  • 回滚: 停进程 + 删用例目录。
  • 失败判据: 提交 main_tick 变更后代理观测节拍未变; 提交 state_file/data_dir 变更未被拒(restart_required 丢失); 进程意外退出或配置文件被迁移改写搅浑。

相位本身是进程内事件, 外部可观测面 = 全局任务注册日志计数与重建后的执行行为。

  • 前置: 同 RM02-04(热重载通道可用, 连续触发两次 L2 重建)。
  • 副作用: 同 RM02-04。
  • 回滚: 同 RM02-04。
  • 失败判据: 第二次重建后日志「创建全局任务 N 个」的 N 翻倍(has_named 幂等被打穿); 或重建后全局任务消失(连续重建第二次应照常送达的语义丢失)。
RM02-06连不上 qB·首连失败: 非托管 fail-fast / 托管重试节流L2无种子

配置指向无监听的空端口(39000-39999 探空, 不是任何 qB 实例 —— 不触碰白名单约束)。与 RM01-01 的配置错误通道不同, 这里 qB 在线性失败。

  • 前置: 无(不起真实 qB 连接; 两小节分别用非托管与托管模式起进程)。
  • 副作用: 无(进程自然退出 / 由 stop_event 停)。
  • 回滚: 删用例目录。
  • 失败判据: 非托管退出码 != 1 或 stderr 带堆栈; 托管模式重试 WARNING 逐拍刷屏(条数 ≫1)或首连成功(端口意外有人听 —— 探空要复核)。
RM02-07运行期断连: 失败日志节流 + 重连指数退避 + 恢复自动接上(红验)L3L0(零种子)

RM01 拍板 D1 移交的验证面。断连注入用本地代理掐断(产品↔代理↔36596), 不碰 qB 进程。

  • 前置: 同 RM02-01 代理基座; 非 dry-run 连上后运行 ≥60s 掐断代理, 再等 ≥30s(退避上限)恢复。
  • 副作用: 无(对 qB 零写; 掐断的是本机代理)。
  • 回滚: 恢复代理 → 停进程 → 删用例目录。
  • 失败判据: 断开期间连接失败 ERROR/WARNING 行数 > 转换次数(逐拍刷屏 = A-07 回归); 重试间隔不递增或 >30s 上限失守; 恢复代理后 60s 内未自动回连(无 INFO 收尾)。红验即断连注入本身: 掐断后节流与退避断言必须仍可区分两种实现(逐拍 vs 转换), 注入不生效(日志无变化)记 BLOCKED 不硬撑。
RM02-08state 损坏恢复: .bak 回退 + 自愈写回 + 孤儿 tmp 清理L2L0(零种子)

持久化兜底面(store_recovery.py + state.load 自愈), 损坏注入即天然负向对照。

  • 前置: 先正常起停一次生成合法 state.json + .bak; 停机态把主文件写坏(截断/乱字节); 另案: 留一个孤儿 .tmp。
  • 副作用: 用例目录 state.json 被自愈重写; 孤儿 tmp 被删。
  • 回滚: 删用例目录。
  • 失败判据: 启动崩溃或退出码非 0; 未从 .bak 恢复(内容不回); 恢复了但未写回主文件(下次 save 再坏); 日志缺「用了备份」类提示; 孤儿 tmp 残留。

07给执行代理的风险点

  1. 代理基建是本轮唯一新增件: tests-real/lib/proxy.py 只做本机转发 + 时间戳记录, listen 端口走 39000-39999 探空且会话内不复用(§2.7 端口两条硬事实); 裸 bind 探测, 禁 SO_REUSEADDR。它只服务 RM02-01/04/07, 别做成通用 HTTP 解析器。
  2. 配置一律 schema_version: 5 + 走 lib/app.py: 否则 v1→v5 迁移改写临时目录搅浑配置面; Popen.pid ≠ 真实 pid, 按 pid 断言用 real_pid(), 杀进程 taskkill /F /T。
  3. 优雅退出只能进程内 raise_signal(graceful_after 跑壳), Windows 外部 SIGTERM = 强杀 —— RM02-02 与 03 的退出方式别搞混(02 优雅 / 03 强杀)。
  4. 时长预算: RM02-03 要跑 ≥70s、RM02-07 断开观测 ≥30s + 恢复等待, 单条用例分钟级, 整片预计 5-10 分钟 —— 别把慢当挂死, 也别把 real.suite 的超时配小了。
  5. state_save_interval 校验下限 30s(0 除外): 想缩窗口观测别写 5s —— validate_config 会 fail-fast, 那是黄金法则 4 不是 bug。
  6. dry-run 不落盘是设计口径: RM02-02 红验对照看到 dry-run 不写 state.json 是预期绿, 别记缺陷。
  7. 36595 只在 guard 里出现, 本片产品进程只连 36596; tests-real/config/instances.local.json 已补建(gitignored, 含实例 API key), 不要提交也不要改名。
  8. 片内 conftest 照抄 RM01 的文件锁串行基座(pytest.ini -n 8 下 xdist_group 不生效), 8 条都会起真实进程/抢端口。
  9. 日志断言只咬结构化锚点(「收到停止信号」「创建全局任务 N 个」「用了备份」), 别咬整句措辞 —— 措辞归单测, 真机只验"发生了"。
