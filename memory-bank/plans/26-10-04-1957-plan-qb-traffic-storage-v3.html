01方案总览与范围划界

1.1 四构思 + 聚合分层在 v3 上的合成

报告 §2 的三个用户认定问题（P1 落盘时机 / P2 采样率变更 / P3 主循环同步）与取证报告 26-10-04-1639 的四条根因（A1-A4）在 v3 上的合并解——四个正交机制互相咬合：

  • C1 采样率下限锁 main_tick（管采样密度上限与 qB 请求预算）：实际节拍 = main_tick + 任务线耗时 d̄（qbmanager.py:518-527 实证），配置时不可知；I ≥ main_tick 硬校验（1.5s 档在 main_tick=2s 下不可得），倍数失配向上取整 + 告警一次（Q2/D5）。时间真值不由节奏预测保证，交由实测 dt（正交分层）。
  • C2 块 + 元数据头行 + 稀疏 delta（管时间真值与 A2 根因消除）：块头 B,<start>,<interval_s>，数据行 5 列无时间戳 + 可选第 6 列 dt_ms；读侧游标 dt 链推算时间，桶宽按记录有效 dt 逐记录计算——采样率变更后新旧数据天然分块，全局桶宽必错的 A2 根因在格式层面消除；块间 gap = 真空（停机）、n 槽 = 断连，两语义分离，组端点「借 global 判 null」退役。
  • C3 批量落盘（管写 IO）：采样 handler 内计时，每 flush_interval 单次 open("a") + flush + fsync；2s 档全局系列 43200 → 144 次/天（300×↓）；崩溃窗口 ≤10min（用户拍板接受，丢失形态与真空同形）；stop() 钩子使优雅退出零丢失。
  • C4 按天分文件 + 按需读（管读放大）：qb-traffic-v3/{global,torrents/<infohash>}/<date>.dat，窗口→日期集合→只读涉及文件 + mtime/size 解析缓存；30d 窗读量 20-60×↓ 且不随历史增长；index.json 机制退役。
  • 聚合分层（第三轮修订，管月/年视图可达性）：hour/day/month 迁出天文件入每系列 agg.dat 追加混存（9 列 + cov_s），内存累计器 + flush 合流封口 + 文件尾水位恢复 + 逐级派生；年视图 365 天文件冷读 → 1 open（≈0.45MB/系列/年，毫秒级），3d/7d/30d 同步受益（冷读 ≤31 open → 1）。

1.2 链路时序（写侧 → 读侧）

主循环 tick（实际节拍 = main_tick + 任务线耗时 d̄, qbmanager.py:502, :518-527）
 └─ 任务线: 采样任务到期(每 k×main_tick, k = 实际倍数, C1)
     └─ handler 现读 main_tick / sample_interval, 倍数失配 → 取整 + 告警一次(Q2/D5)
         ├─ 全局系列: 恒采 → r 记录 / 零速 → z 游程 / 断连 → n 游程 → 写内存 BlockBuffer
         │   (writer 维护 projected_ts; 累积漂移 > tol(250ms, D2) 的记录写实测 dt_ms —— 稀疏 delta;
         │    hour_acc 逐记录累加, 与 dt 链同源)
         └─ 单种系列: 活跃过滤(dlspeed>0 or upspeed>0)才产 r; 零速/断连进 z/n 游程
 每逢 flush_interval(默认 600s, handler 内计时, 与写入同线程 —— 黄金法则 5 不变):
     ├─ 跨天切块(00:00 上界, 跨界开新块新文件, C4)
     ├─ 每系列 open("a") 追加(块头随块首)+ flush + fsync(C3)
     └─ 聚合封口: 内存累计器 + 水位 wm={hour,day,month} → 末尾顺序检查完结:
         完结整小时 → append hour 行; 完结本地日 → day 行; 完结自然月 → month 行(写 agg.dat)
 优雅退出(qbmanager finally → host.stop_all() → 模块 stop() 钩子):
     └─ 全量 flush + 封全部开放游程 + 聚合封口(dry_run 短路; 之后才 state.save, 顺序不变)
 读侧: 端点 → 窗口 → 日期文件集 / agg 文件(mtime+size 缓存解析) → 逐块游标 + 实测 dt 推算时间
        / 逐记录有效 dt 桶宽归桶 → 真空 = 块间 gap

1.3 范围划界（非目标）

  • 旧数据不迁移不读取（R2）：v3 全部落 qb-traffic-v3/ 新目录；旧 qb-traffic/ 原样留存、v3 读侧直接忽略；删留未决，处置权在用户。生产红线 auto-qb-data/ 内只增不改（新目录只增，旧目录不动）。
  • API 响应形状不动：points/totals/meta 三段结构、鉴权、last-good 竞态兜底全部沿用；meta.interval_s 语义保留（= 桶宽）。
  • 前端图表机制不动：uPlot 双系列、spanGaps:false、轮询 setInterval、document.hidden 跳过全沿用；仅轮询下界常量对齐（A4 单行修，qb_traffic_chart.js:46-48, 337-339，守卫 test_web.py:2703-2705 同步）与档位文案（D4）。
  • 黄金法则全不动：单一写线程（handler 跑主循环线程、无锁，flush 驱动在 handler 内不引新线程）；fail-fast 校验聚合报错；保守默认（enabled 默认 False 不变）。
  • dry_run / enabled=false 语义沿用：dry_run 不落盘（缓冲与游程在内存照常推进，flush 触发静默跳过写）；未启用不建任务零开销。
  • 除 flush_interval 外零新增配置键（D7）：raw_window / rollup_window 口径沿用（rollup_window 兼任补算窗口 = 天文件存活期）。

02格式规格（v3 行型）

2.1 天文件（纯 raw 块）

# auto-qb qb-traffic v3              文件头, 每文件一次(天文件与 agg.dat 同款); 双读门闩
B,<start_epoch>,<interval_s>         块头: start = 块首记录实测 epoch; 省略 n_rows_declared / closed_flag(Q1)
                                     块结束 = 下一块头或文件尾; 块不跨天(00:00 硬切, C4)
r,<dl>,<up>,<dlt>,<upt>[,<dt_ms>]    数据行 5 列无时间戳; dt_ms 可选第 6 列 = 距上一记录实际毫秒数(正整数),
                                     缺省 = round(interval_s × 1000); 写入触发 = 累积漂移 > tol(D2)
z,<run_len>,<dlt>,<upt>[,<dt_ms>]    零速游程: 占 run_len 个采样槽, 速率 0; dt_ms 可选 = 行程实际跨度
                                     last_seen − start(毫秒, OpenRun 字段现成), 缺省 = run_len × interval
n,<run_len>[,<dt_ms>]                null 游程: 占 run_len 个采样槽(断连 / 缺字段); dt_ms 语义同 z
  • 全整数 / 毫秒口径：start_epoch / interval_s 整数秒；dt_ms 正整数毫秒，校验上界 ≤ 86,400,000（一天），非法整行按坏行计数跳过、游标不推进（沿用 v2 坏行口径 + 损坏阈值隔离 traffic_store.py:727-735）。
  • 头行门闩：v3 每文件一次；v3 读侧遇旧头行（v1/v2）或旧目录直接忽略——不设双读，换代语义（R2）。
  • 行宽：r 行省绝对时间戳 ~11B（40-52B → 30-40B），漂移行 +5-6B；单种 2s 档全活跃上界 ≈1.5MB/天/系列（活跃过滤 + 零游程后实测远小）。

2.2 聚合文件 agg.dat（hour/day/month 同构 9 列，追加混存）

hour,<hour_epoch>,<dl_avg>,<dl_max>,<up_avg>,<up_max>,<dl_total>,<up_total>,<cov_s>
day,<day_epoch>,同上 9 列             day_epoch = 本地当日 00:00 epoch
month,<month_epoch>,同上 9 列         month_epoch = 本地自然月 1 日 00:00
  • cov_s（第 9 列）= 有效时长秒：hour 必带——8 列无法还原有效时长，部分覆盖小时等权平均有偏；解析器对 8 列旧行兜底 cov_s = 3600（防御性，v3 全新目录正常不出现）。
  • 保留窗：hour 行按 rollup_window 裁剪；day/month 行永久（≈15KB/年/系列，D7 不设上限键）；month 行不随淘汰消失——未冻结长期不活跃种子天文件按龄删后，年视图仍有其历史。
  • 消费面：hour → 3d/7d/30d 窗（桶宽口径不变，30d = 720 桶）；day → 90d/6mo/1y（D4 默认上 6mo/1y）；month → all。

2.3 dt_ms 写入触发与读侧游标（修订轮规则，报告 §6.3）

写入(每系列 writer 状态):  projected_ts = 游标 + 标称推算; |actual_ts − projected_ts| > tol(250ms, D2)
                          → 本行写实测 dt_ms 并自然复位(游标被推到实测点)
                          ⚠ 触发判据必须用「累积漂移」而非「本行偏差」—— 稳态小漂移(d̄=150ms < tol)
                            逐行判永不触发、误差照旧累积回老病; 写后复位使稳态漂移自动退化逐行写,
                            空载保持稀疏
时钟回拨(单调钳制):        dt_ms = max(1, actual − prev); 桶归属 max(ts, prev_ts) —— 回拨行退回标称 dt
读侧(逐块):               t0 = B.start; 每消费一记录 t += (显式 dt_ms 或 槽位数 × interval_s × 1000) / 1000
均摊定位:                 z/n 显式 dt 时, run_len 个槽在 [t, t+dt] 内均摊; 其后首个 r 的 dt 以游程终点
                          (实测)为基准 —— 链式自洽
桶宽:                     逐记录 max(1, ceil(有效dt)); 有效dt = 显式 dt 或 游程均摊 span/run_len
                          两行同桶 → 聚合按行数取均值, 天然兼容, 无伪断线
坏行:                     r 行列数 ∈ {5,6}; dt_ms 须正整数且 ≤ 86,400,000, 非法 → 整行按坏行计数跳过,
                          游标不推进
  • 暂停恢复 / 系统挂起 / 过载顺延：dt 取实测大值如实入行，天然兜底——「抖动是事实，存储层不假装均匀」（traffic_sample_mod.py:123 设计注释沿用）。
  • 纯等间隔推算已被证伪（报告 §6.3 定量）：d̄=0.1s 时 10min 块尾误差 ≈29s 且造成读侧伪真空——v3 不得出现任何「时刻 = start + i×interval」的推算路径，测试钉住（S1 roundtrip 含漂移行逐点相等）。

03写侧：采样器与缓冲（traffic_sample_mod.py + traffic_store.py 写路径）

3.1 BlockBuffer 结构与缓冲上限

dict[series_key, BlockBuffer]

BlockBuffer = {
    start_epoch,              # 本块首记录实测 epoch(块头 B 的 start)
    interval_s,               # 本块采样间隔(块头 B 的 interval)
    records: list[record],    # record ∈ r / z / n, 按槽序追加; 可带实测 dt_ms
    prev_actual_ts,           # 上一记录实测时刻 —— dt_ms 计算基准
    projected_ts,             # 游标 + 标称推算时刻 —— 累积漂移触发判据 |actual − projected| > tol
}

# 上界: 全局 600 槽(1s 档)× ~100B ≈ 60KB; 单种缓冲只对「活跃或开放游程中」系列存在
# 保险闸(Q3): 单系列缓冲槽上限 3600, 超限提前单独 flush(防大种子库最坏 ~60MB 滞留)

3.2 采样与游程纪律

  • 全局系列恒采：速率非零 → r 记录；速率 (0,0) → 推进/开启 z 游程（不出 r）；断连/缺字段 → n 游程 + 全局 null 语义（现行断连处理改写为 n 游程占槽）。
  • 单种系列活跃过滤不变（dlspeed>0 or upspeed>0 才产 r）；零速/断连进 z/n 游程；has_entry 门改目录判定：「种子目录存在且含 ≥1 个 .dat」——零样本仅在已有数据或已开游程时开启/延长游程，从未传输种子零文件零游程（v2 §3.3 拍板语义平移，index 条目门退役）。
  • 游程封口触发 = v2 四触发沿用，⑤退役：①非零到达 ②null 到达先封口再记 n（R2 纪律：z 覆盖不得横跨断连期）③行程时长 ≥ ZRUN_FLUSH_S(600) ④样本数 ≥ ZRUN_CAP_SAMPLES(120)；⑤「小时封口扫描」随 seal_sweep 退役——600s 触发已保证游程不跨小时，封口 = 成为 buffer 记录（不单独落盘），跨 flush 的开放游程滞留内存、随下次封口或 stop() 落盘，崩溃丢开放游程 ≤600s 纯零信息（与 v2 等价）。
  • 游程 dt_ms 零成本：OpenRun 已有 start/last_seen 字段，行程实际跨度 = last_seen − start 现成。

3.3 flush 驱动与跨天切块

  • 驱动点在采样 handler 内计时（now − last_flush ≥ flush_interval → 全系列批量 flush）：不动主循环、与写入同线程（黄金法则 5）、模块自包含；不用 state.maybe_flush 主循环驱动点（避免给模块加主循环耦合）。暂停期间 handler 不跑、缓冲滞留，恢复后首轮补 flush，语义正确。
  • 批量写：每系列单次 open("a") 写 N 行 + flush + fsync；尾字节查补（崩溃残留半行补 \n）每 flush 仅一次，不再每行；块头在该块首次 flush 时随批写入。
  • 跨天切块（00:00 硬切）：落盘/推算以本地 00:00 为块上界，跨界即关当前块、新文件新块头（interval 不变）；代价每天每系列一个块头 ~30B。跨天块方案已否决（报告 §4.4）。
  • 崩溃窗口 ≤10min：未落盘缓冲丢失 = 磁盘块提前截尾 → 下一块 start 更晚 → 块间 gap = 真空，与 C2 判定自洽（用户拍板接受）。
  • tmp+fsync+os.replace 退出常规写路径：现行小时封口 catch-up 读全文件归并重写（traffic_store.py:509-571）退役；原子重写仅保留给 agg.dat 按龄裁剪（§04.5）。

3.4 优雅退出：stop() 钩子

  • qbmanager finally（qbmanager.py:589-596）不改——经 host.stop_all() 触发采样模块 stop() 钩子：全量 flush + 封全部开放游程 + 聚合封口（hour/day/month）；dry_run 短路；stop_all 之后才 state.save，顺序不变。优雅退出零丢失（现行丢开放行程 ≤600s）。

3.5 C1 生效与热重载联动

  • 加载期：sample_interval ≥ main_tick 硬校验（上限 600 保留）——1.5s 档在 main_tick=2s 下加载被拒（与 sync_interval 钳制 ≤ main_tick 同一纪律先例）。
  • 运行期失配（main_tick 热改或 sample_interval 热改致非整数倍）：向上取整到下一倍数 + 告警一次（D5：采样模块检测点 logger.warning + 已告警记忆），不拒采——颗粒变粗不断线（4s 配 3s tick → 6s）。
  • 热重载联动：handler 现读 sample_interval（L0 段），检测变化 → 直接改 task.interval + 触发一次新块（新旧数据分块各有 interval）——A3 根因（task.interval 注册时定死不跟）在此闭合；main_tick 每轮现读（qbmanager.py:479）无需额外联动。

04聚合分层（agg.dat：累计器 · 水位 · catch-up · 裁剪）

4.1 内存累计器与逐级派生（严格逐级，day 不从 raw 直聚）

  • hour_acc：采样时逐记录累加，与 dt 链同源——avg = round(Σ(rate_i × dt_i) / cov_s)，dt_i 裁剪到 min(dt_i, hour_end − t_i)；z 游程槽 rate=0/span 均摊；n 不贡献；cov_s = Σdt_i ≤ 3600。dt_i ≡ interval_s 时严格退化为现行 traffic_store.py:653-657 公式。max 取逐记录最大；totals 取级末快照。
  • day_acc / month_acc：下级封口时累加——avg = Σ(下级.avg × 下级.cov) / Σcov，max = max(下级.max)，totals = 级末快照，cov = Σ下级.cov。
  • 为什么 day 不从 raw 直聚：raw_window 默认 24h，午夜封口时早期 raw 已在裁剪边缘，cov_s 链只在逐级传递才完整（报告 §6.4）。

4.2 封口时点与写入

  • 水位 wm = {hour, day, month}：每次 flush（600s）末尾顺序检查完结 → 完结整小时 append hour 行 → 完结本地日 append day 行 → 完结自然月 append month 行（写 agg.dat）。聚合 append piggyback flush：每系列每 flush 至多 +1 次 open ≈ 24 次/天。
  • 每小时首采样触发点 seal_sweep（traffic_sample_mod.py:497-538）退役——裁决 Q4 旧口径（「沿用每小时首采样触发点」）已随聚合分层作废（报告 §6.4 明文）。

4.3 重启恢复与 catch-up（先于裁剪，硬序）

  • 重启：扫 agg 文件尾一次 → 恢复 wm + 从文件内行重建当日/当月累计器 → catch-up 逐级补算 append：hour ← 天文件 raw、day ← agg 内 hour 行、month ← day 行。
  • catch-up 必须先于裁剪执行（硬序，测试钉住）：否则 hour 已封/day 未封/hour 到龄被裁 → 永久丢 day 行。
  • 补算窗口 = rollup_window（默认 30d）= 天文件存活期（不是 raw_window）：停机 3d < 30d 可完整补算；停机超窗 → 天文件已删 → 对应 hour/day 行缺失跳过不标注、图上呈真空（与块间 gap 语义一致）。

4.4 幂等与坏行

  • 崩溃于 append 后 / 水位落内存前 → 重启从文件尾恢复，不重 append（水位从文件尾推）；撕裂行坏行纪律跳过；同 epoch 重复行取最后一行（traffic_store.py:273 口径沿用）。
  • 解析缓存 mtime+size 键控无漏洞：追加必变 size，裁剪重写 size 严格变小（两向都失效缓存）。

4.5 裁剪与淘汰（新口径）

  • hour 行裁剪：按 rollup_window，piggyback hour 封口时点——存在到龄行才重写 + same_content 跳过（~1 次/天）；tmp+fsync+os.replace 仅存于此。day/month 行永久。
  • 种子淘汰：删超龄系列目录（天文件 + agg.dat，全局系列豁免）；龄期由文件名日期直接算（index.json updated_at 退役）；frozen 超龄照删。冻结语义不变：删种即不再产新块与聚合，文件留存到按龄删除。
  • 淘汰/裁剪触发点改 flush 时点（现行复用小时封口时点随 seal_sweep 退役）。

05读侧：归桶 · 按天加载 · 视图映射（traffic_grid.py + traffic_qb.py + 前端）

5.1 归桶：有效 dt 桶宽 + 跨桶覆盖（D1）

  • 逐记录桶宽 = max(1, ceil(有效dt))（显式 dt 或游程均摊 span/run_len），替代现行全局 ceil(sample_interval) 一刀切（traffic_grid.py:91）——A2 伪断线根因在读侧的最后残留一并消除。
  • 跨桶覆盖（D1 定稿）：单记录有效 dt 跨多桶时覆盖其间桶——被跨桶获得该记录观测（rate 同值、totals 同快照、观测非 null），防伪洞；混桶 raw 优先口径沿用 v2。
  • 真空判定：块 N 结束时刻（游标终值）与下一块实测 start 的差值即真空；程序停机 = 无块 = 天然真空；断连（程序活着）产 n 槽——两语义分离。组聚合「借 global 判 null」退役（traffic_grid.py:223-240 + traffic_qb.py:148-159），每请求省一次全局文件读取。
  • 累计段：相邻桶快照差分、断链/重置 → null 的现行规则不变；游程快照（z/n 槽 totals 同值）进差分链——空闲段 delta=0 链不断（v2 语义平移）。

5.2 按天加载与解析缓存

  • 查询窗口 → 日期集合 → 只读涉及文件（24h 窗 ≤2 个文件）；块不跨天使单天文件可独立解析。

9.1 端到端验收（全量落地后逐条核对）

  1. 采样率变更免疫：运行期改 sample_interval（如 30s→6s）后新旧块各带 interval，图面无伪断线（有效 dt 桶宽）、无全局桶宽错位；热重载即时生效（A1/A2/A3 三根因逐一对账闭合）。
  2. 读放大：24h 窗只开 ≤2 个日期文件；3d/7d/30d 窗只开成员 agg 文件（30d 组图 M×1）；1y/all 单 agg 冷读毫秒级——open 计数实测入基线。
  3. 写 IO：2s 档全局系列 open/flush 实测 ≈144 次/天（300×↓ 于现行 43200）；30s 档 20×↓。
  4. 时间精度：漂移行实测 dt 链推算误差界 ≤ tol + 取整（构造 d̄ 场景验证）；空载 dt_ms 稀疏（漂移行占比可忽略）。
  5. 真空/断连分离：程序停机段 = 块间 gap 呈真空；qB 断连段 = n 槽；组端点不借 global 判 null 且空态语义正确。
  6. 优雅退出零丢失：stop() 后全量落盘（缓冲清空 + 开放游程封口 + 聚合封口）；kill 后重启解析无损（除尾半行）+ catch-up 补算正确（停机 < 30d）。
  7. 月/年视图：6mo/1y/all（D4 拍板档位）出图且数据来自 agg.dat；day/month 行在种子淘汰后仍供年视图。
  8. --dry-run 产链：真实 qB 上 --dry-run 产 v3 天文件 + agg.dat 全链路文件，头行/块头/行型逐字节符合 §02 规格。
