§01目标与设计原则

背景: create-issue 与 memory-bank 深度绑定却物理分居两个 skill —— 双 _common 常量、跨 skill 钉住测试、gen_all 跨目录伸手、提交闸门指向另一 skill; 与此同时 issue 是四工位里机械化最弱的一档: 建件裸 python、翻状态手工两处改、模板停在 10-05 旧版式。绑定是既成事实, 分居是历史包袱。

目标(做到什么程度算成):

  • ① 常量与生成器单点化 —— 状态词表/TYPES/CLOSED_KEEP 只有一份, 3 条跨 skill 钉住测试删除而非继续维护;
  • ② 建件与翻状态走 task id —— issue 对齐「一次逻辑动作 = 一条命令 + 一次填空」, 四工位命令面统一;
  • ③ issue 模板对齐新文档模板 —— 单栏流式 + @@VAR@@, 视觉与机制都入列;
  • ④ create-issue 触发面原样保留 —— 「记个 issue / 入池」的命中行为不变。

设计底线/不变量: 触发界限不损伤(SKILL.md 不合并); AGENTS.md 零改动(余量仅 ~150 字, 且 skill 路径不变, 无需动); 存量豁免 + 冻结线(实施日 stamp); 入池语义、类型枚举、状态机、防过期五条零行为变化。

§02现状与痛点

#事实锚点
1版式分叉(痛点 A): issue 模板 10-05 双栏+粘性目录旧版式; plan/report 模板 11-06 重设计为单栏流式(2026-10-17「宽度不统一不协调」反馈的产物); 占位符机制也分叉({{VAR}} vs @@VAR@@)create-issue/assets/issue-*.html ↔ memory-bank/templates/plan.html
2翻状态手工(痛点 B): kb.status 明确拒收 issue(指路 create-issue), issue 是四工位唯一没有一条命令翻状态的; 每次认领/修复收口要「两处手改 badge+meta → 重跑索引」—— activeContext 74 条切片里出现频率最高的手工流水flip_status.py L162-165
3双 _common: 状态词表(STATUSES ↔ DOC_STATUSES)与 CLOSED_KEEP/ARCHIVE_REL 同值常量两处维护, 靠 3 条钉住测试防漂移(纪律「跨 skill 不 import」)test_memory_bank_cli.py::test_closed_keep_constants_match_issues 等
4建件不走 task id: 裸 python .../new_issue.py; gen_all GENERATORS 跨 skill 登记; 提交闸门直跑 <skill-dir:create-issue>gen_all.py GENERATORS · .my-commit-flow.toml L93
5守卫缺口: check_doc_templates 冻结线扫描面(plan/task/slice/report/baseline)不含 issue 族check_doc_templates.py 头注
6上次拍板: 26-10-17-0527 D2「issues 不入列: 已有 create-issue 生成器在管」——当时跨 skill import 无解, 已标注「可翻案」该计划 §08 D2

§03方案总览

主线: 代码融合 + 双 SKILL(拍板 D3)。scripts 与 assets 物理并入 memory-bank skill; create-issue 保留为独立 skill、只剩一份 SKILL.md —— frontmatter/触发描述一字不动, 内容改写为纯流程文档, 机械面全部指向 commands run kb.*。

落点:

  • 常量单点: TYPES/TIERS/STATUSES 并入 memory-bank 侧 _common(DOC_STATUSES 与 STATUSES 合一), CLOSED_KEEP/ARCHIVE_REL 删重复 —— 钉住测试从「防漂移装置」降级为「可删除」;
  • 建件收编: kb.new issue 族(FamilySpec 扩两处: 模板按档位选 + 文件名中段从 TYPES 拼命名正则), new_issue.py 退役(D4);
  • 翻状态收编: kb.status 加 issue 分支 —— badge+meta 两处一次改 + 状态变更日志追加一行 + 重建索引(D5);
  • 模板翻新: 单栏新样式 + @@VAR@@, 档位正文结构不变; 不引入 SLOT、不扩 check_doc_templates 扫描面(D6);
  • 存量豁免: 冻结线 = 实施日 stamp, 200+ 存量件一字不动(D7)。

关键取舍: 融合只到代码层。全融合(单 SKILL)要吃进类型/档位/防过期/状态机整套流程(约 +4KB), 触发描述被迫同时覆盖「会话协议」与「记 issue」两个场景, 且 AGENTS.md 等外链引用全要改写 —— 用组织整洁换触发可靠性, 不取。双 SKILL 下 AGENTS.md/scope-guard/code-review/doc-forms 对 create-issue 路径的既有引用全部继续为真, 引用面改动收窄到 gen_all、闸门 toml、两个测试文件。

分期: 五波 W1-W5(§04), 顺序即依赖序, 每波结束可提交。
