kb.nav 加 Esc 功能 —— 借鉴 auto-qb Esc 退栈设计

导航页 (kb.nav) 现 Esc 只覆盖两处 (搜索词清空、右键菜单收)。主 webui 把 Esc 做成逐层退栈 (退栈): 一次按键退视觉最上一层, IME 组合期不劫劫, 兜底档有门条件。本方案移植该设计到 nav 壳, 适配其层集 (错误浮层 / 右键菜单 / 详情抽屉 / 行选择 / 搜索词), 改动面单文件.

本轮新增 (26-10-13-0333) · 拉取失败全屏锁

用户报: 拉取失败导致全屏无法操作一段时间. 实测单点 —— doPull() 失败分支 (line 1487 / 1493) 调用 showError(), 把 #overlay 现 position: fixed; inset: 0; z-index: 50 (line 528) —— 全屏遮罩, 压详情抽屉 (z-30) 与右键菜单 (z-40) 之上. 遮罩现无 dismiss 路径: hideError() 只在 applyData() (line 1444) 即下一轮现算成功 里跑, 轮 POLL_MS = 30000 —— 失败即整页 up-to-30s 不可点击. 本方案把遮罩退栈最上档 + Esc 即收, 直接消该锁.

01auto-qb Esc 设计 (参考口径)

单点实现 src/auto_qb/webui/static/shared/lifecycle.js (行 ~90-130), 四构件:

  • 单 document-level keydown 链: if (e.key !== "Escape") return; 后一条 else if 退栈 —— 按视觉层叠顺序 (浮层最上先), 一次按键退 exactly one layer. 例: 弹层遮罩 (z 130) 先于停靠抽屉 (z 80), 否则 Esc 穿过遮罩关被盖住的抽屉 (26-10-06 实测报障)。
  • IME 守卫: if (e.isComposing || e.keyCode === 229) return; —— 中文输入组合期 Esc 属于输入法 (取消候选), 不劫劫浮层/搜索词.
  • 判据用可见性, 不状态位: drawerVisible 而非 drawer.open —— 看不见的面板不吃 Esc (设置页那次 Esc 退设置首页, 不是关 off-screen panel).
  • 兜底档有门条件 + 点名 toast: 最深档 (清全部筛选) 仅数据页 + 非输入态 + 无 hrPop 卡, 触发即 toast 点名, 不静默.
  • 配套纪律: 浮层名单两处同步 (dialogs.js::escBusy 与 chain); 键盘快捷键引擎注册后链, 引擎自身对 Escape 直接放行 (双保险).

03缺口与提案

移植退栈 pattern scaled to nav 层集 —— 一条 document-level chain, 注册在 wire() 后既有 handlers (注册序 = 触发序照 webui 口径), 链里按视觉层叠:

Escape 一次按键退一档 (退栈 order = visual z-order, 遮罩先):
  0. IME 组合期 → return (不劫)
  1. overlay 现 (z-50) → hideError()                [新增 —— 消拉取失败全屏锁]
  2. ctxMenu open (z-40) → closeCtx()               [现有, 并入链]
  3. drawer open (z-30) → S.sel = null; closeDrawer() [新增]
  4. sel row 有        → 清行选择 (复用 dclose 逻辑)  [新增]
  5. 兜底档 (拍板, 见 §04): 收展开态 openRows / 专题 selTopic? 清筛选?

overlay 退栈档即消该锁: 拉取失败弹遮罩, 用户按 Esc 即收遮罩, 页面操作恢复 —— 不再 wait ≤30s poll. 照 webui 口径 (遮罩层先于被盖住的抽屉, 26-10-06 实测报障同根): 遮罩压 drawer/ctxMenu, 退栈必先收遮罩, 否则 Esc 穿过遮罩关被盖住的 drawer (看不见面判).

gq/cq per-input Esc 清词: keep (input-scoped, 链里在Input 档天然先手照 webui inInput 口径); 链里兜档不得双清. 或 fold into chain with e.target.closest("input") detection —— 拍点 P3.

安全/保守默认 (黄金法则 ②)

兜底档 (清筛选/清词) 是destructive-ish on persisted localStorage prefs (mb-nav-filters). 默认off: 兜档 = 收展开态 + 清 selTopic 选择 only; 清筛选 only if拍板 explicit. 与 webui 兜档 (toast 点名) 同纪律: 触发即点名, 不静默.
