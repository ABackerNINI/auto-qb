§01目标与设计原则

背景

一轮保真(计划 26-11-14-1313)修掉了「动效几乎不出现 / 缺常驻菱形 / 0 流量零动效 / x 轴抖动 / 裁剪」五类缺陷, 但生产实现与模板 demo(26-11-12-1139 §04 内嵌实验台)在参数与元素形态上仍有大量出入。本轮只读盘点逐项对照(模板 demo 行号 vs 生产行号, 全清单见 §02), 归因三类:

  • A 类(有拍板/注释记录的落地适配, 5 项): 保真计划 F1/P9/D2/F5/S2-b 等有记录的刻意改动——用户点名只回退其中两项(曲线描边与辉光、束宽感与回声 full 档), 其余不动。
  • B 类(生产守规格、模板违规格, 4+1 项): 计划 I9 明文「t > 0.55×beat 冲击类叠加层(粒子/扫描束/光带/环)零绘制」, 模板 demo 自己画到 0.6~1.0×beat——生产合规、模板越窗。用户拍板按模板观感放宽, 即 I9 该判据随拍板改判(修订见下表), 属「规格跟拍板走」, 不是缺陷修复。
  • C 类(疑似真实漂移, 13 项): 无拍板记录、或记录与事实不符——最典型是方框旋转: 保真计划 F2 写「CSS keyframes 420ms(模板 t/420 同拍)」, 实为单位误读(模板 rot = t/420 是弧度/ms, 一圈 2π×420 ≈ 2639ms; 生产 420ms 一圈, 快 6.3 倍)。其余为元素缺失(全高冲击闪光/次区余晖线)与形态漂移(环不旋转/切片默认档消失/次区圆点/锚辉光变形等)。

目标(做到什么程度算成)

  • G1 点名五项对齐: 方框旋转速度 / 横向扫描线 / 爬升动画 / 线条粗细 / 扫描线颜色变化, 逐项与模板观感一致(判据见 §04 各步验收)。
  • G2 C 类修复: 表 C C1–C11 按模板实现修复(C8 内喷射角子面按 D2 保留); 判定线小菱形(表 A/A5 域)按 D3 不补; C12/C13 两项查无拍板记录的漂移按预拍板 D8 保留生产口径待改判。
  • G3 A 类精确回退: 只回退点名两项; 其余 A 类适配(P3 环心钳制 / F2 DOM 常驻锚 / F1 恒 Lv.1 门 / P9 Lv.1 发粒子 / I9 辉光让位的 ringOuter/bandHalo 结构)一行不动; C12/C13 按预拍板 D8 保留(非经用户改判不扩范围)。
  • G4 放宽落三处面: B 类改判同步落到实现 + 本计划 I9 修订记录 + 守阵(e2e/电池)改判红绿, 不出现「实现改了守阵没改」或反向。
  • G5 不回归: I3 不闪(零 destroy/空态/回跳) / I8 左移连续 / I10 双轨语义色 / I7 降级(reduce 全关) / G7 背景静态零铺色全部保持; 指令预算不抬(束体 ≤23 / 束+切片 ≤28 / 横向细线 ≤12 原样), 仅 blur 与装饰指令按 §03 修订表改判。
