搜索框帮助按钮 · 3 版模板三套 UI 共用模板 · 2026-09-28

目标: 顶栏搜索框增加一个「高级用法」帮助入口, 展示搜索语法全貌。三版模板均可真实交互(点按钮开合 / 点示例回填输入框 / Esc 与点空白关闭), 视觉取自 prism ocean 主题真实令牌; 每版都给出位置 / 按钮类型 / 文案 / 弹出形式 / 开合交互的完整规格, 挑选后按规格落地。

现状与边界语法已有单点实现, 缺的只是一个可发现的入口

高级语法(空格=且 / -词排除 / "短语"连续匹配)前后端各有一份同构实现: views.py::_parse_query(种子/追剧/分组) 与 config_hub.js::trackerParseQuery(站点页)。目前唯一的提示是 placeholder 里挤着的一行小字 —— 输入框常态宽 240px, 占位符后半段被截断, 排除短语与归一化规则完全不可见。

  • 可组合: B 的「点示例回填」已内含在 A 的浮卡里; 若更看重可发现性, 选 B 并接受顶栏增重。
  • C 的定位: 语法将来扩容(字段限定、更多运算符)时, C 的分节弹窗是升级终点 —— A/B 的容器到那时再换也不迟。
