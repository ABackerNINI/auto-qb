§01目标与设计原则

问题：Win11 uv 直跑下，选中种子按 o（或右键）打开目标文件夹时偶发进程级卡死——WEBUI 断联、无相关日志、Ctrl+C 无效，只能强关终端；同一路径重启后正常。

完成定义：取证 gate 产出根因证据后，按 §06 D14 分支判决；若判适用，则修复后满足 §04 的三条验收判据。常规打开 < 2s 用户无感，慢 Shell 在 WEBUI 上有「正在执行」语义，失败有明确回执与复制路径兜底，在途重复点击不新起任务。

不变量（违反即破坏设计）：

  • 单一写线程：打开动作绝不投进主循环同步执行；现有命令队列 handler 在主循环同步跑（runtime_commands.py:57/59），只能借 transfer 的 deferred 通道让主循环写回执，不能让它跑 Shell。
  • 置前失败静默、绝不影响打开本体——沿用 explorer-foreground 坑档三轮固化的语义，抬 Z 序 / AttachThreadInput / ALT 解锁 / 硬切四层都不抛错。
  • 长路径 PIDL 与「定位选中」语义不退化（utils.py:374-514），不为了省事退回字符串路线。
  • 新配置键须进 validate_config + schema（黄金法则 4）——故诊断开关走环境变量 AQB_OPEN_PATH_DIAG=1，不新增 config 键。

§03方案总览

分期：S0 取证 gate → S1 修复（仅在 gate 判适用时）→ S2 验收。gate 不通过走 S1' 加固分支。

S0 取证 gate：① 打开 DEBUG/端点 INFO + faulthandler 看门狗（现成范式 tests/real/tools/run_s0_boot.py:57,89）；② 故障注入确定性复现链（sidefx.py:339-361 钉住的 _win_shell_open/_win_shell_enter 注入点，319-337 是 stdlib LAUNCH patch 不是 Shell 段 + ui_harness.py:997-1021 的 Event.wait 挂起模式）；③ 真机用 CDP 专用 profile 浏览器（hr_fetch_experiment.py:562-580）重复按 o/右键叠加前台条件；④ 按 §06 D14 判决。schtasks 冷后台法被会话安全策略禁（plans/26-10-16-0541:277），不纳入。

S1 修复主线（拍板 D1/Q8a/Q8b/Q8c/D2/D3）：端点改 ctx.enqueue 投递新 open_path 命令（commands.py:68-117 加 handler；commands_common.py:152-171 加 DEFERRED_RECEIPT_COMMANDS），handler 只投递 daemon 线程、Shell 隔离硬超时 8s、置前总时限 5s；daemon 完成经结果队列回灌，主循环 set_result 写终态。前端 POST 拿 cmd_id → waitCmd（commands.js:192-220）→ 2s 后仍 pending 才显示 sticky busy toast（ui_feedback.js:42-61），终态用 _finishToast(:62-75) 原位改文案；按目标键 inflight Set 在 await 前占闸、finally 清理（dialogs_meta.js:7-15 纪律）。失败回执带复制路径兜底。

S1' 加固分支：gate 拿不到现场时，只做「已知无超时点全部隔离+超时」（即 S1 的后端部分），文档明确标注「根因未确证，属加固非修复」。

§07风险与对策

  • 守阵大面积改口径（触发：S1.1 改端点为 enqueue）：test_web_hr_fs.py:141-207 等约 12 处钉同步 HTTP 响应的断言全部失效——逐条改为 deferred 口径，不删断言；401/404/501 可在路由即时返回的部分保留。
  • deferred 通道误用（触发：把 defer_receipt 当延后终态）：它不是——必须照 transfer 走结果队列回灌 + 主循环 set_result，否则回执会提前写 ok。
  • 置前体验倒退（触发：搬线程时静默吞掉四层置前）：逐层保留并用现有守阵（test_utils_windows.py 置前系列）钉住，失败仍静默。
  • 2s 定时器与终态竞态（触发：<2s 完成时定时器仍触发 busy toast）：终态路径先清 timer 再 _finishToast；幂等闸只在 finally 清，避免早放。
  • 根因未确证即宣称修复（触发：gate 空手）：强制走 S1' 标注「加固」，不得写「已修复」。
