§01目标与设计原则

为什么做: 三轮修复各修一层仍有残留 —— R1 数据面修剪(26-11-21-1704)、R2 视口打断继承(26-11-22-0626)、R3 取证定位换窗竞态(stale 判据不含窗口名)。共同的结构根因: 视口是隐式派生态 —— uPlot auto range 从显示列跨度现推, 而显示列是「GET 组点列 + SSE 事件尾点 + F5 补点」三源拼接物; 凡列跨度 ≠ 名义窗的时刻(修剪失效/补点滞留/打断继承漏判/旧窗响应落袋), 视口跟着错 = 用户看到的「整列 x 向压缩」。

做到什么算成: 三不变量立住后, 压缩在结构上不可表达 —— 电池与 e2e 钉死不变量, 任何回归即红; 真机 1m 连续观察 + 换窗对比无压缩无左缺口。

三条结构性不变量 (poka-yoke, 坏状态不可表达):

  1. 视口恒等式: viewport = [anchor − span_s, anchor], anchor = 末样本时刻、单调递增(anchorTo = max(当前anchor, 新tail)), span_s = meta 名义窗长。视口永不从数据跨度现推(auto x range 全窗退役)。旧窗响应晚到只是数据层小噪声, 视口不动。
  2. 单列恒等: store 列 == 显示列(补点/_qbPad 记账/收敛 slice/悬停扣减全退役)。列不变量 = [tail − (span_s + margin), tail], margin = 2×组距(左缘裁剪余量, 防滑动期左缺口 G-B)。
  3. 取数有效性: _qbLoad 落袋前 stale 判据加窗口分量(发射时捕获 w0 = this[def.window], 到达时 this[def.window] !== w0 即弃)—— 竞态从数据层根除, 与不变量 1 构成双防线。

§02现状与痛点

  • R3 根因(取证坐实): _qbLoad 落袋前 stale 判据(chart 文件 :2063/:2070, 三谓词 :371/:389/:405)只核对作用域上下文。仿真复现: 快速双切 1m→5m→1m 响应乱序后 qbHistWindow="1m" 而视口跨度 299.5s, 且 trim 门读 stale meta 的 span_s=300 使压缩不自愈到下一笔对账(≤30s)。触发概率: 单次换窗撞 30s 对账在途 ≈0.2-0.7%, 快速双切两发 GET 重叠高达数十个百分点 —— 「偶尔」; 结尾落在 1m 压缩倍数最大(5m=5×…24h=1440×) —— 「特别是1m」。
  • 前两轮修的面经全链仿真证明无残留: 16+15 相位 GET 打断扫描 × 40-60 拍, 叠加隐藏往返/seq 断档/突发帧/尾点替代, 收敛态视口跨度全部 ≤ 名义窗。
  • 补丁层堆积: 显示列三源拼接 + 补点生命周期(S14-S17 携带门/收敛摘除) + 打断继承公式重建(_qbInheritedViewport/_qbBeatVpRem, 因 uPlot scales 滞后一帧不能直读) + 双锚分离记账(dx0/dxN)。instant/reduce 档恒定压缩变体(上档案 D4)待拍板无解 —— 补点退役后自然消失。
  • 长窗残留锯齿: 5m+ 窗尾组推进拍视口右缘逐拍扩宽(+si/拍), 头切拍补点+摆回把右缘拉回 —— 扩宽-回拉锯齿, 与压缩同类。

§03方案总览

主线

  • 判定帧重写: judge 输出收敛为 {rewin, slide, anchorDelta, step, span}(step/span 变化或锚位移 >2×组距 → rewin 瞬时落地, 保留防假 morph 语义); setData 后无条件显式 setScale("x", [anchor−span, anchor])(含零变化早退拍 —— 列含 margin 后 auto 恒偏宽, 显式视口是唯一真值)。st 记账换 anchor/step/span(退役 xs0/xN0/n)。
  • 帧循环 L0 重写: 单锚滑动 setScale("x", {min: anchor(t)−span, max: anchor(t)}), dx0/dxN 双锚分离退役。打断从 anim.anchorFrom/anchorTo + clock 现算续滑(自身状态直读, 无公式重建)。
  • 收敛帧: dropPad/slice 退役, 只留 L1 真值写回 + setData(视口已到目标)。
  • 快路: _qbPadTailColumns 调用与 _qbPad 赋值整段退役; inh 捕获退役。
  • 修剪线: tail − (span_s + margin), margin = 2×组距; 函数保留线宽一处变。
  • 历史保留合并: _qbStreamOnLoad GET 列落地时, 把旧 store 列中小于新列头且 ≥ 余量线的真值点并入(真实历史观测, 填 GET 打断滑动期左缘裁剪数据 —— 数据层等价替代补点携带, 无状态无门)。
  • 取数竞态: _qbLoad 发射时捕获窗口名, 成败两路 stale 判据加 this[def.window] !== w0。
  • 周边对齐: _qbFxSpawn span/pxPerT 公式重推导(span = 名义 span_s, 不再读 _qbPad); setCursor 悬停扣减改直通; _qbSummaryOf 桶数按「t ≥ tail−span_s」现数(保住 R1 的窗内桶数语义); 建图 opts scales.x 带初始锚视口(免 auto 闪帧); _qbChartRescale slice 退役 + 重申显式视口; 头注 :24-33/:55-58/:79-99/:101-104 与体内全套节注换代。
