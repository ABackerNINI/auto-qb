04

venv 环境卫生

当前 venv 基于系统 Python 3.12.0；CI 矩阵跑 3.12 / 3.13 两个版本，锁定值需要两边都验证。pyvenv.cfg 显示 venv 创建于项目改名前的旧路径 d:\Projects\auto-qb\.venv——仍能用，但建议锁定时一并重建。venv 里的 pip 是 23.2.1，已落后（最新 26.2.1）。

关键发现：venv 混有约 20 个与本项目无关的包——environs、marshmallow、python-dotenv、argon2-cffi（+bindings）、cffi、pycparser、cryptography、rich、markdown-it-py、mdurl、jinja2、markupsafe、esprima、quickjs、prettyprinter、colorful、merge_args，以及 watchfiles、websockets、httptools（后三个是 uvicorn[standard] 的 extra，项目代码用不到）。因此绝对不要在当前 venv 直接 pip freeze 当 lock 文件——这些无关包会被锁进去。

锁定时的七个注意点

  1. filelock / uvicorn 直接锁到最新（3.32.6 / 0.53.0），不沿用本地旧号；锁完跑全量测试 + CI 3.12 / 3.13 双版本验证。
  2. 不要在当前 venv 直接 pip freeze——新建干净 venv，只装 12 个直接依赖后再 freeze，否则约 20 个无关包会进 lock 文件。
  3. 普通 uvicorn 即可，不需要 [standard]：项目用法是线程内 uvicorn.Config(app, host, port, log_level)，不依赖 reload / watchfiles。
  4. qbittorrent-api 是 CalVer（2026.8.1），跟随 qBittorrent 5.x API 语义演进；未来升级时重点回归 test_qbmanager / test_snapshot_sync（见 memory-bank/pitfalls.md）。
  5. customtkinter 6.0.0 是刚发布的 6.x 大版本，当前 venv 已在用、托盘功能正常，直接锁定即可。
  6. CI Action 可顺手升级：checkout v5→v6、setup-python v6→v7；本项目未用到 v7 移除的 pip-install 输入。
  7. apm.lock.yaml 已锁（gem-team 1.125.0 @ 026742a），不需要动。
