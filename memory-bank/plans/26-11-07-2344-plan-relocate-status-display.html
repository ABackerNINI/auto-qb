§01目标与设计原则

背景: 26-11-04-1042 P1 的 rel-badge 文字徽章踩了三个坑(占列宽 / 999px 药丸与多款皮肤风格冲突 / 点击连开种子详情抽屉), 用户 2026-11-07 拍板重设计。参照范式 = 做种时长单元格的 HR 在线核实浮窗(hr.js hrPop*): 状态着色承载在既有内容上 + 详情走悬停浮窗 + 零点击。

目标: 路径列迁移展示改为「着色 A→B 两排(当前位置/目标位置)+ 右缘弧形箭头」, 详情进悬停浮窗; done/cancelled 回落单排。做到 = 四皮肤下三坑全消、守阵全绿、真机四态目检通过。

设计底线(不变量):

  1. 渲染期零触盘(views_relocate.py P0 纪律不动): 行级数据仅 job 快照, 不做任何文件系统探测;
  2. 浮窗数据全来自行载荷、零新请求: /api/relocate_chain 深探测仍只在链浮窗按需触发(pitfalls/web-ui/contract-api 纪律);
  3. 零点击: 行内不再有任何按钮语义, 原生 title 同步摘除(HR 范式同款, 防与浮窗叠影);
  4. 无底形无边框: 状态唯一载体 = 颜色; 药丸形从根上消失, 皮肤冲突自然消解;
  5. 指纹机制不破: relocate 标注值签名仍进装饰指纹, 新展示字段必须同步进签名;
  6. 范围守恒: 链登记簿(外部链接行级数据面)不在本计划 —— issue 26-11-07-1322 单独排期; 外部逐文件硬链接明确不可测。

§02现状与痛点

现状: 路径列尾挂文字药丸徽章 —— 模板 xtpl-cells.html:115-118(组行)与 :204-207(种子行)的 button.rel-badge; 样式 row_lang.css:510-530(border-radius:999px + has-rel flex 布局 :506-509); 展示口径 decorate.js:128-155(relocateBadge/relocateTitle)与点击 :163-169(relocateOpen = openTorrentDrawer + relChainOpen 连开)。

  • 坑①占列宽: 徽章文字(迁移中/待收尾/迁移失败/迁移多任务)+ has-rel 强制单元格转 flex, 路径列 minmax(150px,1.6fr) 被双向挤压;
  • 坑②皮肤冲突: 999px 药丸 vs 皮肤圆角语言 —— atlas --radius:10px / prism 4-6px / flux·console 0px(全直角), 三款全撞(各皮肤 style.css 令牌实测);
  • 坑③连开抽屉: 徽标点击同时开抽屉+链浮窗; 抽屉内本就有链入口(drawer_tpl/ 三处), 列表页连开抽屉属无用操作。

守阵现状: tests/test_webui_relocate_visibility.py P1 组断言钉死徽标形态(:246-254 badge button/click.stop/css), test_webui_relocate_chain.py:406 钉模板取数边界 —— 本计划须同步改写(S5)。

§03方案总览

主线: 数据面小增量(组级聚合补 src)→ 行渲染替换(模板+decorate 单点)→ 悬停浮窗(新调度, 照 hrPop 范式)→ 样式(row_lang.css 四皮肤同一份)→ 守阵改写(红验)→ 全量与真机。

状态行内(组行/种子行)悬停浮窗
moving两排 accent + 脉冲动画迁移中 · moving 小字
pending_finalize两排 warn待收尾(已武装收尾) · armed 小字 + 改写账
failed两排 error迁移失败 · moving · 重试 ×N 小字 + 原因行
mixed(仅组行)单排 warn 回落状态不一致 + 多目标路径块(两行, 无箭头)
done/cancelled/无标注单排默认色(回落)无浮窗(悬停无响应)

两排判定(relocateView(row) 单点): 种子行 = m.relocate state ∈ {moving, pending_finalize, failed} → 两排(a=job src, b=job dst); 组行 = 组级聚合 state ∈ 同集且 src/dst 全组唯一 → 两排, mixed → 单排 warn; done/cancelled/null → 单排正常色。

浮窗结构(定稿, D10/D11): verdict 头(状态色点 8px + 状态词 + phase mono 小字 + 外部类 ttag 虚线小标)→ 3px 状态色分隔条(负边距全出血) → 路径块(「当前位置/目标位置」标签列:目标位置状态色/当前位置 --path-src 固定色 10px + 值 mono 11.5px 单行尾省略, 目标位置值状态色强调, 无箭头/无竖轨/无软底)→ kv 行(成员·别名·改写账 → 来源 → 更新, 单行省略)→ 失败原因行 → note。

皮肤适配单点: 圆点/端点圆角 = calc(var(--radius-sm) / 2) 一条规则四皮肤自适应(atlas 7px→3.5 / flux·console→0 方 / prism 4px→2), 不写皮肤分支; 状态色全走现有语义令牌(--accent/--warn/--error)。

行为变更说明: 列表页不再有链浮窗入口(原徽标点击) —— 链拓扑深看走抽屉内入口(D9 零点击拍板的自然结果); 筛选桶(_relocatePick/_relocateBuckets)口径不变。
