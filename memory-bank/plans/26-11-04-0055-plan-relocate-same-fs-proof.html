§01目标与设计原则

目标:多成员组迁移的闸门不再依赖「qB 上报剩余空间 ≈ 本机卷剩余」的代理判据,改为可判定的三层证据,并做到——①多成员组首次迁移前必然完成一次 E1 强探测(qB 里加删临时种验证「qB 读得到本机 src、写得到本机 dst」);②qB 连接身份变更后自动重探;③单成员组零打扰;④探测/证明失败时零数据移动。

设计底线(不变量):

  • 预检只读契约不破:relocate_precheck(relocate_plan.py:118)保持零副作用;一切带副作用的探测只发生在执行路径。
  • 失败 ⇒ 零数据移动:E1 探测先于建账与 torrents_set_location(relocate_exec.py:639);探测不通过就不建 job、不驱动 qB 搬字节——不回到「搬完才发现、回退=二次全量写盘」的困境。
  • 保守默认:relocate.assume_shared 默认关闭;强制探测不提供 off 开关;越权必须显式。
  • 黄金法则 4:新配置键进 config.validate_config 并同步 config/schema.py(含 UI schema)。
  • 单一写线程:探测结果缓存走 state_file 的模块内 setdefault 单点(仿 relocate_mod.py:70-85),不引入绕开主循环假设的并发代码。
  • 闸门 id 稳定:GATE_SAME_FS(relocate_units.py:52)保留,只换判定来源与文案——测试与前端按 id 断言。

§02现状与痛点

现行证明链(详见报告 26-11-03-2306 R2):same_volume_proof(relocate_units.py:702-714)用 abs(qb_free - local_free) <= max(1GiB, 2%) 做代理判据,取数取的是 qB 默认保存路径那块卷(relocate_plan.py:255-260)。三层后果:

  • 误拒:默认路径本机不可读(实测 56590 报 free_space_on_disk = -1)⇒ 必败;反向迁移两侧都对不上。
  • 误放:不同盘剩余空间落进容差带 ⇒ 放行;真正能穿过本机 verify 防线(_dst_ready,relocate_exec.py:135-148)的误放集中在容器半对齐/巧合副本,破坏延迟到未来成员经链接写入时爆发。
  • 判据语义错位:闸门要回答的是「qB 与本机共享文件系统」,数值代理在逻辑上既不充分也不必要。

执行链现状:verify(本机 stat)→ link → penetrate(本机 stat)→ arm,全部校验都是 auto-qb 视角,没有一个从 qB 侧做(relocate_exec.py:158-190);建链失败不搬回、保留现场 failed(relocate_exec.py:192-197)——预证明必须前置于数据搬移,这是 E1 探测放在执行链最前的根本原因。

§03方案总览

3.1 三层证据体系(拍板 D4)

定位:主方案是 D+F(判据替换,报告 R2 推荐);E1 不替代 D/F,是叠加的一次性强制增强——机器级强证明按连接身份只探一次,路径级的每次复查仍靠 D,运行时兜底仍靠 F。

层手段时机与粒度证明什么失败语义
E1 一次性强探测qB 里加删临时种:写探针文件到 src → recheck 通过(证读)→ setLocation 到 dst、本机比对 SHA-1(证写)→ deleteFiles 清理第一次多成员组迁移执行前,懒触发;缓存键 = qB 连接身份指纹(host+port+username+password/api_key 哈希);指纹变更 ⇒ 下一次多成员迁移前重探机器级「qB 与 auto-qb 同机、共享这套文件系统」FS 不可达 ⇒ 硬拦 + 缓存失败(同指纹不重试);环境性失败(磁盘满/队列满/权限/超时)⇒ 硬拦不缓存
D 每次复查app/getDirectoryContent 列本组 content_root,与本机 scandir 做 name→(size, mtime) 集合比对;qB <5.0 / 端点不可用 ⇒ 降级 B′(torrents/files 元数据比对)每次多成员迁移预检,只读路径级「qB 现在仍看得到这批文件」(兜缓存有效期内的权限/挂载漂移)不可判定按现行 conservative 拒绝;端点不可用降级而非拒
F 运行时兜底建链后 penetrate 阶段加一次 qB 侧列目录自检(依赖 D 端点;不可用则跳过 qB 侧部分,保留本机穿透)每次多成员迁移执行链内「qB 能跟随本进程建的这条链接」失败保留现场 + failed(现状,不承诺搬回)

同卷证明 same_volume_proof 降级为 legacy 提示(仅用户显式 legacy 模式保留),不再单独构成硬拦;其单测保留。
