WebUI 分组行左条区分全选与半选——三模板选型

分组行左条目前对「组内全部种子选中」与「部分种子选中」渲染同一条 accent 实色条,本文档给出三个可交互模板(可点击行复现三态)供选型,拍板后按选定模板改 row_lang.css 的 partial 规则。

doc-added 26-10-30-2359 · doc-updated 26-10-31-0019 · doc-status Open · 载体 单文件 HTML(dark)
来源 用户指令(2026-10-30 会话):「WEBUI选中分组中部分种子与全部种子的状态需要区分,目前的左边选中指示条是一样的,先设计3个简单可交互的模板供选择」

§01目标与设计原则

目标:在分组视图(辅种页/种子页分组模式)中,分组行左条对三种选中态——未选 / 部分选中 / 全部选中——给出一眼可辨的视觉区分。完成判据:任意选中组合下,仅凭左条(不看成员行)即可说出该组是全选还是半选。

不变量(来自 row_lang.css 既有定案,任何模板不得破坏):

  • 文本零位移:条落行 padding 沟槽,不推名称文本;几何 = 行 ::before、left:1px、top/bottom 14% 不满高、3px 宽、右侧圆角(row_lang.css:207-219)。
  • 键盘锚点让位:条占 x[1,4],不与 .kb-cursor 虚线 outline 的 x[0,1] 叠死。
  • 横滚窄条同步:.is-hscrolled 时沟槽条 content:none,改吸左首格 2px 窄条——半选区分必须在窄条形态同样成立。
  • 范围:仅 .rl-scope 内的分组行——追剧页 show-row/ep-row 虽同名 .group-row 但不在 .rl-scope(走皮肤自带 42% 弱化条),不波及;成员行(.member-row)左条不动。frost/golden 主题行语言规则不命中(走皮肤自带的 42% 弱化条),不在本问题范围。
  • 数据层不动:groupSelState(selection.js:453)已返回 selected/partial,模板已挂类(tpl/groups.html:25)——纯视觉问题,除非选模板 C 需追加比例值。

§02现状与痛点

现状:行语言(flat/wave)接管左条后,选中与半选共用同一规则——四组规则里 selected 与 partial 完全同款 background: var(--rl-bar-on, var(--accent)); opacity: 1:

  • flat 沟槽条:row_lang.css:221-225;wave 沟槽条:row_lang.css:384-388
  • 横滚吸左窄条:flat row_lang.css:244-247、wave row_lang.css:407-411

痛点证据:皮肤基线本有区分——三皮肤 views.css 的 partial 条是同 accent 但 opacity: .42 的弱化条(atlas views.css:240-242 / console views.css:162-164 / prism views.css:468-470);行语言接管时「选中/半选显式重申 accent」把这一区分抹平了(flat row_lang.css:122-125 注释即此定案)。用户侧表现:组内勾 1 个种子和勾全部种子,分组行左条一模一样,无法快速定位"没选全"的组。

复现:分组视图展开任一组 → 勾选组内部分种子 → 组行左条与全选组完全相同(accent 实色、同几何、同浓度)。

§03方案总览:三模板交互预览

先看现状复刻(与线上一致,partial 与 full 无区分),再对比三个模板。每张卡可交互:点组行 = 全选/清空该组,点成员行 = 单独勾选;初始状态分别摆了全选、半选、未选三态。卡底附横滚 2px 窄条形态的三态预览。

§07风险与对策

  • 3px 条辨析度不足(模板 B 空心在 3px 宽度实为细双线):触发条件 = 实机截图后肉眼仍难辨;处置 = 该模板窄条混合策略推广到沟槽条,或回退模板 A。
  • hover 中性条与 42% 半选混淆(模板 A):触发条件 = 弱光环境误读;处置 = hover 条降低浓度(.6→.35)或半选改 50% 实测校准。
  • 横滚双条回归:partial 新规则若漏掉 .is-hscrolled 分支会破坏"沟槽条 content:none"定案;对策 = 四组规则成对改 + Playwright 横滚截图验收。
  • 声明序回归:row_lang 状态序 hover < zebra < expanded < search-hit < selected;partial 插错位置会冲掉状态底;对策 = 改后跑行语言三态组合矩阵人工核对。
