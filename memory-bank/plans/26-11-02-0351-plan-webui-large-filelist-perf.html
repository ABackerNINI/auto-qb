§01目标与设计原则

1.1 做到什么程度算成

  • S1 抽屉千级可交互: 千级文件种子的 content 页签, 勾选 / 折叠 / 滚动 / 改优先级不再可感知卡顿; 常驻 DOM 行数从「全量(千级)」降到「视口 + overscan」(可机检: 实际 .group-row 数 << 数据行数, 沿用 e2e/perf.spec.mjs P1-2 既有口径)。
  • S2 数据没变不付全价: 同一份 files 引用未变时, 变体 render 通知零重建零重渲(记忆化 + 廉价 sig); 勾选等局部交互只重装配受影响子树, 不再整表派生。
  • S3 主表零回归(用户要求): 全部改动落地后, 主表在千级种子 / 千级文件场景下 rid+delta 增量轮询、view 裁剪、行窗口化、JSONResponse 短路四件既有优化全部无回归(W5 复测包, e2e/perf.spec.mjs 三条 + tests-real 真机轨)。
  • S4 明确不做: 不引入 AG Grid / vue-virtual-scroller / TanStack(报告 §04 判 C/B-, 违和成本远超收益); 不上构建步骤; 不给 content 列表上 SSE(按需拉取无轮询可替)。
设计底线 / 不变量: ① 窗口化必须零差异回退——行数低于 ROW_WIN_MIN(200) / 容器未渲染 / 行高未量齐时一律全量渲染, 占位件不渲染(现 _rowWindow off 结构即此语义, W2/W3 不得破坏); ② 折叠 / 筛选 / 树语义只在 rowsFn 层, 窗口化只吃已扁平化的可见行, 窗口层不碰树; ③ 整帧换链路的 H.withScroll 保活与 anchFill 锚保活必须继续生效(pitfalls/web-ui/frame-swap-scroll-reset); ④ 任何乐观补丁贴与回滚必须同一单点对称(pitfalls/web-ui/webui-optimistic-rollback-symmetry); ⑤ 零新增配置键——rowWin 等开关是前端 data 态不是配置, 本计划不碰 config.validate_config / config/schema.py; 实施中若真要加配置键, 必须同步 validate_config + schema.py(守卫测试会查)并先停下来说明; ⑥ 红线不碰: config.yml / auto-qb-data/。

§04实施步骤(逐工作包)

W1 · P1 止血: 记忆化 + 廉价指纹 + content-visibility(改 3 文件)

目标

直击 R2/R3/R4: 数据没变时变体 10/11 的 render 通知零重建零重渲; 勾选 / 折叠只重装配受影响子树; render 拍不再全量序列化; 屏外行渲染税(content-visibility)立收。

涉及文件(行号级定位)

  • src/auto_qb/webui/static/shared/drawer_tpl/10-content-tree-detail-tall.js: rowsFn :232-247(调 FT.buildFileTree 重建树)、行装配 :198-227(rowOf/dirRowOf 新建字面量)、sig :316。
  • src/auto_qb/webui/static/shared/drawer_tpl/11-content-treegrid-batch-low.js: derive :153-196(O(F·D) 路径前缀归并)、行装配 :224-289(subtreeFiles 每目录全表 filter + chkStateOf :244/:253 双算)、sig :360。
  • src/auto_qb/webui/static/shared/dt_table.css(现 162 行, 距 700 行 cap 余量足): 加 content-visibility 规则一条。
  • 配套守阵: tests/test_webui_static_dom_panel.py(扩 node 电池 + 静态断言)、e2e/dt-live-update.spec.mjs(扩条目)。

改法要点

  1. 行对象按 path 记忆化(两变体各自内聚, 不动引擎 / 桥 / 核心层): 模块级 Map<path, row> 缓存上一轮行对象; 派生时文件行 = 「文件对象引用相等 且 参与渲染的字段集(size/progress/priority/is_seed/piece_range/availability)浅比对相等」→ 复用旧对象(prop 引用不变 → 桥 v-for keyed diff 时该行组件跳渲); 目录行 = 「子树内无任何失效行 且 自身折叠态与聚合输入未变」→ 复用, 失效沿祖先链传播 O(depth)。⚠ 键集必须覆盖该行参与渲染的全部输入: dt11 的 _cls(rowCls, 勾选三态染色)挂在行对象上, 勾选 / 折叠态变化必须使该行及其祖先链失效重装配, 否则染色停旧值。新增模块级缓存命名避开变体单点 T/R/H 三件套(pitfalls/web-ui/variant-singleton-shadow)。
  2. O(D×F) 装配优化: subtreeFiles 每目录全表 filter 改为派生期一次 O(F) 给每目录累计 subtree size / 进度加权 / 最低可用性; chkStateOf 双算(dt11:244/:253)一次算存行内局部复用。⚠ 聚合口径两处对齐: dt11 头注 :8-9 明示聚合口径以核心 buildFileTree(drawer_templates.js:469)为准 —— node 电池逐项对表。
  3. sig 廉价化(dt10:316 / dt11:360 同形两处): files 数组引用相等 → 直接跳过重建; 引用变了再比「长度 + 首 / 中 / 尾抽样元素关键字段」指纹, 不再 JSON.stringify(files)。loading / err 分量保留。
  4. content-visibility: dt_table.css 加 .drawer-body .dt10-list .group-row, .drawer-body .dt11-list .group-row { content-visibility: auto; contain-intrinsic-size: auto 27px; }(按各自 --tbl-row-minh 定值, 实施时实测校准)。⚠ 与锚保活的家族耦合(frame-swap-scroll-reset「摘下再插回会重启什么」): 真浏览器逐帧采样确认无 4px 跳动 / 动画重播复发; sticky 表头 / 键盘 scrollIntoView / H.anchFill 行为实测不受影响。仅 Chromium 系完整生效(本项目自用 WebUI, 报告已判可接受)。

验收判据(可机检优先)

  • node 电池(真跑纯函数, 非 mock): 同一份 files 二次派生, 全部行对象引用相等; 改一个文件的 progress → 仅该文件行 + 祖先目录链为新对象, 其余引用相等; 勾选翻一个文件 → 该行 + 祖先链重装配且 _cls 正确翻转; derive 聚合值(大小 / 进度 / 缺口 / 最低可用性)与 FT.buildFileTree 口径逐项相等。
  • 静态守阵: grep 断言两变体内不再出现 JSON.stringify(files)。
  • e2e(dt-live-update 扩): 千文件桩下勾选单行, 主线程长任务不出现(Performance API measure, 口径同 perf.spec.mjs 既有埋点); dt-live-update #8/#9 点击不跳动仍绿。

测试计划

  • tests/test_webui_static_dom_panel.py 扩 node 电池条目 + 静态断言(仿 test_frontend_add_options_recent_order 先例); 同步该文件头部 docstring「## 测试计划」清单。
  • e2e/dt-live-update.spec.mjs 扩 1-2 条; 守阵红验(还原 sig 为 stringify / 记忆化键漏勾选态各应翻红)。

回滚面

两变体文件 + dt_table.css 一条规则, 引擎 / 桥 / 核心层零改动; 单提交 revert 即回退; 记忆化缓存是模块级瞬态, 回滚无状态残留。

改法要点

  1. 抽「窗口源描述符」: 每 kind 一份 { scrollY(), viewH(), topOffset(el), bindScroll(handler), unbindScroll(handler) } —— 主表三 kind = window 文档滚动(现行为原样搬进描述符); 容器型 kind(预留) = 滚动元素 scrollTop / clientHeight / getBoundingClientRect().top + 元素 scroll 监听 + ResizeObserver 视口高。主表 kind 的五个函数与现有实现逐行等价, 只是落位。
  2. _rowKeyOf 参数化: 抽屉行键从描述符给(后来 = rowKey 字段名 "k" 的值), 主表路径不变。
  3. _rowPre[kind] 前缀和(键盘跨窗回焦用, :637 附近)按 kind 自然扩展, 主表消费方 shortcuts.js _kbScrollRowIntoView 不动。
  4. 保守默认: 描述符缺失 / 容器型 kind 未注册时回落现行为; ROW_WIN_MIN=200 阈值语义不变(小列表零差异回退)。

验收判据

  • node 电池(扩 test_webui_static_dom_page.py): 容器型描述符下桩 scrollTop/clientHeight, 窗口切片起点 / 终点 / 占位高与文档型同输入同输出。

测试计划
