流量图采样步进显示与SSE推送改造: 消灭尾端持有失真, 管线延迟毫秒级

本篇只回答: 流量图 raw 段窗(1m-24h)的显示语义如何从「挂钟桶 + 轮询 + 持有延伸」彻底改造为「样本步进 + SSE 推送」, 使尾端不再失真、样本落地到渲染的管线延迟毫秒级。契约、传输、前端三层一并重定义, 不做打补丁式修补; agg 段窗(3d+)与存储面不在改造范围。

§01目标与设计原则

背景

用户观察: 流量图尾端一段数据偶尔平直, 下一拍移动到倒数第二段后变为斜线。根因(分析见 §02): 尾桶在首样本落地前被「持有克隆」填值——显示的不是测量值, 是上一桶的复制。这背后是三重语义分裂: 桶栅格锚挂钟、数据按采样节拍到达、前端按轮询节拍刷新, 三台时钟各自漂移, 只能靠持有面把裂缝糊住。

验收口径(做到什么程度算成)

  1. 尾端无失真: 画面上任何时刻的尾点都来自真实样本; 读侧响应里不存在「未落样本却有值」的点。持有克隆面在 raw 段窗不复存在。
  2. 管线毫秒级: 正常状况(回环访问、主循环无卡顿)下, 样本落地→浏览器渲染 <10ms; 步进节奏抖动 = 主循环节拍抖动(ms 级)。远程访问 = RTT + 毫秒级, 文档如实标注。
  3. 全步进: x 轴/曲线/判定线/当前速率读数四者一体钉在最后一个样本上; 图上「现在」= 最后一次测量; 两样本之间整幅静止。
  4. 停流可见: 采样链停滞 → 尾点旁徽标「滞后 Ns」; 断连 → 「已断连」。冻结与无数据在画面上可区分。
  5. 硬切: 旧挂钟桶语义不保留, 不加配置键, 双语义并存面为零。

设计底线/不变量

  • 存储面不动: v4 天文件(样本槽)/agg.dat 的读写格式与游标缓存模式不变——存储单元本来就是样本, 桶化只是读侧表现层, 换表现层不动地基。
  • 黄金法则不破: 单一写线程(事件发布点只挂在主循环线程采样 handler); 事件队列满丢弃靠序号断档检测兜底重拉; 新常量(对账周期/静默阈值/点数上限)为模块常量非配置键, 不进 validate_config。
  • 字节守恒: 差分链/totals 面语义不变——漏采区间字节含在后继样本快照差分里, 分组只是重新划界, 不造字节不丢字节。
  • agg 段窗(3d+)零改动: hour/day/month 行、pending_agg 活尾、组图 agg 合流全部原样。
  • 红线文件不动: config.yml / auto-qb-data/ 照旧禁改; 采样分辨率旋钮(si = multiplier × main_tick, 生产 1×1.5s)不在本次范围。

§02现状与痛点

链路现状

采样器(src/auto_qb/core/modules/traffic_sample_blocks.py)按 si=multiplier×main_tick(生产 1×1.5s)产 r/z/n 样本槽写入 v4 天文件 → 读侧 src/auto_qb/webui/server/traffic_qb.py raw 段窗把样本归到挂钟桶栅格(桶宽 = si 整倍加宽, ≤500 桶)并对链端做活尾延伸(holding 槽) → 前端 src/auto_qb/webui/static/shared/qb_traffic_chart.js(3572 行)按采样间隔轮询全量响应 + L0 滚动/L1 收敛动画。

痛点 1: 尾端失真本体 = 持有克隆面

  • src/auto_qb/core/traffic_store_codec.py:339 v4_live_tail_slots: 链端有速率且间隙有界时在 ts=now 追加 holding 槽(is_hold=True, obs=末槽原值)。
  • src/auto_qb/core/traffic_grid.py:737-764: holding 槽归桶走点位归属同一路径但不进差分面(0 delta / 0 覆盖), 只置桶 is_hold 旗。
  • src/auto_qb/core/traffic_grid.py:919-930 emit 合并序: is_hold 桶速率 = held = 上一非持有观测桶的速率 → 尾桶值 ≡ 倒数第二桶值 → 严格平直。
  • 下一拍真实样本落入该桶(traffic_grid.py:796 is_hold 旗翻假)→ 速率改写为桶内差分均值 → 与上一桶不同 → 斜线。用户看到的「平直→斜线」即此改写瞬间。
  • 触发窗口 = 桶界跨越后到首样本落地前(≤si, 相位漂移决定出现频率); 前端轮询(~1.5s)扫过该窗口时必现。

痛点 2: 三台时钟的语义分裂

  • 桶栅格锚挂钟 epoch(traffic_grid.py build_grid); 样本按主循环节拍落地(相位漂移 + dt 修正); 前端按自设定时器轮询(qb_traffic_chart.js:1950-1955 _qbPollMs = meta.sample_interval_s)。
  • 判定线 = uPlot bbox 右缘(qb_traffic_chart.js:2669), 与数据节奏无关; e2e 反向钉死此契约(e2e/traffic-fx-frames.spec.mjs:952-956「活跃态曲线墨达判定线; 停滞态判定线右侧零墨」)。

痛点 3: 轮询架构的延迟天花板

检出延迟 0~si(样本落在两次轮询之间要等下一轮), 抖动同量级; 与用户要求的毫秒级差两个数量级。收紧轮询只能逼近、不能消除量化, 且空转请求随频率线性增长。

可复用的既有基建

  • SSE 全套纪律: src/auto_qb/webui/runtime_stream.py StreamMixin(subscribe/unsubscribe/事件队列), src/auto_qb/webui/server/routes/events.py(POST 票据换 EventSource ?ticket= 的鉴权形态、心跳保活、X-Accel-Buffering: no、满额 503 退轮询), 前端 EventSource 消费面成熟(static/shared/commands.js:289)。设计纪律「只推信号与小真值, 绝不推全量状态」。
  • 活尾快照发布模式(S6): 采样 handler 每轮把未落盘状态发布为不可变快照供 Web 线程读——跨线程发布点已存在, 事件源挂同一节拍即可。
  • F5 补点/滚动机制: qb_traffic_chart.js _qbRollJudge(:679-699)/_qbPadTailColumns(:719-737) 的整格滚动动画与补点记账与数据源解耦, 可原样适配事件驱动。

沉没成本(显式确认)

plan 26-11-15-1104 刚落地的 raw 栅格面大部分被本改造取代: F2 点位归属归桶、F4-2 桶值单调缓存(V4SeriesBucketCache)、T2/T3 封口定影判定、F3 持有语义、F1 挂钟桶宽加宽——全部随桶面退役。保留复用: 样本槽位数学(v4_block_slots)、差分链/字节守恒、接缝摊配(P2)、D3 窗首种子、null 标记语义、S6 活尾快照发布、_V4BucketDayCursor 增量游标模式(改造为分组点列游标)。

§03方案总览

三层一并重定义, 一次硬切: ①读侧契约(挂钟桶 → 样本分组点列)、②传输面(轮询 → SSE 专用通道)、③前端(轮询判定帧 → 事件驱动判定帧)。三层同仓同发, 无兼容轨。

① 读侧契约(拍板 D2/D6/D9)

项新契约
points 形态样本分组点列: 每点必带 t(真实样本 ts / 组末样本 ts), {t, dl, up}; 缺口 = 显式空值点 {t, dl:null, up:null}(n 游程/过界间隙折叠一点, t=floor(ts))。旧「null 无 t 的定长桶数组」废除。
分组口径k 的选取以「组点数 + 空值点数 ≤ 500」为准: 初值 = max(1, ceil(窗内预期样本数 / 500)), 窗内有缺口标记时上调直至预算达标; k 上限 = 窗内样本数, 缺口标记数 ≥ 500 时预算数学上不可达——按 k 上限交付并如实标注超预算, 缺口显式空值语义不弃(诚实优先于预算), 终止行为有定义。k=1 逐样本(1m/5m), k>1 组内均值 = Σdelta / Σdt(与现行桶均值同口径, 锚换样本索引); x = 组末样本 ts。1m(40 样本)k=1; 30m(1200)k=3; 24h(57600)k=116(组点 497, 余 3 格让位缺口标记, 超限再上调 k)。组点与空值点共用 MAX_RAW_POINTS=500 预算; 变长 = 相位 ±1 + 缺口标记数。
尾组进行中组 t = 最新样本 ts, 值 = 组内已落样本的真实均值——恒有真值, 无克隆; 每 tick 随样本更新。
meta现六键(window/interval_s/sample_interval_s/source/stale/server_started_at)全保留; 新增 schema=2 与 stride=k。interval_s 语义转为组距标称(= k×si)。
totals / limits形状不变: totals = 组粒度快照差分和({up, dl}|null); limits 事件 [[ts, up, down],…] 原样。
组端点成员同 tick 采样天然对齐, 逐成员分组点列同构, Σ 现算口径不变; null 面由成员观测面裁决(承袭)。

② 传输面(拍板 D7/D8)

项设计
通道专用 SSE 端点 GET /api/traffic/qb/stream?scope=global|torrent:<hash>|group:<key>&ticket=…: 复用 StreamMixin 订阅队列/心跳/SSE 帧格式, per-scope 过滤在订阅时定死; 不扩全局 /api/events 枢纽(E1)。
事件源采样 handler 每轮(主循环线程)随活尾快照发布点派发 per-scope 增量: 本 tick 新样本/更新的尾组点。载荷 = 小真值({seq, scope, points:[…]})—— k=1 每 tick 1 新点, k>1 每 tick 尾组更新点 + 组闭合时新组点。全局 scope 每 tick 1 事件, 几十字节。
序号与对账事件带单调 seq; 前端断档/静默(>3×si)→ 立即全量 GET 重拉; 另加低频 GET 对账(30s)校准缓冲(E4)。
降级票据满额 503 / 重连失败 → 退回 GET 轮询兜底(同一契约, 延迟退化为轮询级), 沿用既有 SSE 满额兜底形态(E7)。

③ 前端(拍板 D1/D3/D4/D5 + E1/E3)

  • 判定帧节拍源: 「轮询落袋」→「SSE 事件到达」; L0 滚动动画/L1 双轨收敛保留, F5 补点机制原样适配(补点 = 上一拍首点真值)。
  • 窗口锚定: 响应窗口右沿锚末样本 → 判定线(bbox 右缘)天然落在曲线上, 终点贴线零依赖持有面; FX 锚(DOM 菱形/judgeFlash/扫描束钉 L+W)语义零改动。
  • 停流/断连徽标: 尾点旁 DOM 常驻层内联小字: 冻结 = 「滞后 Ns」(末样本 ts vs 墙钟, 静默 >3×si 起显), 断连 = 「已断连」(显式空值点/重拉失败)。数据信号已有, 只加样式。
  • 契约适配: _qbPointsToData 改点列直读(每点带 t, 等距内插/外推机器退役); _qbSeamHint/_qbGapZone/_qbChainBounds 改按显式空值点判读; _qbBucketTs 用真值 t。
  • 节拍公式保留: _qbBeatMs(0.4×period 夹取 [320,1000])等时间线常量不动, period 仍取 si。
代价与收益的一句话: 持有面(F4/F3)、空桶回填(F2/R8)、桶值缓存(F4-2)、归桶几何(F2/F1)在 raw 段窗整体退役——它们存在的唯一理由(把采样数据糊进挂钟桶并垫住判定线)随「轴钉样本」消失。
