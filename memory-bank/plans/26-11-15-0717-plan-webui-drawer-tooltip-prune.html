WEBUI 种子详情 tooltip 清理: 重复/低价值移除, 增量/长文本保留

§01目标与设计原则

背景。种子详情抽屉的 tooltip 经年累积混入三类低价值内容: 纯自指(悬浮 = 旁边已显示的文本)、英文 API 字段名(内容已用中文显示)、实现细节泄漏(内部计划编号 / qB API 机制句)。用户 2026-11-15 发起清理, 判据单句: 「除了长文本 tooltip 防止原元素过长导致被裁剪的, 其余的重复/低价值 tooltip 一律移除」。

目标(算成标准)。① 移除面 46 处源清零且零回潮(静态守阵钉住); ② 保留面(长文本防裁剪 / 数据承载 / 语义增量 / 图标钮可访问名)一条不动; ③ 文案手术 6 处——摘内部计划编号与字段名前缀, 解释正文保留; ④ 全量测试绿入新基线切片。

不变量。图标钮(无可见文字)的 title 一律保留——它兼作 a11y 可访问名; ui_feedback.js 拦截层机制(title → data-aq-tip 单向迁移)不触碰, 本计划只减内容源; e2e 已钉的保留面断言(drawer-content-variant-tables.spec.mjs:216 钉 dt10 优先级钮)不放松。

§02现状与痛点

机制。全站 title 由 ui_feedback.js MutationObserver 单向迁成 data-aq-tip(.aq-tip 自绘悬浮, 350ms 延迟; 静态守阵 test_webui_static_dom_panel_drawer.py:1198 记载该口径)——模板里的 title 属性与 JS 载荷就是 tooltip 内容源。四皮肤共享 shared/, 改一次全皮肤生效。

盘点(取证面)。模板 title 挂点 157 处: drawer_tpl 十二件 84(dt01×20 / dt02×14 / dt03×14 / dt04×1 / dt05×1 / dt07×8 / dt08×2 / dt10×11 / dt11×6 / dt12×7; dt06、dt09 零) · 抽屉壳层 7(drawer.html:22/41/170/171 + drawer-head.html:28/31/71, 其中 :41 为向 drawer-head 传参链) · 空帧 1(drawer_templates.js:352, 守阵钉 esc) · 引擎 dt 单元格 52(tpl/xtpl-cells-dt.html, 仅种子详情消费) · peers 单元格段 13(tpl/xtpl-cells.html:325-354, 仅抽屉 peers 表消费)。另有 JS 载荷源 7 处(drawer_tpl/04 stats 202/206/208/209、05 stats 213/216/219, 经 :title="s.title" 动态绑定渲染)。主视图面(xtpl.html、xtpl-cells.html 非 peers 段)不在本次范围。

痛点五类(带行号证据)。

  • 自指: dt02:282 开关徽章 builder title="${label}"(×5 实例, 标签就在旁边); dt03:244/251 crow/sideKv builder title="${label}"(同)
  • 英文 API 字段名: dt01:197-218 hero 五卡 tooltip 全是 progress / amount_left / availability 式字段名串; state/site/category/tags/private chips 在 dt01/dt02/dt03 各一套; dt02:157 up_limit/dl_limit; dt02:213/216 hr_site_need/hr_site_remain; dt03:206 状态行; tracker 统计格 num_seeds (num_complete) 等(04:202/206、05:213/216/219、xtpl-cells-dt:101/102)
  • 实现细节泄漏: dt07:305 尾缀「(计划 P-04 口径)」; xtpl-cells-dt:110 头缀「P-02 回退: 」; dt11:444 整句「批量优先级走 files/priority indices 数组, 一次提交」; xtpl-cells-dt:37 status = 0(备注正文已完整解释)
  • 复述: dt10:298「全部完整」chip tooltip =「子树内全部文件均已完整」; dt10:297/301 同族; dt06「正在汇报」chip(xtpl-cells-dt:105, pulse 动画 + 文字已示意) tooltip =「该 tracker 正在汇报中」
