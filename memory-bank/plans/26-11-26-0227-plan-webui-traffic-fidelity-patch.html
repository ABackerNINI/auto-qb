§01目标与设计原则

背景

二轮保真 S1-S5 已落地(档案 Done), 但真机复报与逐函数代码比对共同暴露出: 二轮只对齐了特效的数值参数(alpha 系数、自旋速率、尺寸范围、粒子基数), 漏掉了几处形态/存续因子(辉光存续、裁剪域、粒子轨迹压缩、粒子寿命缩放、边数轮换)。这些漏项在文档里没有任何拍板记录, 是纯粹的实施缺陷, 不是「有意保留」。

取证方法差异要讲清: 文档驱动的清单(初版 §05)来自二轮计划 26-11-22-2330 的差异表/§05/§06, 只能复述已记录项; 代码驱动的比对(R2 本版)逐个读 qb_traffic_chart.js 的 _qbFxParticleAt/_qbFxSpawnSpecs/_qbDrawFxScan/_qbTailFrame/_qbDrawFxAnchor 与模板 demo(26-11-12-1139 §04)的 particles/seedParts/scanBeam/flowDots/line, 才挖出真正没被记录的漂移。

目标(做到什么程度算成)

  • G1 辉光常驻: 双轨 level>0 时曲线辉光在整个拍周期与拍间静默期持续可见(模板 demo:1407-1409), 不再每拍闪一下; reduce/关总开关/calm 档仍无辉光。
  • G2 视口溢出归零: 曲线辉光只画当前锚视口内的点(齐 uPlot 原生曲线裁切), 不再把余量列的曲线段画到绘图区左缘外浮到图例上方; 缺口段按 spanGaps:false 断段不桥接。
  • G3 粒子三漂移归零: 粒子轨迹恢复模板椭圆(sin·d×0.7)、尺寸随寿命线性缩小(size×life)、边数按序号 3/4/5 轮换(3+(i%3))。
  • G4 勾选六项落地: P1/P2/P4/P5/P6 按模板对齐(含「右向粒子/环不被裁剪」的附加约束), P3/P7/P8 明确不动; 每项给修法与守阵改判面。
  • G5 不回归: I3(不闪/零 destroy)、I8(左移连续)、I10(双轨语义色)、I7(reduce 全关)、G7(背景静态零铺色)全保持; I9 辉光预算 ≤5、束体 ≤23/束+切片 ≤28/横线 ≤12 不抬。

设计底线(不变量, 本轮不动)

  • I9 辉光预算: 同帧 blur 描边 ≤5(环外圈 ≤2 + bandHalo 1 + 曲线辉光 2)保持; 常驻后每帧重绘整图, 不逐帧累加。
  • I11 黑名单: 曲线本体、背景、网格、tooltip、图例、限速虚线恒静态; 曲线辉光色恒为轨语义色, 不借改版改成 Lv 色或给背景铺色。
  • I1 / I4 / 调度: animEnd = max(shiftRatio,0.6)×beat、收敛窗 [0,0.6×beat]、单调无 overshoot 一律不动; 全部改动在绘制钩子面与粒子纯函数面, 不碰调度与数据面。

§02现状与痛点: 五个实施缺陷(代码级根因, 引到行)

缺陷一 NEW: 曲线辉光每拍闪现

面模板 demo生产 :3479-3511
辉光存续line(arr,…,glow,blur)(demo:1409)每帧重绘都带辉光, glow=level>0?trackCol:null(demo:1407), 无时间窗。辉光重描包在 if(t<fx.beatMs)(:3479), 整段钩子在 a.phase==="tail" 直接 return(:3461)。
拍间demo 自有 rAF 连续重绘, 无「拍间」概念。animEnd(缺省 0.6×beat)收敛 → st.anim=null(:3937) → 下一拍判定帧前钩子因无 anim 不画 → 拍间辉光消失(消失占比 = 1−0.6×beat/period, 短周期约 0.76、长窗 beat 触顶趋近 1.0), 每拍闪一次。
归因模板原生观感实施缺陷: 二轮 D4「辉光窗收敛到拍内 t<beat」被照搬, 但生产 draw 钩子是事件驱动重绘(非 demo 连续 rAF), 拍内窗在拍间必然留空。

缺陷二 NEW: 曲线左侧浮在图例上方(与辉光同步)

面模板 demo生产 :3479-3511
裁切line() 内先 clipPlot()(demo:1021-1024)裁在绘图区内。辉光重描段(:3493-3507)无自身 clip; 真正的 ctx.clip() 在 :3517-3519, 属锚辉光段(顶门 :3512 之后)。
遍历disp[k] 长度 N 恰为视口显示点数。遍历 for(i<a.n)(:3495), a.n 是全列长度; 尾锚视口下列 = [anchor−(span+margin), anchor] 含左侧 2 组距余量(:3582), 视口外点在 valToPos 下落到绘图区左缘外 → 带 blur 画到图例区上方, 与辉光同段同窗故严格同步。

缺陷一、二同根: 都在二轮 S3 新增的 A1 辉光段 _qbDrawFxAnchor :3473-3511, 合并为一处重构(§03.1)。

缺陷三 NEW · 代码比对发现, 文档零记录: 粒子纵向压缩丢失(椭圆变正圆)

面模板 demo生产
y 位移var yy = y + Math.sin(p.a) * d * 0.7(demo:1072) —— 纵向压 0.7, 喷雾是椭圆(横向铺得开、纵向收敛)。y: spec.y0 + Math.sin(spec.ang) * d(_qbFxParticleAt :1062) —— 无 0.7, 喷雾是正圆。
文档—二轮 C8 只记「alpha / rot / 尺寸范围 / 基数」, 附件 :82 同样; 0.7 纵向因子从未进入任何计划或拍板记录。纯实施漂移。

缺陷四 NEW · 代码比对发现, 文档零记录: 粒子随寿命缩小丢失

面模板 demo生产
尺寸poly(xx, yy, p.sz * life, …)(demo:1073), life = 1−t/(0.55beat)(demo:1064) —— 碎片随寿命线性缩小, 消散感来自「变小+变淡」双通道。_qbFxPolyPath(ctx, ps.x, py, sp.specs[i].size, …)(:3112) —— 尺寸恒定, 只有 alpha 淡出(_qbFxParticleAt :1063), 少一个通道。
文档—二轮 C8「尺寸 1.6–4.2」只对齐了范围(_qbFxSpawnSpecs :1082 1.6+rnd×2.6), 漏了 ×life 衰减。纯实施漂移。

缺陷五 NEW · 代码比对发现, 文档零记录: 粒子边数轮换丢失

面模板 demo生产
边数sides: 3 + (i % 3)(demo:944) —— 同批碎片按序号3/4/5 规律轮换, 视觉有节奏。sides: 3 + Math.floor(rnd() * 3)(_qbFxSpawnSpecs :1081) —— 伪随机 3/4/5, 无节奏。
文档—无任何记录; 与 C8「几何碎片 3/4/5 边」口径的差别只在分配方式, 但观感可辨。纯实施漂移。

为什么文档驱动清单漏了 3-5: 二轮盘点是「按差异表逐项对照」, 而 C8 那条只写了「自旋/alpha/尺寸/基数按模板」——注意力落在有明确数值的系数上, 像 *0.7、*life、i%3 这类嵌在表达式里的形态因子没有独立条目, 于是既没盘点、也没拍板、更没实现。这次逐函数读代码才补齐。

维度改法
