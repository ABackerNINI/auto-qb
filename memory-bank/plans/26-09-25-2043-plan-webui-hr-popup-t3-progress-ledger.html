实现说明

  1. 触发与延迟 —— 触发面 = 做种时长单元格(.m-dur 所在单元格整体)或其中来源徽标(.hr-src); mouseenter 120ms 后显示, mouseleave 160ms 宽限后隐藏, 移入弹窗不隐藏(可悬停选中复制); ESC / 页面滚动即时关闭; 无 hr_safety 的行(R8 ubuntu 镜像)不触发。样张区的触发器为静态示意, 不绑定悬停。
  2. 定位 —— position:fixed 锚定触发矩形: 优先上方(间距 10px), 上方空间不足翻下方; 横向夹取视口(8px 边距); 箭头指向触发矩形中心并随翻转换向。
  3. 字段映射 —— 结论←hr_safety_text; 配色←hr_safety(danger 橙=考察中 / failed 红=考核未通过终态, 2026-09-25 用户修正 / safe 绿 / unknown 灰); 徽标←hr_safety_src; 依据←hr_reason; 站点侧值←hr_site_need / hr_site_remain / hr_site_ratio / hr_site_dl(与详情抽屉 hrSiteLine 同源); 本地值←seeding_time / hr_req_time / ratio / hr_req_ratio; 旧 :title="hrDurTitle(m)" 移除。前端只做比例呈现(已做种/要求、站点还需/要求)与着色, 不重算判定; 站点值滞后一个刷新周期, 以角注提示。
  4. 落点 —— shared/hr.js 单点渲染方法 + 6 处模板绑定(两 UI × 组内成员/种子页/明细三语境) + atlas style.css 与 prism css 各一份同值规则; z-index 140, 高于 ctx-menu(100) 与 speed-pop(131)。
  5. T3 实现要点 —— 双轨进度: 本地主轨 6px(已做种/要求比例, 档位色填充), 站点细轨 3px(仅站点给出 need/remain 时出现, 半透明填充区分, 小图例「本地/站点」, 不带数值端点 —— 数值由角标承载); 轨道角标只在结论短语没说时出现: 考察中 = 还需 X, 本地兜底 = 已超出 X, 终态未达标 = 考核期已过(已达标不重复出角标); 无时长要求时轨道收起换状态徽记(盾形线性图标, 只说「无时长要求」, 不与结论重复); 数值条 = 站点侧值专用(站点分享率/站点下载), 本地值不上弹窗(表格行可见), 无站点侧值时整条不渲染; 生命周期 chip 仅终态标「已结束」(考察中短语已含, 不重复); 来源章移除(结论短语已含在线/本地/策略/未核); 本 mockup 用 vanilla JS, 实装时渲染逻辑进 shared/hr.js。
