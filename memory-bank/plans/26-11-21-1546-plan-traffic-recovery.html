§01目标与设计原则

背景: 用户报 auto-qb 重启后 WEBUI 骨架秒开(D 系列前序修复成效), 但种子列表 ~15s 才出现。取证(2026-11-21 生产日志): 启动序列 start_all → 连接 qB → 加载规则 → 主循环首轮同步 中, 流量采样模块 start() 钩子的 _recover_aggregates(traffic_sample_mod.py:312→:614)同步占住主线程 11.72s(236 系列 / 466 万槽), 首轮 qB 同步、0259 提前发布、搜索索引全部被挡在它后面; 其余 ~3.2s 是首轮管线(归组 files 串发等, 由 doc-refs 所列两条已入池 issue 承接, 不入本计划)。

North Star(D10 拍板): real-machine 轨道环境(测试 5000 种子语料放 R 盘, D17)受控重启: ①优雅重启恢复 ≤2s ②崩溃模拟重启 ≤2s ③无快照 fallback(水位新鲜)≤15s ④极端 fallback(水位陈旧+全天活跃)诚实记录不设硬判据; 236 生产规模对照 before = 11.72s。另: flush 追加 stall 增量 ≤50ms/600s; 语料总量 ≤20GiB。

设计底线 / 不变量:

  • 黄金法则 1/2/3/4/5 照常: 快照/清理动作幂等; 清理只删超窗观测文件(保守判据); 状态持久化口径不变; 不新增配置键(D14 复用 raw_window); 恢复/快照/封口仍在主循环线程, 唯一新线程 = 清理子线程(D13, 目标文件与主线程写面年龄不相交, 见 §07 R5)。
  • 快照与提前发布同为加速器不承载正确性(D9): 账本缺失/损坏/指纹失配 → 该系列回退 B1+B2 快速重建, 单系列隔离不放大。
  • 文件格式零换代零迁移: 天文件(B/r/z/n 行)与 agg.dat 逐字节不动; 兼容面见 §03.5。
  • 不挪恢复位置(D5): 仍在 start_all 主线程同步执行 —— 修完它是亚秒级, 挪位置失去意义; 与用户「该思考机制而非挪位置」方向一致。
  • 在线行为零变化(D6): 聚合输出(封口行/活尾行/读侧合流)逐位不变; 唯一例外 = 开放小时内存表示重构(D12), 行为等价由对拍守阵承担。
  • 与「流量图毫秒级响应」要求(plan 26-11-15-1104 F 系列)的关系(D16): 无冲突 —— 本计划全部落点在主循环线程恢复/写侧面, Web 读侧线程(V4DayCache/增量解析/agg 缓存/活尾合流)零触碰; 正向叠加: 恢复亚秒化后流量图冷启动活尾提前就绪。

§03方案总览

四件套: B1 水位过滤前移(字节级 \nB, 块定位, 封口块跳过解析与入账, 只处理开放小时尾段) + B2 游程级闭合式入账(z/n 游程按小时段 O(段) 记账, r 行逐行; 前向记账边界/跨块 tail 上下文/形态 D ramp 忠实移植) + A acc 快照账本(折叠态落盘, 恢复零重算) + C raw 保留窗清理(补齐 raw_window 删除半边, 5000 规模尺寸预算达标)。分期见 §04。

03.4 改造后流程

  • flush 时点(600s, 主循环线程): ①raw 批量追加(不变) → ②agg 封口 append(不变) → ③acc 账本追加本 flush 有状态变化的系列行(新; 空闲系列零追加) → ④账本压实检查(超 16MB 单次重写; 新)。
  • 启动恢复(start(), 主循环线程, D5 位置不挪): 扫系列键 → 账本存在: 整读+按系列取最后一行(与 agg.dat「同 epoch 取末行」同款纪律) → 逐系列 stat 指纹比对: 匹配 = 直接采信折叠态与游标(累计器/pending/earliest_hour 全部就位, 零 raw 重算); 失配/缺失/损坏 = 该系列 fallback(B1+B2); 账本不存在(升级后首次启动) = 全体 fallback, 首轮 flush 自举账本 → 恢复完成后 spawn 清理子线程(D13)。
  • stop(): 封游程 + 全量 flush + 聚合封口(不变) → acc 账本全系列终态行 append(新)。
  • 在线入账: 信用进折叠态(D12 表示面重构; 信用到达顺序不变 → 浮点累加顺序不变 → 聚合输出逐位等价)。
  • 游标语义: 快照行记录「累计器已入账到的最后槽位」。crash 后 raw 尾 ≤ 游标: 缓冲信用已在账本(raw 面真空 = 现有崩溃语义, agg 面比现状更完整); raw 尾 > 游标(crash 恰落 raw 追加与账本追加之间): 回放该小尾段。
