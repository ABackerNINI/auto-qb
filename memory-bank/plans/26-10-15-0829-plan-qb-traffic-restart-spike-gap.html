00目的 · 范围 · 口径

报告已把两件事从「现象」推进到「机理」:异常峰值是 z 游程快照冻结与读侧 delta/w 在进程重启缝上的单桶归因;无采样区是数据层 ~10s 缝与呈现层 ~8.5s 投递黑障的叠加。报告 §07 给了六层修复方向,但只停留在「建议」。本计划把它拆成有落点、有验证、有验收判据的步骤。

一句话范围界定

要治的是接缝处的放大方式(写侧快照语义 + 读侧归因口径),不是细流本身。细流是 seed↔seed 冗余连接的握手/协议字节与模型化 IP 开销,属 libtorrent 正常行为、幅度仅几百 B/s -- 本计划明确不「治」细流。

三件不变的事(任何步骤都不得破坏)

  1. 诚实性优先:没有数据就是没有数据。停机洞、断连期的呈现必须仍是 null(斜纹/断线),不得为了让曲线好看而用摊配值填出伪数据。
  2. 格式不动:v4 天文件(5 列 B/r/z/n)与 agg.dat(9 列 hour/day/month)行格式保持兼容,旧数据无需迁移、新代码可读旧文件。
  3. 口径守恒:qb-traffic 的读数始终等于 qB alltime 计数器的差分(含握手/协议/IP 开销成分)--修复改变的是「差在哪个时间粒度上呈现」,不改变总量。

02目标与非目标

编号目标可判据的形态
G1接缝处不再出现与桶宽成反比的幻影尖峰同一接缝在 30m/3h/24h 三窗的峰值同量级,且不超过真实夜均速率(~630 B/s)的合理倍数;窗越细不再越尖。
G2重启缝与停机洞仍诚实呈现无观测区间仍为 null(断线/斜纹);不引入任何凭空的非 null 桶。
G3字节守恒任意窗口 Σ(rate × w) 与对应区间的 alltime 真增一致(摊配只改分布,不改总量)。
G4格式与旧数据兼容v4 天文件 5 列 / agg 9 列不变;旧天文件不经迁移即可读。
G5不破既有黄金法则幂等(重复执行无副作用)· 单写线程 · 保守默认 · fail-fast(新配置键必须进 validate_config + config/schema.py)。
非目标(明确不做)
  • 不消除细流:seed↔seed 握手开销是 libtorrent 正常行为;本计划不通过关连接/改协议去「治」它。
  • 不改 qB 本体:不重启、不改 qB 侧 prefs(P6 只做评估与文档,改与不改都只是结论)。
  • 不改前端断线语义:null 不连线(spanGaps:false)与斜纹缺口保持;P4 只加「接缝提示」,不改断线呈现。
  • 不引入跨仓库操作:全部改动只落在当前 clone。

03分步实施

阶段按「先确认机理 → 先拿纯读侧收益 → 再动写侧语义 → 加固与清理」排序。每阶段都给出落点、做法、验证与判据;P1 与 P2 必须同批验收(单独任一都不闭环 -- 只做写侧仍会在边界留下单桶台阶,只做读侧在没有时间锚点时会摊错跨度)。

P2
读侧:快照台阶按真实发生跨度摊配(消放大) 核心 已完成 26-10-15-1135 · 结论见下方实施记录

落在纯读侧、零格式影响、旧数据即受益,故排在写侧之前先拿收益。

  • 落点:traffic_grid.py -- v4_totals_points(:469) / _bucket_delta(:205) / v4_rate_from_totals(:490) / v4_grid_obs(:533)。
  • 做法:给「快照台阶」加真实时间锚。当相邻两个变化点之间的跨度 Δt 明显大于单桶宽(阈值常量,默认取 2×标称 interval_s,兜底下限如 60s)时:
    rate = delta / Δt_span(真实发生跨度),并把这个 delta 按覆盖秒摊到跨越的栅格桶(v4_grid_obs 已按重叠秒加权,天然可摊),而不是按接收桶的桶宽 delta / w;
  • 诚实兜底:Δt 超上限(常量 SEAM_NULL_S,默认 60s)时该段宁可标 null(= 承认「这段跨越太长,速率不可归因」),而不是摊出一个看似精确的平均值 -- 对齐 G2;
  • 不新增配置键:阈值取模块常量(如 _V4_SEAM_SPREAD_MIN_S / _V4_SEAM_NULL_S,与 _V4_NULL_FLOOR_S 同族)。若评审要求配置化,则必须同步 validate_config 与 config/schema.py(黄金法则 4,守阵会查)。

验证:tests/test_traffic_grid.py 新增用例 -- 1构造「长零速游程 + 末端大台阶」桶点流,断言不再单桶尖峰;2断言 Σ(rate × w) == delta(字节守恒);3断言超 SEAM_NULL_S 段标 null。判据:真实数据回放后 06:36 桶峰消失/降至真实量级,且总量不变(见 §05 E2E1)。
