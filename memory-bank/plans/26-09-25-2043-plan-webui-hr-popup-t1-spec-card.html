实现说明

  1. 触发与延迟: 触发面 = 做种时长单元格(.m-dur)整体或行内 .hr-src 徽标; mouseenter 120ms 显示, mouseleave 160ms 宽限后隐藏, 移入弹窗不隐藏(文字可选中复制); ESC 或滚动立即关闭; 无 hr_safety 的行(样表第 8 行)不触发。
  2. 定位: position: fixed 锚定触发单元格矩形, 优先上方(间距 10px), 上方空间不足翻下方, 横向夹取视口(边距 8px); 指向箭头随翻转换边, 箭头 x 跟随触发中心(--arrow-x)。
  3. 字段映射: 结论 ← hr_safety_text; 档位色 ← hr_safety(danger/failed/safe/unknown/none; failed=未达标红档, 2026-09-25 用户修正, 与考察中橙分色); 徽标 ← hr_safety_src; 依据 ← hr_reason; 站点侧值 ← hr_site_need / hr_site_remain / hr_site_ratio / hr_site_dl(与详情抽屉 hrSiteLine 同源, 滞后一个刷新周期); 本地 ← seeding_time / hr_req_time / ratio / hr_req_ratio。前端只做比较与着色, 不重算结论; 旧 :title="hrDurTitle(m)" 移除。
  4. 生命周期(2026-09-25 语义修正): 已达标 / 未达标 / 免罪(安全放行、超龄豁免)均为考核期已过的终态, 弹窗标「已结束」; 仅考察中(site_scope)是进行中, 标「考核中」并显示还需/剩余倒计时。已结束态不渲染还需/剩余行(即便站点字段非空)。映射 ← hr_safety_src: site_scope=考核中; site_satisfied / site_unsatisfied / site_released / local_exempt=已结束; policy / local / unverified 无考核期概念, 不标。
  5. 落点: shared/hr.js 单点方法产出弹窗数据 + 6 处模板绑定(两套 UI × 组内成员/种子页/明细三语境) + 两套 CSS 同值规则; z-index 140, 高于 ctx-menu(100) 与 speed-pop(131)。
  6. T1 档案卡要点: 左色条 + 档位色结论短语 + 来源徽标构成头部; 「本地」「站点」两小节 kv 逐行(label 左 dim / value 右 fg, tabular-nums), 行间 hairline 分隔, 站点小节按 hr_site_* 有无整体显隐; 底部「依据」+ 滞后角注; 宽 320px(max 340), 内边距 12/14, 字号 10.5–13px 层级; prism 侧数值走 --font-mono、结论走 --font-display; 层级全靠排版, 无大色块。
