方案 · kb.nav 增加「正在处理区」(WORKING): 手动加入 + 终态自动退出

本篇只回答: 怎么在 kb.nav 加一个「正在处理区」—— 手动加入、终态自动移出、位置在置顶区下方、入口在右键菜单, 并与置顶区互不干扰。

§01目标与设计原则

给 kb.nav 台账视图加一块「正在处理区」(WORKING), 让用户把当前手上在推的件手动收拢到眼前, 而这些件一旦进入终态就自动从工作集里消失。做成算成:

  • 右键任一文档可「加入 / 移出正在处理」, 支持多选批量 (与 pin/hide 同款语言)。
  • 专区在置顶区正下方, 与主表同栏 (克隆 thead + 共用 ledgerCells), 可折叠、空则隐藏、不受筛选/搜索影响。
  • 主表成员用整行左色条标识; 不加第二个行内图标 (用户明确: pin 图标旁再加图标太凌乱)。
  • 状态变 Done / Dropped / Superseded 即从 localStorage 工作集永久移除并落盘; 状态改回不自动回区。

不变量: 成员资格与文档状态 In Progress 解耦 (不按状态自动填充, 只按手动动作加入); 置顶区与工作专区两份状态独立, 同一件可同时在两区; 30s 轮询只读数据, 不重播种任何用户选择; 隐藏件不进任何内容视图; 数据层 / 服务层零改动。

§02现状与痛点

今天 kb.nav 台账已有图钉置顶区 (置顶专区 / PINNED, 26-10-04 拍板实施)、隐藏区、多选与右键批量菜单 (26-10-31)。置顶表达「总在眼前」, 隐藏表达「不想看」, 但没有表达「我正在推」的位置 —— 只能靠 In Progress 状态筛, 而状态是流程事实, 不是个人当前关注; 用户要的正是把这两者分开: 手动指定在推的件, 和在推的件一旦结束自动退场。

调研确认的落点: 全部交互与状态集中在单文件壳 .agents/skills/memory-bank/scripts/nav_page.html, 数据层 (nav_data.py / gen_doc_map.py) 与服务层 (nav_server.py) 零改动。状态词表取自 doc-status / issue-status meta 与 task 的 **Status:**, 数据层统一成 item.status, 现库实际出现 Open / In Progress / Done / Dropped / Superseded。既有守阵见 tests/test_kb_nav_shell.py / tests/test_kb_nav_interaction.py (pin 专区 / 折叠 / 批量 / 隐藏 / 轮询不重播种)。

§03方案总览

照 pin 专区的成熟骨架扩一份平行实现, 只在「状态来源」和「退出机制」两处不同: pin 是纯人工偏好, 永不自动退; working 是人工加入 + 终态自动退。拍板 D1–D11 见 §06。

构件做法与 pin 的关系
存储WORKING_KEY = "mb-nav-working" (link 数组, 顺序即加入序); 折叠态独立键 mb-nav-working-collapsed。只在 boot 装载一次, 读写 try/catch 兜底。新增平行键, 不复用 mb-nav-pins
专区#workZone 插在置顶区与账务表之间; 标题「处理中 · WORKING (n)」+ 闪电内联 SVG; 克隆主表 thead + 复用 ledgerCells; 折叠按钮仿 pzToggle (aria-expanded / aria-controls); 空则 hidden。完全照置顶区 (D8/D11)
入口右键菜单加 data-act="working", 复用 ctxTargets 冻结快照、批量灰色 N 后缀、toggleWorkingBatch(links) 幂等分发 + saveWorking() 落盘。完全对齐 pin (D7)
主表标识工作成员整行加 wip 类, 左色条走暖橙 --amber 族 (壳内无 --warn, 真实令牌是 --amber: #e2a55a / --amber-soft); 与 sel / msel 同框时按「多选 > 预览 > 工作」层级让位。不加第二个行内图标。有意不同 (D5/D6)
自动退出boot 装载后 + 每次 derive() 末尾调 pruneTerminalWorking(): 仅对终态成员做删除并落盘, 不新增、不重新入选。pin 无此机制 (D2/D3/D4)
隐藏件workingZoneItems() 与 ledgerCells 的 wip 标识都要挡 isHidden(link), 与 pin 专区同款。与 pin 一致

范围只做台账视图 (D10): 控制台 / 卡片墙不加专区、不加入口、不加色条。落点仅壳单文件 + 守阵, 数据层与服务层零改动。

§04实施步骤

步内容验收判据
S1 结构与样式DOM 插 #workZone; CSS 加 .workzone / .workzone.collapsed / 闪电 SVG / #v-ledger tbody tr.wip 左色条 (层级低于 tr.sel / tr.msel); 常量 WORKING_KEY / WORKING_COLLAPSE_KEY / WORKING_SVG; 全局 S.working / S.workingCollapsed; 工具函数 loadWorking / saveWorking / isWorking / workingZoneItems / pruneTerminalWorking。空区整块隐藏; 色条在单选/多选态被正确盖住; 壳仍 dark、零外链、无 emoji 图标。
S2 渲染与接线renderWorkingZone() 画专区 (克隆主表 thead + ledgerCells + 折叠应用); renderLedger() 同时画主表与专区并挂 wip; wire() 右键菜单挂 working 项、专区委托点击 (条目 / 移除 / 折叠); boot() 装载 working 与折叠态各一次。右键 / 批量加入退出即时反映到两处; 点闪电外的条目开抽屉链路与 pin 同; 点移除按钮不误开抽屉。
S3 终态自动退出pruneTerminalWorking() 在 boot 与 derive() 末尾各调一次: 取 item.status 命中 Done / Dropped / Superseded 者, 从 S.working 删除; 有变更才 saveWorking(); 同步把移出件剪出 S.multi (与批量隐藏同款边界)。derive() 不做装载、不做新增。改状态后下一次 30s 刷新即从专区与主表色条退场, 并从存储里消失; 刷新页面也不回区; 轮询不把用户主动加入的件洗掉。
S4 守阵与收尾在 tests/test_kb_nav_shell.py / test_kb_nav_interaction.py 头部 docstring「## 测试计划」清单同步新增条目, 并补守阵: 骨架/键/闪电内联 SVG; 装载点唯一且 derive() 只调 prune 不 load; 终态三词触发删除; 双区独立; 隐藏件退场; 色条层级; 折叠态持久化与焦点保留。跑 commands run test.full + commands run kb.nav 人工过一遍 (加入/移出/批量/终态退出/筛掉后专区仍在/30s 轮询/折叠)。既有 kb-nav 守阵一条不红; 全绿见 kb.baseline; 新基线切片记录实测数字; 人工验收五项全过。

#决策点结论
D1成员资格来源手动加入; 不按文档状态 In Progress 自动填充
D2退出语义永久移除: 终态成员从 localStorage 工作集删除落盘; 状态改回也不自动回区
D3终态范围Done / Dropped / Superseded 三者都退出
D4检查时机boot 一次 + 每次 30s 数据刷新; 刷新只读数据, 不重播种工作集
D5主表标识不加第二个行内图标; 工作成员整行左侧色条 (暖橙 --amber 族)
D6色条优先级多选 > 单击预览 > 工作; 交互态在时盖住工作色条, 退出后仍在
D7批量处理完全对齐 pin: 冻结快照 + 灰色 N + toggleWorkingBatch 幂等 + saveWorking
D8专区形态完全照置顶区: 其正下方 / 同栏 / 可折叠持久化 / 空则隐藏 / 不受筛选搜索影响

D10作用范围仅台账视图; 控制台 / 卡片墙不动
D11标题与图标「处理中 · WORKING (n)」+ 闪电内联 SVG (非 emoji, 暗色令牌)

§07风险与对策

  • 轮询重播种 (触发: derive() 里装载 / 新增工作集): 与 pitfalls/web-ui/poll-reseed-filter.md 同源。对策: 装载点全壳唯一且只在 boot; derive() 只调 pruneTerminalWorking() (只删不增), 守阵钉住「不出现 loadWorking / 不新增成员」。
  • 终态退出误删 (触发: 状态词表漂移或字段缺失): 只认 item.status 严格等于三个终态词; 无状态 (NO_ST) 不删; 删除以 link 为键, 与加入时同一编码。
  • 隐藏件残留 (触发: 加入工作区的件后来被隐藏): workingZoneItems() 与主表 wip 标识都挡 isHidden, 与 test_hidden_items_excluded_from_views 同款守阵扩面。
  • 色条层级打架 (触发: 多选 / 预览与工作同框): 选择器特异性按 wip < sel < msel 排列, 组合态 sel.msel 仍胜出; 守阵钉三个选择器与顺序。
  • 折叠重画丢焦点 (触发: 折叠走整表重渲染): 折叠只切 collapsed 类与 hidden, 仿 pin 的 applyPinCollapse() 模式新写 applyWorkCollapse(); 原生 button + aria 属性保留键盘操作。
  • emoji / 外链回潮 (触发: 闪电图用 emoji 或图标库): 闪电走内联 SVG 常量, 守阵同时钉 test_shell_no_external_resources 与「无 emoji」。
