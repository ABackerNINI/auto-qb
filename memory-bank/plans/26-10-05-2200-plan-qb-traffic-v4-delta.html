01 · Format Spec

方案总览与 v4 格式规格

一次 v3 → v4 格式换代打包四件事:块头携带 totals 基线 + r/z 行存相对基线的 delta + 按落盘切块(flush ∧ 块内有 r 行才关,空闲块不关) + 跨块覆盖自然推算结算。收益定位 = 行宽结构性封顶(与 all-time 计数增长脱钩)+ 约 10-14% 文本量 + 每种子 B 行放大器拆除 + 空闲期写盘归零;动机与量化见报告 §03-08,本计划不复写。核心不变式:delta 只存在于线格式 —— 内存结构(V4Sample / V4ZeroRun / V4NullRun / LiveTail / 聚合累计器)全部维持绝对 totals,parse 以块基线 cumsum 复原、format 序列化时减法,读侧归桶 / agg / catch-up / WebUI 语义零改动。

v4 行型(取代 v3 计划 §02.1「逐列冻结」条款;interval_s 小数秒 + dt_ms 毫秒口径沿用)
# auto-qb qb-traffic v4                              文件头, 每文件一次(头行门闩, 不设双读)
key,<系列标识>                                  不变(global / torrent:<infohash>)
B,<start_epoch>,<interval_s>                    3 列 = 无基线块(仅 n 游程合法)
B,<start_epoch>,<interval_s>,<dl_base>,<up_base>  5 列 = 基线 = 块内首个带 totals 观测的快照
r,<dl_rate>,<up_rate>,<dl_delta>,<up_delta>[,<dt_ms>]  delta 相对块基线; 负值 = 坏行(免费校验)
z,<run_len>,<dl_delta>,<up_delta>[,<dt_ms>]      块首 z 的 delta = 0
n,<run_len>[,<dt_ms>]                            不变

定约清单(读写两侧同源,风格与现行 dt 链一致)

定约内容
基线立点块首记录带 totals(r 或 z)→ 基线 = 该快照,其 delta = 0;块首为 n 游程 → 写侧把 n-only 前缀拆成 3 列 B 无基线块,恢复传输的记录开新块立基线。解析守卫:无基线块内出现 r/z 即坏行。
关块状态机既有触发点(00:00 硬切 / 改间隔 / 落盘失败复位)+ 新增计数器重置(cur < last)强制关块(新块基线 = 重置后 totals,首记录 delta = 0)+ flush ∧ 块内有 r 行才关(纯空闲块跨 flush 开放)。关块时开放 z/n 游程先封口。
空闲封口开放 z 游程按「非 z 事件」封口:恢复传输 / null 游程 / 计数器重置 / 00:00 / stop。空闲段盘上恰 1 条长 z 行,空闲期主文件零写入,解析缓存全天有效。代价(已知接受):崩溃窗口 ≤ 当天已过时长,丢失形态 = 真空,avg/totals/max 无偏。
负 delta基线块内负 delta 必是损坏 —— 绝对值形态做不到的解析免费校验;整行跳过计数、游标不推进,现行坏行纪律原样保留(delta-vs-基线逐行独立,坏行不传播)。
覆盖结算判定函数单点、在线/离线两路复用:gap = 新块 B.start − 上一块末槽,gap ≤ interval_s + DRIFT_TOL(250ms)→ 连续,按上一记录速率把 [末槽, 本槽) 结算进 credit;否则真空(崩溃保护内核不动)。
换代语义目录 qb-traffic-v4/ 全新落点;旧 qb-traffic-v3/ 原样留存不读不迁移(R2,删留决定权在用户);头行门闩 v4,不设双读。agg.dat 行型与逐级派生不变(仅结算规则同上)。
