流量图采样间隔演进: 旧秒值键退役改整数倍数新键(配置升级v6-v7)

本篇只回答: 怎么把 qb_traffic 采样间隔从「秒值」语义演进到「main_tick 整数倍数」语义——旧键退役、新键 sample_interval_multiplier 走配置升级链 v6→v7 保行为换算、运行时抽生效间隔纯函数单点; 且升级除一项明示的默认变更外不改变存量用户的实际采样节拍。

§01目标与设计原则

背景: 采样间隔演进(roadmap D6)方向定过案但从未立项, issue 26-11-08-1717 承接。前置依赖「raw 桶数上限 MAX_RAW_BUCKETS=2880」已实施(src/auto_qb/core/traffic_grid.py:93)——24h 视图桶数已封顶, 本切片加细采样只涨存储不涨视图。

目标(做到什么程度算成):

  • 配置语义: qb_traffic.sample_interval_multiplier(int ≥ 1, 默认 1 = 1×main_tick 即「跟随主循环节拍」); 旧秒值键 sample_interval 退役, 程序其余部分零旧键分支。
  • 升级保真: 已设旧键的存量配置经迁移 v6→v7 保行为换算(细则以 §06 D8 为准: 非整除向上取整、贴上限冲突钳到 floor(600/main_tick), 逐键 WARNING); 唯一行为变更 = 未设旧键者默认 30s → 1×main_tick(明示, 见 D9)。
  • 运行时: 生效间隔解析抽纯函数单点, 采样器与 webui 同调; 旧计划 26-10-04-1957 裁决 D5 的「失配取整+告警」逻辑整体删除。
  • 测试: 全量测试绿 + 基线切片; 迁移/校验/采样三面单测覆盖。

设计底线/不变量:

  • 黄金法则 4: 新键四处登记(models / validation 白名单 / schema Field / 守卫测试)。
  • fail-fast: 非法形态(0/负/小数/旧 time 串残留)不可表达——校验层报错, 不静默曲解。
  • 项目定位=要上线的真实生产项目: 迁移路径、报错文案、默认值变更按生产标准评估, 不以「够用了」降级。
  • 红线: config.yml(生产, 现含 sample_interval: 1.5S)不碰——升级在用户跑程序时由迁移链自动完成。

§02现状与痛点

现状(取证 2026-11-10):

  • 配置: sample_interval: float = 30.0 秒值, models 默认 30(src/auto_qb/config/models.py:436); 校验下限=main_tick(硬)、上限 600s(src/auto_qb/config/validation/sections.py:1181); 「main_tick 整数倍」不在校验层(旧计划 26-10-04-1957 裁决 D5)。
  • 运行时: _apply_interval 每轮现读 (sample_interval, main_tick) 签名, 失配向上取整到 main_tick 下一倍数 + 告警一次(src/auto_qb/core/modules/traffic_sample_blocks.py:32-52); 节拍已挂时钟线自持(issue 26-10-16-0954 起), 间隔变化关块重开。
  • webui: 24h 栅格兜底 DEFAULT_SAMPLE_INTERVAL_S=30.0, traffic_qb.py:129 直接读 conf.sample_interval; MAX_RAW_BUCKETS=2880 已封顶视图桶数。

痛点:

  • 默认 30s 与主循环节拍脱钩: main_tick 调了采样不跟, 配置值与生效值是两套口径。
  • 失配取整是隐式行为: 配置写 7s、实际跑 8s, 靠运行时 WARNING 兜, 校验层不拦。
  • 生效间隔两处消费(采样器/webui 栅格)各自解释, 无单点——哨兵/倍数类语义演进每加一处都要人肉对齐。

§03方案总览

主线: 新键硬切 + 配置升级链 + 运行时单点, 三层各自独立可验:

  1. 配置层: sample_interval_multiplier(int ≥ 1, 默认 1)替代旧键; 无哨兵(默认 1 已表达「跟随」, poka-yoke: 非法形态不可表达); 上限口径=有效秒数 multiplier × main_tick ≤ 600 硬校验(main_tick 同 config 现取, _current_main_tick 管道已有), 倍数本身无独立上限。
  2. 升级链: CURRENT_VERSIONS["config"] 6→7; 迁移函数 _migrate_config_6_7 保行为换算(见 D8), 幂等, note 经 migrate_with_notes 落 WARNING。
  3. 运行时: 纯函数 effective_sample_interval(multiplier, main_tick) = multiplier × main_tick 落 core/traffic_grid.py(webui 已 import tg, 采样器可加同源 import, 无环); _apply_interval 重写为直乘, 删取整/_ratio_warned 告警(倍数语义下失配数学上不可能); webui traffic_qb.py:129 改调单点。

分期: 单切片一次落地, 无分期表; 步骤顺序见 §04。

§07风险与对策

风险触发条件处置
生产 config 的 1.5S 升级后节拍漂移首次启动触发 v6→v7D8 换算下 1.5/1.5 → 1 精确还原; 迁移单测固化该形态; 红线不碰文件
非整除换算节拍变粗(如 7S/main_tick 2 → 4×=8s)旧值非 main_tick 整除逐键 WARNING 写明旧值/新倍数/生效秒; 用户可显式改倍数微调
旧键残留(迁移被绕过的路径, 如手工编辑配置回灌)校验层收到 sample_interval白名单不含旧键 → fail-fast 报未知键, 不静默曲解
设置页控件形态回归Field kind time→int 后 webui 渲染设置页按 schema 渲染自动跟随; e2e 设置页断言覆盖(config_hub 既有真浏览器桩面)
用户对默认存储增长有异议升级后 raw 体量上涨(仅未设旧键者)schema help + 迁移 docstring 双处写明; 显式配 15 倍回旧密度的出路写进 help
