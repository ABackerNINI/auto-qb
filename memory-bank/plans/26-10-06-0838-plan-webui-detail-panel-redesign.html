02

总体架构

注册表 + 宿主 + 经典版兜底: 模板是「插进面板的渲染模块」, 面板骨架与数据管线一次性留好插座。

四层结构数据仍是 Vue 的, 皮是插拔的

层载体职责与不变式
数据层(不动)drawer.js 现有管线_fetchDrawer* 四源 + 流量 qbCur* 三挂点、5s 轮询、FX-29 软切换、请求代际 —— 零改动, 只在落袋处补一发通知(§3)
骨架层(一次改)drawer.html + drawer.js 钩子每页签 = 经典版包裹层 + 变体宿主 二选一显示; 头部加切换器与收起摘要条; 挂载/通知/卸载钩子共约 9 行
核心层(新)shared/drawer_templates.js new注册表 / 生命周期(dtSync·dtNotify·卸载) / dtHtml 自动转义标签模板 / CSS 注入单点 / autoqb.ui.drawerTpl 读写 / 收起态摘要默认实现
变体层(新 ×15)shared/drawer_tpl/01-…-15-…js new ×15每变体一个自注册文件: {id, tab, label, css, render(host, ctx), summary?, destroy?}; CSS/内部状态/定时器全自包含, 删除 = 删文件 + manifest 3 行

变体契约核心层保证的

/* shared/drawer_tpl/02-general-cards-low.js — 每变体一个文件, 形状统一 */
(function () {
  "use strict";
  const reg = window.AQB_DRAWER_TPL_REG;
  if (!reg) return;                       /* 核心未载入(清单序错): 静默退出, 守阵会抓 */
  reg.register({
    id: "02", tab: "general",             /* id = 模板 NN 号, 与报告/模板文件一一对应 */
    label: "六卡聚类(矮档)",
    css: "...",                           /* 一次性注入 <style data-dt="02">, 规则一律挂在 .drawer 作用域下 */
    render(host, ctx) { /* 全量重建 host; ctx = 组件实例(白名单面见下) */ },
    summary(ctx)  { /* 可选: 收起态摘要, 返回已转义 HTML; 缺省用核心内置 */ },
    destroy(host) { /* 可选: 定时器/监听清理; 关面板与换变体时核心必调 */ },
  });
})();

ctx 契约(白名单, 写进核心头注释) —— 读: drawer.detail / trackers / files / peers 及各 loading 态、qbCur* 流量态、memberByHash; 格式化复用现成单点 (fmtSpeed/fmtSize/fmtDuration/fmtTs/fmtEta/fmtPeersQb/drawerFileRows/drawerPeerRows/drawerTrackerStatus…); 动作直接调现有方法(drawerCmd("reannounce") / trackerAdd/Edit/Remove / setFilePriority / openFilePrio / openTargetPath / copyText / qbSetWindow / _editDetail(magnet 按需))。 变体只读这些、只调这些, 不触碰面板几何(dock/动画/高度)与轮询生命周期。

渲染纪律: host 子树归变体自管, Vue 零感知; 变体内禁止 innerHTML = 裸拼 —— 一律走核心的标签模板 dtHtml\`...\`(插值自动转义, dtRaw() 显式豁免且守阵 grep), XSS 单点收口(对齐 F1/F2 审计口径)。每次 notify 全量重建时用 replaceChildren 原子换帧, 自保滚动位置与内部 UI 态(折叠/筛选/选中), 5s 轮询频度下不闪不跳。

生命周期与数据流9 行钩子在哪触发

时机(drawer.js 现有方法)核心动作
_loadDrawerTab(:812)尾部_dtSync(): 换页签时卸旧变体、按 drawerTplSel 挂当前变体并喂当前数据; 选中 classic 则只亮经典包裹层
四 fetcher 落袋(:738/:756/:770/:784)_dtNotify("detail"|"trackers"|"files"|"peers"): 活动变体重渲染(过期响应照旧不落袋不通知)
closeDrawer(:684)_dtUnmountAll(): 逐变体 destroy(), 定时器(如 06 倒计时)必清
toggleDrawerCollapse(:995)_dtNotify("collapse"): 刷新收起摘要条(含 15 的迷你走势)
drawerTab(:800)补强二: 收起态点页签 = 先展开再切页签(2 行), 消灭「点了没反应」

FX-29 软切换 / 收起遮罩 / 页面守卫不用动: 变体宿主位于 .drawer-body 内, switching 遮罩与可见性门天然覆盖; 换种子时数据落袋走同一批 fetcher 钩子, 变体自动跟新。

取舍: 为什么是命令式渲染, 不是 Vue 动态组件挂载点最少优先

备选是每变体一个 Vue 动态组件(<component :is>): 响应式更新免费, 但子组件拿不到根实例的 mixin 方法面(drawerCmd / fmt* 等), 得铺 props / provide 接线, 面板骨架与 15 个变体全部耦合进 Vue 组件树 —— 增删一套要动的东西反而更多, 与拍板②相反。命令式 render(host, ctx) 把变体做成「纯插件」: 核心一次保证 转义 / 原子换帧 / 生命周期, 变体只写纯渲染。代价(自保 UI 态、5s 全量重建)在 §7 风险表里有对冲。
