§02现状与痛点

现状: 探测异步化产品面已完整——意图入队+单飞 kick+「探测中」gate(relocate_exec.py:2028 起)、verdict 消费/重放/防自环/终态补发全链在位。三项真机复验是验收最后一段。

痛点证据: 修复前形态 = run_probe 三段 time.sleep 在主循环线程同步执行, FS 不可达单次阻塞约 25s+(上界 ~35s; issue 26-11-10-0638 复验 2026-11-10 实证)。真机复验要证的就是这个形态消失且闸语义没变。

造法核实结论(③的输入): 任务提示的「幽灵盘 save_path → 证写 10s 超时」造法与代码不符, 双向都到不了探测: 幽灵 src ⇒ 组级 GATE_SOURCE_MISSING 先拦(relocate_units.py:1041-1046, 声明文件 exists=False), 即使绕过组闸, 探测第一步 os.makedirs 本地写即失败(local_write_failed, env=True 秒级, 非目标形态); 幽灵 dst ⇒ GATE_SPACE 先拦(relocate_common.py:40-58 _volume_free_resolved 上溯全链失败 → target_free=None)。26-11-01-2113 基线 :49/:56 的幽灵盘是「qB free_space_on_disk=-1 同卷证明解锁」记录, 不是探测窗造法。

4.3 RM04-37 [S6-③] FS 不可达行为面代理(句柄锁造法, 零产品改动)

造法(写死): 组拓扑同 RM04-36(真实 save_path + 真实 dst); POST 受理后测试进程以 50ms 间隔轮询组 save_path 下 aqb-probe-* 目录出现 → 对探针文件 save_path/aqb-probe-<tok>/aqb-probe-<tok>.bin(run_probe :379-391)立即 open(path,'rb') 持句柄。Windows 语义: 句柄无 FILE_SHARE_DELETE ⇒ qB 同卷搬迁 rename 失败 / copy 后 delete 失败 ⇒ 证写轮询「dst 一致且 src 消失」(relocate_probe.py:447-460)10s 超时 → failed env=False(relocate_probe.py:449 单点, timeout 与 mismatch 皆 env=False)→ 写指纹缓存(relocate_exec.py:164-166)。句柄读共享不阻 recheck(证读照过); 探针文件写于流程最初、setLocation 在证读完成后(时机裕度 ~1s, 50ms 轮询必赶上); _cleanup 尽力不抛(docstring: 失败不抛不改变探测结论)⇒ verdict 不会被 runner_crashed 覆盖。
