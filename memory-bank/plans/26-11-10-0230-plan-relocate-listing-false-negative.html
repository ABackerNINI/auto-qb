§01目标与设计原则

背景: 2026-11-10 00:36 生产 26586 对 Blood.The.Last.Vampire 辅种组(8 颗共享同一 5.69GB mkv 的跨站辅种)整组移动 H:→I:,65 秒后被运行时 F 自检判 failed(qb_side_check_failed),组视图裂成两组。数据与做种全程无损。历史失败账 jr-82f6dee7620d(11-05 move_stalled)一并纳入处置(D3)。

目标:

  • 自检对「qB 列目录返回链接对象元数据」形态精确判 skipped,不再假阴性;真失败判定力不回退。
  • 假阴性的两个现场后果收敛: 裂组定性为设计边界并回写口径;Blood 组恢复路径写入 runbook(用户执行)。
  • 范围外发现(终态留账无清理出口 / 启动计数文案)入池,不扩本计划范围(D3/D6)。

设计底线 / 不变量:

  • 保守默认: 判别只在「qB 条目元数据与源侧链接自身 lstat 逐字段一致」这一精确形态触发;其余一切形态判定语义逐字节不变。
  • 改动面收窄: 只动链接跟随自检支(link_follow_evidence → _d_evidence 的 name_filter 分支);迁移预检 D 级路径证据(path_evidence 常规支)零改动。
  • 失败处置路径不变: 真失败仍 failed 终态 + 现场保留(不删链不搬回,relocate_exec 既有语义)。
  • 真机验证硬约束(用户拍板 D5): 只碰环境1 白名单测试实例(real.* guard 口径),生产 26586 零触碰。

§03方案总览

3.1 主线: 链接对象判别(D1=(a))

链接跟随自检比对失配时,补一步源侧 lstat:qB 条目 (size, mtime) 与源侧同相对路径条目的链接自身 lstat 一致 → 该条记 inconclusive(列目录语义未解析链接,真伪不可判)。汇总口径:

qB 条目 vs 本机判定处置
与 dst stat 一致(size+mtime)POSITIVE照常武装(原语义,不变)
抽样全部 inconclusiveskipped不 fail 不挡武装;rt 记排查笔 + 日志一行(修复生效第一证据)
与 dst / 链接对象都不符NEGATIVE真失败,原语义不变(failed 终态 + 现场保留)
  • 源侧定位: qb_dir=job.scope(qB 视角)经 file_access.map_to_container 单点换算 syscall 路径,逐条目 os.lstat;长路径前缀走 utils.add_long_path_prefix_for_win 单点(与 _alias_live 同款)。lstat 失败(OSError)按现行「不等」处理(保守,保留真失败判定)。
  • 兼容面: dir_alias+junction(列举返回目标侧真实条目,路径穿越时 OS 解析)与 file_links+硬链接(条目即同 inode 数据,size/mtime 与 dst 一致)均不命中判别形态,原语义;POSIX qB 列举 stat 跟随 symlink → 与 dst 一致 → POSITIVE,判别不触发。
  • 已知代价(D1 拍板接受): qB 条目=链接对象时无法区分「列目录语义不解析」与「qB 真读不到」→ symlink 形态自检对真失败降为不可判(skipped)。兜底 = 成员读失败由缺文件联动(整组暂停+MISSING)/errored 状态下游抓取。

3.2 测试面

单测红绿(stub qB 客户端列目录返回):①链接对象元数据(size=0/mtime=链接时刻)→ 现行代码判 NEGATIVE(红验)→ 修复后 skipped(绿);②目标元数据 → POSITIVE 不回归;③两者都不符 → NEGATIVE 不回归。守阵落位 tests/test_relocate_proof* 系(现行 relocate 证据电池)。
