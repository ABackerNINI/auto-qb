§01目标与设计原则

背景。26-11-12-1139 交付的 T6 节拍动效, 引擎机械面(setScale 微任务合并 / y 钉档同值交还 / tick 标签冻结 / L0 边界连续性)经实测自洽——但用户真机观感是「默认配置下没有扫描、没有粒子、没有旋转方块, 0 流量完全没有动效, 每次左移后流量图有一瞬间(x 轴)抖动, 有流量时部分动效被右/下裁剪, 不是每一拍曲线都落到检查线, 面板显示采样 2.0s 而配置是 1.5s」。取证结论: 引擎没坏, 坏的是四个门与一个数值面(§02), 另有一处根因在后端栅格。

目标(做到什么程度算成)——验收判据 A1-A7, 全绿收口:

#判据量法
A1稳态流量(Δ≈0 且值>0)下每拍出 Lv.1 反馈(扫描束+粒子+环), 不再整段静默帧采样: 拍窗内右缘装饰带像素量显著高于拍间基线
A2两轨末点菱形常驻连续旋转(拍间不停); calm 档退化圆点; 关总开关 / reduced-motion 不出现DOM 探针: transform 持续变化; 三档门逐一切换断言
A30 流量: L0 平滑左移照常 + 菱形旋转仍在; 扫描/粒子维持静默(与模板 zero 场景一致)零流量段帧采样: 装饰带回到基线, L0 边界连续
A41m 窗 2s 桶连续观测(≥10 分钟): rewin 0 次、x 轴 split 集稳定(仅视口边界的自然滑入滑出, 无中段 pop)轮询日志 n 恒定 + split 数分布单峰
A5采样器活跃时曲线终点恒落判定线(尾桶不再间歇 null); 真缺口(qB 断连)仍诚实断线桩: 活跃/停滞两态分别断言
A6有流量时环/粒子/菱形无右缘裁切; 近底时环完整可见(不墨染轴标区)画布右缘/底缘像素探针
A7面板显示「采样 1.5 s · 桶宽 2.0 s」两值(配置 1.5s 时); 相等时维持单值e2e 文案断言

设计不变量(违反即破坏设计, 全部承自 26-11-12-1139 不放松):

  • 语义色守恒(I10/D1): 曲线描边恒 --today-up/down; Lv 色只上 N 层白名单(judgeFlash/ringOuter/partOuter/anchorHalo/lvBadge/bandHalo); 黑名单(曲线/背景/网格/tooltip/图例/限速虚线)零触碰。
  • 背景恒静态(G5/R4): 本轮新增的常驻菱形是 DOM 元件, 不引入任何画布铺底/呼吸。
  • I9 视觉预算不放宽: 粒子 ≤32 / 束体 ≤23 / 束+切片 ≤28 / 同帧 blur 描边 ≤3 恒成立; F1 只是让既有预算被用到(原来恒零), 不抬上限。
  • reduced-motion 强退(I7): on = enabled && !reduce 有效值单点不变; 常驻菱形受同一门。
  • 真值面零污染(I4/I8/§05.4): 菱形位置是显示面; L0 仍只动视口; 预览拍/真拍同构不变。
  • 诚实性(traffic 仓纪律): 活尾延伸仅在采样链活跃且间隙有界时持有末次观测速率, 停滞/断连不延伸——不造数据, 只把「最新已知状态仍有效」表达出来(z 游程延伸到 now 的既有合成同款语义)。
  • fail-fast 边界: 本轮零新配置键(meta 增 sample_interval_s 是响应契约键, P4「只增不改」; 不触发 validate_config 面)。

§02现状与痛点(根因 × 实证)

#报障根因(代码事实)实证
G1 默认配置没有扫描/粒子 等级门 × 真实数据语义: _qbFxLevel(qb_traffic_chart.js:635) Δ<0.5% 静默; 生产尾桶是未完成桶(live_tail 每轮询重算), 同桶内相邻轮询速率漂移恒 <0.5% → 恒 Lv.0 → _qbFxSpawn(:1973) 返 null → 全装饰静默。模板 demo(plan 26-11-12-1139 §04)是合成 ±25-40% 摆动才「每拍都有」 帧采样: 平滑合成流 98 拍等级分布 U0=37%/U1=4%; 真实稳态流几乎 100% U0。Δ 大时引擎完整出装饰(U3 实测 glow 581 vs 稳态 51)——引擎本身正常
G2 缺旋转方块 模板末点菱形 t/420 常驻连续旋转(§04 demo :1417, draw 循环永不停); 生产 _qbDrawFxAnchor(:2409) 只在拍窗(≤0.55beat)且 fx 存在(Lv≥1)才画——缺常驻环境层, 拍间/低级位全停 生产无拍间 rAF(「无常驻定时器」纪律), 菱形拍间零帧
G3 0 流量零动效 计划 26-11-12-1139 的 D2(§03 L1 约定)/I10(§01 不变量)拍板「零流量/Δ≈0 零装饰, L0/L1 照常」——实施忠实执行; 但模板 zero 场景仍有旋转菱形+流动光点+判定线余晖(环境层不静默)。用户 26-11-14 反馈推翻此口径 零流量段 44 拍全 0/0(L0 滑动在, 装饰全无)
G4 x 轴逐拍抖动 源头在后端: _floor_buckets(traffic_grid.py:135-142) n = ceil((t1−first)/interval), 而 t1 = int(now) 整秒截断 + 首桶 floor 对齐 → t1−first 一半时间恰落在桶边界(整秒 mod 整桶宽) → n 在 k/k+1(跨度 58s↔60s 方波)随轮询相位翻转 → 前端两连锁: (a) rewin = st.n !== n(:2520) 把点数变化判「跨窗换档」→ 跳过 L0 瞬时多格跳; (b) uPlot split 集(网格线+轴标)随跨度方波每拍重推, tick 冻结等长守卫每拍破防 生产同构桩实测: 103s 内 #52 n=30→31(尾桶跳 2 格头桶 1 格, rewin 瞬跳); split 数 11↔12 翻转 39 次/20 拍(≈每拍 2 次); 轮询周期==桶宽时相位漂移使翻转周期性出现
G5 曲线不总落检查线 活尾链止于 last_seen/projected_ts(traffic_store_codec.py:235 v4_live_tail_slots; traffic_sample_mod.py:346 _publish_live_tail), 不延伸到 now。采样 1.5s 栅格 × 2s 桶宽(ceil) → 尾桶约 37% 轮询无观测(覆盖概率 P(age<r)≈0.625 推导) → spanGaps:false(:3031) 断线 → 曲线终点收在检查线左侧一格 概率推导 + 桩 null 尾桶复现「间歇不落线」; 引擎面: 尾桶 null → 轨死(live=false) → 不插值不画锚, 曲线可见终点 = n−2 位
G6 动效被右/下裁剪 _qbDrawFx(:2083-2085)与 _qbDrawFxAnchor(:2424-2426) clip = 绘图区矩形 → 末点在绘图区右缘(tipX=L+W)的环/粒子/菱形右半被切; 模板 clipPlot 延到画布右缘(§04 demo :1014-1017); 扫描束同因已修过一次(:2319「评审 blocker 修复」先例)。下方: 环/粒子越过绘图区底缘被切(模板同口径, 但生产低流量时末点贴底才显形) 代码面(clip 矩形逐字对照); 用户真机目检
G7 面板「采样 2.0 s」vs 配置 1.5s interval = max(1, ceil(sample), ceil(span/2880))(traffic_grid.py:157-162)——桶宽向上取整防伪断线是正确行为(1.5s 采样行落 1s 桶会隔桶为空); 但 meta 只带 interval_s(桶宽 2s), 面板「采样」标签读 _qbPollMs=meta.interval_s → 显示与配置不符, 是显示口径问题不是取整问题 用户配置 main_tick 1.5s × 1 倍 = 采样 1.5s; 面板显示 2.0s(=桶宽)
另录在案未列入本轮: y 轴逐拍重钉瞬时缩放(_qbYRange 顶值=峰值×1.05 不取整, 实测 98 拍 14 次 3-10% 整幅纵向跳变)。用户修正「抖动是 x 轴非 y 轴」, y 轴面本维持现状; 若后续观感仍见纵向缩放, 另案(1-2-5 阶梯取整)。
