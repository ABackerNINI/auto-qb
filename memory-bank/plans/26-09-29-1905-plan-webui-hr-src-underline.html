HR 来源标记 · 非文字化

替掉「在线 / 本地 / 未核」两字芯片，用「长度 / 线型 / 明暗」三重编码：线色一律跟着字色走（绿 / 橙 / 红 / 灰），不引入新色；在线横盖整格，本地与未核实只盖数值段（未核实走点线）；已排除 / 无 HR 不画线，文案进 title。

01编码表

三个维度各投一票：长度（整格 / 半格）是主线索引，线型（实线 / 点线）与明暗各作兜底。同状态色（如同为绿色已达标）下靠「盖不盖到 / 要求值」分开，不比粗细 —— 色相不承担区分来源的职责。已排除 / 无 HR 不画线，无线本身即「这一行没有来源结论」。

来源线色长度线型 / 明暗语义
在线核实随状态色整格（含 / 要求值） 2px 实线 · 100%站点结论覆盖整格
本地兜底随状态色半格（仅数值） 2px 实线 · 50%本地只对实际值负责
未核实随状态色半格（仅数值） 2px 点线 · 80%站点未给结论
已排除不画线— —不参与 HR，文案进 title
无 HR不画线— —hr_safety 为空 / none

「已排除」原是独立文字 chip（与来源芯片同款、同样占宽），已确认一并改为 title 文案：文案单点收进 HR_EXCLUDED_TITLE，与来源文案由 hrDurHint(m) 拼成单元格 title；三套 CSS 的 .m-pair .hr-src 规则随之删除（已无消费方）。

hr.js · 徽标改类名，文字只进 title

const HR_SRC_CLASSES = {
  site_scope: "src-online", site_satisfied: "src-online", site_unsatisfied: "src-online",
  site_released: "src-online", site_exempt: "src-online",
  local: "src-local", unverified: "src-unver",
};
/* title 文案单独一份: HR_SRC_BUCKETS 的 unverified 是空串(筛选器语义), 不能拿来当提示 */
const HR_SRC_TITLES = { "src-online": "在线核实", "src-local": "本地兜底", "src-unver": "未核实" };
/* 已排除提示同走 title: 原本是行内「已排除」文字 chip(与来源芯片同款、同样撑宽) */
const HR_EXCLUDED_TITLE = "已排除出 HR 管理(排除标签/分类命中)";
hrSrcClass(m) { return m.hr_safety ? (HR_SRC_CLASSES[m.hr_safety_src] || "") : ""; }
hrSrcText(m)  { return HR_SRC_TITLES[this.hrSrcClass(m)] || ""; }
/* 单元格 title = 来源文案 + 已排除说明(已排除行 hr_safety 恒 none, 实际只出现一条) */
hrDurHint(m)  { const p = []; if (this.hrSrcText(m)) p.push(this.hrSrcText(m));
                if (m.hr_excluded) p.push(HR_EXCLUDED_TITLE); return p.join(" · "); }
hrSrcFull(m)  { return this.hrSrcClass(m) === "src-online"; }   /* 整格: 只有在线 */
hrSrcHalf(m)  { const c = this.hrSrcClass(m); return c === "src-local" || c === "src-unver"; } /* 半格 */

05待确认

  • 行高：padding-bottom: 6px 是否撑高行。明细表行高多半由名称列主导、可被吸收；若被撑高，把 --dur-pad 降到 4px（半格线的 calc 会自动跟随）。
  • 半格线共线：.dur-val 与单元格的底线是否严格同 y，真机上差 1px 就很显眼，必要时把两种长度都挂到外层、用 width: 100% 与「半格线写死数值宽度」区分（注意不能写 width: auto，空元素会收缩到 0）。已确认（2026-09-29）：两种长度都挂文字级盒子 —— 整格挂 .dur-body、半格挂 .dur-val，同一个 calc(-1 * var(--dur-pad))，真机共线；顺带把整格线从「随列宽」修回「随文字」（见 02 下方注）。
  • 数值为空：cellSeedingTime(m) 为空时半格无线可画，来源只能靠 title —— 这类行多为 HR 已触发但尚未开始做种。
  • 长度线索失效的场景：不显示要求值时（无 hr_req_time 的行）整格与半格都只剩数值段，长度这一维归零 —— 在线 vs 本地只剩明暗（100% vs 50%），本地 vs 未核实只剩线型（实线 vs 点线）。本版保留本地 50% 半透明就是为了这个兜底；若真机上仍难辨，退路是「在线额外加粗到 2.5px」。
  • 点线可见度：未核实的 2px 点线在深色底上天生比实线弱（点线本身已"稀"一层，再叠透明度更淡）。本版已从 75% 提到 80%；真机若仍偏淡，直接提到 100% —— 点线靠线型区分，不必再靠明暗。上一版本地 / 未核实的线整条不可见是 width 缺失导致的（见 02 下方注），不是透明度问题。
  • 无线两类的互相区分：已排除 / 无 HR 都不画线，彼此只剩字色（无 HR 是 teal）与 title；已排除若与未核实字色撞（都偏灰），必要时给已排除留一条极淡实线。
  • 已排除 chip（已确认撤掉）：文字 chip 已改为 title；代价是已排除行在做种时长列里没有任何可见标记，只能靠悬停发现。真机若觉得"看不出这行被排除了"，退路是给已排除留一条极淡实线（挂在半格位置，透明度 ≤ 30%）。
  • 无障碍：文字进 title 后读屏仍可读（title 与 aria-label 同源），但键盘焦点行需要 :focus-visible 时才看得见标记含义，必要时在 HR 悬停弹窗里补一行「来源」。
