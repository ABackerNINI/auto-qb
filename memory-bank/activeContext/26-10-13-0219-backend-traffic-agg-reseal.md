# 26-10-13-0219 流量聚合封口三修: 亚秒残余崩 + 重封丢覆盖 + 单系列异常停写

> 摘要: 用户贴来另一工作区(`auto-qb-long-seeding`, 旧快照 `2119931d`)的真机报错「执行异常: 逐级聚合无有效覆盖」, 要求先验证现版本是否仍在, 随后指令「直接修复」→「提交后修复同源缺陷以及健壮性放大器」→「收尾然后提交」。**验证结论: 未修复且仍存在** —— 按栈帧行号反查确认那段代码自 `2119931d` 起逻辑一字未改(差异全在重构与恢复读集优化); 用当前代码跑真机数据把三段根因全部钉死。**根因族(同一处语义: 已封桶仍会被迟到补记)**: ①小时封口 `pending.pop(h)` 弹桶后, 长空闲 z 游程(按 `ZRUN_FLUSH_S`=24h 才封口)的信用落在早已封口的桶上, 重建出只含残余的桶; ②亚秒残余经 `int(round())` 折 0 ⇒ 该行成为日里唯一子行时 `Σcov_s = 0`, day 封口的 `v4_rollup_agg` 抛「逐级聚合无有效覆盖」; ③抛点在 `_agg_append` 之前 ⇒ 每轮 flush 复现 + 整批 agg 行丢弃 + 其余系列同样不封口(放大器: 单系列异常 = 全局静默停写, 真机持续一小时多)。**修法**: ①小时行 `cov_s` 下限 1(生产者收口, avg 仍按 float cov 加权); ②同 epoch 重封由「替换」改**合流**(`v4_merge_agg` 新增, 落批行 = 合流行 —— 解析按「同 epoch 取末行」); ③`_agg_flush_all` 逐系列隔离 + `_agg_reset_after_error`(告警一次 + 重置该系列累计器)。**真机验证**: 按合流重算, global 日覆盖 44712 → 86400 = 离线全量重算值(6ac66e 56659 → 86398 同)；红验三处闭环。

> 最后活动: 2026-10-13 02:19

## 背景

报错来自**另一个工作区**的旧快照(仅只读取证, 未做任何写操作)。用户要求: 先验证现版本是否还在 → 直接修复 → 提交 → 再修同源缺陷与健壮性放大器 → 收尾提交。

## 根因(实测复现, 非推理)

1. **触发形状**: 小时封口 `pending.pop(h)` 之后, 桶里只剩「先到的那部分覆盖」已封; 而信用的入账时点取决于**记录封口**时点 —— 长空闲 z 游程按 `ZRUN_FLUSH_S`(24h)才封口, 其槽位区间起始落在早已封口的桶上 ⇒ 重建出一个只含残余的桶, 再封一次。
2. **崩点**: 残余 Σdt ∈ (0, 0.5] 时 `int(round(cov))` = 0; 该 hour 行成为当日累计器里唯一子行时 `v4_rollup_agg` 的 `Σcov_s > 0` 前置条件失效 → 抛「逐级聚合无有效覆盖」。真机残余实测 0.263s(10-12 末槽 `23:59:59.737` → 10-13 首块 `B.start = 00:00:01`, 跨 00:00 拆成 0.263 + 1.0)。
3. **丢覆盖**: 重封若按「替换」写进日累计器, 先到的那部分覆盖被丢弃 —— 真机每个小时两行(如 `1791745200` 的 1598 + 2002)、日行 `cov_s` = 44712, 而该日各行「取末行」相加恰好 44712(证明保留的是残余), 离线全量重算 = 86400。
4. **放大器**: 抛点在 `_agg_append` 之前 → 整批 agg 行丢弃 + 累计器停在「已封未落盘」态 → 同一错每轮 flush 复现; 且异常上抛到 handler, **其余系列本轮也不封口** ⇒ 全系列 agg 静默停写(真机 00:41~01:41 期间 10-13 一条小时行都没落)。

## 修复

- **`traffic_store.py`**: `v4_hour_agg` 的 `cov_s` 加下限 1(`max(1, int(round(cov)))`), 两侧 docstring 写明不变量与后果链; 新增 `v4_merge_agg(prev, row)`(cov 相加截到桶宽 / avg 按各自 cov 加权 / max 取大 / totals 取后封行 / 异 kind-epoch fail-fast)与 `_agg_width_s`(hour 3600 · day 86400 · month 当月秒数)。
- **`traffic_sample_mod.py`**: 新增 `_agg_merge_prev` 单点(该 epoch 已在累计器里则返回合流行), `_agg_ingest_hour`/`_agg_ingest_day` 的**落批行改为合流行**(`_ingest_acc` 骨架与批次内行序不动); `_agg_flush_all` 逐系列 `try/except` + 新增 `_agg_reset_after_error`(同系列告警一次 + 重置该系列累计器, 恢复健康后清记忆)。
- 「替换」语义保留给**完整重算**路径(重启 catch-up 走 `_catch_up_level`, 不经合流 —— 否则重复计)。
