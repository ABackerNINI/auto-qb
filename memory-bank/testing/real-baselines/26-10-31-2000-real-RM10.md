## 03 本轮实测确认的代码事实(回写素材)

1. **journal 相位链 armed→removing→removed 可在真机完整观测, 但窗口极窄**(RM10-05 实测): removing→removed 之间只有 `_delete_links` 的执行时间, 实测 300 条 junction ≈ 70ms(单条 0.23ms)—— 毫秒级轮询 watcher 可稳定抓住; 常规 3-5 条别名的生产场景窗口 <2ms, **外部轮询实际观测不到中间相位**, 对账面只能依赖终态 journal + 链接存在性的「二者唯一确定」语义(relocate_journal docstring 的设计本意)。观测法已固化进 RM10-05(300 条别名拉宽窗口 + 后台 watcher), 复跑可直接引用。
2. **RM04 遗留收口**: guardian 删链路径(qB 退出后半边)由 RM10-05/06/07 三态覆盖(removed 正向 / verify_mismatch 保守零删 / stopped 终态挡删)+ RM10-07 参数互斥面(no_spec/already_running/timeout)—— RM04 记账的「guardian 在 qB 退出后的删链半边」至此闭环; alias 建链/搬数/穿透/journal 恢复半边仍在 RM04(引用不复测)。
3. **`_proc_absent` 的实例级口径真机成立**(finalize_watch.py:103-117): spec 端口指死端口 ⇒ 端点拒连 ⇒ 证一成立, 同机 36595/36596 两个 qB 进程在跑不影响判定(P7 同机多实例问题的本地构造法); 反之端口可连(哑 socket)则三证永不齐, max_wait 兜底退出带 armed 心跳 —— 与 RM10-07③ 实测一致。
4. **notify 管线的发送尝试计数口径可靠**(RM10-04/08): handler 路径 powershell 子进程在 drain 线程串行执行(不重叠), pid 差集==尝试数; 但 `notify_fatal` 是**同步** send —— 子进程随调用出现并退出, **事后采样必然错过**, 采样必须与发射并发(测试侧教训, 见 §04-2)。
5. **哑监听 socket 的「可连」面必须真应答**(RM10-07③ 假红根因): `listen(1)` 且从不 accept 时, 首个探测连接占满 backlog, 之后 guardian 的探测全部拒连 —— 在 guardian 眼里这就是「qB 已退」, 它按设计删链返回 removed。产品三证逻辑无缺陷; 哑 socket 必须 accept 后立即 close(测试造法修正)。
6. **exporter 双跑幂等在真实库上成立**(RM10-02③): 同参数双跑字节级一致(域名 sorted 序 + gen_tracker_name taken 集), tracker 名生成无漂移; only-missing 骨架 = `config.trackers` + `schema_version` 版章程(计划「只含 trackers 键」按实况含版本章, 计划 §02 锚点表自身载明盖章行为, 非漂移)。
7. **AUMID 回退路径可进程内构造**(RM10-03): monkeypatch `_register_appid_registry` 抛 OSError → `_appid` 回退 `Microsoft.Windows.PowerShell` + DEBUG「通知 AUMID 注册失败, 回退 PowerShell 来源」—— 计划预判「如无处断则降代码走读」实测可断, L2 全额通过。

## 04 排障轮次(测试侧假红, 非产品缺陷, 代码零改动)

1. **首轮 RM10-07③ FAIL: timeout 期望实测 removed**(19:40 首轮)。根因: 哑 socket `listen(1)` 从不 accept, 首个探测连接占满 backlog 后 guardian 探测全拒连 ⇒ 三证凑齐按设计删链(§03-5)。instrumented scratch 复现实锤(`_port_refused` 首轮 False / 次轮起 True)。修复: accept 线程随连随关。单跑复核 1 次绿(3.56s)。
2. **首轮 RM10-08① FAIL: notify_fatal 直发实测 0 尝试**(19:40 首轮)。根因: notify_fatal 同步 send, powershell 子进程在采样窗开始前已出现并退出(对照: handler 路径异步派发, RM10-04 同法即过)。修复: emit_fn 进后台线程与采样并发。单跑复核 1 次绿(25.76s)。

两处修复都只动 `tests-real/rm10_notify/test_rm10_notify.py`(测试造法), 产品代码一行未改; 官方最终轮(19:56)8/8 全绿, 计为本片基线轮。
