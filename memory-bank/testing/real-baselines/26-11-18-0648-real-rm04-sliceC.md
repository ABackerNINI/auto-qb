## 03 修法清单(全部测试侧, 产品代码零改动)

### 3.1 RM04-24 首跑前 2 处造法缺陷
1. **空骨架无 model_version 章**: 断言注入底座自带 model_version 失败(实测 None)—— 迁移器只对
   旧格式账动手, 空骨架不盖章。修: 注入面显式写 `box["model_version"] = ru.MODEL_VERSION`
   (按「已迁移新格式账」的盘上形态补齐), 区别于 RM04-23 的旧格式整盒重写。
2. **空 dict 探针真值坑**: B10 清空后磁盘账断言 `return ld if ld == {} else None` —— 空账恰是
   期待态, 但 `{}` falsy 被 wait_until 当「未就绪」→ 100s 假超时(实际账已清空)。修: 探针回
   `True if ... == {} else None`(wait_until 按真值判, 探针只回 True/None)。

### 3.2 RM04-25 首跑 3 处造法缺陷(含一条可复用新纪律)
1. **R4 收缩判定拍错过删除轮(可复用新纪律)**: 收尾窗删光成员后 120s 无收缩行 —— 根因:
   `_step_absence_shrink` 一拍一判(rt["absence_round"]=判定时 store.rounds_applied)且取数面 =
   **当前轮** last_removed 快照(零变化轮先清空再走公共路径, 不留上一轮残值); main_tick 2S vs
   sync_interval 1.5S 下删除轮(存活 1.5S)有概率被主循环拍整个错过 → 证据永久丢失 → 静默缺席
   永不计数 → 收缩不发生 → 删链门(在 _step_verify)永远到不了。修: 三腿配置 **main_tick 1S**
   (`_write_cfg_fast_tick` 单点, M.write_cfg 派生后 2S→1S 文本替换)—— 1S 拍间隔 < 轮存活期
   1.5S = 每轮至少一个判定拍覆盖, 删除证据确定性进判定。**对片F RM04-30(E5 成员收缩)直接
   适用: 同一删光成员→收缩→删链门通路, 同款 fast-tick 配置必带**。
2. **祖先跨种种子被搬迁带走**: X1 先于搬迁加入时, 其物理文件在成员搬迁被 qB 移走的文件夹里
   (X1 内容根 = 旧根 = 成员 save_path), 迁移发起拍产品日志「检测到删除种子 1 个」(06:15:42.341,
   setLocation 后 3ms)—— X1 被 qB 侧带走 → 依赖扫描空手。修: **X1 移到 armed 后加**
   (A2.5 段): 搬迁已完成, X1 经 junction 读 dst 数据校验后在场, 删链门扫描读当前 save_path 与
   加入时机无关; 添加预检对祖先位零 confirm 属预期(不在收尾窗判据面)。
3. **场景 2 confirm 无 actual_path**: C 腿断言 confirm 回执 actual_path 指镜像位失败(实测空串)
   —— actual_path 是**目录级重定向面**的展示键(base_add 恒 None, 文件级场景 2 不覆写), 首跑
   实测校准。修: 改断言 requested_path == 落点位(f.bin 撞链接同名位), actual_path 如实记账。

## 05 坑点候选(供 pitfalls 回写)

1. **R4 收缩判定拍 vs 删除轮快照的竞态**(§03.2-1, 可复用新纪律): `last_removed` 是「最近一轮」
   语义, 零变化轮即清空; 判定拍(main_tick)慢于轮存活期(sync_interval)时删除证据有概率永久
   丢失 → 静默缺席永不计数。**收尾窗依赖「删光成员→收缩→删链门」通路的用例, main_tick 必须
   < sync_interval**(本轮 1S vs 1.5S)。片F RM04-30 直接适用。
2. **共享物理文件的组外种子不得在搬迁发起前加入**(§03.2-2): 其文件在成员搬迁被移走的文件夹

   后再加(删链门扫描读当前 save_path, 与加入时机无关)。
3. **空 dict 是 falsy**: wait_until 探针只回 True/None, 回「期待态本体」(空账/空集)会被真值
   判定吞掉(RM07-11 issue 26-11-08-0044 同族)。
