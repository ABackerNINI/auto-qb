## 04 收尾与口径说明

- **清场**: `real.seed.rm --all --yes --port 56590`(只认 real-fake)删种子与数据 → `real.seed.clean --yes` 清 `.work` → `real.down --port all` 优雅关闭两实例。`real.seed.list` 确认自造种子 0, `.work` 无残留, BT_backup 只剩 `queue`; 进程/端口回到开工前状态, 未给后续 clone 留下占用。
- **未新增 `tests-real` 常驻用例 / 本轮不升档的理由**(§06 与 §08 的「没做必须明示理由」): 本轮是一次性功能验收而非排期轮, 断言已由「命令输出 + 端口/进程/磁盘 mtime/重启读回」这类外部可观测事实固化在本切片; 起停类常驻用例会与 §2.2「多 clone 单实例、同一时刻只许一个 clone 跑 real.*」冲突, 且没有分步计划与三态用例表。失败分支(API 失败 / 60s 超时 / 镜像核验拒绝一律 fail-closed)由 `tests/test_real_machine_safety.py` 的桩守阵覆盖, 不做真机故障注入。
