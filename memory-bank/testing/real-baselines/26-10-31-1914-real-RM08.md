## 03 本轮实测确认的代码事实与判据漂移(回写素材)

1. **零回传拍实形态 = {status, rid, updated:false}**(RM08-01 实测): status(traffic/server/totals 恒回传段)由
   /api/state 路由层包在 ensure_state 结果**之外**(state.py:70-93)—— ensure_state 自身零回传分支只回 {rid, updated}
   (runtime.py:1570), 数组键缺席是门控本体。计划「零回传拍也不丢 traffic/server/totals」与实码一致;
   「响应字节数 < 首拍 5%」只在 status 占比小的大库成立(3 枚种子实测 17%, 1200 枚 0.06%), 小库界放宽到 50%。
2. **show 视图已进 delta 增量矩阵**(计划 §03 RM08-02⑤ 漂移): 计划 spec 写「show ∉ _DELTA_VIEWS 恒全量」, 实码
   S9b 起 `_DELTA_VIEWS = {group, torrent, show}`(runtime.py:91, 计划 §02 锚点表自身也这么记 —— 计划内部矛盾)。
   ⑤按实码契约断言「view=show&delta=1 归约形态合法」, 不入池缺陷。
3. **「≈1/4」字节收敛界是库形态函数**(RM08-03/04 实测): view=torrent 对无 view 全量的字节比, 3 枚种子 0.66 /
   1200 枚未归组 0.62 —— 无归组库的 groups/shows 数组恒空, 收敛下限 ≈ (status+torrents)/(status+singles+torrents);
   40% 界只在 groups 有货的库形态成立(产品注释「≈1/4」源出真实归组库)。断言按无归组库下限 70% 钉, 实测比入
   metrics.log。
4. **SSE 坏票负向在冻结驱动形态下不可达**(RM08-07⑤ BLOCKED 子项): skip_local_verify=true 时 auth.py 的 loopback
   免鉴权返回先于票据闸(auth.py:168-175)—— 坏票/无票在本机回环恒 200, 属免鉴权配置的显式语义非缺陷。
   解锁 = 驱动改 skip_local_verify=false + Bearer token 重跑。
5. **missingFiles 造法在 qB 5.2.3 不成立**(RM08-08 BLOCKED, 两轮复现): 计划造法「删数据文件 + recheck」——
   recheck(running)→ checking 后落 **stalledDL(progress 0)**; recheck(stopped)→ **stoppedDL**; 删后 start →
   fast-resume 不核文件仍 **stalledUP**。missingFiles 需一次真实失败的文件操作(如 L2 传输读失败)或 qB 重启期
   resume 核验。解锁 = 造法定案后按同口径补断言(missingFiles 行「文件丢失」载荷 + delta 即达)。
6. **delta 窗口「恰含变更行」在新鲜入库种子上不成立**(RM08-02②, 两轮复现): 刚入库种子的错峰 check 完成派生变更
   会落在 rid 基线的相邻代(upsert 混入内容与当前视图完全一致的邻代行); 且 pending_ver 生产者门控让存量脏可能在
   零回传拍之后才补发一代 —— 单次静止不代表排空(用例侧加 wait_quiesced_rid: 静止→睡眠>main_tick→再静止 ×2)。
   承载性判据改为「变更行在 + 窗口全部行内容现取一致(R1)+ removed 空」; 恰单行只在注入后静置 ≥60s 才确定。
7. **qB /torrents/delete 多 hash 分隔符是 `|` 不是 `,`**(用例侧踩坑, guard.pause 同款佐证): 逗号连接静默删 0 枚
   (HTTP 200), RM09 逐个删没暴露 —— 大库批量删除必须 `|` 连接。
8. **RM08-06 收尾零速偶发**(官方第 3 轮): 传输完成 60s 内 totals 未回零速一次, 复跑即过 —— 用例已把失败时的
   产品行/qB 行真实速度嵌进观测值, 下次复发有证据链可定性; 本轮不记缺陷。
