`lib/app.py` 里钉了**四条**实测事实(后续片直接引用, 别再重新踩):
1. **`--dry-run` 不启 WEB 服务**(`webui/module.py:66` 是 `if dry_run or not web.enabled: return`)⇒ WEB 类用例必须不带 dry-run。
2. **Windows 上从外部发 SIGTERM 等于强杀**(`Popen.send_signal` 走 `TerminateProcess`, 退出码 1, `finally` 一行不跑); Ctrl+C 也投递不到(子进程无控制台)。优雅退出只能**进程内** `raise_signal(SIGTERM)` 触发, 或在 Linux 上从外部发。
3. **配置必须写 `schema_version: 5`**, 否则每次启动走 v1→v5 迁移; 非 dry-run 时还会改写配置文件并留备份, 把临时目录搅浑。
4. **`Popen.pid` ≠ 进程实际 pid**: uv 在 Windows 上给 venv 的 `Scripts/python.exe` 是 47KB **启动器**(基解释器 91KB), 真解释器是它的子进程。按 pid 断言要取 `real_pid()`(锁 meta), 杀进程要 `taskkill /F /T`(带 `/T` 否则留孤儿继续持锁)。

## 04 本轮踩到并已解决的问题

1. **`port_free()` 不能用 `SO_REUSEADDR`**: Windows 上它的语义是「允许抢占别人正在监听的端口」, 于是 `bind` 成功 ≠ 端口空闲。RM01-07 第一次跑就因此谎报「已释放」, 紧接着重启撞 `Errno 10048`。**裸 bind 才是可信探针**。
2. **端口不能复用得太快**: 上一条用例刚停的进程, 监听套接字要过一小会儿才真正消失 —— 整片连跑时 RM01-07 抢到 RM01-05 刚释放的 39000 就 10048, 单跑不复现。改为**会话内端口不复用**(段够大, 比 sleep 等它可靠), 并加跨进程串行锁。
3. **`-n 8` 会把这些用例并行化**: `pytest.ini` 的 addopts 是 `-n 8`, 默认 `--dist load` 下 `xdist_group` 标记**不生效**。官方入口 `real.suite` 传 `-n 0` 本就没问题, 但直跑 `pytest tests-real/...` 会互相抢端口 —— 用文件锁兜住。
4. **子进程无控制台时 `CTRL_C_EVENT` 投递不到**(10s 不退出, 只能 kill), 所以「优雅退出」这条**只能**靠进程内自投 SIGTERM, 见 §03-2。
5. **托盘起不来的根因是解释器缺 Tk(已修)**: 首次跑(08:31)报 `No module named 'tkinter'` ⇒ RM01-09 记 BLOCKED。查下来 `.venv` 的基解释器是 `H:\Programs\AutoClaw\resources\python`(随宿主打包的裁剪版 3.13.12), 目录里**没有** `_tkinter.pyd` / `Lib/tkinter/` / `tcl/`。
   - **这不是 uv.lock 的问题**: `tkinter` 是 CPython 标准库的一部分(Tcl/Tk 编译产物), 不是 PyPI 发行版, **不可能**出现在 lock 里; `customtkinter==6.0.0` 装得上, 但它在 `__init__.py:6` 就 `from tkinter import ...` —— **安装成功 ≠ 能用**。
   - 对照实验: uv 自己装的 CPython 3.13.15 带 Tk 8.6(`_tkinter.pyd` + `tcl86t.dll` + `tk86t.dll` + `tcl/`), 所以不是 uv 装错。
   - 处置: 用 uv 管理的 CPython 3.13.15 **重建 venv**(`uv venv --clear` 指向该解释器), 再走 `env.sync` 按锁装依赖。重建后 `import tkinter` / `import customtkinter` / `import pystray` 全通, `tests/` 4302 passed / 覆盖率 99.05%, RM01 复跑 9 条全绿。
6. **观察项(不属本片, 转 RM07)**: 未配置流量数据源时, 每次启动都打一条
   `[WARNING] 流量快照 | 读取流量数据失败(): [Errno 2] No such file or directory: ''` ——
   路径是**空串**, 说明"没配"被当成"读失败"报了。归 `core/traffic_source/` + `traffic_snapshot_mod`, 是 RM07 的 glob。
