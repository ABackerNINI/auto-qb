# WEB UI 渲染细节 (表格几何 / 排序引擎 / 列风格)
> 摘要: 表格几何字符串单点 dt_table.layout、三态排序引擎 AQB_SORT.setSort、五维列风格引擎的派生链与守阵 —— 主档 webui.md 外迁的渲染层细节。
> 触发: 表格几何, dt_table, DT_TABLE.layout, assertLayout, 排序, setSort, 三态排序, 列风格, colstyle, data-cs-*, progBand, speedBand, numScale, HR 三表, 守阵

## 表格几何单点 (webui/static/shared/dt_table.js + columns_grid.js)

- **`DT_TABLE.layout()` 是全仓表格几何字符串(轨道串 / aligns)的单一生产者**(计划 plans/26-11-10-0027-plan-dt-table-wiring.html, 2026-11-10 接线): `columns_grid._gridTemplate` 与 `colAlignCss` **内部委托**该单点取轨道串与对齐, 旁路拼接已删; 调用方(主视图 computed + 抽屉桥)与 DOM 零改动, 全部表格面(含主列表、含 flux)同一链。新增/改表格几何逻辑只改 dt_table.layout 一处 —— **禁止再造平行计算**。
- **`assertLayout()` 常驻生产渲染自查**(拍板 D3): 三处 O(1) 计数(grid 轨道数 / 列头格数 / 首行子格数), 不一致 `console.error`(含 tableId 与三方计数)**不打断渲染**(保守默认); 未挂载豁免。
- **D4 例外清单(26-11-17-0059 第二轮后收缩)**: 现役例外只剩 **04 卡片形态面**(drawerTrackerV04, 非网格形态, 入池 issue 26-11-17-0038 待排期); 另有桥验证 fixture **drawerStubV0**(仅 `?dtstub` 查询参数注册, 生产零观感)是 `ASSERT_SKIP_FACES` 成员但不算现役面。HR 三表(hrDetail / hrWave / hrKv)已随计划 plans/26-11-17-0059-plan-hr-table-wiring.html 迁入 aq-table grid 链路(2026-11-17): 列定义补 tpl/align 并入 `ALL_TABLE_DEFS`(page 键 hrDetail/hrWave/hrKv, 几何走同一 `DT_TABLE.layout()` 单点), 四项交互(拖宽/拖序/右键隐藏/持久化)复用主表引擎单点, 状态落 `autoqb_cols_v5` 新 page 子树(不升版本); hrDetail 排序并入引擎 `setSort`(E8, 逐站点记忆→表级); hrKv k 列 locked(E7, 拆散 k/v 对不可表达 —— 隐藏侧引擎既有守卫, 拖序侧 W2 补 `startColDrag`/`applyColOrder` locked 检查, 主表 locked 列随之不可拖走); 值格渲染注册化(`registerCell` → `HR_CELL_RENDERERS`, 模板经 `cellOf` 消费, dt_table 六口子全活); `<aq-table>` 的 `mode="thead"` 借壳模式随迁移整体退役(hrDetail 是唯一消费方); settings 页 `.hr-full-modal` 的 v-show 未展开态走 assertLayout「未挂载豁免」口径(展开态经 `headDom: true` 锚覆盖)。
- 守阵: node 电池等价性探针(`tests/test_webui_static_r4_node_batteries.py::test_r4_dt_table_layout_geometry_equivalence`, 13 表 136 列 + colWidths 五类场景, 断言现役拼轨 ≡ DT_TABLE.layout 输出; 13 表不含 HR —— 沙箱不加载 hr_status.js, HR 等价性由例外清单守阵静态形态钉 + parity e2e 真跑) + e2e `dt-table-layout-parity.spec.mjs`(语义 = **钉住单点输出不变**; 26-11-17-0059 W3① 起含 HR 三面 hrDetail 10 列 / hrWave 8 列 / hrKv 2 列, route 拦截喂合成载荷)与 `dt-table-face-bg.spec.mjs`。

## 排序引擎单点 (webui/static/shared/sort.js)

- **三态排序全仓单点 `AQB_SORT.setSort`**(scope = 表 id, 见 sort.js 头注): 首击某列降序 → 再击升序 → 第三击复位默认; 状态分两形——经典表落根 data 的 `gk/gd` 字段(主视图四表), dyn 表落 `dtSortState[tableId]`(抽屉变体 + HR 三表), `dtSortCell` 懒建保响应式。表壳 `<aq-table>` 的 `headActivate` 与键盘 Enter/Space 同走此单点, `headAriaSort` 与箭头渲染同源。IP/地址列走 `_dtStrCompare` 的点分数值序(字典序会把 10.10.2.x 排到 10.10.10.x 后)。
- **默认升序键的隐藏前提(2026-11-19 修复)**: `defKey` 非空 + `defDir:1`(默认按某列升序, 如用户表 addr/1、Tracker 06 sev/1)时, 初始 cell 恰为中间态 `(defKey,1)`, 点击默认列旧实现三击全落复位 no-op(IP 列点了没反应)。修法 = 第三击复位前判 `cell.key===defKey && defDir===1` 则翻降序, dyn/经典两分支同口径; 非默认列三态与 defDir=-1/空 defKey 表零行为变化。坑档 `pitfalls/web-ui/sort-default-asc-tristate-noop.md`; 守阵 node 电池 `test_r4_sort_domain` 的 dPos 组 + e2e `drawer-peers-variant-tables.spec.mjs` dt07 点 addr 列。

## 列风格引擎 (webui/static/shared/colstyle.js + app.js + format.js + console_hub.css)

主种子表五维「列风格」(进度条样式 / 进度条颜色 / 速度色阶 / 数值列色阶 / 单位色组, 计划 plans/26-11-20-0009-plan-webui-column-style.html, 2026-11-20 S1-S6 落地): 表头右键菜单入口 + localStorage 引擎 + 四皮肤 CSS 派生映射。**保守默认**: 五维默认档全部 = 现状(跟随皮肤/跟随状态/跟随现状/关/统一), 用户不选 = 零视觉变化、零行为变化; 展示偏好走 localStorage 不进 config.yml(既有拍板), 配置侧零改动。

- **引擎与存储(timeFmt/rowlang 杂交范式)**: 单键 `autoqb.colstyle.v1`(常量 `COLSTYLE_STORE_KEY` / 值域 `COLSTYLE_ENUMS` / 默认档 `COLSTYLE_DEFAULTS` / 容错读 `loadColStyle` 逐字段枚举回落, 全部 app.js 单点; 键刻意不与列集合/时间口径混键 —— 三者读写面互不相干)。读链: state.js `data.colStyle` 注入(load 先于首渲染, 无 FOUC)→ `watch.colStyle` 派发 `_colStyleSyncAttrs` 把五维逐枚写到 `<html>` 的 `data-cs-barstyle/-barramp/-speedramp/-numeric/-units` 属性(colstyle.js 同步单点, **逐字段过枚举闸** —— 状态被绕开写坏时属性面回落默认档, 派生面恒为合法枚举)。写链: 菜单 `headMenuStyle<Dim>` 五写链(menu.js)→ `_headMenuStyleSet` → `setColStyle(dim, value)` 单点(校验 + 同值幂等 + 落盘 try/catch, 隐私模式/配额满降级会话内生效不抛错)。跨标签: lifecycle.js storage **独立监听**(列集合/显示口径/列风格三键生命周期不同, 各自监听)→ `adoptColStyle` **整份采用**幂等(timeFmt 先例, 半合并会各留一半旧值); 标签被冻结/事件丢失 → visibilitychange 回场补对齐一次; beforeUnmount 撤听。首帧同步在 created 即写属性(首帧即终态)。键登记 `ui_prefs.js` PREF_KEYS(进备份 bundle, 登记闸红面在 `tests/test_webui_static_ui_prefs.py`)。
- **判定纯函数家族(format.js 单点, JS 只产档位类名, 永不产颜色值)**: `progBand(p)` 进度 20% 一档左开右闭 + 端点特殊(0/负值 = 空端点 `csb-0`, 1..5 五档, 100% → 终点档 `csb-t`), `progBandClass` 装配; `speedBand(bytes, limit)` 同构 + over 档(>100% 严格大于, 恰 100% 仍第 5 档; 分母读全局 qB 限速单点 `dialogs.js::speedLimitBytes`, 0(不限)/null(未知)/速度 0 一律无类); `numScaleRatio/numScaleAvail/numScaleEta` 三件语义判定(ratio <1→cst-warn ≥1→cst-good / availability <1→cst-warn / eta <60s 且非哨兵 8640000→cst-soon); `fmtSizeParts/fmtSpeedParts` 单位拆分(梯子下沉 `_fmtLadderParts` 单点, 返回 `{v, u, c}` 或 null=零值 dash 形态不拆, c = 单位档类 csu-*; 与 fmtSize/fmtSpeed 输出串逐字一致, node 电池钉死)。渲染消费面 `cellSpeedTone` 三态互斥派发(current→numTone 两档类链一字不动 / off→空串类链源头关闭 / 谱→csp-*)与 `cellNumScaleRatio`(**HR 伴值共存让位**: hrRatioClass 非空不产 cst-*, JS 侧让位而非 CSS 特异度搏斗)。
- **颜色/形状映射全走 CSS(`shared/console_hub.css` 四段渲染面, 共用规则族纪律 —— 四皮肤逐字节相同进 shared 单点, 皮肤 components.css 只留基线色源原位改行)**: 选择器一律 `html[data-cs-<维>] × 档位类` 派生映射(谱×档矩阵, 令牌名严格照计划 §03 谱目录表), 未选档无规则 = 现状级联照旧。四段(行号为 2026-11-20 取证时值, 后续漂移以段注释标题定位): 表头菜单色样 :302-358(「选项的静态预告」, 不吃 data-cs-* 派生映射, 与渲染面不串色) / 进度条两维 :360-558(**`--cs-fill` 机制变量**拆「形态」与「颜色」: 未选谱无定义回落皮肤基线 --st 链, 选谱后条填充与百分比文字同源取色; barstyle 形状维 led/plain 纯 CSS 切换) / 速度+数值 :560-623(谱色落文字, (0,4,1) 特异性压过状态色 (0,4,0) = 显式选谱真出色) / 单位色组 :624-691(xtpl-cells.html 大小/速度族 19 格双 span 拆分 `.cs-v` 数值 + `.cs-u` 单位, 拆分**恒产**「统一」组也拆 —— 单一代码路径不分支, 同色=视觉与现状无差; 单位串携带前导空格, 拼串与拆分前逐字一致, 文本总宽不变)。
- **覆盖面边界(D5)**: 主表四行模型(组/种子/集/对端)同模板自然继承; 辅种/追剧页组展开明细行(tpl-aq-member-cells)与抽屉变体预装配串、状态栏 `.sb-spd` 不纳入; 样式维全局作用于 `.m-progress`(用户拍板, 明细行跟着变形态)。速度维例外: 消费面仅种子行 dlspeed/upspeed 两格, 组行速度格刻意不挂 `cellSpeedTone`(S4 拍板: 组行现状无速度着色, 挂了破坏默认零变化)。
- **守阵**: node 电池 `test_r4_prog_band_boundaries` / `test_r4_speed_band_and_num_scale` / `test_r4_unit_parts_family` / `test_r4_colstyle_engine_semantics`(分档边界/over/哨兵/part≡fmt 逐字/引擎语义, `tests/test_webui_static_r4_node_batteries.py`); 静态守阵 `test_frontend_colstyle_tpl_class_css_paired`(片段模板 ctx-menus.html/xtpl-cells.html 的 cs- 命名空间类名在四皮肤**各自**有效级联面均有定义 —— 既有挂件闸只扫 `<main>` 标签覆盖不到片段模板, 见 conventions/webui.md「片段模板类→CSS 配对」); e2e `e2e/colstyle.spec.mjs` 24 例(引擎面 prism/atlas + 计算色 SKINS_ALL 四皮肤, 计算色全部「现读 CSS 变量真值→通道比对」零写死色值)。
