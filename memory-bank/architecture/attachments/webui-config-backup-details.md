# WEB UI 配置备份 bundle 导出/导入
> 摘要: 单文件 JSON bundle 的四段形态、掩码不出机、先验+临界区导入管线、错误码语义与前端勾选段交互 —— 主档 webui.md 外迁的配置备份细节。
> 触发: 配置备份, bundle, 导出配置, 导入配置, mask_yaml_text, MASK_SENTINEL, unmask_yaml_doc, 残留哨兵, 422, ui_prefs, PREF_KEYS, settings-backup

## 配置备份 bundle 导出/导入 (webui/server/routes/backup.py + config/writer.py + static/shared/ui_prefs.js)

- **bundle 形态(计划 plans/26-11-14-0624-plan-webui-config-backup.html, D1/D5)**: 单文件 JSON, `format: "auto-qb-config-bundle"` + `bundle_version: 1`(常量单点 `BUNDLE_FORMAT`/`BUNDLE_VERSION`) + `created_at`/`app_version` + 四段: `config_yaml`(**掩码化**的 ruamel round-trip 原文, 非重排版树)/ `webui_keys`(与 GET /api/keys 同一 `load_keys_doc`)/ `gtm`(在线时 = `{config, tool_version, captured_at}`, 离线 null; 经 traffic_monitor `_source_status` 单点, 不另起探活链路, D9)/ `ui_prefs`(浏览器偏好**由前端并入**后再落盘, 服务端响应不含该段 —— 与「只存浏览器」裁决一致, D3)。运行时落盘文件(state.json / hr/ / 流量历史 / 删种备份 / 日志 / .bak)全不纳入 —— 导出=「配置」非「整机快照」(D5)。
- **掩码单点 `config/writer.py::mask_yaml_text`**(S1): 判定与 `mask_tree` **同一套常量**(SENSITIVE_KEY_PARTS / TRANSFER_TARGETS_PATH / TARGET_SECRET_KEYS), 不新增敏感键类别; 键名含敏感片段的非空标量与 transfer targets 条目的 password/api_key → `MASK_SENTINEL`, 空值不掩码; ruamel **就地改值**(换新对象会丢挂在键节点上的注释)⇒ 注释/引号/缩进 byte 级保留(测试钉「掩码前后 diff 仅敏感值行」); 空文件/非映射文档回空串(绝不把明文原样回传, 堵 D2 旁路)。掩码失败 500 的 detail **只含异常类型名, 绝不拼 `{e}`** —— ruamel DuplicateKeyError 的异常文本逐字回显重复键明文值(坑档 pitfalls/backend/ruamel-roundtrip-mask-pitfalls.md), detail 进响应体 = 凭据泄敏。
- **两端点契约**: `GET /api/backup/export`(可下载 JSON, Content-Disposition 时间戳文件名; **掩码不出机**, D2 —— 不做明文导出)与 `POST /api/backup/import`(body `{bundle_version?, sections{config_yaml, webui_keys, gtm}}` 只带勾选段; 未知 section 忽略+warnings 向前兼容), 响应 `{applied, skipped[{section, reason}], warnings}`。
- **导入管线(S2, D6 整份替换)**: 先验阶段纯内存 fail-fast 聚合(bundle 文本 1MiB 上限 + 节点/深度上限 + **alias 共享引用拒收** + 段形状闸[缺失/空/非映射 422 拒] + bundle_version 高于本机 422 拒指路升级[R2]) → 应用阶段 `commit_import_yaml_doc` **同一 `_WRITE_LOCK` 临界区闭环**(现读本机旧值 → `unmask_yaml_doc` 哨兵回填[空串/None/哨兵 = 不可 resolve, **聚合 422 逐路径列出**, 绝不把 `"********"` 字面量写盘, R1] → readonly 字段回退 → 临时文件走 `load_config` 与启动同一校验路径 → `find_residual_sentinels` 全树残留哨兵扫描[堵 unmask 不下钻列表位的 R1 旁路] → .bak + 原子写) → `reload_config` enqueue(投命令不在端点干活)。keys 复用 sanitize 原子写; gtm 走 `_ready_endpoint` + PUT 代理(离线 skip/工具 400 原样透传进 warnings, R3 不阻断其余段)。旧版本 bundle 的 config_yaml **原样落盘**, schema 迁移靠启动链 `materialize_schema_migration` 兜底(保存路径不做迁移)。机器相关路径(tool_dir/tool_exe/dat_path/qB 保存路径)原样导入不做字段级回退(D10 —— 路径面无法穷举, 清单会漂移)。
- **错误码语义**: 400 = body/sections/bundle_version 形状错; 422 = 先验聚合失败(逐路径)/bundle 版本高于本机/bundle config_yaml 解析递归溢出/ConfigError/残留哨兵 —— 全部**未写盘**(含 .bak 未创建); 500 = 掩码失败/bundle config_yaml 解析失败/本机 config.yml 坏 YAML 竞态 —— detail 一律只含异常类型名(D2 收口, 见掩码单点条)。
- **前端偏好键双清单与登记闸(D8/D11)**: `ui_prefs.js` 单点双清单 `PREF_KEYS`(进 bundle, 18 键)/ `PREF_EXCLUDED`(明确排除, 7 键), 新增浏览器存储键必须登记其一; `collect/apply` 未登记键/非字符串值忽略+警告。守阵 `tests/unit/test_webui_static_ui_prefs.py`(S4): 递归扫 static/ 全树 .js 收存储键字面量(注释剥离后代码位, 含 const 单键/无插值反引号模板), 与双清单交叉验证 + 死登记红 + 一键双登红 + 负例红绿双验(点分 `autoqb.ui.*` 与下划线 `autoqb_*` 两形态)。
- **前端入口与交互流(S3, D7/D12)**: 设置页 actbar「导出配置/导入配置」双钮(`shared/tpl/settings-detail.html`, 「放弃改动」左, 常显不随脏态隐藏, shared 模板四皮肤 parity)。导出: cfgDirty 提示**不阻断**(导出恒读磁盘, 未保存改动不含在内) → GET → 并入 ui_prefs 段 → Blob 落盘。导入三闸: ①选文件 + JSON shape 检查(format 不符直接报错) → ②脏态确认(未保存改动将丢失, 确认后先 cfgLoad 再走) → ③confirm 勾选+摘要(**机器路径固定提示行恒在**, D10) → POST 只带勾选的服务端三段 → **ui_prefs 本地写回在 POST 成功之后**(失败/取消路径本机零改动, 与结果 dialog「一字未改」文案保真) → 结果 dialog → reload。e2e `e2e/settings-backup.spec.mjs` 6 用例(@fast)。
