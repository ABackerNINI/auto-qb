- **请求级超时单点(issue 26-10-16-0954 + 26-10-16-1303, 2026-10-16)**: 前端**没有**无超时的取数口 —— ① 高层 `auth.js::_request`(经 `api()`)自带 `AbortController` + 15s(`AQB_FETCH_TIMEOUT_S/MS`), 悬挂被翻译成「请求超时(15s)」+ `timeout` 标记; ② 5 处**有意绕开 `_request`** 的旁路(启动分片装载 / 本机免鉴权判定 / 导出下载[二进制流, `_request` 固定按 JSON 解析] / 快捷键密钥读写 x2)统一走低层单点 `shared/fetch_low.js::aqbFetch(path, opts)` —— 它只做「带超时的 fetch」, 返回**原始 Response**(不解析 JSON / 不判 401 语义 / 不加请求头, 由调用方各持自家收口), 超时值 `AQB_FETCH_LOW_TIMEOUT_S` 与 `_request` 同值、两处由守阵钉相等; ③ `boot.js` 在清单脚本之前执行、用不了单点, 自带等价内联超时(`BOOT_PART_TIMEOUT_MS` = 10s, 阻塞首屏故取更短值; 悬挂 → `fail()` 可读占位 + 重新加载按钮, 不再是白屏)。**禁止新增裸 `fetch`** —— 守阵 `test_frontend_raw_fetch_timeout_single_point` 只允许这三个文件出现调用点(`fetch_low.js` / `auth.js` / `boot.js`)。
