- **分层**: `shared/` 是唯一逻辑层(三套 UI 共用 `shared/` 的 app.js 与全部片段); `atlas/`(星图)与 `prism/`(棱镜)/`console/`(控制台)只放模板 shell 与主题 CSS —— 逻辑类改动三套自动生效, 版式类需各自改模板/CSS。
- **毛玻璃纪律(PERF-01, 2026-09-24)**: `backdrop-filter` **不得**挂在全屏遮罩(`.modal-mask`)与常驻吸顶/吸底条(`.topbar` / `.status-strip` / `.statusbar` / `.ce-actions`)上 —— 遮罩铺开时它的 backdrop 里正压着这些条, 嵌套毛玻璃让浏览器每帧回读 + 重复模糊整个视口(星图"点状态栏历史流量卡顿"的根因)。摘掉模糊后底色必须改**不透明**(半透明底靠模糊才有意义, 否则滚动内容会从条下透出来) —— 星图 `--glass` 因此 `rgba(19,26,38,.88)` → `#131a26`, 与棱镜 `--glass: #111e31` 同口径。两套 UI 各自**只允许** `.drawer-mask` 保留 blur(2px)。守阵 `test_frontend_static_bundle_health` 第 13 项(`_scan_backdrop_filter`)钉位置 + 钉两套数量相等(已红验)。
