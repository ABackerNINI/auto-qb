- 两路并行只读取证: ①代码直读(渲染链 qb_traffic_chart.js / traffic_card.js + 供数端 traffic_sample_events.py / traffic_group_assembly.py / traffic_qb.py, 锚 0c2ab2ec); ②历史文档提取(两轮设计 1104/2330、修补 0858/0227、契约换代 0037、拍语义附件、issue 0936/1401、坑档)。
- 结构判断: 0858 显式视口、0037 样本分组列、拍调度内核均成立; 病灶 = 0037「有意偏离」留下的无契约合并缝(per-tick 原始尾点直显 vs 30s 对账组粒度改写, 摊配追溯改写不重发)+ 判定帧无合并门 + rewin/stride 边界无迟滞。三症状全部落在缝上或其边界。
- grilling 两轮六问拍板(D1-D6, 结论单点在计划 §06): 观察面长短窗都有; 取向 = 合并缝结构收口(否决第三次全量重构与最小点修); 尾粒度 = 前端活尾组折叠 + 后端修正帧重发 + GET 装配对齐; 拍门 = 一拍至多一格 + 拆步追平 + 积压 >4 格或真换窗 rewin; 其它症状无清单 S0 一并排查; 建件三件零代码改动。
- 复杂度对照轮(实施前审查): 实测库存(生产 6501 行 / 守卫 11973 行, 1.84:1)+ 成熟方案对照(uPlot 官方 Non-Features 反动画 / qB 环形缓冲无动画 / 24h 窗 57,600 样本 vs 500 点预算)→ 判定「不需要简化重构」; D7 用户拍板取向 A(维持现功能按计划推进); F2 修正帧降级按需; 白捡清理(node 电池拆域 / 附件退役节压缩)挂实施轮, S0 探针增加复杂度使用度证据。
