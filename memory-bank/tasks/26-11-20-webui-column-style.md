## 原始请求

用户提案(2026-11-19, 「WEBUI列风格切换」):

1. 进度条可选择常规进度条 / 或控制台版本的方块控制条;
2. 进度条可选择颜色跟随进度本身而不是种子状态;
3. 下载/上传速度颜色可选择根据限速设置变化颜色;
4. 剩余时间/分享率/活动时间/最近活动/可用性等颜色参考上方;
5. 文件大小/速度单位颜色可选择统一或预设几组不同颜色, 包括大小/总大小/已下载/上传/下载等所有 B/MiB[/s] 类单位。
