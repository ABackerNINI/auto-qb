## 思考过程与决策

- **链路核实**(基线 676f761): 三类触发源(删除 / save_path 变化 / 状态转移)汇于 `_check_missing_files` 单点 —— 修一处覆盖全部; 代表种 2026-09-12 放宽后 errored 可当代表, 恰覆盖重校验改名窗口; 扫描事件驱动, 轮内去重靠 `_missing_scanned_keys`(qbmanager.py:218/:663), 「本轮跳过」= 跳过本次触发事件 → 必须配连续次数上限。
- **取舍**: 采纳 issue 建议修法 1(过渡态容忍)为主体 + 连续 3 次上限兜底残留; 修法 2(移动后按组冷却)降为备选(需持久化状态 + 时序猜测, 升级条件已写入计划 §04); 修法 3(排除校验中)已被现有代码部分覆盖(MOVING 天然不在 complete/errored 集合)。
- **check_filelist 链路不改行为**: CheckAction 决策链 4 失败走 skip、不发 recheck, 最坏后果「跳检白跳一次」, 仅加「疑似 .!qB 过渡态」诊断文案。
- **不加新配置键**: 触发条件本身窄(原名缺失 且 孪生存在); 需要开关时再走 validate_config + schema.py 联动。计数放 store 不落盘(软信号, 重启归零方向保守, 沿用 verified_references 仅内存先例)。
