§03影响面

维度结论
触发条件批次含二进制可评文件的新增/替换(如测试夹具图片/压缩包)且批内无其它可评文本改动 → 实算恒 0, 必现
影响范围评审闸门(check_review_trace)的基哈希机检对此类改动失效; 行数实算与 SKILL.md 口径不受影响; 文本改动面无影响
严重度低-中(窗口面窄: 本仓二进制可评文件稀少; 但属「评完到提交」机械绑定的真实漏洞, 且静默无告警)
