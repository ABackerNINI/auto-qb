03影响面

维度结论
触发条件任何 L2 级配置热重载（改规则 / interval / 曲线 / tracker domains|rules|groups，或新增未列出配置项）—— Web UI 保存设置即常态触发
影响范围exec_history / skip_check_day / recheck_fails / reannounce_ts 等本次运行累计的全部内存状态被回滚；任务队列重建属预期行为（store 记录/分组保留）
严重度高 —— 确定性触发、无需崩溃；skip_check_day 丢失 ⇒ 同日可重复跳检（PT 本地统计再丢一次）；recheck_fails 丢失 ⇒ 坏种子当日最多再校验 3 次
