03建议（可选）

  • 双版本支持口径: 同库同服 5.2.3/5.3（逐端点按探测 WebAPI 版本门控）; 禁开 RAISE_ERROR_FOR_UNSUPPORTED_QBITTORRENT_VERSIONS; 库钉版下限 2026.8.1 不许降。

  • 升级后核对项: server_state 会话速率口径 = 各任务 payload 之和（流量采样/限速曲线读数与旧基线不可直接对比, 重测基线并新建基线切片, 按 AGENTS.md 基线口径）; HR 达标时点因 seeding 计时修正会略变。
