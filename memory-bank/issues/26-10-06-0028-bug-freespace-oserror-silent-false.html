同一函数两种失败语义劈叉: FileAccessError(映射 miss)显式抛 ExprError 停规则, OSError(盘不可读/盘符掉线)静默 return False — 低空间类规则在磁盘故障时静默失活, 与 expr 形式 freespace()(env.py:201 同样 OSError 抛 ExprError)判据不一致。

可达性证据: 配置 freespace 条件 + 磁盘 OSError 即可达; 失败表现是「规则不匹配」, 与「空间确实够」同形(坑档 format-driven-parse 的「恒空同形」同族); rule-system 文档虽记载旧行为, 但与本项目「绝不降级成假值」原则(env.py 头注)冲突。

影响面: 低空间类规则在磁盘故障时静默失活(与正常不匹配同形, 难察觉)
