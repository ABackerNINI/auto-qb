  • 空态 .empty 11 处(认领复验实测 12 处、无图标 4 处, 见 §04「入池计数更正」): 图标 + 文案。其中 4 处连 <svg> 都不写(设置页 HR 三张表 + 变体表 teleport 兜底), 视觉上与其余 8 处不一致; 图标的语义分工(加载中 hourglass / 错误 warn / 空 inbox)也无文档。
  • 空态文案: groups/torrents/shows 三处是四层嵌套三元, 且分支集合已经不同(torrents 少一个"正在构建索引"分支)。

04修复与验证（2026-10-21 认领并修）

复验(认领后第一件事, 2026-10-21 04:20): 现象仍在 —— class="row-pad" 四份 (groups 4 处 / torrents 2 处 / shows 2 处 = 四处三明治各上下一个)、class="empty" 12 处 与入池记录一致; 三处处在 tpl/settings-detail.html 的空态确实只有 <span> 没有 <svg>; 测试侧零守阵(grep row-pad / class="empty" 实证)。

入池计数更正: 入池记录写「.empty 11 处、其中 3 处无图标」, 实测 12 处、其中 4 处无图标 —— drawer 5(流量三态 + 详情加载/错误) / groups 1 / torrents 1 / shows 1 / settings-detail 3 / xtpl 1。两处偏差: ①总数差 1, 入池时把 drawer 的流量三态并作一处数; ②无图标的除设置页 HR 三态外还有 xtpl 的变体表 teleport 兜底(<div v-else class="empty"><span>暂无数据</span></div>), 入池时漏计。 守阵的活性下限按 12 定。

先画清边界再动(§03 点名的前置动作): 四处三明治与十二处空态看似同构, 实则各留了刻意的分歧, 收敛时一律保留 —— ①种子页搜索分支说「无匹配种子」而辅种页面筛分支说 l10nGroup (服务端匹配裁决落在成员不在组); ②追剧页全空是「暂无剧集可展示」; ③drawer 三态的顺序是 pending > error > empty(图标 hourglass / warn / inbox 各自对应), 不能并成一个「空」; ④无图标的那 4 处收敛时按语义补, 不是一律 inbox: 设置页 HR 的错误/读档失败补 warn (d.error / d.readError)、HR 空态补 inbox、xtpl 兜底补 inbox。

实际修法: 两件套各收敛成一份, 与 aq-table / combo-input 同范式 (x-template 注入 body、组件定义在 shared/table.js、app.js 末尾注册) ——

  • 新增单点分片 tpl/list-shell.html: 两个 x-template (#tpl-aq-row-pad / #tpl-aq-empty) + 头注。三份 index.html 的 tpl-manifest 各挂一行 {"src": "/shared/tpl/list-shell.html", "into": "body"} (在 #app 之外, 不当根模板编译, 不多包 DOM 层)。
  • <aq-row-pad :height>: 落地为同一组件挂两次 —— 上占位在 v-for 行之前、下占位在行之后(<aq-row-pad v-if="padTop" :height="padTop"> …rows… <aq-row-pad v-if="padBottom" :height="padBottom">)。§03 建议的 :top :bottom 单实例形状做不到: 占位必须夹住中间的行, 而单个组件实例的渲染结果只能出现在它自己的位置上 (多根片段也只是连续一段)。两者语义完全一致(同 class / 同 aria-hidden / 同 style), 差别只在调用点位置, 故只留一个 height prop。
  • 行本身不收敛: 仍由调用方 v-for 内联渲染 —— 每列表两个占位实例(不是每行), 「不引入逐行组件实例」的性能纪律照旧(计划 26-10-11-1722 §06 风险 4)。
  • <aq-empty :icon :text>: 根元素仍是 div.empty、内部仍是 svg.ico + span —— 三皮肤 CSS 直接按 .empty 与 .empty .ico 选择, 改类名或包一层会让整条空态样式静默失效。组件注释里把图标语义口径单点写死: #i-hourglass 加载中 / #i-warn 出错 / #i-inbox 空(缺省值)。
  • 空态文案: 四层嵌套三元收敛为一份带参 method listEmptyText(hitNoun, noun, noneText) (filters.js::methods), 三个视图各一个无参 computed 薄壳 (groupsEmptyText / torrentsEmptyText / showsEmptyText)。 三分支集合先对齐 —— 种子页补回此前缺失的「正在构建文件索引…」分支, 否则索引构建期会把中间态 说成「无匹配种子」。

守阵: tests/test_webui_static_dom_page.py::test_frontend_list_row_pad_and_empty_single_point —— 形态查(除单点分片外任何模板不得再手写 class="row-pad" 或 div.empty; 两个 x-template 各一处; 组件定义各一处且 template 指回自己的 x-template; app.js 注册各一处) + 活性探针(调用点计数下限 aq-row-pad ≥ 8 / aq-empty ≥ 12, 否则删光调用点会让前面所有断言恒真) + 带参单点必须在 methods 段(落进 computed 会 TypeError ⇒ 空态整块白屏) + 图标语义口径三段文档必须在分片头注里; 有 node 时真跑 15 项语义电池(三列表 × 五场景), 把上面四条分歧逐条钉死。

验证(红验四类突变 + 测试数字): 四类突变全部判红, 均以精确反向编辑还原, 还原后逐字节比对原文件 —— ①某张列表的空态换回手写 <div class="empty"> ⇒ 红, 报「列表外壳两件套回潮: tpl/torrents.html 手写了 1 处空态块」; ②抹掉追剧页「暂无剧集可展示」的分歧 ⇒ 红, 报「列表空态文案 行为漂移: plain/showsEmptyText = "暂无剧集"(应为 "暂无剧集可展示")」; ③删掉种子页一个 <aq-row-pad> 调用点 ⇒ 红, 报「列表外的 <aq-row-pad> 调用点只剩 7 处(下限 8)」; ④把 listEmptyText 从 methods 挪进 computed ⇒ 红。 突变 ③ 第一轮曾误判为绿 —— 活性探针用原始 count 计调用点, 而各分片头注里就写着 <aq-row-pad> 字样(解释收敛缘由), 注释把下限撑满; 已改为计数前剥离 HTML 注释, 剥后实测 row-pad = 8 / empty = 12, 下限与实际值相等, 删任一处即红。测试数字: 新守阵单跑 1 passed; 前端静态三件套 103 passed; commands run test.full 3968 passed / 10 skipped / TOTAL 99%(20467 语句 / 7012 分支, 各 93 单位缺口; 覆盖率闸照过) —— 数字誊至基线切片 memory-bank/testing/baselines/26-10-21-0426-dup-code-audit.md。
