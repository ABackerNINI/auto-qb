§05根因

spec 用 .move-note 单元素定位器, 写于只有一个提示段的年代; 9a010b25 引入条件段后(relocate 启用场景)两段共存, strict mode 判歧义。已排除: 本批 R3 改动(未触 move-dialog)。

§06建议修法
