01现象

C 类(同一事实多表示, 且已见取整分歧)。同一「KiB↔bytes + 0=不限速」单位口径在多处实现: qbapi 的局部 _kib 两份(bytes→KiB, 整除 floor); set_global_speed_limits / set_alt_speed_limits 中 0 if x<=0 else int(x)*1024 共 4 处; 而 curves.bytes_to_kib(bytes→KiB)取「半值向上取整」(注释称略严), 与 qbapi 的 floor 不同。同一换算两种取整方向, 跨 qbapi/curves 双包; 又与 config UNLIMITED_SPEED 三态口径相关。
