03影响面

维度结论
触发条件宿主 os.symlink 「假成功」（不抛异常但不成重解析点）的环境必现 —— 本机 R 盘与 C 盘临时目录、开关沙箱均复现；TMPDIR 不是变量
影响范围①提交闸门被卡死：ship.commit 的前置 test.quick 恒红，任何提交都过不去；②测试信号噪音：本机 test.full 基线数字长期带这 2 条 failed（见基线 26-09-29-2004），掩盖真回归；③生产代码无影响（SEC-1 逃逸判定在真 symlink 环境下逻辑本身未被证伪）
严重度中——不掩盖生产行为，但直接阻塞交付流程；同类风险：任何依赖 os.symlink 的用例在假成功环境都会以「断言红」而非「skip」显形

06建议修法（可选）

方向 + 候选方案 + 各自代价；没有想法就留「待定」，只写方案，不在本报告里实施。

倾向 ①（与项目既有先例一致，改动最小）：_dir_symlink_or_skip 在建链后补 os.path.islink(link) 判定 —— 为 False 即 pytest.skip（与「无权限」同一条路径）， 两条端到端用例在假成功环境自动退化为 skip，闸门恢复绿；真 symlink 环境照常跑端到端。 代价：本机这两条 SEC-1 端到端路径不再被真实验证（靠 test_mapped_escape_containment_logic 的 realpath 桩兜底，它本来就是「无特权环境可跑」的补充）。

实际修法（2026-09-29 认领后实施 = 建议修法 ①）

tests/test_file_access.py · _dir_symlink_or_skip：建链后补 os.path.islink(link) 复核，为 False 即 pytest.skip（与「无权限」同一条路径）， 并把 AttributeError 也并进 except（极老 Python 无 os.symlink）。 同步更新该文件头部「## 测试计划」清单里两条的描述（补 skip 条件）， 并在 memory-bank/testing/file-conventions.md「测试不得依赖宿主环境能力」 补为第 ③ 例 + 一条通用形态（建链类 helper：异常路径之外必须再判 islink）。

    try:
        os.symlink(target, link, target_is_directory=True)
    except (OSError, NotImplementedError, AttributeError):
        pytest.skip(f"无法创建目录符号链接(权限不足): {link} -> {target}")
    if not os.path.islink(link):
        pytest.skip(f"os.symlink 假成功(建出的不是重解析点, islink=False): {link} -> {target}")

备选 ②：不动测试，改闸门 —— 把 .commands/my-commit-flow/.my-commit-flow.toml 里 pytest 闸门的 TMPDIR 换到能建真重解析点的盘；代价是换机器即失效，且与「测试不得依赖宿主环境能力」的约定背道而驰， 不建议。验收标准（修法 ①）：commands run test.quick 全绿且两条转为 skipped， test.full 基线数字更新到 testing/baselines/。
