06建议修法（可选）

方向 + 候选方案 + 各自代价；没有想法就留「待定」，只写方案，不在本报告里实施。

单点 sanitize_tracker_url() 剥 query 中 passkey/token/key/uuid 类参数（保留 path），包住两处日志调用；验收：日志 grep 不到 passkey=。

实际修法已改道（2026-09-22 用户口径）：不按参数名剥，而是只保留主地址 scheme://host[:port]，path / query / fragment 整段丢弃。理由：部分 PT 站的凭据参数不是 passkey，可能是其它任意名称（authkey / token / uid / secret …），参数名黑名单每漏一个名字就漏一个站；而排查只需要「哪个站」的信息，主地址已足够。建议原文保留以存改道原因。
