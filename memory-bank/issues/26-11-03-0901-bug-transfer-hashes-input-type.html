transfer/run 未校验 hashes 为数组: 传字符串会按字符拆成多条伪 hash

直调 POST /api/transfer/run 时 hashes 若为字符串, 会被逐字符当作 hash 处理, 产生 N 条 SOURCE_READ_FAILED 并线性占用主循环; 前端恒传数组故仅直调可达。

01现象

路由对 hashes 只做 [str(h) for h in (b.get("hashes") or []) if h]，未校验必须是数组：传一个字符串时会被逐字符拆成多条伪 hash，逐条走完 SOURCE_READ_FAILED；批次串行占用主循环，条数随字符串长度线性放大。前端恒传数组，故仅直调 API 可达（需 web token）。
