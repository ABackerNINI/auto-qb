03影响面

维度结论
触发条件任何让 test_web.py 先于 test_qbmanager.py 执行的跑法（显式文件顺序 / -k 过滤 / 分片）；全量默认字母序不触发
影响范围仅该用例假红（信号噪音）；同类风险: FakeConfig 其余可变类属性（trackers / delete_tags / add_episode_tags 等）同样被共享, test_web 已知改写 grouping 一处, 其它字段谁先改谁污染
严重度低——不掩盖生产行为, 但污染测试信号; 曾在方案 C W1-W4b 闸门调试中消耗排查时间
