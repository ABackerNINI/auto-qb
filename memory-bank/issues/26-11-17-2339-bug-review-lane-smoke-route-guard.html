§01现象与发现场景

skill 可移植性改造批2 做 rmtree 审计时的相邻观察（当时定性「不属 S3 害类, 记录不改」）：.commands/review/scripts/review_lane.py 的 cmd_smoke 把 CLI 参数 --route 的值原样拼进快照清理路径 _smoke-{route}, 随后的清理对该路径执行 shutil.rmtree —— 这条路径没有过 _guard_snap_path 容器守卫（守卫的调用点只在 start/fresh 两条路径上）。
