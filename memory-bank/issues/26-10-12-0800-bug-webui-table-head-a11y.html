01现象与发现场景

发现场景：计划 26-10-12-0527 U2（用户表三变体表格体接引擎）收口跑守阵，test_drawer_tpl_a11y_and_fetch_error_states 的 sort_variants 段对 07/08/09 手搓排序表头的 role="button"+aria-sort 断言转红 —— 手搓表头已按 D3 拍板退役，排序交互/表头/箭头全归引擎 aq-table。守阵随载体退役改版时核对引擎侧等价物，发现引擎表头从未具备这套 a11y 件套（主视图各表同款形态，属引擎全域既有缺口，U2 改版使其从「变体局部有」退化为「全域无」）。

02证据

引擎表壳模板（取证 2026-10-12 08:00，xtpl.html tpl-aq-table）—— .h-cell 是纯 click div，无 role/tabindex/aria-sort：

<div v-for="col in cols" :key="col.key" class="h-cell"
     :class="['hc-' + col.key, { sortable: col.sortable, ... }]"
     @click="col.sortable && $root.setSort(col.key, tableId)"
     @mousedown="$root.startColDrag(...)"
     @contextmenu.prevent.stop="$root.openHeadMenu(...)">
  <span class="h-label">{{ col.label }}</span>
  <span v-if="col.sortable" class="arrow">...svg 箭头...</span>
  <span class="resizer" ...></span>
</div>

对照旧手搓表头（U2 前的 07/08/09，守阵原 pin，已随 D3 退役）：role="button" + tabindex="0" + :aria-sort="ui.sortDir === 1 ? 'ascending' : 'descending'" 随排序态输出。守阵原断言：re.search(r'role="button"[^>]*aria-sort="|aria-sort="[^>]*data-sort', text)。

03影响面

维度结论
触发条件键盘用户 / 读屏用户操作任意引擎表头（主视图种子/分组/追剧 + 抽屉经典三表 + 桥变体表全部表头）

严重度中（可访问性回归：U2 前抽屉三变体表头键盘可达，U2 后与主视图一起不可达 —— 能力面净减）

05根因（可选）

历史成因：P3-4 件套（报告 26-10-07-0542）只盘点了 drawer 变体的模拟控件，主视图引擎表头当时不在盘点面；D3 把排序表头并进引擎后，变体侧件套随载体退役，引擎侧缺口因此全域暴露。已排除：U2 重写引入的新缺陷（是既有缺口暴露，非新造）。

06建议修法（可选）

方向二选一（待拍板）：

  • A 最小件套：.h-cell.sortable 加 role="button" tabindex="0" :aria-sort + @keydown.enter/space 转发 —— 单点改动全引擎受益；代价：要过 aq-table 相关 DOM 等价守阵（属性新增会破「逐位一致」类断言，需同轮改版守阵）。
  • B 原生化：.h-cell.sortable 改 <button> 载体 —— 键盘天然可达；代价：CSS 重写面大（grid 表头内嵌按钮的样式重置），且 resizer/右键的事件委托面要重核。

建议 A；修法落点在引擎（主视图 + 抽屉同时受益），不属单变体波次。

实际采用（2026-10-12，方案 C，计划 26-10-12-2330）—— 改道 A/B：A/B 用 role="button" 或 <button> 载体，而 aria-sort 只对 role="columnheader"（或 rowheader）生效 —— 挂 button 上读屏会忽略，"读屏不知排序态"那半个 bug 加完 A 依然存在，且列头语义降级成"按钮"。故语义载体改用 role="columnheader"；件套收进表壳组件两方法（headAriaSort/headActivate）单点，grid 与 thead 两模式同轮。建议 A 原文保留如上。

修复后补充

实际修法（方案 C，引擎单一落点）：① src/auto_qb/webui/static/shared/table.js 的 AQ_TABLE_COMPONENT 加两方法 —— headAriaSort(col)（命中列 sortKey === col.key 时出 ascending/descending，与箭头 v-if 判据同源）与 headActivate(col)（grid → $root.setSort(col.key, tableId)；thead → $emit('sort')）。② shared/tpl/xtpl.html：grid 的 .h-cell 加 role="columnheader" + :aria-sort + :tabindex="col.sortable ? 0 : null" + @click/@keydown.enter/@keydown.space 全走 headActivate；.group-head 加 role="row"、.col-drop-line 加 role="presentation"；thead 的 <th> 同补件套。③ 三皮肤加 .h-cell.sortable:focus-visible（atlas 落 css/views.css，因 components.css 顶 700 行 cap；console 落 components.css / prism 落 views.css）。
