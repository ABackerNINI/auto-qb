§01现象与发现场景

发现于计划 26-11-07-1300 P1a 真机实验 E2c 附加变体(2026-11-07, 测试实例 56589/56590, qB 5.2.3 Legacy, 环境2/C盘机)。触发条件: 保存路径与 qB 自身 CWD 同盘符的部署形态。

现象: 整组迁移物理前段全部正常(setLocation 搬移 → 建链接 → 穿透校验 → 离线窗触发),但 daemon 对非 mover 成员的 fastresume 改写被跳过 → qB 重启后非 mover 成员滞留旧根(经别名可读、账面正常、零 recheck),job 静默停在 rewritten,删链门永等,别名永不删。

§02证据

原始 JSON 证据在 tests-real/.work/p1exp/evidence/(gitignored,取证 2026-11-07);要点誊抄如下。

# probe_fr_path_forms.json(qB 5.2.3 实测)
# 与 qB CWD 同盘的保存路径: fastresume 三路径键写相对形态
#   ..\..\..\..\Users\...   (相对便携 profile 目录)
# 跨盘符路径: 绝对形态, daemon 改写正常(E2 主实验 X:=subst 跨盘拓扑双成员改写成功)
# 同盘变体(E2c): daemon 改写按 N10 口径跳过相对形态键
#   → 非 mover 成员重启滞留旧根(经别名可读, 零 recheck), job 恒 rewritten

§03影响面

维度结论
触发条件数据保存路径与 qB 工作目录同盘符(便携/同盘部署)必现;跨盘部署不受影响
影响范围整组迁移收尾链(fastresume 改写→核验→删链)对同盘部署整体无效;成员功能不受损(经别名可读),但收尾永不收敛、别名与 D16 拦截面永久存在。与计划 1300 的嵌套闸门修正无关(先于其存在);生产 26586/16585 是否存在同盘部署待核
严重度中(功能不坏但收尾链静默失效;若生产存在同盘部署则为高)

§04定位锚点

  • daemon fastresume 改写器(grep fastresume + rewrite, relocate 生命周期模块;取证 2026-11-07)· N10 口径的相对形态跳过逻辑在此
  • qB 侧键写入: qBittorrent 5.2.3 源码按路径与自身 CWD 的盘符关系选择 fastresume 路径键形态 —— 本仓控制面只能适配,不能改 qB
  • 实测证据: tests-real/.work/p1exp/evidence/probe_fr_path_forms.json + E2c job 时间线(gitignored,§02 要点已誊抄)

§05根因（可选）

实测口径: qB 5.2.3 对同盘路径写相对形态的 fastresume 路径键,daemon 改写器只处理绝对形态(N10 口径)→ 同盘部署改写整体跳过。已排除: 本仓改写器缺陷 —— 跨盘拓扑下同代码 E2 全链路改写全绿。

§06建议修法（可选）

  • ① daemon 改写器支持相对形态解析(把相对键按便携 profile 基准归一化后改写)—— 修本体
  • ② 迁移预检对「数据盘 = qB 同盘符」部署加 confirm 告知(不静默)—— 防护面
  • ③ 两者兼做;认领时定,不在本报告实施
