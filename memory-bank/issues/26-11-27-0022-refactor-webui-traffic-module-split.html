§03影响面

维度结论
触发条件结构性债务，非运行时触发 —— 任何改动/评审/拆分场景都承担成本（改一处需通读多关注点；评审 diff 无法按域隔离）。
影响范围qb_traffic_chart.js 本体 + 73 处静态钉与 8140 行电池的文件引用 + e2e 动效面守阵；拆分时需同步重锚。
严重度低
不修的代价可控：缺陷史四轮（栅格 ceil / auto range / 隐式视口 / 合并缝）全在行为与契约面，无一次结构事故 —— 结构债未产生实际损害，故挂账而非立即修。
