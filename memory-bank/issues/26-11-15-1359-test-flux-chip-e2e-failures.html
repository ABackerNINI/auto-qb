§05根因（可选）

两条都是断言过时, 实现无回归(复验 2026-11-15, 单跑两条 spec 同位复现后逐条取证):
  • hr-semantics: 报错为 strict mode violation —— .dt01-hr .dt01-chip.is-hr 命中 2 枚 chip(hr-e2e 标签 chip + TV 分类 chip)。抽屉 hero 的 HR 摘要条(shared/drawer_tpl/01-general-hero-tall.js hrStrip)按规则件渲染多枚 is-hr chip(hr_tag/hr_category 各一枚)是设计内行为; 桩自计划 26-11-12-1012 S3 起同时注入 add_tag=hr-e2e(scripts/ui_harness.py)与 add_category=TV, spec(计划 26-11-14-0001 S4, 源于 issue 26-11-12-1037)写的裸 .is-hr 严格定位没料到标签 chip 同场。
  • shape-glow: .f-on hover 断言期望 boxShadow === 'none', 实测拿到 rgb(94, 234, 212) 2px 0px 0px 0px inset = --hr-done(#5eead4)—— 是 .cat-chip.hr-done 的 HR 左边线基线(flux/css/components.css:353 inset 2px 0 0), 不是 hover 辉光; hover 规则的 :not(.f-on) 排除分支完好(fx-mount.css:330-335)。spec 选样 .cat-chip:not(.f-on).first() 撞上 HR 态 chip, 文件头「基线无 box-shadow」的前提已失效。
