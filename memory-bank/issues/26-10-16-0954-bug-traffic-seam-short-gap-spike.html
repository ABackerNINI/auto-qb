01现象与发现场景

怎么撞见的：用户报告「WEBUI 流量图重启后出现重启峰值」，给出 1m 窗截图（屏幕截图 2026-10-16 081655.png / 081707.png）。本轮为只读复现：对运行实例天文件走本仓真实读侧管线（v4_series_points → v4_totals_points → v4_rate_from_totals → v4_grid_obs），并对照截图做像素标定。

现象：08:16 重启后，1m 窗（2s 桶）在 08:16:04 桶出现一颗上行尖峰，达 ~1.25 MB/s，持续一个桶后立即回落；数分钟后再拉接口，同一桶已变成平线（up=122,818）。对照 04:45 那次重启，缝首桶没有尖峰，只有一颗 0 值孤点（另见 26-10-16-0954-bug-traffic-seam-zero-bucket-isolated-marker）。

触发条件：进程在两次采样之间重启，且重启缝同时满足两点 —— 观测覆盖缝 ≤ _V4_SEAM_NULL_S(60s)（判为「重启缝」而不是停机洞），且变化点跨度 ≤ _V4_SEAM_SPREAD_MIN_S(60s)。此时接缝差两头落空：不被断链丢弃、也不被摊配回收，只能整块落进缝后第一个桶。

03影响面

维度结论
触发条件进程重启，且观测覆盖缝与变化点跨度都 ≤ 60s。注意方向是反直觉的：停机越久（>60s）反而走洞判、被诚实丢弃，不出尖峰；几分钟内的正常重启才是尖峰高发形态。
影响范围raw 段窗全部（1m/5m/15m/30m/1h/3h/6h/12h/24h）的缝后第一个桶；agg 段窗（3d+）直映不上差分，不受影响。且是瞬态的：块头刷盘后接缝差被真空标记丢弃，同一桶会变成 0/0。
严重度中。尖峰把「进程不在的那几秒里的真实增长」渲染成瞬时高速，放大倍数 = 缝宽/桶宽（本例 7s 缝打到 2s 桶 ⇒ ~3.5 倍，且绝对值达 1.25 MB/s）；叠加瞬态性后，同一桶在刷盘前后取值不同，用户无法判断哪个是真的。

05根因（可选）

默认「待查」—— 不为填单做分析。有结论才写；不确定就写已排除的假设，不要把猜测写成结论。

已定位（读码 + 真实天文件复算，未跑自动化用例）：v4_totals_points 用两个不同的分母判两件事 —— 用「观测覆盖缝」（相邻观测桶点的覆盖间隔）判是不是停机洞，用「变化点跨度」（接缝锚点到接收点的距离）判要不要摊配。两个常量都写成 60s，而两个判据的方向相反：洞判定是 gap > 60，摊配门槛是 span > max(2×桶宽, 60)。当两者都短（本例 gap 5.5s、跨度 < 60s）时接缝差两头落空 —— 不被丢弃（非洞）、也不被摊配（跨度不够），于是整块 delta 落进缝后第一个桶，2s 桶吃到 2,496,825 B 的增长，按 delta/w 打成 1,248,412 B/s。

已排除：①不是摊配判据②（「锚点之后等值游程全 z 形」）不成立 —— 本例游程确为 z 形；②不是前端渲染放大 —— 后端接口对该桶直接给出尖峰值；③不是写侧记录错误 —— 两条记录的 totals 各自自洽，差值是真实的停机期增长。

06建议修法（可选）

方向 + 候选方案 + 各自代价；没有想法就留「待定」，只写方案，不在本报告里实施。

  1. 让两条门槛一致（推荐）：摊配判据改为「观测覆盖缝 ≤ _V4_SEAM_NULL_S 时无条件摊配」，_V4_SEAM_SPREAD_MIN_S 只保留给「锚点远在窗外」的保守场景。代价：需同步改 test_v4_seam_below_threshold_unchanged 与 test_v4_seam_constants_frozen，并论证「短缝摊配」不会把本可忽略的亚秒抖动摊成可见平线。
  2. 降门槛：把 _V4_SEAM_SPREAD_MIN_S 从 60 降到 2×接收桶宽（2s 桶 ⇒ 4s）。改动最小，但丢了「跨度明显大于桶宽才算台阶」的保守性，抖动场景有误摊风险。
  3. 换层兜底：在 v4_grid_obs 对「缝后首个桶」按缝宽重算速率（缝宽 < 桶宽时不改）。代价：栅格层拿不到缝信息，需要把标记透传下来。

三条都只影响 raw 段窗的缝后首桶。动手前请先与专题计划的拍板面对齐：计划 26-10-15-0829 §07 待拍板 #2 已定「阈值与兜底落为模块常量、未配置化，守阵钉值」—— 改值属于该拍板面的扩大，宜先征得同意。

修复后补充

实际修法（建议修法 1 的落地；未采用 2/3）：core/traffic_grid.py 的 v4_totals_points 摊配判据不再依赖「变化点跨度 > max(2×桶宽, 60s)」单一门槛，改为三条同判：①本点前有 null 标记（磁盘路径重启缝）；②未覆盖段存在（span > cov，活尾路径同几何由此同判 —— 两路径取值一致）；③陈旧长跨度（P2 原门槛面，阈值行为不变的保守支）。覆盖份额口径：step_w = span > cov ? step × cov // span : step（未覆盖秒不归因，只回收覆盖份额；span == cov 时与 P2 原式逐字一致）；份额按累计比例取整（每桶偏差 ≤ 1 字节，不把取整余数堆到接收桶成残留尖峰），余额归接收桶。常量仍为模块常量、值仍 60/60（计划 §07 #2 拍板面不变，未配置化）。
