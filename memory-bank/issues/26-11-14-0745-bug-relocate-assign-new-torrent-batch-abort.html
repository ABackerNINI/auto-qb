§03影响面

维度结论
触发条件重启首轮全量基线的批处理中, 某条种子的 files 取数抛异常 —— WebAPI 断连/超时/5xx(长期无人值守运行低概率可达)或异常形状
影响范围该批其余种子归组中断且运行期不自愈(rid 在批循环前已推进, 失败轮种子已 upsert 进账, 下轮增量/全量重放均不再判 added → 永不补归组; regroup_scope 仅 relocate 建链触发, _handle_save_path_changes 只处理已归组成员) —— 唯一补归组路径 = 本产品进程重启(账本 by_hash 与 rid 均纯内存态, 重启后账本空、rid 起步 0 → 首轮强制全量全判 added 重放; qB 重启不清产品账本, 不是恢复路径); 不丢数据不损账
严重度中(触发面低概率但真实可达, 后果运行期不自愈、恢复靠重启; 大批量重启场景遇断连会放大)
