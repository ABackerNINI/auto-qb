§01现象

真实 docker build 失败：OSError: Build script does not exist: scripts/hatch_build.py —— 镜像构建环境里没有 hatchling custom hook 文件，wheel 构建期报缺。此为 既有事实（Dockerfile 从未 COPY 过该文件进 builder 阶段；重构前钩子在根目录时虽在 build context 里，同样未被 COPY），非本次仓库结构重构引入；但容器构建路径始终不可用。

§03建议（可选）

待拍板二选一：(a) 补 Dockerfile COPY 行把钩子脚本放进 builder 阶段并放开 .dockerignore 对应排除项，使容器构建可用；(b) 维持现状（本地 uv build 正常，容器构建本就不在项目交付路径上）。选 (a) 需评估镜像内 hook 依赖 git 上下文的副作用（BUILD_ID 取 git hash，sdist 两段式下为空——计划 R4 既有观察）。
