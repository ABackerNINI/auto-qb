§03影响面

维度结论
触发条件两键任一写裸 0(cooldown: 0 / notify_cooldown_s: 0,YAML 裸标量或整数 0)时必现:「无效时间格式: 0」校验报错,保存被拦
影响范围example_rules 全部规则的 cooldown 键 + traffic_source.global_traffic_monitor.notify_cooldown_s;「0 = 不冷却(关闭冷却)」语义不可表达
