§06建议修法（可选）

方向：在导入 confirmDialog 的 config_yaml 段加「查看变更」入口 —— 前端把 bundle 的 config_yaml 解析成树，与本机 GET /api/config 现树逐段对照，只读 diff 列表（增/删/改三态）。两个候选：

  • 纯前端对照：零后端改动；但前端拿到的是掩码树（GET /api/config 整树掩码），敏感行 diff 恒「不变」，语义有盲区。
  • 后端只读预览端点（推荐）：复用计划 S2 导入校验管线（掩码 resolve + readonly 回退后返回「将写入的树」），不落盘；diff 语义与实际写入一致。

代价：diff UI 一块 + 树对照逻辑；推荐候选多一个只读端点与金清单登记。
