01现象

现象: 每个对话框都把同一套外壳重抄一遍。

  • 遮罩关窗 10 处: <div class="modal-mask" @mousedown="maskDownSelf" @mouseup.self="maskCloseIfArmed(…)"> 双行, 除关窗方法名外逐字同。
  • 标题头 11 处: 图标 + 标题 + add-dialog-x 关闭钮五段, 差异只有图标 id / 标题文本 / 关闭方法。其中 3 处异形(hist 插了分段钮 / kb-help 用 <h3> 而非 <span> / speed-pop 无遮罩)。
  • 底部动作栏 11 处: ghost + primary 双钮尾, 钮数 1-3 不等。
  • 管理对话框双胞胎: 标签管理与分类管理两个对话框同构约 40 行, 差异只有 6 处(分支值 / 图标 / 数据源 / 分类多一列与一钮 / 分类多一输入框 / 分类无提示行)。
  • 行式键值两套: modal.verdict 与 modal.details 同构渲染, 但 :key 口径(索引 vs 标签)、:title 口径(String vs hint ||)、复制钮有无都不同。

应该是什么样: 外壳一份(aq-modal), 中部走插槽; 行式明细一份。

  • 三段计数: src/auto_qb/webui/static/shared/tpl/ grep maskDownSelf(10) / class="modal-title"(11) / add-dialog-x(9) / modal-actions(11)。分布: dialogs-mgr.html(3) · dialogs.html(2) · move-dialog.html(1) · popovers.html(5)。

  • 行式键值: tpl/popovers.html grep modal-details / modal-detail-row(两处, 取证 2026-10-20 22:30)。
  • 明细台账: R23-A-02 / R23-A-03 / R23-A-08。

03建议（可选）

抽 <aq-modal>(参数 open / close / icon / title / width-class / body-class + actions 插槽), 三段一并收。这样"mousedown 记臂位 + mouseup.self 才关窗"这条 2026-10-03 报障的修复会从"要记住"变成"写不出来"(现在只有 1 处有出处注释, 另 9 处只有代码)。

管理对话框合并为单份 + mgrDef 数据表(行/列/新建字段/提示行由表驱动)。modal-details 合一并顺带修 String(d.value || '') 在 value === 0 时不出复制钮的边界。
