LocalQbClient._session 覆盖签名与三方基类不兼容(override 错误码进豁免面)

core/qbclient.py 覆盖 _session property 返回 requests.Session, 基类 qbittorrentapi 返回 QbittorrentSession(子类) —— 返回类型收宽违反 LSP, mypy override 报错被 [tool.mypy] disable_error_code 豁免; 注解改 QbittorrentSession 即可摘除豁免

01现象

mypy 接入期(计划 26-11-05-0635-plan-type-annotations-mypy)首跑清单里 core/qbclient.py 报 override 不兼容: LocalQbClient._session property 覆盖三方基类 qbittorrentapi.request.Request._session, 基类返回 QbittorrentSession(requests.Session 的子类), 覆盖版注解返回 requests.Session —— 返回类型**收宽**(子类 → 父类), 违反 LSP 签名兼容, mypy 按其报错。运行期行为是**有意设计**(docstring 注明: 覆盖 property 强制 trust_env = False, 对任何时刻新建的 Session 生效), 问题只在注解: 现被 [tool.mypy] 对 auto_qb.core.qbclient 的 disable_error_code = ["override"] 豁免, 属 allowlist 递减面。

02位置

  • src/auto_qb/core/qbclient.py:47 · grep def _session(取证 2026-11-06 02:47)—— 覆盖 property, 注解 -> requests.Session
  • .venv/Lib/site-packages/qbittorrentapi/request.py:912 · grep def _session —— 基类注解 -> QbittorrentSession(取证时 venv 内路径)
  • pyproject.toml · grep auto_qb.core.qbclient —— override 豁免条目所在 override 块

03建议（可选）

覆盖版返回注解改 QbittorrentSession(from qbittorrentapi.request import QbittorrentSession, 与运行期实返对象一致 —— 覆盖体内 session.trust_env = False 后返回的仍是基类构造的 QbittorrentSession), disable_error_code = ["override"] 即可整块摘除(allowlist 递减一格)。修复时先复验: commands run dev.typecheck -- src/auto_qb/core/qbclient.py 确认 override 报错仍在。
