01现象与发现场景

2026-11-03 端口盘点（只读）读 WebUI 生命周期代码时发现：web.port 被占用时，uvicorn 在后台线程里绑定失败，异常路径被吞成一条 ERROR 日志，主程序继续运行；用户看到进程还活着，但 WebUI 实际不可用，且没有任何「谁占了端口 / 怎么改」的可操作信息。配置校验只检查端口范围（1–65535），不检查占用。

触发条件：多 clone 同时用默认 8080、上一次进程没退干净、或用户配置了口被其它服务占用。属于产品侧行为，与测试口方案无关，单独立项。
