01现象

现象: 四族"小控件"各有多份实现。

  • 开关 hb-switch 7 处: "启用/关闭"文字 4 处带、3 处不带; 且同一位置的段开关(xtpl.html 的 section vs settings-detail.html 的分区块)一个带一个不带 = 纯漂移。
  • 折叠段头 hb-sub-toggle 5 处: toggle 签名三种(字符串 key / 组件方法 / 双参数), 键盘契约(role=button + tabindex=0 + keyup.enter, 无 space)各写一遍。
  • 折叠交互 4 种: 原生 <details>(3 处) / hb-sub-toggle + v-if(5 处) / v-show + 钮(1 处, 缺 aria-expanded) / aria-expanded 挂钮而整栏可点(规则 meta)。
  • 分段单选钮 4 套: hist-tabs(内联字面量映射) / qb-tabs(单点属性) / qb-seg(硬编码 3 钮) / drawer-tabs(合并态数据驱动、非合并态硬编码)。

03建议（可选）

① <hb-switch :checked :on-change :text :tone>, 并在组件注释写清"何时该带文字"; ② <hb-fold :open :on-toggle>, 三种签名归一为回调; ③ 折叠立判据(一次性排障 → <details>; 主内容区段 → hb-sub-toggle; 禁用 v-show 折叠与"整栏可点但 aria 挂钮"); ④ <seg-group :items :value :on-pick :cls>, 四套改数据表(CSS 四组规则保留, 视觉确实不同)。
