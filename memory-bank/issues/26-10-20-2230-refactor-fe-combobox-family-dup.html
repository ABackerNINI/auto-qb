01现象

现象: 一个 combobox(输入框 + 自绘候选面板)在项目里被实现了 6 次, 其中 5 处骨架逐字同(仅 5 组标识符不同), 第 6 处(设置页站点搜索层)已明显分叉。

  • 模板侧: .add-input-row + input 五绑(focus / click.stop / input / focusout / keydown) + .add-pop-clear + .pop-menu.add-pop + pop-item(on / data-hi / mousedown.prevent / mousemove) + pop-empty, 约 18-22 行 x 5 = ~100 行。
  • JS 侧: 键盘导航 5 处同骨架(上/下/Enter/Esc/Home/End), "40ms 合帧失焦收层" 3 处, comboHoverIdx(kind, …) 的 kind 是字符串字面量(拼错不报错, 只是悬停高亮失效)。
  • 第 6 变体: settings.html 的站点搜索层用自己的 hb-tr-drop / hb-tr-hit / hb-tr-hint 类族, 还多了分组 chip 与逐项入场动画。

应该是什么样: 状态层已单点(comboHoverIdx 按 key 分派即证据), 缺的只是模板层与键盘层各一处实现。
