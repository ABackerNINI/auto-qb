01现象

现象: 单元格内的构件跨行模型各抄一份。

  • site-chip 3 处(group 行 / torrent 行 / ep 行): 其中 torrent 版缺 search-hit, 且 torrents.html 的行级 class 里也没有它 —— 表现为"种子页搜索时命中的行/chip 不高亮", 属功能遗漏而非纯重复。
  • m-progress 4 份: 百分比算式 Math.min(100, x*100) 手写 4 遍。
  • m-dur / m-ratio 各 2 份且跨文件(xtpl-cells.html ↔ xtpl.html), 连".dur-body = 文字包裹层, 挂外层会随列宽画成整列一条"这段口径注释也各写一遍。
  • tag-chip / cat-chip 各 3 份。
  • 另: rowIcon 在每个 chip 内被调用 3 次(单处 3 次 x 3 处)。

02位置

  • grep site-chip / m-progress / m-dur / dur-body / tag-chip / cat-chip in shared/tpl/xtpl-cells.html 与 xtpl.html(取证 2026-10-20 22:30)。
  • search-hit 缺失对照: groups.html member 行有、torrents.html 行级无。
  • 明细台账: R23-B-07 / R23-B-09。

03建议（可选）

先修功能遗漏(torrent 版补 search-hit, 行级同补), 再谈收敛。site-chip 可以组件化(chip 是单元格内元素, 不违反"单元格必须是行的直接子元素"); 其余几族不建议组件化 —— 抽组件会多包一层, 破坏 grid 的 :nth-child 列对齐。那几族只做两件事: 注释合一(标明另一处逐字同) + 百分比算式抽 $root.progPct(v)(纯 JS, 零 DOM 风险)。

04实际修法

先修遗漏再收敛(按建议段顺序):

  1. search-hit 补齐: torrent 版 chip 与 torrents.html 行级都补 'search-hit': m.hit。取证附注(filters.js:268-270): 种子页行对象刻意不复制 hit 字段(26-10-07「保留即命中, 全亮反而无区分」决策 + 实测 3000 条复制 68ms), 故两处绑定在当前数据流下休眠 —— 本修的实质是 markup 与另两页对称 + 决策反转即自动生效; "种子页搜索不高亮"的现状是已记录的设计意图而非回归, 若要真高亮属产品决策, 超出本 issue 范围。
  2. site-chip 组件化(按建议, 唯一组件化的一族): 新增 #tpl-aq-site-chip 单点模板(xtpl-cells.html)+ AQ_SITE_CHIP_COMPONENT(table.js)+ app.component("aq-site-chip")(app.js), group/torrent/ep 三处 11 行骨架 → 3 个调用点。组件根即 span.site-chip, 渲染 DOM 与旧三份逐字同(e2e 实证)。改道说明(建议原文保留): 台账 R23-B-09 建议的 :m :with-hit 两 prop 未采用 —— 三处调用点都需要 hit 绑定, with-hit 是恒 true 的死配置, 常绑更简; rowIcon 三连调用保留在单点模板内(9 次→3 次同处), 未改 computed —— 组件维持"只贡献模板"契约, 且 rowIcon 的 Date.now() 过期判据与 computed 缓存有语义差。
  3. 百分比算式抽 $root.progPct(v)(format.js AQB_FORMAT 单点): group/torrent/ep/member 四处 m-progress 的 Math.min(100, X*100) 与 (X*100).toFixed(1) 都改调它。文本同取钳后值(progress>1 时旧文本显示 >100% 而条已满格, 本就不一致, 顺带收口; qB 口径 progress≤1, 常规渲染零变化)。
  4. 注释合一: .dur-body 口径注释(FX-02/04 唯一载体)两份互指"逐字同"; m-progress 标注四处逐字同 + 登记不动理由; tag-chip/cat-chip 标注组行与 torrent/member 行的真实分歧点(聚合口径 vs $root.mTags(m); diff 三态 vs 两态) —— 建议段"标明另一处逐字同"对这两族不成立(它们不逐字同), 按实际分歧记。
