§01现象

键位面板展开态(kbFullOpen)有未保存改动时经 kbGuardLeave 的确认弹窗「放弃并离开」, 回调里只做 kbDraftRevert() + 导航, 不复位 kbFullOpen —— 覆盖层展开态残留到下次进入 webui 分区。非脏早退路径(:76)同病已在本轮 issue 26-11-08-0229 #11 修掉(this.kbFullOpen = false), 脏路径是漏网的同形残留。(来源: 子批B 报告, 0229 修复批清单外发现, 2026-11-08)

§02位置

文件 + grep 关键词（比行号稳）；行号要标取证时间。

  • src/auto_qb/webui/static/shared/shortcuts_panel.js:79-89（取证 2026-11-08 16:21）· kbGuardLeave 脏路径 confirmDialog 回调 · grep 放弃并离开
  • shortcuts_panel.js:245（取证 2026-11-08）· kbDraftRevert —— 只回滚草稿, 不碰 kbFullOpen · grep kbDraftRevert()
  • 已修对照: shortcuts_panel.js:76 非脏早退 this.kbFullOpen = false(0229 #11)

§03建议（可选）

照 :76 非脏早退的同式, 在「放弃并离开」确认回调里导航前补 this.kbFullOpen = false。
