01现象

现象: 抽屉变体插件层(drawer_tpl/ + xtpl-cells.html)有三族重复:

  • 三态空帧 + 整帧换帧 12 份: general 三件各 1 次 createContextualFragment, bridge 九件各 4 次。同一"加载态 / 空态 / 错态 + 整帧替换"骨架。
  • peers 判据四件 3 份逐字同: 吸血启发式 / flag 分桶 / 内网判定 / FLAG_META 表。判据漂移会让同一 peer 在三个版式下分桶不同。
  • peer 行渲染器 dt07 / dt08 / dt09: 10 个 col 分支各 30 行, dt07 与 dt08 除 CSS 类名前缀外零差异(注释已自认"同款单元格"), dt09 仅 upspeed 一处特化。

02位置

  • 三态空帧: src/auto_qb/webui/static/shared/drawer_tpl/*.js grep createContextualFragment(取证 2026-10-20 22:30)。
  • peers 判据: 同目录 07/08/09 三件 grep isBad / bucketOf / isLanIp / FLAG_META。
  • dt 渲染器: shared/tpl/xtpl-cells.html grep tpl-aq-dt07-cells / dt08- / dt09-。
  • 明细台账: R21-B(6 项 A)、R21-C(peers 判据四件)、R23-B-05。

03建议（可选）

三族分开处理: ①三态空帧入 reg.helpers(已有 skipUnchanged / paintHtml 等 13 个 helper, 少这一个); ②peers 判据四件提为变体层共用模块; ③dt07/08/09 渲染器接 prefix prop, 不改 CSS 类名(改名会撞三皮肤 CSS 与 _scan_ui_diff_registry)。

③的价值不在省行数: 现在加一个 peer 列要改 3 处, 漏一处 = 该变体该列空白且无任何报错。
