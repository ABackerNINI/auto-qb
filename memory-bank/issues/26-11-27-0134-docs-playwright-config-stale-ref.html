§01现象

playwright.config.mjs 的注释称根 package.json 不能改 "type": "module"，理由是 tests/test_extension_proxy.py 会对 extensions 下的 .js 跑 node --check。但该文件并不存在（重构前就不存在，S2a 迁移时暴露），实际是三个分开的文件：test_extension_proxy_manifest.py / test_extension_proxy_options.py / test_extension_proxy_page_fetch.py。注释引用的文件路径失效，但结论（不能改 type module）本身仍成立。

§02位置

文件 + grep 关键词（比行号稳）；行号要标取证时间。

  • playwright.config.mjs:44（取证 2026-11-27 01:34）· grep test_extension_proxy.py —— 注释里的失效路径。
  • 实际存在：git ls-files | grep test_extension_proxy → tests/unit/test_extension_proxy_manifest.py / _options.py / _page_fetch.py 三件。
  • 在 S2c（e2e→tests/e2e）与 S4（文档回写）中按范围守恒未改——属既有失效引用，非本次重构引入。

§03建议（可选）

把注释里的 tests/test_extension_proxy.py 更新为三个实际文件路径（或概括为「extension proxy 相关测试」），保留「不能改 type module」的结论与原因不变。纯注释改动，零行为影响。
