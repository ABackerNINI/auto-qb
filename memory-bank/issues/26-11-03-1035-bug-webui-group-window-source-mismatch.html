01现象与发现场景

第三次全量 code review S3（区间 bf9920d3..812ad785）评审 _rowWindow 的 W3 坐标系分流时发现。触发条件：任意皮肤切到 group 视图且组数 ≥ ROW_WIN_MIN(200)。与配置无关，四皮肤共用同一份 shared 代码。

  • 抽屉关闭：group 视图窗口化始终不启用，全量渲染所有组行。
  • 抽屉打开并滚动 .drawer-body：主表 group 行切片跟随抽屉滚动，而不是跟随页面滚动。

05根因（可选）

06建议修法（可选）

方向 + 候选方案 + 各自代价；没有想法就留「待定」，只写方案，不在本报告里实施。

推荐 A：给滚动源描述符加显式族标记（如 family: "doc" | "containor"），_rowWindow 按族分流，不再做对象身份比较。代价：改一处描述符契约。

B：比较滚动读数函数同一性（group 与 doc 共用同一个 scrollY 函数），不改数据结构。C：直接按 kind === "drawerContent" 判定，最简但把语义硬编码进引擎。
