01现象

「控制面强制绑定 127.0.0.1」是 docstring 明示的安全不变式, 但 http_host 是可配置键且校验只查非空 —— PUT /config 设 http_host: 0.0.0.0(或任意地址)后重启, 控制面(PUT /config / POST /shutdown / 订阅注册, Bearer 单因素)即对局域网暴露, 而 monitor.token 明文落盘。校验层没有兑现绑定承诺, 属安全声明与实现的契约漂移(配置者即本机用户, 按健壮性缺口记, 不记安全洞)。

来源: 第二次全项目 code review(报告 memory-bank/reports/26-10-30-0237-report-full-code-review-2.html)批T 条目 T-02, P3; 复验留待认领时做。

文件 + grep 关键词（比行号稳）；行号要标取证时间。

03建议（可选）

validate_payload 对 http_host 加回环约束(127.0.0.0/8 + ::1), 或把两处 docstring 改成「默认 127.0.0.1, 可配置放开」并写明 token 风险面 —— 声明与实现必须取齐一头。
