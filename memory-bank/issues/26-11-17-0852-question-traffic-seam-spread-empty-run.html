§05根因（可选）

默认「待查」—— 不为填单做分析。有结论才写；不确定就写已排除的假设，不要把猜测写成结论。

待拍板（非缺陷取证）：两候选语义 —— (a) 空游程 + marked 时 step_w 全额归接收桶是 P2 原意，判据行为正确，只需显式化；(b) 原意是「仅在 z 游程上摊配」，空游程不该走摊配 —— 判据加 run_list and 前置后：marked 下走 :814 得 delta = None 不入账；未 marked 下同样走 :814 else 得 delta = step，经 :816-823 全额入账（cov_ms_pair>0 时）——与案 (a) 的 step_w 全额可能缩放值（span>cov 时 step_w = step·cov//span < step）不同。两案桶值分布不同，需按 P2 承袭语义取证后拍板。

§06建议修法（可选）

先取证 P2 承袭语义（旧实现 / 接缝摊配系档案，如 issue 26-10-16-0954 一族），拍板后在判据处显式化：

  • 案 (a)：条件不改，摊配注释补一句「空游程（marked 直达）时 step_w 全额归接收桶」，把空真值形态写明；
  • 案 (b)：判据改 run_list and all(z for ...)，行为变为空游程时 marked 下 delta=None 不入账；未 marked 下 delta=step 全额入账（cov_ms_pair>0 时，与案 (a) 的 step_w 可能缩放值不同）。

验收：语义有档案级结论；判据与注释对空游程形态不再有歧义；「缝跨标记 + 空游程」路径有单测钉住（按拍板结果断言桶值分布）。
