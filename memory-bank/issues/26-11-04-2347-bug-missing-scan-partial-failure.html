01现象与发现场景

计划 26-11-03-2337 计划级 code review（正确性面）在审 collect_torrent_tracker_hostnames 时发现：该函数对每颗种子的 tracker 查询异常一律吞成空集（except Exception: trackers_info = []），随后 /api/sites/missing 与 CLI --export-yaml 都把「全部查询失败」等同「库里没有未配置站点」。

触发条件：扫描进行中 qB 重启、断连、或 tracker 查询接口批量报错（种子量大时一次扫描仍逐种发请求）；只要 torrents_info() 本身成功而逐种 tracker 请求全失败，就会返回空结果。该语义在 M1 重构前已存在，本计划按「沿用现状」保留，非本计划引入。

03影响面

维度结论
