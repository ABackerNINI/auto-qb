01现象与发现场景

第三轮全量代码评审 S2 · B1（transfer 全链）静态评审发现（2026-11-03，区间 bf9920d3..812ad785，终点 812ad785）。

场景：WEB UI 种子转移（计划 26-10-31-0306 W3，未勾选「保留源种子」）。单种子流水在目标侧加种并验证成功后，调用源 qB 的 torrents_delete 删源任务；该调用没有任何异常兜底。只要删源 API 抛异常（qB 重启中 / 短暂断连 / 认证失效），异常一路冒到 run_batch 的逐种子兜底，结果被记成 FAILED / 未预期异常(...)。

触发条件：仅需源删除 API 单次失败，与平台、种子数量、是否映射路径无关；目标侧是否成功不受影响（此时已成功）。
