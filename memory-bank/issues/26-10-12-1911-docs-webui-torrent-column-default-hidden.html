01现象

TORRENT_COLUMNS 的扩展段注释（以及该列模型的文件头注释）都声明这批扩展列「默认隐藏、按需开启」，但这 13 个列定义里没有任何一个带 hide: true；而列状态的默认隐藏播种只认 hide 标志（loadColState 里的 filter(c => c.hide)），于是种子页首载时全部 28 列默认可见，与注释声明不符。

影响面：种子页表体默认比同口径的辅种表（21 列 / 隐藏 4）、明细表（28 列 / 隐藏 13）宽得多，是「表格太挤」体感的一部分成因；与列选择器改造（报告 26-10-12-1854）独立，故单独立池。对照：辅种表/明细表的默认隐藏列都显式写了 hide: true，种子页这一批漏了。
