01现象

现象: 三套皮肤不是同一结构的三份实现, 而是两份同构 + 一份变形。

  • atlas 缺 3 个字体令牌: 令牌名集 atlas 86 / console 89 / prism 89, 差集恰为 --font-ui / --font-display / --font-mono。后果已记录在 drawer_templates.js 的头注里(该文件的"CSS 令牌白名单"段)。
  • prism 无 dialogs.css: atlas/console 是 style.css → components → views → dialogs 四级, prism 是 tokens → themes → base → components → views 且把弹窗族拆进了 components(modal.strip 7 + hr-detail-table 3)与 views(其余)。
  • 级联序因此相反: prism 的弹窗族比另两皮肤更早介入级联, 同名规则的覆盖方向相反。
  • 机器噪音: 由此产生约 300 行"错位克隆"(atlas/dialogs ↔ prism/views 195 行、atlas/dialogs ↔ prism/components 121 行), 把真重复淹没在错位块里。
