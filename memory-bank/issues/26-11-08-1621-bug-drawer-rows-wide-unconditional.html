§01现象

drawer 明细契约里「下载路径/根路径」两行无条件 wide: true, 且 text 兜底「—」—— 值为空(未配置下载路径等场景)时这两个空值行也各占一个整行折行位, 路径段被两行占位撑高。(来源: 子批C 报告, 0229 修复批清单外发现, 2026-11-08; 纯观感, nit)

§02位置

文件 + grep 关键词（比行号稳）；行号要标取证时间。

  • src/auto_qb/webui/static/shared/drawer_rows.js:108-109（取证 2026-11-08 16:21）· { label: "下载路径", text: d.download_path || "—", wide: true, act: "open" } / { label: "根路径", text: d.root_path || "—", wide: true, act: "open" } · grep download_path
  • 受影响变体: 02(drawer_tpl/02-general-cards-low.js)与 03(drawer_tpl/03-general-dossier-collapsed.js)的路径段同吃这份契约
