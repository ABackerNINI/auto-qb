§06建议修法（可选）

方向 + 候选方案 + 各自代价；没有想法就留「待定」，只写方案，不在本报告里实施。

方向: 用例收尾兜底, 不改生产代码与桩; playwright 错误信息自带的官方口径两候选:
  • A(推荐): stubDisk() 模式统一兜底 —— afterEach 或用例末 await page.unrouteAll({ behavior: 'ignoreErrors' }); 一处兜底同文件全部共用用例受益, 语义 = 忽略结束后的残余路由, 不吞运行中的真实路由错误。

认领时先复验: 单跑两条失败用例确认复现率(竞态类单跑可能绿, 需构造窗口或信任全量轮口径); 修完跑 fast 子集全绿 + 机制红验(摘兜底须能复现)。复用面排查若发现其它 spec 同模式, 一并纳入或另立一件。
