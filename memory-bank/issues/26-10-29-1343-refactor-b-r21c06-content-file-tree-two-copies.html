01现象

「qB files[].name 的 / 分隔路径 → 目录树 + 自底向上聚合（大小/进度/缺口/可用性最低值）」这一套算法在 content 页签有两份完整实现（10 树表、12 树图），而且节点模型已经分叉：10 用 dirs 计数 + hasAv/minAv 布尔对，12 用标量 av（undefined = 无值）。两份不能互换消费，改聚合口径（大小重复计数、可用性取最低、空目录）要改两处。

03分歧点与判定

  • 可用性聚合表示：hasAv + minAv(Infinity 哨兵) ↔ av(undefined = 无值)。语义等价（目录 = 子树最低可用性，全树皆无则「无」）；后者少一个状态位、少一个哨兵，属演化优劣而非业务取舍。
  • dirs 计数：只有 10 有（10:273/339/405 展示「文件 / 子目录」）。12 不需要，但多带一个计数字段对 12 无害。
  • 是否有意分叉：无判据。两份文件头注都自称「与另一版同判据」（12:117「树构建(与 10 同判据, 自包含)」），没有一处注释说明「12 的 treemap 不要 dirs / 不要 hasAv」是设计选择。归类 (b)：无判据漂移，该合；不判 (c)，两份当前都能算出正确结果。

判定：值得做（refactor / light）。① 重复真实（newDir/buildTree/aggregate/findNode 四件各两份，约 60 行）；② 行为可保持 —— 统一到「dirs + 标量 av」的单一节点模型后，10 只需把 n.minAv→n.av、节点 hasAv→n.av !== undefined（10:322 的全局 hasAv 可换成树根判定，等价），12 不动；③ 可验证 —— 静态守阵（全仓只允许一份 buildTree/aggregate）+ 现有 content e2e + 一份 node 语义电池（见下）；④ 收益（聚合口径单点，11 将来并入有落脚地）> 风险（中低：只动 content 两档的树构建，渲染分支不变）。

04收敛建议与验证

在核心层落一个 buildFileTree(files)（含内部 aggregate，findNode 一并导出），节点模型取两份的并集与更优表示：{ dir, name, path, depth, children, size, done, miss, files, dirs, prog, prio?, av? }（av 标量，缺省 undefined；dirs 恒有）。挂载位置按抽屉层既有惯例：reg.peers 是「判据命名空间」的先例，本项可落同类命名空间（如 reg.content）或 reg.helpers —— 服务 2 处（将来 3 处）才够格，不要为单处造 helper；不要做成带一堆 option 的万能函数（withDirCount/withAv 会让调用方又回到「各写一套判据」）。

改法：10 删本地四件 → const tree = H.buildFileTree(files)，渲染处把 n.minAv 换 n.av、n.hasAv 换 (n.av !== undefined)，10:378 的全局 hasAv 改为树根同判定；12 删本地四件 → 同一函数，渲染处不变（n.av 本就对）。11 保持现状（第三算法），本项不并入，只在其头注写明「口径以核心 buildFileTree 为准」。

验证手段：① 静态守阵（tests/test_webui_static_dom_panel.py 抽屉变体族，写法参照 test_drawer_variant_skeleton_single_point 的「逐件对账 + 本地副本零残留」）：drawer_tpl/ 下 function buildTree/function aggregate/function newDir 各 0 命中，10/12 各出现 buildFileTree( 1 次；② node 语义电池（等价性主证据）：把新旧实现在 node 里对一组 fixture files[]（嵌套两层 + 单文件在根 + size 缺失 + availability 为 null/负数/小数 + 空目录路径）各跑一次，逐节点比 JSON.stringify（10 的 minAv/hasAv 先归一成 av），要求全等；③ e2e 回归 tests/e2e/drawer-content-variant-tables.spec.mjs + drawer-content-dt11-sticky.spec.mjs（结构不变，预期绿），另需手工过 10/12 两档的目录行与右侧详情。

收益：聚合口径（大小/进度/缺口/可用性最低值）从两处收成一处，改判据只动一处，11 将来并入有落脚点；风险：中低 —— 只影响 content 两档的树构建，渲染分支与字段语义不变，且有静态 + node 电池 + e2e 三重等价性手段兜底。
