01现象

审计的三个低危加固点（均 Open 未修，证据见 memory-bank/reports/26-09-21-1158 报告 S1-02/S1-03/S1-04）：① SSE /api/events 用 ?token= 查询串兑底鉴权（EventSource 发不出 Authorization 头），反代场景密钥可进中间层日志；② GET /api/config/public 免鉴权可探测「是否处于免鉴权模式」，等于向攻击者广播 CSRF 面开关状态；③ uvicorn 未显式 proxy_headers=False，反代部署在本机时 XFF 可致 loopback 免鉴权误判（此条置信度低，直接连接不受影响）。

03建议（可选）

SSE 改一次性 ticket（POST 换 ticket → EventSource 带 ticket）或 fetch+ReadableStream 消费；config/public 限 loopback；uvicorn.Config 显式 proxy_headers=False（项目自身直连监听）或文档警告反代场景必须关 skip_local_verify。
