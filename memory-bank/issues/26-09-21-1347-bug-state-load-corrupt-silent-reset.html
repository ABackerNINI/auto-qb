修复后补充

实际修法（与建议一致，多两处收口） —— src/auto_qb/mixins/rule_engine.py：

  1. 拆读写：新增 _read_state_file(path) 返回三态 —— dict（可用）／ None（不存在＝首启，静默）／哨兵 _CORRUPT（存在但非法 JSON、非 dict、非法 UTF-8）。 两态必须分开：这正是「损坏被当成首启」的根因。UnicodeDecodeError 一并算损坏 —— 位翻转可能先坏编码而不是坏 JSON 语法。OSError（权限等）不在此吞：那不是内容问题， 静默只会掩盖运行环境故障。
  2. 回退：_load_state 见 _CORRUPT 先记 WARNING（含路径，损坏文件 原样保留、不删），再读 state_file + utils.BACKUP_SUFFIX；读到合法 dict 即用并记 INFO「已用备份恢复（N 个键）」。备份也不可用才返回 {}，并再记一条 WARNING 说清后果 （执行历史与跨日去重丢失 ⇒ 同一天可能重复跳检）。
  3. 自愈写回（建议里没有，但不写等于白恢复）：_write_back_recovered() 把恢复出的内容 写回主文件，且刻意不带 keep_backup —— 否则下次 save_state 会把损坏的 主文件复制成新的 .bak，把唯一一份好备份盖掉。写回失败只告警、不阻断启动（内存里已是恢复出的状态）。
  4. 命名单点化：utils.BACKUP_SUFFIX = ".bak"，写侧 atomic_write 与读侧 回退共用同一常量 —— 两侧各写字面量时漂移不会被任何测试发现（备份写出去没人按同名读回来，正是本 issue 的形态）。

验证方式：新增 3 条守阵（tests/test_rule_engine.py，已同步该文件头部测试计划清单）：

  • test_load_state_corrupt_falls_back_to_bak —— 两版 save_state 造出真实 .bak（不手搓备份文件），再把主文件写成 {not json；断言返回值 == .bak 内容、 WARNING 含「损坏」、INFO 含「备份」，并断言主文件已被修好且 .bak 仍是那份好备份（钉住第 3 条自愈）。
  • test_load_state_corrupt_without_backup_warns —— 无备份时仍是 {}（不阻塞启动）， 但必须留下「损坏」+「备份不可用」两条 WARNING（修复前是完全静默）。
  • test_load_state_missing_file_is_silent —— 首启（文件不存在）不得告警，反向钉住 「损坏 vs 首启」的分开处置，防止后来者图省事把 WARNING 挪到公共路径上刷屏。
  • test_load_state_recovered_writeback_failure_is_nonfatal —— 自愈写回抛 OSError（磁盘满/只读） 时仍要返回备份恢复出的状态、只告警不抛：这条专门钉 _write_back_recovered 的异常分支 —— 它若把异常放出去，「有备份可恢复」反而比「没备份」更糟（启动直接崩），与修复意图正好相反。

配套改动：tests/test_utils.py::test_atomic_write_keep_backup 的备份路径断言改按 path + utils.BACKUP_SUFFIX（不写字面量）—— 一旦有人在 atomic_write 里改回字面量，这条就红。

附带发现（报告「现象」里的第二条，原标「可选，低优先」）—— 已一并修完：新增 _cleanup_orphan_tmp()，在 QbManager.__init__ 里持锁之后调用，清理 <state_file>.<随机>.tmp。两条硬判据：

  • 持锁才清 —— 拿到单实例锁才说明没有别的实例在写；否则删掉的可能是别人正在用的临时文件 （atomic_write 随后 os.replace 失败 ⇒ 状态白丢一次更新）。只读模式 （--export-yaml 等 no_lock=True）因此不做这次磁盘副作用。
  • 只认这一个形状 —— .bak（恢复凭据）、别人的 *.tmp、 空随机段的 state.json..tmp 一概不碰。放宽成"同目录所有 .tmp"会把唯一的退路删掉。

守阵 4 条：只删孤儿 / 目录不可列只告警不抛 / 单个删不掉继续清其余 / 接线守阵（源码里 _cleanup_orphan_tmp 必须出现在 self._lock.acquire() 之后且落在 if not no_lock 分支内 —— 这条防的是后来者把它挪到持锁之前或挪出分支）；并断言二次调用幂等。
