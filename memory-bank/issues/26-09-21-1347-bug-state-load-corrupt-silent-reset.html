01现象与发现场景

触发条件：state.json 存在但不是合法 JSON —— 磁盘级损坏、外部工具/手工改写、或极老版本（原子写引入前）遗留的半截文件。_load_state 捕获 JSONDecodeError 后静默返回空字典，启动继续，无任何日志。与平台无关。附带发现：崩溃落在 mkstemp 与 os.replace 之间会残留 state.json.*.tmp 孤儿文件，启动无清理。
