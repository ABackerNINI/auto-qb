04结论: 根因 / 修法 / 验证 / 遗留

根因(中危 18 条按簇拆三处, 均为「守阵只断言浅层可观测、深层实参/初值不可见」):

  • gf_140/144/147: _group_facts 把同卷判定 same_volume=bool(same_vol) 传给 platform_verdict, 后者再经 cap.file_alias_kind(same_volume) 走硬链接兜底。既有替身只回放 file_kind, 没有「同卷 + 符号链接不可用 + 硬链接可用」组合, 也不断言 facts.same_volume, 实参被 None 化/删除/内层 bool(None) 时 capability_ok 翻假却无人发现。
  • sm_41/43: _step_move 崩溃窗补发 torrents_set_location(torrent_hashes=[job.mover], location=job.dst)。 既有断言只比对 ("set_location", dst), 不看 torrent_hashes —— kwarg 缺省成 None 或整段删除会让 qB 走全局改路径(影响面最大的一类), 属真洞。
  • sj_145(连带 136–145 整簇): _start_job 的 rt 初值 {"last_size": -1, "sample_ts": 0.0, "stall_since": 0.0}。 既有断言只看 issue is True —— 键名大小写漂移或 stall_since 非零时停滞时钟先手开跑, elif not rt.get("stall_since") 分支永远轮不到。
