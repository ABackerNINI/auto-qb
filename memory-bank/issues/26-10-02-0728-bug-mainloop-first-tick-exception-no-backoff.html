03影响面

维度结论
触发条件首轮 tick 抛任意非 StopIteration 异常 (next_*_at 尚未推进); 非首轮是否也快转取决于异常路径是否推进 next_*_at, 待复验
影响范围主循环节拍面 —— 异常场景下 CPU 快速重试 (有 ERROR 日志, 非静默); 与 _reconnect_due 的退避机制不对齐
严重度低-中 (不静默、不丢数据, 但异常风暴时 CPU 空转且日志刷屏)
