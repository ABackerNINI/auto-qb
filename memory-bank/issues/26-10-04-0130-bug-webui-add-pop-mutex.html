01现象与发现场景

2026-10-04 凌晨修「点字段 label 下拉闪烁」第三轮(a7ebbe14 之后)时, 用 Playwright 走查 scripts/ui_harness.py 桩后端撞见: 路径面板(保存路径的候选浮层)开着时聚焦分类 或标签输入框, 路径面板不收, 两个浮层同时悬着; 且路径面板浮在上方会盖住分类字段的 label, 真实点击该 label 被面板拦截(Playwright 判"subtree intercepts pointer events" 拒点重试直至超时)。与三下拉 label 闪烁修复无关(该修复只动模板 label 的修饰符), 属既有 互斥矩阵缺口。

05根因（可选）

互斥矩阵只做了单向: 三个开层方法各管各的, 收 addPathPop 的 开关只写在 openAddPathPop 一侧, openAddCatMenu/openAddTagMenu 漏配(已排除: 失焦收层兜底 —— 会被新字段的 @focus 撤销, 收不到旧浮层; window click 兜底 —— 输入框自身 @click.stop 挡掉)。

06建议修法（可选）

方向一(最小, 推荐): openAddCatMenu/openAddTagMenu 各补两行 this.addPathPop = false; this.addPathHi = -1;, 三浮层互斥补成双向。注意不用动 失焦合帧定时器(直接置 false 即可, 与 openAddPathPop 现有写法同款)。

方向二: 抽 closeAddPopsExcept(kind) 单点, 三处开层各调一次 —— 略重, 但后续加第四个浮层不会再漏。守阵两侧都一样: tests/test_web.py 既有 add combo 守阵补一组"互斥双向"静态断言。
