03影响面

维度结论
触发条件主进程串行跑（-n 0, 含 test.one 定向单文件）且用例使用 tmp_path/临时目录；并行（xdist）与直接 uv run pytest 的主进程行为不同。
影响范围本地调试、定向单文件跑、以及任何不派生 worker 的 pytest 调用会被守卫判红；并行闸门 test.quick/test.full 不受影响。
严重度中 —— 不改业务代码，但会让「串行全绿」不可信：真实副作用越界会被大量假阳性淹没，也可能让定向验证被误当成失败。

04定位锚点

写「符号名 + grep 关键词 + 当时的行号（标取证时间）」—— 代码会漂移，靠符号与 grep 重新定位，行号只是加速项。

  • tests/conftest.py:76 与 :82（取证 2026-11-02 21:42）· grep 关键词 import sidefx / _tmp_bootstrap.bootstrap() · 导入先于自举的顺序点
  • tests/sidefx.py:133-150（取证同时）· 符号 _temp_roots / TEMP_ROOTS / is_temp_path · 模块导入时求值的临时根集合
  • tests/_tmp_bootstrap.py:180-220（取证同时）· 符号 _acquire_instance_root / bootstrap · 设置 TMPDIR 并清 tempfile.tempdir 缓存
  • tests/test_sidefx.py:30（取证同时）· 断言 sidefx.is_temp_path(tempfile.gettempdir()) · 最小复现点

05根因（可选）

默认「待查」—— 不为填单做分析。有结论才写；不确定就写已排除的假设，不要把猜测写成结论。

已定位（2026-11-02）: conftest 先 import sidefx, 该模块在导入时把 TEMP_ROOTS = _temp_roots() 固化为当时的 tempfile.gettempdir(); 紧接着 _tmp_bootstrap.bootstrap() 才把 TMPDIR 切到 R:\Temp\auto-qb-tests\<实例> 并清 tempfile.tempdir 缓存。 ⇒ 守卫手里的临时根集合仍是切换前的系统 temp, 之后所有落在 R:\Temp\auto-qb-tests\... 的 FSDEL/SYMLINK 都被判「临时目录外」。并行闸门不暴露: xdist worker 继承主进程已写好的 TMPDIR（含自举标记）, worker 内 import sidefx 时 gettempdir() 已指向实例根 ⇒ 根集合正确。
已排除: 路径归一化（realpath/normcase 对 R:/Temp 正常）、 is_temp_path 前缀匹配逻辑、sidefx 记账入口本身 —— 单跑 test_sidefx_is_temp_path 的断言 is_temp_path(gettempdir()) == False 已直接证明是「根集合不含当前 temp 根」。

06建议修法（可选）

方向 + 候选方案 + 各自代价；没有想法就留「待定」，只写方案，不在本报告里实施。

方向: 让守卫判定时使用的临时根集合与「当前生效的 tempfile.gettempdir()」保持一致。候选:

  • A（改顺序）: conftest 把 _tmp_bootstrap.bootstrap() 提到 import sidefx 之前。代价最小、语义最直接; 但 conftest 里 _StubRegKey = sidefx.StubRegKey 等模块级引用必须后移, 且要防「以后有人又把 import 提前」—— 可在 tests/test_tmp_bootstrap.py 加一条顺序守卫。
  • B（延迟求值）: sidefx 不再在导入时固化 TEMP_ROOTS, 改为 is_temp_path 调用时按需重算/缓存（或在 bootstrap 末尾回调 sidefx.refresh_temp_roots()）。对导入顺序免疫; 代价是每条路径多一次 gettempdir()（可忽略）以及需处理 TEMP_ROOTS 被外部直接引用的兼容性 （tests/test_sidefx.py 与 conftest 均可能引用）。

两者都只动测试基建, 不触碰业务代码; A+B 可叠加（顺序修正 + 延迟求值）作为双保险。
