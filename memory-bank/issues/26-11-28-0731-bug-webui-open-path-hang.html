§01现象与发现场景

用户在日常使用 WEBUI 时报障：选中一个种子、按键盘 o（「打开目标文件夹」）时偶尔导致 auto-qb 卡死——彻底无响应、WEBUI 断联、无相关 log、无法 Ctrl+C 退出。触发平台 Win11 uv 直跑；右键菜单未测但用户判断后端同源、大概率一致。强行关闭终端重启后，选择同一种子能正常打开。

属于偶发，尚未拿到可重复的触发条件；用户明确要求先找到根因、稳定复现，再确定修复方案是否适用。

§03影响面

维度结论
触发条件偶发未定；已排除「特定种子路径错误」（重启后同种子正常）。嫌疑面：Shell/DCOM 调用挂起（杀软扫描 / Shell 扩展慢 / Explorer 复用窗口）占死 uvicorn worker；置前线程内的 AttachThreadInput/keybd_event 等同步 Win32 调用次嫌。
影响范围进程级：WEBUI 断联、主循环停摆、Ctrl+C 无效，只能强关终端；键盘 o 与右键两个入口共用同一后端端点。
严重度高——用户失去对进程的控制且无自愈路径，只能强杀（state 落盘窗口可能丢失）。
