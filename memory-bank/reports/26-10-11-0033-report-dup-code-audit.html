33.5 六条结论(方法论沉淀)

  1. 机器提名只能当线索, 不能当结论。 jscpd 在 src/ 上 0 克隆(P1)、在 tests/ 上 1.30%(P3)、前端 121 克隆里仅 3 处 JS 字面克隆落到 A 类 —— P2 的 166 项里 163 项(98.2%)来自结构线索 grep + 精读; 反过来工具又是 CSS 面唯一的高命中手段(74 克隆 / 18.55%)。
  2. 三个阶段的重复形态根本不同, 收敛手法不能互相照搬: 后端 = 函数级样板 + 契约层(抽 helper 即可); 前端 = 层内构件级, 有 DOM 硬边界(单元格必须是行容器直接子元素, 组件化会破坏 :nth-child 列对齐); 测试 = 字面拷贝沉积(机器可提名、可机械守阵、阻力最小)。
  3. 收敛必须配守阵, 否则会重新长回来。 P2 的 R23(模板层)是 A 类密度最高的一段(9/23), 恰恰因为它此前做过两轮大收敛 —— 已收敛面复扫的命中率反而更高。
  4. C 类(同一事实多表示)收益最高、也最难。 配置键面 8+1 表示处至今是全局最大单账, docs 两处仍无守卫且已实证漂移。
  5. 审查的副产品价值高于纯重复本身: 4 处实质缺陷面 —— torrent 行与 chip 同缺 search-hit(跨文件功能遗漏) · aq-table 排序箭头双分支口径相反 · 抽屉四页签非合并态仍硬编码(前轮收敛只做了一半) · hrGroupTitle 单点被内联四层三元绕过。
  6. 「入池 → 认领 → 带守阵修复」的闭环在本专题跑通: 69 条全 Done, 每轮修复都附等价性实证(静态赢家表 / 真浏览器像素 / node 语义电池 / e2e), 清偿过程零漂移回流。
