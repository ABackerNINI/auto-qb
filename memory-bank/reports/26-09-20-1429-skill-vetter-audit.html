02唯一红线：Chrome 凭据解密链

🔴 命中「访问浏览器 cookie / 会话」—— 按协议属立即拒绝项

位置：autoclaw-design-capability/审美相关skill/design-skeletons/last30days/scripts/lib/chrome_cookies.py

这是一条完整的凭据窃取链，目的为取得 X/Twitter 会话 auth_token + ct0：

读 ~/Library/Application Support/Google/Chrome/Default/Cookies
  → security find-generic-password -w -s "Chrome Safe Storage"   (取 Keychain 主密钥)
  → PBKDF2-HMAC-SHA1(salt="saltysalt", 1003 轮) 派生 16 字节 AES key
  → openssl enc -aes-128-cbc -d -K <key> -iv "20"*16 -nopad   (解密单条 cookie)

同目录还挂着 youtube / tiktok / instagram / reddit / pinterest / threads / github 抓取器、vendored 的 bird-search（X 客户端）、第二个 cookie 模块 cookie_extract.py，以及读取 OPENROUTER_API_KEY、BRAVE_API_KEY、SERPER_API_KEY、EXA_API_KEY 的配置向导。

风险被两层压制：① 仅 macOS 可触发（Windows 上 ~/Library、security、openssl 路径均不存在）；② 所在目录被同步脚本排除，运行时根本加载不到。属于「git 里的危险品」，不是「活动攻击面」。
