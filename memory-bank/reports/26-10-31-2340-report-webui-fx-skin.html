§01结论摘要

零依赖约束不构成动效表现力的硬上限——MD3 的 token 体系、OpenProps 的「家族 × 强度档位」曲线分层、View Transitions + @starting-style 两个 Chrome 原生特性,足以覆盖 fx 库需要的全部编排能力;JS 侧只留「挂载器 + 重触发跳终态 + 少量 rect 测量」的薄层。7 组 P0 组件每组件产出 5-6 条候选(共 39 条,§05),全部标注属性层 / 时长曲线 / JS 依赖 / reduced-motion 降级,供 showcase 页逐组件挑选。

调研来源(七路):

  • Material Design 3 — motion easing/duration token 规格(m3.material.io,SPA 页面数值经搜索摘要核对);另回溯 MD2 choreography 编排模式。
  • Apple HIG Motion — 反馈/引导/过渡三语义与动效礼仪(developer.apple.com,.md 端点直取全文)。
  • GSAP Eases 文档 — 「家族 × 方向 × 场景」命名法与 UI 场景推荐(gsap.com)。
  • Motion One / motion.dev — stagger 工具形态与快速上手范式(motion.dev)。

§02easing 曲线库(证据快照 A)

A1 · Material Design 3 token 体系(系统级锚点)

tokencubic-bezier适用
emphasized(0.2, 0, 0, 1)大型/表达性过渡默认,轻微慢起快收 + 急收尾,M3 的「签名曲线」
emphasized-accelerate(0.3, 0, 0.8, 0.15)退场专用,元素离开屏幕
emphasized-decelerate(0.05, 0.7, 0.1, 1)入场专用,快起缓收
standard(0.2, 0, 0, 1)小型功能过渡(与 emphasized 同值,语义区分用)
standard-accelerate(0.3, 0, 1, 1)小型元素退场
standard-decelerate(0, 0, 0, 1)小型元素入场
linear(0, 0, 1, 1)进度/倒计时类,不用于空间移动

M2 遗留曲线(大量现成 CSS 抄的是这套,识别用):standard (0.4, 0, 0.2, 1) 即浏览器 ease-in-out 加强版;decelerate (0, 0, 0, 1) 即 ease-out 终极版;accelerate (0.3, 0, 1, 1)。来源: m3.material.io/styles/motion/easing-and-duration/tokens-specs(页面为 Angular SPA,数值经搜索摘要核对)

A2 · easings.net 家族(带精确 cubic-bezier,零依赖直接可用)

家族out 变体in 变体inOut 变体视觉性格
sine(0.61, 1, 0.88, 1)(0.12, 0, 0.39, 0)(0.37, 0, 0.63, 1)最柔,适合缓慢/循环

来源: easings.net(数值为该项目 canonical 值)

A3 · GSAP 体系(映射到 bezier 与场景)

  • 家族 = power1-4 / sine / expo / circ / back / elastic / bounce / steps × in / out / inOut;GSAP 默认 ease 是 power1.out。
  • UI 场景推荐:power1.out/power2.out = 最安全反馈/过渡;back.out = pop-in、按钮点击回弹;elastic.out = 通知/玩趣场景(慎用,弹跳多轮容易腻);steps() = 像素/CRT 风格(retro preset 预留)。
  • slow(SlowMo)/rough(抖动)在 EasePack,core 没有;对应需求用 bezier/linear() 近似。

结论:GSAP 的价值是「家族 × 方向 × 场景」命名法而非曲线本身——曲线 A2 已全覆盖。来源: gsap.com/docs/v3/Eases/

A4 · OpenProps 令牌设计(现成的零依赖 token 层,高度可抄结构)

  • 分级 1-5(不是 1-4/1-6),越大越陡:--ease-1..5(对称)、--ease-in-1..5、--ease-out-1..5、--ease-in-out-1..5。样例:--ease-out-2: cubic-bezier(0, 0, .5, 1)、--ease-out-5: cubic-bezier(0, 0, 0, 1)、--ease-in-out-5: cubic-bezier(.9, 0, .1, 1)。
  • overshoot 家族用 cubic-bezier 可表达:--ease-elastic-1..5 = (.5, .75/1/1.25/1.5/1.75, .75, 1.25)——y2=1.25 过冲强度分 5 档,这就是纯 CSS 弹性。
  • spring / bounce 用 CSS linear() 函数(cubic-bezier 表达不了的物理曲线):--ease-spring-1..5、--ease-bounce-1..5 全是超长 linear(0, 0.006, 0.025 2.8%, ...) 采样点列表。Chrome 113+ 支持——正好命中计划 D5 决策「Chrome/Edge 全特性、其余降级」:Firefox/Safari 声明整条作废,降级写法 = 先写 bezier 再写 linear() 覆盖。
  • 设计启示:fx 库 token 分层照抄「家族 × 强度档位」结构,强度档位直接当 preset(neon 用大档 / glass 用中档 / crisp 用小档)是天然映射。

来源: github.com/argyleink/open-props(src/easing.css;unpkg.com/open-props@latest/easing.css)

B2 · 距离/位移建议

  • 小反馈位移(hover 抬升):1-2px;入场位移:8-16px(元素级)/ 24-100%(抽屉全宽);弹窗 scale:0.96→1(≤4% 差,过大显廉价)。
  • M3「距离越长时长越长」原则:位移每翻倍,时长约 ×1.3-1.5。
  • Apple HIG 额外原则:频繁交互的 UI 不加动效、动效应可被取消(不必等动画播完才能继续操作)——对 torrent 表格行和按钮这类高频交互,时长档取各档下限。

§04编排模式清单(证据快照 C)

C1 · stagger(sequential transition,MD2 choreography)

  • 适用边界:卡片/弹窗内部区块、toast 队列、抽屉内段落这类「少量(≤8 个)表面」的顺序浮现;每项 delay 步进 20-50ms(不是逐项串行),同 duration 同 easing 级联。
  • 明确不适用: torrent 高密度表格行(项目硬约束)。列表刷新的替代:整表一次 cross-fade 或 View Transitions root 默认交叉淡化,不做行级 stagger。
  • 来源: m2.material.io/design/motion/choreography.html(sequential/symmetric/radial reaction);motion.dev stagger(0.1) 工具形态。

C2 · enter/exit 非对称编排

  • M3 系统性结论:入场 decelerate + 时长长,退场 accelerate + 时长短(dialog 400ms 入 / 200ms 出是官方例)。退场快是因为用户已经拿到结果,退场只需「干净消失」。
  • fx 库应把这对(曲线+时长)作为一个「编排骨对」成对定义,而不是两条独立 token。
  • 来源: m3.material.io tokens-specs 及 applying-easing-and-duration(官方例: emphasized-decelerate 入 / emphasized-accelerate 出)。

C3 · View Transitions API(零依赖库里最「免费」的编排工具)

  • 同文档用法:document.startViewTransition(() => updateDOM()) + 共享元素打 view-transition-name;浏览器自动做旧/新快照交叉过渡与 FLIP 位移。if (document.startViewTransition) 一行探测,Firefox/Safari 天然走无动效终态——与计划 D5 降级决策完美对齐。
  • 适合:页签切换(old/new 内容交叉淡化+自定义曲线)、弹窗共享元素放大(按钮→dialog)、列表过滤/排序的行位移(row 移动自动 FLIP)、抽屉开合。
  • 成本/风险:transition 期间整页被快照伪元素盖住,动效 250-400ms 内 UI 不响应指针——必须短;::view-transition-old/new() 可用 CSS 换曲线;大量行打 view-transition-name 有内存成本(torrent 表只在选中的行上打)。
  • 来源: developer.chrome.com/docs/web-platform/view-transitions;css-tricks.com 同文档实践;MDN View_Transition_API。

C4 · CSS scroll-driven animations

  • animation-timeline: scroll()/view() 把动画进度绑到滚动位置,纯 CSS 无 JS。适合:侧栏阅读进度、列表视口边缘渐隐遮罩、P1 的长列表视差。P0 七组组件里基本没有刚需——登记为 P1 工具,不为 P0 强加。
  • 来源: developer.chrome.com/docs/css-ui/scroll-driven-animations;scroll-driven-animations.style;MDN animation-timeline。

C5 · @starting-style + discrete transition(Chrome 117+,纯 CSS enter/exit 的另一半拼图)

  • dialog[open]、.toast 这类从 display:none 出现的元素,@starting-style 提供初始态,transition-behavior: allow-discrete 让 display 参与过渡——零 JS 的弹窗/toast 入退场,退场靠关闭前加 class + transitionend 兜底或 View Transitions。Firefox/Safari 下作废 = 无动效终态,符合降级哲学。
  • 来源: developer.chrome.com/docs/css-ui/transitions-after-display-changes(同类模式);MDN @starting-style。

C6 · animate.css 命名法(变体命名参考,非曲线参考)

  • 结构:animate__ 前缀 + 基类 animated + 家族 × 方向 × In/Out × 强度(Big)/角方向(TopLeft);工具类时长(delay/repeat/speed)用 CSS 变量(--animate-duration)可覆盖——与 fx 两层变体模型同构:data-fx-variant 对应家族+强度,data-fx-preset 对应 duration 全局变量。
  • 可抄:方向词表(up/down/left/right/topLeft/…)、强度分级(Big)、「attention seekers」家族名(pulse/headShake/tada/jello——toast/danger tone 可用)。
  • 来源: animate.style。

C7 · Apple HIG motion 语义(设计哲学输入)

  • 三语义:反馈(跟手势、简短精准)、引导/状态传达、过渡。高频交互的 UI 避免加动效;动效应可取消;移动大对象用 fade 替代长距离滑动;不要用动效作为传达关键信息的唯一途径(reduced-motion 不只是降级,是可访问性要求)。
  • 对 fx 的落点:挂载器(fx.js)设计「重触发即跳终态」语义(动画未播完用户再点击→直接落到终态,不排队);toast 错误类信息必须有非动效冗余(声音/颜色/文本)。
  • 来源: developer.apple.com/design/human-interface-guidelines/motion(全文已读,.md 端点可直取 markdown)。

§06对 fx 库设计的 5 条影响结论

  1. 入/退非对称「骨对」作为一等公民:入场 decelerate + 长(200-300ms),退场 accelerate + 短(150-200ms),成对定义、不成对独立调参(M3 官方例:dialog 400ms 入 / 200ms 出)。
  2. linear() 弹簧降级链:OpenProps 的 linear() spring/bounce 家族让零依赖库拥有纯 CSS 物理弹性(Chrome 113+),降级链 = cubic-bezier 近似在前、linear() 覆盖在后——契合计划 D5「Chrome/Edge 全特性、其余降级」决策。
  3. View Transitions + @starting-style 瘦身 fx.js:这两个 Chrome 特性覆盖了「编排」与「display:none 进出场」两大原需 JS 的场景,fx.js 可瘦身为:挂载器 + 重触发跳终态 + 少量 rect 测量。
  4. stagger 边界规范背书:适用边界以 MD2 choreography 为准——少量表面级联 OK(≤8 个,步进 20-50ms),高密度行禁(项目已有硬约束,与规范一致,showcase 可放心标注)。
  5. HIG 礼仪进文档段:Apple HIG 补的维度是「语义与礼仪」——高频交互不加动效、动效可取消、关键信息非动效冗余;建议进 fx 库 README 段与 showcase 标注体系。

§07方法与局限

  • 方法:纯桌面调研,不开浏览器实测。MD3 easing/duration 页为 Angular SPA,数值经搜索摘要交叉核对;Apple HIG 走 .md 端点直取全文;OpenProps 直接读 src/easing.css 源码;其余按官方文档与 demo 集逐条提炼,逐条标注出处 URL(全文见附件笔记)。
  • 候选数:7 组 P0 组件 × 每组件 5-6 条 = 39 条,满足计划 S1 DoD「每组件 ≥3 变体」。
