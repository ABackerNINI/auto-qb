03机制背景 —— HR 波次引擎 5 分钟版

3.1 账号级对账, 数据落 <site>.json 而非 state.json

HR 状态是账号级的 (model.py:6), 不进 state.json, 落 <data_dir>/hr/<site>.json (store.py:6, 51-62), 一站点一文件一把锁 —— 多实例共享同一份账号事实。三层模型:

  • index —— 站点清单条目 (tid / lane / active / missing_streak / first_seen / last_seen / infohash_v1/v2 …), model.py:84-168。这是「对账底账」: 站点清单长什么样, 引擎就记什么。
  • verified —— 放行记录 (infohash → 来源/时刻), 永续有效 (model.py:250-256, 471)。它不是「核实过没有」的标记, 而是「不受管束」的结论。
  • wave —— 最近一波的元数据 (healthy_ts / 各档状态 / releases_enabled …), model.py:378-431。

3.2 A-B-C(-D) 档位与「波」的生命周期

站点 HR 清单页按考察状态分档: A = 考察中 (LANE_SCOPE) / B = 已达标 (LANE_SATISFIED) / C = 未达标 (LANE_UNSATISFIED) / D = 免罪 (absent)。主循环 (worker.py) POLL_INTERVAL=60s 自唤醒 (260-285), 逐启用站点 refresh_site (287-309)。一波的生命周期:

_refresh_locked 闸门 (service.py:448-496) → _do_wave (500-587) → _run_pages A/B/C 轮流翻页 (589-727) → _process_rows 行处理 (825-855) → _run_downloads 身份登记下载 (873-953) → _finish_wave (968-1097)。

4.3 「依然在拉取」的实测

BTSchool 当日 04:10 / 09:15 / 14:20 三次 refreshed 正常, 精确 5H 间隔, 其间 waiting (还差 10789s) —— 与「依然在拉取」的观感吻合: 取数节奏从未停。

4.4 判定与修复方向

判定: 设计内行为 (高置信)。账号级对账的含义就是: 清单是动的, 随时可能出现新的 A 档考察行, 把本地种子重新拉回管束 —— service.py:6-9 设计说明明文。但「只看做种中」按钮名 vs 实际过滤条件「本地库存在」之间有误导空间。

修复方向: 文案消歧 —— 空态附一句「站点清单仍有 N 行, 点显示老旧种子查看」, 或把按钮名改「只在本地」; 可选增强 (零对象稳态 N 波后自动拉长间隔) 属产品取舍非缺陷 (§10)。

08统一解释 —— 四个独立事实被压进同一界面

8.1 同一根: 对账机器不看本地

S1–S3 三个现象同根: 取数引擎是账号级对账机器 —— 本地种子状态只影响「翻多深」(对象集 / 三停翻), 永不影响「抓不抓」。这是 service.py:6-9 设计前提的直接推论, 不是缺陷。

8.2 四个独立事实, 一块界面

展示层把四个各自正确的独立事实压缩进同一面板, 用户把它们读成了互相矛盾的状态:

8.3 两两配对, 四个症状全部涌现

  • S2 ↔ S3 是同一批行的两列: 站点把种子长期挂 B 页 remain=0 (BTSchool 50 行 / CarPT 17 行) ⇒ 主列表显「在线·已达标」(resolve 通路, resolve.py:342) + 明细表档位「B已达标」; 但行不消失 ⇒ _freeze_terminal 不触发 ⇒ verified 无记录 ⇒ 同一行的「核实结论」列显「未核实」(status 通路)。
  • S1 与 S2/S3 同框: 明细表默认「只看做种中」(实为本地库存在过滤) 把本地零交集的站点滤成空表 ⇒ 显「该站点本地没有 HR 种子」; 而 kv 行「下次拉取」仍在倒计时 —— 「没有种子却在拉」同框成立。
  • 时序量化: 5H 间隔 + 2H 复用窗下每天每站约 4-5 波, 每波 A/B/C 各 1 页 (3 请求), day_count 与日志逐次对平 —— 「依然在拉取」拉的是清单页, 不是种子 (§3.4)。
  • S4 独立: 三列改版 (8cb2da59) 让「失踪 N 波」成为可见文案, 但把 A 档观察期计数器套在了退役行的展示上 (§7.2), 叠加 v3 断层盲窗 (§7.6) 造成「很多波过去而界面纹丝不动」。
