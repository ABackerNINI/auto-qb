01摘要(结论先行)

总结论

四项构思 C1-C4 全部验证成立(经 26-10-04 修订轮口径修正), 且互相咬合成一个自洽的 v3 存储层设计: 采样率下限锁 main_tick、倍数约束降级告警级(C1 管采样密度上限与 qB 请求预算) → 数据按块组织(块头带起时与采样率, 游标推算时间, 漂移行写实测 dt_ms; C1 与 dt 正交分层 —— dt 管时间真值) → 每 flush_interval(默认 600s)批量落盘 → 按天分文件 + 每系列一个 agg.dat 聚合文件(hour/day/month 9 列+cov_s)、读侧按查询窗口只开涉及日期或聚合段(§6.4)。本轮仅出报告不实施(用户拍板), 旧 qb-traffic/ 数据不迁移, v3 直接落 qb-traffic-v3/ 新目录、旧目录留存不读。

构思一句话验证结论关键量化
C1 采样率下限锁 main_tick + 倍数约束(告警级) 实际节拍 = main_tick + 任务线耗时(d̄): 实际节奏 = ceil(I/(main_tick+d̄))×(main_tick+d̄), 有载量化误差 ∈ [0, main_tick+d̄) 且配置时不可知 —— I = k×main_tick 仅空载(d̄=0)时误差 = 0; 时间真值不由节奏预测保证, 交由实测 dt(与 C1 正交分层) 成立(口径修订) 3s 配置实走 4s(+33%, d̄=0)且随负载漂移(d̄=0.5s → 5s, +67%); 倍数失配 → 向上取整 + 告警一次; 1.5s 档不可得(I ≥ main_tick 硬校验, 与 sync_interval 钳制同一纪律)
C2 块 + 元数据头行 + 稀疏 delta 推算时间 块头 B,<start>,<interval>; 数据行 5 列无时间戳 + 可选第 6 列 dt_ms(实测时间差), 游标推算 + 累积漂移超容差才写实测 dt 成立(格式精化, v2 修订) 行宽省 ~11B(漂移行 +5-6B, 空载稀疏占绝大多数); 有效 dt 桶宽使 A2 伪断线根因不可再发生; 纯等间隔定量失效(块尾 ~29s)被 dt 链修正(误差界 tol+取整); 真空/断连语义分离; 聚合迁出天文件入 agg.dat(hour 9 列+cov_s, §6.4)
C3 10 分钟批量落盘 采样 handler 内计时, 每 flush_interval 单次 open("a") + flush + fsync 成立 写 IO 300×↓(2s 档)/20×↓(30s 档); stop() 钩子使优雅退出零丢失
C4 按天分文件按需读 qb-traffic-v3/{global,torrents/<infohash>}/<date>.dat, 窗口→日期集合→只读涉及文件 成立(目录定型) 30d 窗读量 20-60×↓ 且不随历史增长; index.json 机制退役

04逐项设计验证与对比(C1-C4)

4.1 C1 · 采样率下限锁 main_tick + 倍数约束(告警级) 成立(口径修订)

验证结论

(a) 节拍累加是「实际时刻」, 非计划网格(修订轮实证): TaskQueue 最小堆按 next_run 到期弹出, 收尾 next_run = now + task.interval(taskqueue.py:226), 任务只在主循环 tick 边界被执行; 但 next_tick_at = time.time() + main_tick 两处(qbmanager.py:518-527)均在本轮线执行返回之后取值(合并轮还有 :520-521 先同步后任务两行) —— 任务线起始节拍 = main_tick + 上一轮线耗时, 且无追赶无补齐(错过不补跑, run_due 弹积压上限 max_tasks_per_tick=20, models.py:333)。稳态节奏 =

用户补充输入「后续需要月/年视图; 若聚合数据与 raw 一起放按天文件, 访问月/年视图要读所有天文件, 不可取; 将 hour/day/month 这类聚合数据分开存储」, 经子智能体验证成立, 采纳聚合分层方案: 每系列一个 agg.dat 追加混存 + 9 列行型(+cov_s)+ 内存累计器/flush 合流封口 + 文件尾水位恢复 + 逐级派生 + 零新增配置键。布局选型: (A)单 agg.dat 追加混存(采纳: 文件数最少/裁剪最廉/复杂度最低); (B)hour/day/month 分层三文件(否决); (C)按月分文件(否决)。

  • 量化验证(用户判断成立): 现行 v3(hour 行在天文件)下年视图 = 365 个 <date>.dat 冷读, 每文件 open+read+全量解析(raw 行占 99%+ 体量), 解析量 Σ≈536MB(2s 档上界)/15-37MB(30s 典型), 秒级耗时; 解析缓存救不了(驻留 ParsedSeries 含全 raw ≈105 万 RawRow/系列 ≈100-200MB 内存不可接受, 不驻留则每次冷读 365 open)。分层后读 1 个 agg 文件(≈0.45MB/系列/年, 毫秒级); 3d/7d/30d 同步受益(冷读 ≤31 open → 1); 组端点 30d 组图 M×31 → M×1(traffic_qb.py:148-149)。
  • 行型与聚合口径: hour 从 8 列改 9 列(+cov_s=有效时长秒) —— 8 列无法还原有效时长, 部分覆盖小时等权平均有偏; 8 列旧行读侧兜底 cov_s=3600; day/month 同构 9 列(day_epoch=本地当日 00:00, month_epoch=本地自然月 1 日 00:00)。raw→hour 改实测 dt 加权 avg=round(Σ(rate_i×dt_i)/cov_s)(dt_i 取实测 dt 裁剪到 min(dt_i, hour_end−t_i), z 游程槽 rate=0/span 均摊, n 不贡献, cov_s=Σdt_i≤3600; dt_i≡interval_s 时严格退化为现行 traffic_store.py:653-657 公式); hour→day→month 逐级同构(avg=Σ(下级.avg×cov)/Σcov, max=max, totals=级末快照); 派生链严格逐级(day 不从 raw 直聚: raw_window 默认 24h 午夜封口时早期 raw 已在裁剪边缘, cov_s 链只在逐级传递)。
  • 写入与恢复: 内存累计器(hour_acc 采样时逐记录累加、与 dt 链同源; day_acc/month_acc 下级封口时累加)+ 水位 wm={hour,day,month}; 每次 flush(600s)末尾顺序检查完结 → append; 重启扫 agg 文件尾一次 → 恢复 wm + 文件内行重建当日/当月累计器 → catch-up 逐级补算(hour←天文件 raw、day←agg 内 hour 行、month←day 行)append。幂等: 崩溃于 append 后/水位落内存前 → 重启从文件尾恢复不重 append; 撕裂行坏行纪律跳过 + 同 epoch 重复行取最后一行(traffic_store.py:273 口径)。补算窗口 = rollup_window(默认 30d)= 天文件存活期(不是 raw_window): 停机 3d<30d 可完整补算, 超窗 → 天文件已删 → 对应 hour/day 行缺失跳过不标注、图上呈真空(与块间 gap 语义一致); catch-up 必须先于裁剪执行(否则 hour 已封/day 未封/hour 到龄被裁 → 永久丢 day 行)。
  • 退役与保留: 每小时首采样触发点 seal_sweep(traffic_sample_mod.py:497-538)退役 → 裁决 Q4 旧口径(「沿用每小时首采样触发点, 与 flush 合流」)就此作废; 现行读全文件归并重写(traffic_store.py:509-571)退役; tmp+fsync+os.replace(:584-607)退出常规写路径, 仅保留给 agg.dat 按龄裁剪重写(hourly piggyback hour 封口时点, 存在到龄行才重写 + same_content 跳过, ~1 次/天)。除 flush_interval 外零新增配置键(rollup_window/raw_window 沿用, 仍须过 validate_config+schema); hour 行留 rollup_window、day/month 行永久(≈15KB/年/系列, 如需上限预留 aggregate_window, 开放项); 种子淘汰口径微调为「删超龄系列目录(天文件 + agg.dat)」; 未冻结长期不活跃种子: 天文件按龄删、agg 内 day/month 行保留, 年视图仍有其历史。
  • 自洽性(核过): flush / 跨天切块 / 真空判定 / 单写线程 / dry_run 全兼容 —— 聚合 append piggyback flush(每系列每 flush 至多 +1 次 open ≈ 24 次/天); dry_run 同 :482 闸门不落聚合; 解析缓存 mtime+size 键控无漏洞(追加必变 size, 裁剪重写 size 严格变小); 组端点 3d+ 窗读成员 agg 文件, earliest_row_ts 扩展计入 day/month 行; 冻结即聚合自然停更, 无需专门处理。agg 文件单次快读上界需从 205KB 口径(traffic_store.py:707)放宽到 ~1MB(开放项, §8.2)。
