02

用户点名 4 问题核实结论

四条全部确认成立。每条给现象 / 根因 / 证据 / 影响面。

Q1 模板尺寸小、4K 下横向比例失调 确认根因三层叠加

根因①抽屉本体无最大宽度: STATIC/atlas/css/dialogs.css:13-15 —— .drawer-dock 只有 padding: 0 12px, .drawer 无 max-width, 4K 下面板宽 ≈ 视口 − 24px。
根因②变体栅格全部等分拉伸: 所有变体 label/value 容器用 repeat(N, minmax(0,1fr)) 或 flex:1 1 0 铺满面板宽, 无宽度上限 —— 01-general-hero-tall.js:81(4列键值栅格)、:39(英雄行5格 flex:1 1 0)、02-general-cards-low.js:36(3列卡)、 03-general-dossier-collapsed.js:72(3列)、04-…-tall.js:81、07-peers-dashboard-tall.js:64(4卡)。
根因③label/value 用 justify-content:space-between: 单元格一拉伸, 标签推最左、值推最右 —— 「进度 … 100.0%」相距半屏。证据: 01-general-hero-tall.js:83(.dt01-cell)、02-general-cards-low.js:51(.dt02-kv)、 03-general-dossier-collapsed.js:73(.dt03-item)、:103(.dt03-kv)、14-traffic-annotated-split-low.js:43(.dt14-row)。
对照经典链 .f-row 固定标签列 + 值紧随其后(atlas/css/dialogs.css:96 grid-template-columns: 16px 112px minmax(0,1fr) auto), 大屏不散架 —— 变体放弃该口径且零宽度断点(15 个文件无宽度类媒体查询; 仅 dt15 有高度类 @container, 15-….js:33,38)。
影响面全部 15 变体 × 3 皮肤在宽视口(≥2K)下的可读性; 窄视口不受影响, 故用户感知为「4K 下才坏」。

Q2 缺乏图标 确认数据在、经典链在用、变体全丢

事实①经典链字段行图标数据本来就存在: drawerGeneralSections() 每行带 icon 字段(STATIC/shared/drawer.js:1178-1247), 经典渲染消费它(shared/tpl/drawer.html 的 <use :href="r.icon"> + icoTone 着色, drawer.js:1255-1270)。
事实②general 三变体全部丢弃该字段: grep r.icon 在 dt01/02/03 零命中; dt01 的 cell() 只渲染 label+value(01-general-hero-tall.js:205)。 变体里 svg 仅限 chevron / 动作钮 / 空态图标(如 01:197-198,212)。
事实③traffic 两变体完全无 svg: 13-traffic-chart-led-tall.js、14-traffic-annotated-split-low.js grep <svg 均为 0 (仅 dt15 摘要条有一个非交互迷你走势SVG)。未引入图标库; 状态 / 速度 / 大小等字段行在变体里均纯文字。
影响面变体行扫读效率与视觉层次整体低于经典渲染; 修复成本低 —— 数据源无需改动, 变体侧消费即可。

Q3 收起状态不随鼠标点击切换种子 确认守卫复用错位

根因鼠标单击行 → onTorrentClick → _kbFollowDrawer()(STATIC/shared/selection.js:154-171), 这是唯一「面板开着点哪行换哪行」通道。 但 _kbFollowDrawer 首行守卫收起即返回, 且在换目标逻辑之前: STATIC/shared/drawer.js:848 if (this.drawer.collapsed) return;。 收起态点任何行, _switchDrawerTarget 永不执行, drawer.hash 不变 → 头部标题与收起摘要条继续显示旧种子, 观感「点了没反应」。
旁证不一致三处: ① 双击 / 右键详情 / Enter 走 openTorrentDrawer, 重置 collapsed: false(drawer.js:658) —— 同是「点种子」, 单击不动、双击强制展开; ② 收起态点页签会先展开再切(drawer.js:806-807), 设计者知道此问题但只修了页签; ③ 收起态点行还会把 kbCursor 落到新行(selection.js:156), 用户随后点展开钮时面板突然跳到之前点过的行(drawer.js:1007 展开补跟), 行为延迟不可预期。
设计意图该守卫对键盘 ↑↓ 是有意设计(drawer.js:847 注释「收起态跟随暂停」), 但鼠标路径复用同一守卫未区分。
影响面收起态下的全部鼠标单击跟随; 衍生危害见 P2-3。

Q4 「高 / 矮 / 收起」被当成模板名 确认档位后缀混入展示名

根因15 个变体注册 label 全部把档位后缀写进展示名, 如 01-general-hero-tall.js:308 "英雄行·键值栅格(高)"、 06-trackers-table-collapsed.js:346 "增强表格(收起)"、15-traffic-adaptive-collapsed.js:196 "紧凑自适应(收起)"(共 15 处, 见各文件 register 块)。
传导链该 label 直接进变体切换器下拉: drawer_templates.js:153-154(options() 透传 label) → drawer_templates.js:205(dtTplOptions) → shared/tpl/drawer.html 两个 <select class="dt-select"> 的 <option>。用户在 UI 看到的选择项就是「……(高)/(矮)/(收起)」。
判定档位(tall/low/collapsed)只是物理形态描述, 同一变体三档语义都收进去了(各文件头注声明「收起/矮/高三档语义全部收进本变体」), 把档位写进名字冗余且误导, 应改描述性命名。
影响面全部 15 个下拉项的文案; 与 P3-7(160px 截断)叠加后长名更难辨认。
§2 小结

Q1 / Q2 / Q3 / Q4 —— 四条全部确认成立, 无一误报。Q1 与 Q4 相互独立; Q3 另有衍生危害(P2-3)。

03

新发现问题

本轮摸排新发现, 按严重度分档: P2(应修, 有用户可见危害) ×3 · P3(随增强批次) ×5。

P2 档3 条 · 用户可见的功能危害

P2-1变体渲染抛错后该页签整幅空白, 无用户可见降级P2
现象变体渲染函数抛错时用户看到纯空白页签, 须手动切回「经典」。
根因drawer_templates.js:291-299 _dtRender catch 里只 replaceChildren() 清宿主 + console.error; 此时经典包裹层因 drawerTplSel.<tab> !== 'classic' 仍隐藏(drawer.html 经典层 v-show)、.dt-host:empty 又 display:none(drawer_templates.js:189) —— 两条退路同时断掉。
证据drawer_templates.js:291-299 / :189 / shared/tpl/drawer.html(经典层 v-show)。
影响面全部 15 变体 × 3 皮肤; 任何一次渲染期运行时错误即触发。
P2-2宽表格变体横向滚动位置每轮重渲染可能归零P2
现象窄窗口下使用宽表格变体时, 5s peers 轮询数据一变, 用户的横向滚动位置丢失(跳回最左)。
根因dt07/08/09 固定列宽 grid, 最小宽 ≈ 990-1000px(09-peers-density-collapsed.js:72-74 列合计 988px; 08:95,99; 07:129,133), 窄窗口 / ≤900px 固定全屏态(atlas/css/dialogs.css:37-41)必然横向滚动; 但重渲染只保 scrollTop 不保 scrollLeft(09:303-304,325、08:334-335,366、07:470-471,492), sig 变即整帧重建。dt06 同理(06:226-227,268)。
影响面dt06 / dt07 / dt08 / dt09 四个表格型变体, 触发条件 = 数据轮询刷新 + 用户停在非最左横向滚动位。
P2-3收起态摘要条展示陈旧种子数据P2
现象收起态点 N 个行均不换目标, 44px 摘要条的「状态·进度·速度·比率」持续描述旧种子, 误导性强于「没反应」本身。
根因Q3 的衍生危害面: 守卫(drawer.js:848)挡住换目标 + drawer.js:347-360 默认摘要读 drawer.detail(旧数据)。
影响面收起态摘要条; 与 Q3 同一改动点可一并修。

P3 档5 条 · 体验 / 一致性 / 可维护性

P3-4可访问性: 变体可交互元素不可键盘达P3
现象折叠组头纯 div + click 委托(01:210-215 data-fold; 02 card-h 同构); 排序表头 cursor:pointer 的 span/按钮无 tabindex/role/aria(09:81-84 .dt09-sortable); 核心层注入的折叠/关闭钮无 aria-label/title 仅 svg(shared/tpl/drawer.html 两个 <button class="drawer-fold/drawer-close">; .dt-select 反而有 aria-label)。
影响面变体子树对键盘 / 读屏用户不可操作。
P3-5fetch 失败与空列表在变体里同形态P3
现象首拉失败只 toast(drawer.js:755-756,792-793), 变体仅按 loading + 列表长度分支(04:236-246、06:219-230、07:462-474), 失败后显示「暂无 tracker / 暂无已连接用户」式空态而非错误态。
影响面fetch 型数据组(trackers / peers)的变体展示; 用户误以为「真的没有」。
P3-6变体间折叠态「换种子是否重置」口径不一致P3
现象content 组 dt10/11/12 明确「按 path 记账, 换种子重置」(提交 1fece608 与文件注); general 组 dt01/02 折叠态是模块级 ui.folded 跨种子保持(01:32 + render() 无 hash 重置) —— 换种子后上一部的折叠选择延续, 与 content 组相悖。
影响面跨变体行为一致性; 需先拍板统一口径再改。
P3-7变体头选择器 160px 上限截断长名P3
现象drawer_templates.js:180 .dt-select { max-width:160px }, 长 label 下拉收起态被截断。
影响面变体切换器; Q4 改短命名后可一并缓解。
P3-8变体重复代码: 16 份文件各自复刻同一套骨架P3
现象16 份文件各自复刻 size/dur/present 工具、滚动自保、sig 比对、wire/destroy 骨架(如 01:107-109 vs 03 vs 02), 且 dt02:135 / dt03:139 用行内 style 拼布局。
影响面可维护性: 核心层可再抽公共 helper, 否则后续改动 15 处锁步。
