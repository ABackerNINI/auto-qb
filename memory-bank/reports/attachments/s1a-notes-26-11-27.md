基线: 分支 feat/traffic-seam-hardening @ 21bb0be0(本地态, 未 commit)。计划 26-11-26-2333 §03 F3 + §04 S1「F3 必做」半程。

## 1. 设计裁决: 组锚从「窗内序号」换「时间桶」

S0 症状③根因 = k>1 组界按「窗内第 [i*k,(i+1)*k) 个样本」划分, 锚随窗沿平移 → 每 30s 对账整列换格(报告 26-11-27-0526: 30m 窗 dropped≈407-410)。INV-3「对账只补精度不改形状」要求已闭合组点跨请求逐位不动, 因此本批的核心改动是组锚换代, 不只是加标记:

- **k=1(1m/5m 窗)**: 逐样本直通, 组键 = 窗内序号, 语义逐位不变(每样本恒一点, 抖动不合并)。
- **k>1**: 组键 = `group_bucket(ts, stride, si) = floor(ts / (stride*si))`(`traffic_group_assembly.group_bucket` 单点)。桶相位 = epoch 原点, 桶宽 = 组距标称 k×si = meta.interval_s 同源积。桶界是纯 ts 函数, 与窗位置无关 → 同批样本恒同桶, 已闭合桶点跨 GET 逐位不动。
- **窗首跨界桶只收窗内成员**(窗外同桶样本弃入, g=None 同旧面): 桶值随窗沿左移单点重写一次后随桶整体出窗 —— 有界改写(每次对账 ≤1 点), 不再整列改写。stride 翻 k = 桶宽整体重对齐 = 真换窗语义(前端 rewin, 计划 F4)。
- 缓存与冷算等价保持: 缓存 respond() 的桶成员集 = 冷算「窗内样本按自身 ts 归桶」逐位同(k>1 桶界 bisect 现推; eps 带破例位 dips 落窗内时转逐样本归桶精确面 —— bisect 界在非降破例处不可靠, 实测发现并修复, 防御路径生产不可达)。
- 尾组恒真值语义、摊配/差分链/标记判定、存储格式、配置键、采样周期、per-scope SSE 传输面、GET payload 形状: 全部不动。无新配置键(未动 validate_config/schema; typecheck 未跑 —— 未触配置面)。

## 2. 输出形状: 脊柱 + 活尾组

- `GroupAssemblyResult` 增 `tail_open: bool`(默认 False): 末个真值点(totals 非 None 的最后一点)是否活尾组点。k>1 且有组点 → True(进行中桶, 组内已落样本真实均值); k=1 直通窗与无组点窗(纯缺口/空列)→ False。
- 组闭合迁移: 后继样本落入新桶 → 旧桶点即成脊柱(t/值逐位不变), 新桶点为活尾组点。points/payload 仍为合并升序全列(脊柱 + 末真值点 = 活尾), 前端 S2 据此二分; 响应 payload 零变化, 现行前端无回归。
- 预算口径注: 桶命中数 ≤ 样本数, span/W ≤ 500 保证不变; 稀疏数据(节律 ≥ 桶宽)每样本独桶, 点数 ≤ n_samples + marks; 边界 ±1 由前端 564 点 cap 吸收。

## 6. 给 S1b 等价电池的接口

输入: 同一批 V4Slot 槽流(含缺口/台阶/断连/摊配)喂两侧。GET 侧 = `assemble_group_points`(或缓存 respond); 事件折叠侧 = 前端 F1 公式的 Python 复刻: 按桶宽 W = meta.interval_s(= stride×si 同源积)折叠, 桶键 = `Math.floor(ts / W)`(与 `group_bucket` 同式, IEEE 754 double 逐位一致), 桶值 = Σ(样本速率×dt)/Σdt。断言: 折叠脊柱点列 == GET 列去除末真值点的真值点集(t/dl/up 逐位); 折叠活尾组点 == GET 末真值点; tail_open 两侧一致; k=1 窗两侧逐样本直通恒等。缓存侧已有五元组逐位等价主阵(test_traffic_group_cache, _assert_bitwise 已扩 tail_open)可作模板。
