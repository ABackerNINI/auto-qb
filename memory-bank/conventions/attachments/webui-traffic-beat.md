## 流量图节拍动效 (2026-11-14, 计划 26-11-12-1139 S0-S4 八批落地)

- **落点与总纪律**: qB 口径 Canvas 流量图(三挂点共用)的同画布装饰面 —— 装饰走 uPlot `drawAxes`(网格后、系列前)与 `draw`(系列上)钩子, **不新增 canvas、不新增独立 rAF 循环**(装饰帧挂节拍调度器循环内); 运行期状态本体存图记录 `u._qbBeat`(拍时钟/视口偏置/双轨 tracks/ticks 冻结缓存), 不进 Vue state(同 `u._qbLimits` 款); 模块级纯函数(公式/时间线/状态机/粒子运动)与带副作用的方法域分离, 纯函数被 node 电池直接真跑。
- **节奏内核(1s 硬上限与周期自适应)**: 单点公式 `beat = clamp(period × 0.4, 320, 1000)` ms(`_qbBeatMs`, 面板 beat 展示值 computed 复用同一单点); period 取 `_qbPollMs()` 实算值夹取 `[1.5s, 600s]` **每拍重算**(适配任意合法 `sample_interval_multiplier`, 跨窗换档天然跟随); 段内时间线常量单点 `_qbBeatTimeline`: impact 窗 `0.12×beat` / 左移窗 `shiftRatio × beat`(校验域 [0.2,1] + 判定帧再防御夹取) / 数值收敛窗 `0.12-0.60×beat` / 次区 tail `min(period - beat, 2000)`(600s 长窗也只铺 2s, 非常驻) / 动画总长 `max(shiftRatio × beat, 0.60×beat)`。调度器 = 判定帧起每拍 rAF(`_qbBeatStart/Frame/Converge/Cancel`): 判定帧 = 续拉快路 `setData` 真值落袋时刻**同帧**起拍; **零变化拍与不可见位移拍瞬时落地零 rAF**(静默); 页面隐藏时钟自然冻结(rAF 不触发), 恢复后从当前显示值接续不重播, 单帧 dt 上限 100ms(掉帧不跳变过半拍); 打断/销毁/换肤三路终止即落真值不留半帧(rAF 先摘)。
- **L0 左移底座(视口偏置, 不是谱面式横移)**: 定长滚动窗口 + auto x range 下整图每拍瞬时左移一格是跳变主因; L0 = 真窗口立即 `setData` 落袋(数据/锚/tooltip 全程真值, 不改 x 轴语义、不重建 xs) → 判定帧 `setScale("x")` 把视口摆回旧位置 → 每帧 `dx = (1 - easeOut(clock/shiftMs)) × dx0` 归零 → 收敛帧 `setData` 交还 auto range(已读 uPlot 1.6.x vendor 源: setScale 只写一次 pending 表, 无持久手动 range)。**0.75px 最小可见位移**: 单格像素 < 0.75px 的拍直接瞬时落地(24h 长窗 2880 点恒瞬时, 省每帧全量路径重建); 量不到绘图宽按 0 = 瞬时, 宁可不动画不可错动画。**y 轴定档成对**: 每笔 `setScale("x")` 必配 `setScale("y")` 全窗真值档位(偏置可视窗会逐帧重推 y 垂直跳), 纯数值收敛帧先钉 y 再 redraw; **动画期 x 轴 ticks 冻结**(判定帧挂 pending, 收敛帧清冻结后一次性刷新); `shift="instant"` 为对照档(跳过过渡, 数据语义不变); 系统减弱动效(reduce)强退瞬时落地(I7)。
- **L1 双轨状态机(语义色守恒/独立状态机/主导轨仲裁/预算两轨合计)**: 每轨 `{prev, target, shown, delta, level, live}` 独立推进且与 L0 解耦(零变化/缺口/关闭时零反馈但左移与数值收敛照常); delta 分档 `<0.5%` 静默 / `<5%` Lv.1 / `<30%` Lv.2 / 其余 Lv.3(常量单点可调), 分母用可视下限(y 轴顶值 × 0.02)防 prev 近 0 爆炸; 缺口轨 `live=false` 静默不插值, 死轨复活直落真值不造斜坡; `shown` 以显示值接续禁回跳(I3); 数值插值曲线单点 `_qbFxCurve`(out = easeOut / linear, 未知回落 out), **判定帧冻结进 anim.easeF 拍内不换式**(唯一例外条款, 中途换曲线会位置跳变), ease 只作用于 L1 数值收敛, L0 与装饰运动曲线恒 easeOut; 主导轨仲裁 `_qbFxLead` = argmax(delta), 优先非缺口非静默轨, 恰等取 up, 双轨皆缺口/静默 = null(零装饰); 三策略 `_qbFxAlloc`: both(默认)各发半套各 ≤16 / lead 全套 ≤32 / merge 两轨 y 中点一次, **合计恒 ≤32**(I9)。Lv.1 也发粒子(基数 16 × 密度, 计划原型"Lv.1 不发粒子"未采纳, 用户拍板维持现状)。
- **视觉引擎 V 图层顺序与预算(I6/I9)**: 图层顺序单点 `_QB_FX_LAYER_ORDER = bg > grid > geometry > neon > curve > anchor > hud`(绘制落位读 vendor 1.6.32 源实证): bg 恒由 CSS 提供零铺色(G7), geometry+neon 挂 drawAxes 钩子(网格后系列前), curve = uPlot 系列原生(**装饰永不压曲线, 描边恒语义色一行不动** I10/D1), anchor 挂 draw 钩子, hud(DOM tooltip/图例)零触碰。预算**两轨合计**(I9): 粒子 ≤32 / 碎片 ≤16 / shadowBlur 上限 neon 10 / glitch 14 / calm 0, 同帧辉光(blur)描边 ≤3 次(环外圈 ≤2 + 光带辉光 1, 锚辉光用无 blur 低透明外圈替代) / 冲击窗 ≤0.55xbeat(t > 0.55xbeat 冲击类叠加层零绘制, tail 光点例外每轨 ≤2) / N 层回落 ≤0.33xbeat / 两轨末点 y 间距 <26px 反馈按比例缩小(下限 0.4, 不合并不取消) / 横向细线条 ≤12 条/帧 / 束体 ≤23 条绘制指令、束体+切片 ≤28 / **整块全高 fillRect 恒 0**(G7/I11; 梳齿与 glitch 切片是 1px-6px 级例外, 不构成铺底); L0 的 setScale 全量路径重建帧成本计入同一预算; 无可见变化的帧不提交(逐帧提交守卫)。
- **N 霓虹元素层与背景静态(I11/G7)**: 白名单(可着 Lv 色的局部元素) = 判定线短亮段 / 环外圈 / 粒子外圈 / 锚辉光 / lvBadge / 光带辉光(bandHalo); **黑名单(恒与静态基线逐像素一致, 引擎零触碰)** = 两条曲线 / 绘图区背景 / 右缘背景 / 网格 / tooltip / 图例 / 限速虚线 —— 曲线描边恒 `--today-up/down` 现读与图例同源; 背景/右缘恒由 CSS 提供(G7), 删除整块 Lv 色呼吸与右缘入场地带铺色。Lv 色表 = 常量(Lv.1 蓝 `#7AD9FF` / Lv.2 金 `#FEFFA9` / Lv.3 品红 `#FF6BD6`): 四皮肤无 `--qb-lv*` 令牌(落表前已核查), canvas 热路径不逐帧 getComputedStyle; 分级反馈色不属皮肤语义色面, 换肤不变。`cfg.neon` 独立开关。
- **T6 综合表现层(唯一交付形态, D25)**: T2 光带 + T3 粒子 + T4 扫描束 + T5 分级 + T1 霓虹(N 层)五层组合; **无模板选择器**(面板不提供模板下拉, T1-T5 是 T6 的构成要素非独立交付)。扫描束双相位六层: 亚像素 1px 硬核(`x + 0.5`) + 六层晕(34/24/16/10/5/2.5px, alpha 递进逼近高斯) + 双侧 ±1.6px 青/品红色散 + 5 段非对称彗尾 + 梳齿 3/5/7 条 + 1px 回声, 纵向亮度按**两轨末点 y 包络**起落(贴近 <0.08 合并单峰), 束体逐帧 ≤23 指令、零整块 fillRect, 束体 clip 放宽到画布右缘(判定线右侧留白是"滑入"可见域), 段尾自含 save/scale。**回声受控行程(R7/D19)**: `span = clamp(0.22 × 绘图宽, 100, 200)` px 且不超绘图宽, 相位窗 0.18-0.45×beat 匀速, 距离衰减 `pow(1 - d/span, 0.85)`, `d >= span` **几何硬停零绘制**(不是 alpha 逼近 0), alpha 恒 ≤0.20; 整幅扫掠 `full` 仅对照档(存储白名单放行, **生产观感降格为 auto**, D19 不交付)。横向线条(R6): 撕裂切片 2/3/5 条 + 梳齿 3/5/7 条按 lead 等级, 长度/带宽随 delta 增长, 随机源 = `hash01(拍序号, 槽位)` 确定性伪随机 + 分层采样(**同拍逐像素冻结、可复现可断言**; random/fixed 仅对照档, spawn 判定帧定型拍内不闪), 色池故障色为主(Lv 色 45% / 品红 35% / lead 语义色 20%, 语义色为主会与曲线同色隐身); 切片右端 0-18px 伪随机缩进, 微震 ±3px 正弦(抽屉入场 rAF 追赶在途时暂停)。T5 分级联动: 环边数 3/6/8、束宽感 ×0.9/1/1.1、梳齿/切片条数, **grade 层关恒 Lv.1 色**(分级只留边数/粒子数不再变色); T6 内束强度 ×0.78。
- **数值面板(右键非模态浮层, R8/D20-D28)**: 载体 = `.fx-panel` 非模态锚定浮层(固定宽 320 不可拖拽 resize, max-height 兜底 + 正文内部滚动, `overlay_fit` 单点钳位 + 图右缘内缩 8px), 开合 120ms 仅 opacity、reduce 零动画。**不是 `.ctx-menu`**(无 role=menu/方向键导航, 不参与菜单选择器统计, `e2e/drawer-merge.spec` 的计数不受影响)、不是 aq-modal(无遮罩, 边调边看)、不是抽屉二级页(会替换宿主销毁图)。**入口 = 图宿主独立 `contextmenu`**(冒泡阶段 `preventDefault + stopPropagation` 拦住 drawer.html 的 `@contextmenu.prevent`; **不改 menu.js 早退判据** —— 改则整片正文右键出半残菜单并撞 strict-mode 计数); 右键监听只 openFxPanel **零开关语义**(D24 终态: 总开关唯一入口在面板, 计划早期"右键勾选项"方案已废弃)。落点 = `.drawer-dock` 的**兄弟**节点(flux 的 transform containing-block 会把 fixed 后代劫持成相对抽屉定位)。**Alt 看穿**: `fx-alt` = opacity .22 + `pointer-events: none`, keydown/keyup 同处理器按 `e.altKey` 写态, blur 复位防卡看穿态。**Esc** 走面板根 `fxEsc` 处理器(面板可见才 stopPropagation + preventDefault + fxClose, 焦点在面板控件内也只关面板; 退场过渡期 visible 已翻 false 放行该次 Esc 给 document 退栈链; 禁 `.stop/.prevent` 修饰符 —— 修饰符阻断先于处理器表达式会吞掉放行次)。**收层登记七处**: lifecycle 点空白名单 + Esc 退栈链(紧跟 drawerMenu 之后, 后开先关) + dialogs_meta escBusy + shortcuts `_kbOverlayBusy`(追加名单**末尾**) + closeDrawer + drawerTab + drawer_store 换 kind 收口, 另加 IntersectionObserver 兜底(观察 `.qb-chart-host`, 开面板装/关面板断; **不挂 `_qbChartDestroy`** —— 换肤也走 destroy→build 会误关)。根节点 `@click.stop`(`_onDocClick` 无 contains 判断, 漏了拖一下滑杆面板就关)。
- **字段表与 `autoqb.ui.qbFx` 契约(D22/D23)**: 15 可调项 = 节奏 `impact` / 视觉 `palette`/`particles`/`neon`/`tail` / 位移 `shift`/`shiftRatio` / 双轨 `dual` / 高级(默认折叠) `ease`/`tear`/`echoSpan`/`layers.band`/`layers.particles`/`layers.scan`/`layers.grade` + 总开关 `enabled` 置顶 + 版本 `v: 1`; **只读两项** `period`/`beat`(状态行实算显示) —— 采样周期涉及后端与数据文件, 面板不提供任何写入入口(观感 vs 采集边界)。存储 = 单键 `autoqb.ui.qbFx`(与 qbWin/qbYAxis 同族), **四皮肤共用一份**不分 scope(观感偏好), 不进 `config.qb_traffic` 不写后端; 读校验逐字段 clamp / 枚举白名单 / 严格布尔, 未知键丢弃, parse 失败/非对象/`v !== 1` **整体回落默认且不清键**(防旧值复活); 写只在用户操作时 `try/catch` 静默失败; 「重置为默认」写回默认值**不删键**; 「复制配置片段」输出可直接粘贴的 `QB_FX_DEFAULTS` 形状。量纲统一: `impact`/`particles`/`shiftRatio` 显示 0-100、存储 0-1(换算单点在面板处理器), 校验按存储量纲 clamp。配色只用中性令牌 + `--accent` 滑杆, **禁 `--today-up/down`**(曲线语义色, 冒用让人以为滑块调的是某条曲线)。枚举白名单: ease out/linear, palette neon/calm/glitch, shift smooth/instant, dual both/lead/merge, tear linked/random/fixed, echoSpan auto/100/150/200/full(`full` 是对照档, 存储放行、观感降格 auto)。绘制热路径只读普通对象 `window.AQB_FX_CFG`(watch 整对象 JSON 克隆同步), 不逐帧读 Vue。
- **预览一拍六条语义(D21)**: ① 不动窗口(不 shift 不 push, `dx === 0`, xs 与 `u.scales.x` 逐帧不变) ② 假 Δ 贴近真实量级 `clamp(0.18 + 0.35 × 粒子密度, 0.10, 0.50)`(相对量, 方向按轨 up 减 / dl 加), 不固定拉满 Lv.3 ③ 连点重启(previewToken 递增令旧帧失效, 从当前显示值接续, 不排队不叠加) ④ 真值抢占(真拍判定帧先取消预览, 真值 setData 已整组落袋; 真拍主区在途时预览忽略) ⑤ 不写 store(零持久化副作用, 末帧还原真值显示面 + 双轨状态机复位真值对齐, 假值不留痕, 连点早退角点同走还原核心) ⑥ 同预算(spawn 与绘制走真拍同一条代码路径, I9 不放宽)。生效门 `cfg.on === true`(reduce 与 enabled=false 无动效可预览); **不自动循环**(仅显式点击, 无定时器 —— 与真拍撞车且真假不可辨)。
- **状态行与镜像**: 状态行 = 「采样 X s · beat Y ms · 上次真实拍 Z」+ 预览在途后缀「· 预览中」; period/beat 由 computed 现算(复用 `_qbPollMs`/`_qbBeatMs` 单点); 「上次真实拍」三态(— 无真拍 / X s 前 / 时钟未追上钳 0.0), 真拍判定帧只写面板浮着的当前 scope 的墙钟镜像(fxBeatAt), 1s 步进时钟仅面板开着装/关面板摘; 「· 预览中」是翻转沿写的显示镜像, 动画态本体在图记录。
- **守阵路由**: 电池 + 静态钉 = `tests/test_webui_static_dom_panel_traffic.py`(节奏公式/时间线/状态机/预览语义/预算/收层七处/持久化三件套, node 纯函数电池直接真跑); 真机面 = `e2e/traffic-fx-panel.spec.mjs`(冒烟链/收层顺序/Alt 看穿/四皮肤 rect)与 `e2e/traffic-fx-frames.spec.mjs`(左移连续性/预览拍帧级, CPU 敏感子集)。已知坑: **Vue 生产构建(vue.global.prod.js)对模板缺失处理器完全静默**(警告仅 dev 构建) —— 接线断掉没有任何运行时报错面, 模板绑定静态钉是唯一闸; 守阵捕聚合原文含注释, **注释不得复现守阵锚串原文**(见 pitfalls/testing/static-guard-mutation.md)。
