# pitfalls — 陷阱、风险点与文档漂移

> 摘要: 全库陷阱总索引 —— 按**你要做的动作**选类, 再进类索引选主题文件; 改代码前先在这里定位一次。
> 触发: 改代码前, 踩坑, 事故, 禁令, 判别法, 不知道读哪份

> **读法**: 条目以"规则 / 判别法"为主, 统一字段化 —— `触发` / `判别` / `处置` 三必填, `守阵` / `复发` 选填;
> 括注日期的是历史事故沉淀(结论已固化进代码与测试), 叙事只用于理解"为什么"。
> **精简时只压叙事, 不删规则与判别法。**
