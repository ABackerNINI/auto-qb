# 并行跑测试 (pytest-xdist)

> 摘要: 并行**能用且现在值得用** —— 全量串行 19.4s → `-n 4` **5.0s**(约 4×)且波动极小; 但 sidefx **台账在并行下不打印**(拦截仍在, 已用注入实测), 覆盖率与串行差 1 个单位。
> 触发: 并行, 并发跑测试, xdist, -n, 加速, 多进程, 跑得慢, 闸门, 端口冲突

### 结论: 建议采用 `-n 4`, 但先把三件事说清

- **触发**: 想把全量从 ~20s 再压下去(2026-09-23 实测, 本机 32 逻辑核)。
- **判别**(每条都 `1191 passed + 1 skipped`):
  | 方式 | 耗时 |
  |---|---|
  | 串行 | 19.37 / 19.38 / 19.81 / 20.16s |
  | `-n 2` | 8.56s |
  | **`-n 4`** | **5.00 / 5.06s** |
  | `-n 8` | 4.88s |
  | `-n 16` | 6.82s(**更差** —— worker 启动开销开始占主导) |
  | `-n 4` + 覆盖率 | 7.61s(TOTAL 仍 91%) |
  ⇒ **`-n 4` 是甜点**(约 **4×**)。⚠ **别用 `-n 16`** —— 全量才 5s, worker 启动本身就成大头。
- **⚠ 为什么"早先不推荐、现在推荐"—— 判据变了, 别把旧结论当定论**:
  同日早些时候测出 `-n 4` 在 **15.94 ~ 209.77s** 之间乱跳(中位 ~31s, **尾部比串行最坏还差**),
  当时的结论是"闸门保持串行"。根因是**底层文件操作被拦截**(见 [perf-measurement.md](perf-measurement.md))——
  多进程只是把那份争用**放大**。系统层排除项修好后, 同一命令变成 **5.00 / 5.06 / 4.88s**, 波动几乎消失。
  ⇒ **"并行划不划算"取决于底层是否串行; 底层一改就要重测。**
- **两个必须知道的行为差异**:
  ① **sidefx 台账不打印** —— `pytest_terminal_summary` 在 worker 上不产出终端输出, 收尾那张
     「副作用台账 … 越界 0 条」**在并行跑里看不到**; 但**拦截没丢**(见下一节)。
  ② **覆盖率与串行差 1 个单位** —— 并行 `7729 语句 / 623 未覆盖 / 219 分支` vs 串行 `622 / 218`
     (TOTAL 都是 91%) ⇒ 若把并行设成默认, **覆盖率基线要重刷**。
- **处置**: ①`-n 4` 作**本地快车道**; ②要把它当**闸门**之前, 先补**控制器侧台账聚合**
  (worker 经 `workeroutput` 回传, 控制器在 `pytest_terminal_summary` 汇总打印), 否则"越界 0"这个日常信号
  会**静默消失**; ③需要把 `pytest-xdist` 加进 dev 依赖(属入库改动)。

### ❗sidefx 守卫在并行下**只失去打印, 没失去拦截** —— 别误判成"守卫瞎了"

- **触发**: 想用 `-n` 换速度, 但担心安全网失效(2026-09-23 实测)。
- **判别**(用仓库外插件 `R:/Temp/auto-qb/plugins/pa_violate.py` 故意往仓库根注入一条越界删除):
  · 串行 → `AssertionError: 测试期出现 1 条越界的真实系统副作用` ✅
  · `-n 4` → **同样报 `AssertionError: 测试期出现 1 条…`** ✅
  ⇒ 守卫是**会话级夹具**, xdist 下每个 worker 各跑一个会话、**各自会红**; 每个用例必然落在某个 worker 里,
  所以**拦截覆盖没丢**。丢的只是那行**可见的台账**。
- **处置**: 见上 ② —— 既别因为"看不见那行"就以为守卫失效, 也别因为它还在就忽略"看不见"这件事。

### 项目文档里"并行不行"的那条理由是错的

- **触发**: 评估并行时会撞到既有说法 —— "本项目有绑定本地端口的 `FakeQbServer` 用例, 所以不能并行"。
- **判别**: **事实有误** —— `tests/helpers.py:388` 用的是 `ThreadingHTTPServer(("127.0.0.1", 0), ...)`,
  端口 **0 = 由内核分配**, 天然不撞。
- **处置**: 别拿这条当挡箭牌。
