# 轮询观测断言读「最后一轮」= 把必然事件与任意交错事件混进一个读法 —— 到达顺序敏感假红

> 摘要: e2e 断言等一次**必然发生**的轮次(如「lastRid 置空 ⇒ 请求不带 rid ⇒ 服务端恒回全量」)时读探针记录的「最后一轮」: 只要与该动作无因果的其它轮次(在飞旧 rid 请求被 ver 抬高后回落的增量轮)在全量轮**之后**落袋, 末值就停在否定态, 轮询窗内恒红 —— 隔离跑恒绿、全量顺序偶发红(issue 26-10-11-1825 实证)。存在性判据(「踢出之后落过一次 full=true」)对到达顺序免疫: 必然事件发生了就是发生了, 不该由可选事件的先后裁决。
> 等级: L0
> 触发: flaky, 顺序相关, 探针, 末值断言, 轮询竞态, expect.poll, 隔离绿全量红, 在飞请求, rid 过期, delta 轮, 全量轮, window.__d, applyStateRows, lastRid, delta-sync

**Refs:** memory-bank/issues/26-10-11-1825-test-delta-sync-full-round-flake.html

### 末值判据 vs 存在性判据

- **触发**: 写 / 改异步观测型断言 —— 页面内有持续运行的轮询循环(或任何会重放入侵观测点的事件流), 要断言「某动作之后发生了某类事件 X」; 或排查「同一用例隔离重跑恒绿、全量 / 长顺序偶发红, 且红在等待 X 的轮询断言超时」。
- **判别**: 断言形如 `expect.poll(() => rounds[rounds.length - 1].full).toBe(true)` —— 读的是**最后到达**的观测, 不是**发生过**的观测。若 X 由本动作**必然**触发, 而事件流里还有**与该动作无因果**的其它事件 Y 随时可落袋, 则 X 与 Y 同窗时 Y 后到即假红。签名: 红时轮询窗内确实发生过 X(探针 / 日志可证), 只是末位不是它。本仓实例链(2026-10-15 定案): `polling.js refresh()` 按发送时刻读 `lastRid`、手动踢一次**不取消在飞请求**(`scheduleNext` 只在每轮末尾续排) ⇒ 踢出的无 rid 请求与在飞旧 rid 请求并发; `runtime.py _reduce_delta` 对 `0<rid<ver` 回增量(full=false) ⇒ Y 的来源; e2e 共享长驻桩(`workers:1` 串行)的命令泵 / 回弹抬 ver ⇒ 全量顺序下 Y 落入本窗。与 [assertions.md](assertions.md) 的恒真 / 恒红形态并列: 这条是**判据读了错的统计量**(末值 ≠ 存在性)。
- **处置**: 改**存在性判据** —— 动作前快照观测数 `n0`, 轮询 `rounds.slice(n0).some(r => <X 的判据>)`。X 必然发生 ⇒ 充分; Y 的先后不再影响 ⇒ 时序无关。反模式: ①读末值(本坑); ②只等「长度自增」再读末值 —— 第一个新轮可能恰是 Y, 照样红(issue 报告已记此改道原因); ③抬超时窗口 —— 掩盖真问题且拖慢全量收口。红验: 等 X 落袋后注入一次迟到 Y(直接调观测入口喂等价载荷), 末值判据确定性假红、存在性判据绿 —— 2026-10-15 一次性探针 spec 实证(`newRounds=2 lastFull=false someFull=true`), 探针跑完即删不进提交。
  **泛化**: 「等一个必然事件」的断言, 判据都要落在**存在性**上; 只有事件本身**互斥且恰好一次**(状态机终态一类)才可读末值。
