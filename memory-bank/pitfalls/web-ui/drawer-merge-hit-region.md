# 几何分区式右键命中: 区域容器不必然覆盖其视觉范围 (静默)

> 摘要: 抽屉合并双列的右键菜单按「命中区域」定目标页签(宿主 `data-dt-host` → 列 `data-dt-tab` → 回落当前页签)。但**视觉上属于某列的大片区域并不在列元素里** —— grid `align-items: start` 让 `.dt-col` 只到内容高(短列下方留白落在 `.drawer-split`)、列间 24px gap 与分栏居中封顶 2400 之外的两侧留白也不属于任何 `.dt-col`。命不中时直接回落当前页签 ⇒ 在右侧空白右键拿到的是**左列(常为当前页签)**的模板选项(用户报「合并后右侧鼠标右键菜单会显示更改左边的模板选项」)。处置 = 正文区内按指针 x 归列兜底, 不得裸回落。
> 触发: 右键菜单命中区域, 合并双列, 右键弹错列的菜单, 右侧右键弹左边模板, 命不中回落, closest 判区域, grid gap, align-items start, 分栏留白, 居中封顶

### 视觉分区 ≠ DOM 包含: 区域判定必须覆盖「未落到元素上」的空白 (2026-10-10 实测)

- **触发**: 任何用 `el.closest("<区域标记>")` 判「点在哪个区域」的交互(右键菜单/拖放落点/点击分区)。当各区域是**平铺的兄弟容器**且容器**不铺满其视觉领地**时中招。
- **判别**: 症状是**命中了邻区/默认区**(不报错、不白屏)。本坑指纹 = 点在右侧大片空白却弹左列菜单。三个来源: ① `align-items: start`(grid/flex)让列元素不撑满行高, 短列下方留白归父容器; ② grid `gap` 落在容器上; ③ 居中 + `max-width` 封顶后两侧留白归父容器(宽屏各空数百 px)。
- **处置**:
  1. 命不中区域标记时,**不要直接回落"当前/默认值"** —— 先按几何(如指针 `clientX` 与各列矩形)归到最近的区域。
  2. 兜底只作用于**该交互所在的容器**(正文 `.drawer-body`), 不波及同类标记的其它宿主(页签栏/头部右键仍走原回落语义)。
  3. 归列判据用**列矩形右缘**从左到右取首个右缘不早于 x 的列(落在最右列之右取最右列、最左列之左取最左列), 与「左右半区」的视觉直觉一致。
- **守阵**: `tests/test_webui_static_dom_panel.py::test_drawer_tpl_menu_right_click_selection`(静态: `_drawerMenuColByX` 存在 + 限定 `dtSplitOn && .drawer-body` + 按 `.dt-col[data-dt-tab]` 取列) + `e2e/drawer-merge.spec.mjs`(真浏览器: 右列下方空白右键仍须弹内容模板, 双皮肤; 真实坐标手势)。
