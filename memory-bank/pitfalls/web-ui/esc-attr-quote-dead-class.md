# 字符串 DOM 拼属性: 插值出的引号会被转义 —— 类名带引号 = CSS 静默失效

> 摘要: 用 `dtHtml`(esc 单点)拼标签时, 属性名与引号必须写在**字面量部分**, 插值只能是「属性值」—— 把整段属性文本(`' class="virtual"'` / `' class="' + cls + '"'`)当插值传进去, esc 会把引号转成 `&quot;`, HTML 解析时再还原成类名里的引号字符: 元素 `class` 的实际值是 `"virtual"`(含引号)而不是 `virtual`, 于是 `.drawer-table tr.virtual` / `tr.skipped` / `tr.sel` 这类规则一条都不命中, 且没有任何报错 —— 只有把渲染结果 dump 出来逐字节比才看得见。
> 触发: 字符串拼 DOM, dtHtml 属性, esc 引号, 类名带引号, 条件类名, classList 不生效, 跳过态没变灰, 选中行没高亮, 属性拼进插值, A/B dump 逐字节比

### 条件属性拼进插值 ⇒ 类名带引号, 按类名写的 CSS 全线静默失效

- **触发**: 在字符串 DOM 层(变体 `drawer_tpl/*`、页插件、任何 `dtHtml` 调用点)按条件加类名/属性; 或把这种代码**平移**到 Vue/模板层。
- **形态**: 条件属性写成「插值产出一整段属性文本」—— `<tr${cls ? ' class="' + cls + '"' : ""}>`; 正确形态是属性名与引号在字面量里, 只把值插出去 —— `<div class="f-row${r.wide ? " wide" : ""}">`。
- **判别**: **当场**看渲染后的 DOM 属性值 —— 值里**带引号**(dump 里 `class="skipped"` 而同一行其它属性 `class=prio-btn` 不带)即是本坑; 浏览器 devtools 里 classList 只有一个含引号的类。**事后**症状是「按类名写的 CSS 不生效」而不是报错 —— 先怀疑类名本身, 再怀疑特异性/加载序; 同一文件里两种形态会**混用**(类名插值正确、条件属性插值错误), 所以"别的行是对的"不能排除本坑。**反向**: 若一个类名同时被两条路径写(渲染期拼字符串 + 运行期 `classList.add`), 会出现「首屏不生效、点一下才生效」的错位现象 —— 这是本坑最强的现场特征。
- **处置**: 字符串层**属性名与引号一律进字面量**, 插值只放值; 要按条件整段加属性时, 把条件写进**值**(或先拼好值再进同一个 `class="..."`)。平移时**不要照抄生效 DOM**: 迁到 Vue 后 `:class` 给出的是不带引号的真实类名, 与旧 DOM 不等价 —— 这是**旧实现的缺陷被修好**(观感会变: 变灰/高亮终于生效), 不是隐蔽回归, 按「重建期偏差」逐项记入计划变更记录并报给用户, 不许静默修、也不许为了"逐字节等价"把引号再拼回去。⚠ **`class=""` 是另一个方向的不等价**: Vue 的 `:class` 表达式恒被 `normalizeClass` 包成字符串, 全假时是空串, `patchClass` 会写出 `class=""` —— 旧 DOM 没有这个属性; 要逐字节等价就用 `v-bind="{ class: 值 || undefined }"`(`patchClass` 对 null 走 `removeAttribute`), 别为此在比对器里放宽。
- **复发**: 0
- **退役注 (2026-10-12, 计划 26-10-11-2106 W5)**: 本坑的**载体**(`dtHtml` 字符串拼 DOM)已随 15 个变体整体退役删除(W3 拍板「缺陷留到 W5」就此了结 —— 变体上的死类名缺陷不回灌修法, 随退役消失); W2 起 `content`/`trackers` 页签的 Vue 组件用真 `:class`, 变灰/高亮首次生效(当时已按「重建期偏差」报用户)。**机理仍在库**: 任何「平移字符串 DOM 到模板层」的场景照读本档 —— 属性名与引号进字面量、插值只放值; Vue 侧 `:class` 全假时写 `class=""` 的反向不等价(`v-bind="{ class: 值 || undefined }"` 规避)仍是活纪律。
