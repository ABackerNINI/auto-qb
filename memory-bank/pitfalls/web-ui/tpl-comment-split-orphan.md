# 模板分片切割丢失注释开头 → 聚合后孤儿 `-->` 渲染成可见文本

> 摘要: 把单文件模板切成 `shared/tpl/*.html` 时, 若一条 `<!-- ... -->` 的开头半被切走/丢弃, 分片里只剩
> 结尾的 `-->`, 聚合(boot.js 把清单里同目标分片拼成一条 HTML 串再注入)里就成了**孤儿 `-->`** ——
> 被当**文字节点渲染出来**。标签配平 / CSS 注释扫描等既有守阵全查不出。
> 触发: 页面出现不该有的中文注释文字, 页面上出现 `-->`, 模板分片, tpl-manifest, 聚合, 注释没闭合

### 分片边界切断注释 → 孤儿 `-->` 变可见文字(静默)

- **触发**: 拆分 / 重排 `src/auto_qb/webui/static/shared/tpl/*.html` 分片后, 页面某视图冒出一段本应是
  注释的文字(2026-10-03 实测: 设置页出现 `复用 .modal/.add-dialog 视觉语言(...); 打开时取一次, 卡内可手动刷新 -->`)。
- **判别**: `boot.js` 把清单里 `into:"app"` 的分片 `buckets.app += text` **拼成一个字符串**再
  `insertAdjacentHTML("beforeend", ...)` ⇒ 跨分片边界的注释本可正常跨接; 但**开头一行被整行丢弃**时,
  末尾 `-->` 成孤儿 → 渲染为文字(用户可见)。静态守阵 `_scan_css_comments`(只扫 CSS)与
  `test_frontend_template_split_wiring` 的标签配平都**不查 HTML 注释配平**, 全绿。
  定位: `grep -n -- '-->' shared/tpl/` 找**同一分片内无对应 `<!--` 开头**的行 —— 但合法续行也会命中,
  必须**连前后分片一起看**才能判孤儿。
- **处置**: 从分片前的原文件取回完整注释补上, 如 `git show <split-commit>^:<ui>/index.html`。
  注意别误伤跨分片边界的合法注释: 如 `dialogs-mgr.html:1` 的 `-->` 由 `dialogs.html` 尾部的
  `<!-- 添加种子对话框...` 闭合, 聚合后是配平的, **不要动**。
