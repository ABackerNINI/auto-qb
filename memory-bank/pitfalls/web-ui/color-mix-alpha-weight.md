# color-mix 混入带 alpha 的颜色且不写权重会产出半透明色

> 摘要: color-mix 混入带 alpha 的颜色且不写权重会产出半透明色
> 等级: L0
> 触发: color-mix, 半透明合成, tint 合成, 不透明基色, 吸左首格

### color-mix 想做「tint 叠不透明底」时混入带 alpha 的颜色且不写权重 ⇒ 半透明结果

- **触发**: 用 `color-mix(in srgb, rgb(255 255 255 / .12), var(--bg))` 这类写法表达「半透明 tint 叠不透明基色」（如吸左首格 hover 底）——混入色带 alpha 且两个颜色都没写权重百分比。实际案例：主表行语言 flat 名称格 hover/选中底（2026-10-30，用户目验「名称列一直与其它列不一致」）。
- **判别**: 合成结果**恒久**与预期不一致（不是过渡帧错位那种瞬间态）；用 getComputedStyle 取该元素背景色，发现 alpha < 1（半透明）。机理：权重缺省 50%/50%，premultiplied 结果 alpha = .5·.12 + .5·1 = .56——半透明 + 着色强度减半。
- **处置**: 「tint α 叠不透明底 C」的正确 color-mix 写法是**不透明色按权重**混：`color-mix(in srgb, rgb(255 255 255) 12%, var(--bg))`（恒等式 α·255 + (1-α)·C_bg，结果 alpha=1）。竖带/闪变类的**瞬间**不一致则另查插值管线（opacity 合成层 vs background-color 重绘），两种症状别混。
