# 多形态宿主: 同一功能的控件散在多个头部/正文, 改一处漏一处

> 摘要: 抽屉/面板承载多种形态后, 同一功能(如流量图的「时间档位 + 纵轴设置」)的**数据域是共用的**(`qbCurScope` 单点派生), 但**UI 挂点各自独立** —— 全局/分组流量图走**流量形态头部**(`v-if="drawer.kind === 'traffic'"`), 种子流量图走**种子形态头部**(`v-else`, `kind === "seed"` + `tab === "traffic"`)。把控件从正文「上提到头部」这类版式改只接了其中一个头部, 另一个形态的同一功能就**整组消失**(2026-10-09 用户报「种子流量图的时间档位与纵轴控件弄消失了」)。既有守阵钉的正是「控件落在**流量形态头部**内」—— 断言为真而缺陷不在断言面内, 属**断言口径太窄**而非「没断言」。
> 触发: 多形态, 形态宿主, 两个头部, 控件消失, 按钮消失, 版式改回归, 上提到头部, 流量形态头部, 种子形态头部, drawer.kind, kind === "seed", kind === "traffic", tab === "traffic", qbCurScope, torrent 分支, 共用数据域不等于共用挂点, 断言口径太窄

### 「上提到头部 / 挪进某容器」只接了一个形态宿主

- **触发**: 改动形如「把 X 从正文挪到头部/工具栏」(改的是**位置**而非逻辑), 而该功能的 UI 在多个形态下由**不同的头部/正文模板**承载时。
  2026-10-08 实测: 流量图档位/纵轴自正文上提到头部, 只写进了 `drawer.html` 的 `v-if="drawer.kind === 'traffic'"` 头部; 种子流量图(`kind === "seed"` + `tab === "traffic"`)走 `v-else` 的种子头部 ⇒ 该页签控件整组消失。当时的提交信息写「三挂点(全局/分组/单种)共用同一段头部/正文」——**前提就不成立**: 单种与另两挂点**不共用头部**。
- **判别**: 改版式前先问「这个功能的 UI 在**所有形态**下分别由哪段模板渲染」。判据: ①找该功能的**门**是什么(`v-if` 条件) —— 若门是 `drawer.kind === "X"`, 而功能数据域的派生点(如 `qbCurScope`)另有分支, 两者不一致即嫌疑; ②数一数模板里同类控件块的出现次数(`grep -c 'class="qb-tabs"'`), 与形态数对不上就是漏接; ③`v-if` / `v-else` 两个头部的**子元素清单**逐个比对, 差异项逐个解释。
- **处置**: 每个形态宿主**各接一份**(本仓库无模板 partial 机制, 只能复写); 复写必须**逐字同源**, 并**加守阵钉住两块内层一致**(空白归一后比对) —— 否则一处改了另一处静默漂移。落点选**用户已拍板的那个形态的观感**(本例: 用户上次明确要求控件在头部栏 ⇒ 补到种子头部, 而不是把工具条放回正文)。
- **附带陷阱**: 若目标头部已承载导航等元素、控件再并进单行放不下, **不要依赖自然换行**(换行点随视口宽漂移, 宽视口会把动作钮与控件挤在同一行)。用容器包成一组并 `flex: 1 1 100%` + 置于该容器**末位**, 才能**恒**换到第二行; 置于中间会把后续元素顶到第三行。
- **守阵**: `tests/test_webui_static_dom_panel.py` —— `test_frontend_qb_traffic_chart_wiring`(两头部控件组齐全 + `qbCurScope === 'torrent'` 门 + 内层逐字同源) 与 `test_frontend_qb_traffic_yaxis_and_annotation`(`qbSetYAxisMode(` 计数 = 6 = 两处 × 三态 + 三皮肤 CSS 成对清单)。
