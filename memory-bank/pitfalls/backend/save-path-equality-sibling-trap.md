# save_path 等值判据把同保存根兄弟目录种子当组内

> 摘要: save_path 等值判据把同保存根兄弟目录种子当组内
> 触发: save_path 等值/前缀判据,内容根,兄弟目录,组内身份,foreign 候选门,删链门,假阳性

## 本篇只回答

relocate/组账类判据里「以 save_path 等值或前缀当组内/作用域信号」这一类假阳性的触发与处置 —— 组内身份判据必须锚内容根, 不锚 save_path。

### 「save_path 恰等 job.src/旧根」的候选门会卷进全部兄弟目录种子

- **触发**: 任何把「save_path 归一恰等 job.src(旧根/下载保存根)」或「save_path 在其前缀下」当**组内/作用域身份**信号的判定面 —— qB 的 save_path 是**下载保存根目录**(内容根在其下一层), PT 库按分类目录做保存根是常态布局, 同一根下几十颗内容根各异的无关种子全部满足等值。已三踩: ① 删链门旧锚(2026-11-07 T1b/E7 实测假依赖, 组外兄弟种子顶进依赖集致收尾自锁, 修复 = 计划 26-11-07-1300 D9 重锚 job.scope); ② foreign 侦测面候选门(2026-11-21 真机, 计划 26-11-20-0434 落地后首次整组迁移, issue 26-11-21-1500: activation 扫描 61 候选 60 条为兄弟目录无关种子, mismatch 洪泛呈现与通知); ③ 删链门等值面残留(2026-11-22 S4 真机 dir_alias+同根兄弟布局, issue 26-11-22-0905: 修复①的 2076c889 评审 blocker 有意加回「save_path 恰等旧根」等值面并联判, 目录级命中即依赖无精判 → 假依赖 deps 恒非零收尾自锁不可自愈; 修复 = 消费侧 per-file「任一文件落 scope 下」精判, 计划 26-11-22-1714 批1/F1)。
- **判别**: 候选/依赖/拦截计数与真实形态严重失衡(如 61 候选仅 1 真命中); 被标记种子的**内容根**与迁移组内容根不同但 save_path 相同; R5 类文案(「同目录异内容」)与用户核对结果(「不同根目录的无关种子」)对不上 —— 出现这类错位先怀疑判定门锚错了路径维度, 而不是怀疑 qB 数据。
- **处置**: 组内身份判据锚**内容根**维度 —— 候选内容根经 `content_root_of`(layout_of 三形态: 唯一顶层段 = save_path/<段>; 平铺/混合退化 = save_path 本身)现算, 与 `job.scope`(建账既有产物)比对; 组员恒共享同一内容根(组键 = 归一 save_path + 排序文件元组, group_key_of 单点, 比内容根更严); 退化形态(平铺/混合, scope=save_path)预筛恒过、交文件清单比对兜底(保守回落, 不引入新行为); 复用同一次文件表拉取(记录级惰性缓存)零附加 API。新判定面立项时先对齐删链门先例(ru.chain_gate_hits 的 scope 锚 + 仅等值并列面), 别再从 save_path 入门。依赖判据同法 —— 等值面命中只是候选信号不是结论, 目录级 job 由消费侧补 per-file「任一文件落 scope 下」精判(混合布局宁拦勿漏, 清单不可得保守计依赖, 计划 26-11-22-1714 F1)。
- **守阵**: 计划 26-11-21-1600 B1 批为 foreign 门落内容根预筛纯函数 + 全 layout 形态单测(平铺/混合/大小写折叠/空文件表); 既有删链门形态守阵(test_relocate_units chain_gate 系列)同面; 计划 26-11-22-1714 批1 为等值面精判落 per-file scope 落点守阵(兄弟假依赖豁免/纯落进保留/混合保留/清单不可得保守/scope 缺失旧账不精判)。
- **复发**: 0 (建档前已两踩: 链门 T1b/E7 与 foreign 门 issue 1500, 见触发条 —— 建档即为此; 后续复踩在此行追加「+N (日期): 为什么没命中」)
- **复发 +1 (2026-11-22, issue 26-11-22-0905)**: 建档把第①踩当「已修复历史」, 没识别出修复本体 2076c889(11-08)评审 blocker **有意加回**了等值面并联判 —— 该残留面在建档勘察时漏盘; 守阵 chain_gate 系列也未覆盖 dir_alias + 同根兄弟恰等旧根布局(11-21 事故才首现该布局)。第三踩假依赖收尾自锁, F1 消费侧精判收口(计划 26-11-22-1714 批1)。
