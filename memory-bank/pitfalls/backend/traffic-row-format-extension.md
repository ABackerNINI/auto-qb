# v4 天文件行型扩列: 位次歧义与「回滚 = 整行判坏」

> 摘要: 给按列数白名单解析的行型加列(本仓 v4 天文件 z 行加「末端快照对」, plan 26-10-16-1509 形态 D)有两处非显然约束 —— ①新列位次不能追加在**可选尾列**之后: 会产生歧义列数(6 列既可读成「尾列 + 半对」也可读成「无尾列的整对」), 必须插在可选尾列**之前**让列数唯一可判; ②旧解析器对白名单外的列数是「**整行判坏、静默丢弃**」而不是「忽略新列」 ⇒ 回滚到旧版本前必须先剥列, 否则那段记录被静默丢掉(游程消失、dt 链重排、坏行占比上升)。
> 等级: L0
> 触发: 行型扩列, 加列, 可选尾列, 列数歧义, 位次定约, 回滚, 旧解析器整行判坏, z 行末端对, v4 天文件, 格式定约, 向后兼容

**Refs:** memory-bank/tasks/26-10-15-webui-qb-traffic-restart-spike-gap.md

### 新列位次: 追加在可选尾列之后 = 歧义列数

- **触发**: 给「列数白名单」解析的行型加列(实例: v4 z 行加末端快照对, plan 26-10-16-1509 形态 D; 行型本身有可选尾列 dt_ms)。
- **判别**: 列出新旧形状的**列数集合** —— 若存在交集即歧义(6 列: 是「dt + 半对」还是「无 dt 的整对」? 解析器无法判别)。判据与值有没有默认无关, 只看列数能否唯一映射形状。
- **处置**: 位次插在可选尾列**之前**(`z,rl,dlt,upt[,dle,upe[,dt_ms]]`: {4,5} = 旧, {6,7} = 新, 两集合无交集), 解析按列数分支。同族要点: 新解析器必须同时接受新旧形状(旧 → None → 语义退化); 写出侧恒写新列(拿不到时写与旧列同值 = 显式退化), 避免「有无新列」的两态行为分叉。
- **守阵**: `tests/test_traffic_store.py::test_v4_z_end_pair_shapes_legacy_compat`(混合形状同文件共存) · `::test_v4_format_fail_fast_and_torn_tail`(位次文本逐字钉住)。

### 回滚到未扩列的旧版本: 旧解析器把新行整行判坏

- **触发**: 已落盘新列的版本需要回滚; 或设计扩列时评估兼容面/回滚预案。
- **判别**: 看解析器对「白名单外列数」的行为 —— 本仓是**整行记 bad、游标不推进、记录直接丢弃**(不是「忽略未知尾列」), 于是回滚后那段 z 记录凭空消失(空闲段游程没了, 相邻记录的 dt 链锚点重排), **静默且不可逆** —— 与「多一列被忽略」的直觉相反。
- **处置**: 回滚前必须先剥离新列(6/7 → 4/5 列)或保留一段兼容解析; 约束写进格式定约注释(实例: `src/auto_qb/core/traffic_store.py` 文件尾 v4 行型定约的「形态 D 回滚约束」段)。已写入的新列不回补不删除(与「历史坏行不回补」同口径)。
- **守阵**: 无(工具链/运维面判据; 兼容面由上方形状用例覆盖)。
