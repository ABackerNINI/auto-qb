# 哨兵值泄漏进算术比较: 「0 = 无位置概念」被当成 epoch 0, 覆盖判据静默恒通过

> 摘要: 哨兵值泄漏进算术比较: 「0 = 无位置概念」被当成 epoch 0, 覆盖判据静默恒通过
> 触发: cutoff_done, 哨兵, 0 = 没有位置概念, 位置证明, 覆盖判据, 减法, 比较, epoch 0, 恒通过, 退化, 永续放行, 缺席证明, 观察期, HR 管束

### 把「0 = 没有位置概念」的哨兵当真实 epoch 去做减法 / 小于比较

- **触发**: 一个 float 字段用 `0` 表示**「这个概念不存在」**(而非「时刻为 0」), 而下游判据直接把它
  当作时间戳参与算术 —— 本仓 `HrLaneState.cutoff_done`(model.py 注释原话「0 = 没有位置概念」),
  供给侧 `_update_cutoff` 只在 `page_deepest > 0` 时前进 ⇒ 整列 done 不可解析时它恒为 `0.0`。
  三处覆盖判据(终态冻结 / 观察期推进 / 批量「未列出」签发)各写一份 `done < st.cutoff_done`
  (或 `done - COVERAGE_SLACK < st.cutoff_done`), 于是:
  - `cutoff_done == 0` 时, `done < 0` 对任意真实 epoch(≈1.7e9)**恒为 False** ⇒ 「未覆盖」出口永不触发;
  - 判据**退化成恒通过**, 三条路全部签发**永续放行**, 种子就此退出 HR 管束 —— 用户据此删种即真吃 H&R。
- **判别**: 三个信号一起出现即确诊 ——
  1. 字段的 0 值在注释/文档里被写成「无 / 未取到 / 没有概念」, 而不是「1970-01-01」;
  2. 下游判据里出现 `x - SLACK < field` 或 `x < field`, 且 **没有**对 `field <= 0` 的提前返回;
  3. 用真实 epoch 代入手算: 不等式**恒成立**(恒通过)或**恒不成立**(恒拦截), 与数据无关 ——
     即判据已经失去分辨力。测试面若只有「field 非 0」或「另一条分支被短路」的用例, 就盖不住。
- **处置**: 别在调用处各补一份 `field <= 0` 守卫(三处复制 ⇒ 迟早再漂一次)。**把谓词收成一个纯函数**,
  在唯一一处显式判死哨兵语义: 本仓 `hr/service.py::_lane_covers_done(st, done, slack=0.0)`
  —— 全深度 ⇒ 对任意位置成立; 位置有界档 ⇒ `done` 已知且 `done - slack >= cutoff_done`;
  `cutoff_done <= 0` ⇒ **位置不可证**(保守维持管束, 命中照常)。三处调用方全部改调它。
- **守阵**: `tests/test_hr_service.py::test_position_proof_cutoff_zero_is_unprovable`
  (零位置概念三判据 + 反向对照组「全深度 / 边界已越过 / 差 1s 落余量外」, 防止修过头拦死正常放行; 已红验)
