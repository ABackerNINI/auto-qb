MECH机制自检 + 交接说明(T5)

入场原语(fade / rise / pop / slip)的样例演示机制 = display:none 一帧后恢复, @starting-style 会重新播放入场; --fx-i(stagger 序号槽)只允许设在 ≤8 个表面级联的入场样例上(hover/press 反馈样例绝不设 -- 否则交互被 delay 拖慢; torrent 行禁全行 stagger)。S3a 后补的 4 组组件走「构造器卡」: CARDS 条目带 ctor 字段(modal/drawer/rows/toast), buildSample 分发到对应 make* 构造器, comp.demo() 承接演示钮与循环档 -- 弹窗/抽屉/toast 均为真触发。ripple / 图标附加 / zoom-out 这几个「样例页内实现」的候选若被选定, 是否把实现提升进 fx 库(fx.js 加 ripple 助手 / fx.css 加图标子元素契约与反差缩放原语)是 S4/S6 的决策点。

对最重的 4 个样例做页内基准: 350ms 节奏连触发 4s, rAF 计帧 + longtask 统计 -- backdrop blur(D2-4) / sheen(D1-3) / 弹窗入退场(D2-1) / 行插入(D4-4)。数值以跑基准当时的环境为准, S4 裁决请用有头浏览器复测。 S3 实测记录(Playwright chromium 1.63, 1440x960, longtask 全零; 数字为当时环境快照, 不作裁决): 有头 -- D2-4 blur 过渡 21.5 fps / blur 静置维持 53.7 fps / D1-3 sheen 74.5 / D2-1 弹窗 62.1 / D4-4 行插入 53.8; headless -- blur 35.7 / sheen 59.5 / 弹窗 60.0 / 行插入 60.0。结论向: blur 过渡期是唯一明显掉帧项(大面积 filter 逐帧重模糊), 静置维持无负载级差; 余项接近满帧。
