D9 · 形态挑选区(追加)消息通知形状 / 边标(材质不动, 只挑形状)

为什么单开一区: 上一轮把提示条与确认框「统一」成同一套切角 glass, 用户否决 —— 「消息通知不要切角」。切角是弹窗级大面浮层的语言(弹窗 / 限速浮层), 通知是过路小条: 切角在小面积上读作装饰缺口, 还会啃掉底部倒计时条右端。故本区材质一行不动(高光渐变 + 近不透明底 + 语义描边 + 语义图标, 与确认框同源), 只挑形状与边标; 六个候选共用同一基座, 配色/几何与生产逐字同源(fx 皮肤令牌)。每张卡摆 ok / warn / error 三档, 方便看全严重度; 点「演示」重放入场, 勾「选定」后页尾可导出 JSON 清单。
