# commands

项目命令的**统一调用面**:要跑命令时不去文档里抄,先按层级定位再调。

> **路径约定**:`<skill-dir>` = 本 skill 所在目录,安装位置因项目而异 —— 先用 Glob 定位(`**/commands/scripts/run.py`),别照抄路径。
> 用**项目自己的解释器**跑它(`uv run python <路径> run <task>`)。

引擎只认识**包**与**命令**:项目事实全在包里,它只读 `<包>/config.toml` —— 所以**加命令只有"放进某个包"这一条路**,包外的文件引擎扫不到(静默失效)。

## 入口:先装 wrapper

`commands` 不是可执行程序,**cwd 也不在任何 shell 的搜索路径里**(实测 Git Bash / PS 都不搜)——
所以首次用先装一次(幂等):`python <skill-dir:commands>/scripts/install_wrapper.py`。
装完 `commands run <task>` 直接可用;落点 / 撤销 / 批处理坑见 [references/wrapper.md](references/wrapper.md)。

## 记法

- **文档记法** `commands run <task>` —— 文档与回复里一律用它。`<task>` = `list` 里的 id;子包**两种写法都认**(`ship.commit` / `包/子包.<task>`)。
- **真实入口** 装了 wrapper 就是它本身;没装时展开成 `python <skill-dir:commands>/scripts/run.py <子命令> [参数]`。

两者都**不是**让你去抄命令本体 —— 文档里再抄一份就是反漂移闸门要判红的形态。

## 四个子命令

| 子命令 | 作用 |
|---|---|
| `run <task>` | 校验前置后执行,超时按失败计。**常规路径只用它** |
| `list [包路径]` | 列出**当前层级**:包 + 常显命令 |
| `show <task>` | 打印展开后的真实命令与 `doc` 深读指针,不执行(排障/自证) |
| `add` | 收录一条命令进包(默认 dry-run) |

`run` 默认只回摘要、不 dump 命令;**带 `requires` 或 `risky = true` 的例外**,先打印再执行。
摘要 = **末几行结论 + 异常行**(`[WARN]`/`[FAIL]`/`Traceback`,封顶 8 行)—— ❗**只取末几行是错的**: 检查表的 WARN 内容在中段,截掉它调用方只能重跑。

## 引导:按当前任务逐级下钻

- **不知道调哪个** → `list`:有哪些包、各自管什么事,以及各包的常显命令(`★`)
- **按任务选包** → `list <包>`;未定位 → 继续下钻 `list <包>/<子包>`(深度不限)
- **已知 id** → 直接 `run <id>`;**要看细节** → `show <id>` 给的 `doc` 指针(包内 `references/`)
- **排障** → `list --all`:全树(含被禁用的)

包内 README 与 `references/` 是**包私有**(引擎不读):日常只要 task id,走 `doc` 指针按需读,**不要整读**。

`★` = 常显(`pin = true`),浮到父级;一级视图只出"包 + 常显",命令长到 200 条也不臃肿 —— **靠分层,不是靠写得短**。

## 收录协议

三条判据**任一命中**就自己收:①**重复**(本会话第二次) ②**难拼**(≥2 个环境前缀/参数) ③**易错**(有"看着正常但不生效"的写法)。都不中 → **不收**。

细节(判据怎么判/放哪个包/`add` 必填项/防滥用/**低噪音包的写法**)见 **[references/howto-add-command.md](references/howto-add-command.md)**,真到要收录时才读。

## 停手点

- **STOP(rc=1)**:配置写错(未知键 / 非法 timeout / 未确认)·占位符展不开 · **参数给了不接参数的 task** · `requires` 前置非 0 · task id 全树重复 · 包名≠目录名 · 子包目录不存在 · **`doc` 指向的文件不存在**。**不静默降级** —— 静默失效比报错坏得多。
- **命令非 0(rc=3)**:看输出里的失败行,不要照着重跑。

## 反模式

- ❌ 去文档里抄命令(可能正是"看起来最正常但不生效"的那版);用 `list`/`show` 取。
- ❌ 见命令就收 —— 三条判据同时是上限,否则配置变垃圾桶。
