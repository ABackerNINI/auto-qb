- 用户口径（四轮收敛）：①不要显眼动效；②不许在数值后方追加图标等占宽元素；③来源编码不能只靠线宽/亮度，必须独立于 HR 状态色；④中途试过「在线副线用 accent 蓝」被否；⑤中途定 M2（双轨）→ 移除副线。**最终版**：线色一律 currentColor 随状态色，不引入新色；三编码 = 长度（在线整格、本地与未核实半格）+ 线型（未核实点线 80%）+ 明暗（本地 50% 兜底）；已排除 / 无 HR 不画线、文案进 title。
- ⚠ 误判一次：用户连说两次「本地看不到线」「未核实也看不到」，我当成"要删除"而撤掉了未核实的线 —— 实际是**渲染 bug**。根因：半格线挂在空 `<i>` 上，绝对定位只写 `left: 0` 不给 `width`，`width: auto` 收缩为 0 → 整条不可见；整格线因写了 `width: 100%` 才正常。修法：半格线补 `width: 100%`。教训：用户报告"元素看不见"先查布局/尺寸塌陷，别当成设计意图变更。
