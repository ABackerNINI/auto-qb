AUTO-QB · WEB UI · 命名与目录迁移计划 · 待确认

Atlas 星图 & Prism 棱镜

两套并存 Web UI 各取一个身份名，目录随名落位，公共逻辑层收进 shared/，为后续更多 UI 预留干净的结构。
日期 2026-09-15 分支 frontend/develop（工作区干净） 范围 目录移动 + 引用改写 + 1 条路由 后端改动 仅 web.py 重定向

两套 UI 目前一个叫"旧版"、一个叫 newui—— 都是代际词：再添第三套 UI 就会失效，也不承载任何风格信息。本计划给它们各起一个与视觉气质同源的身份名：旧 UI 定名 Atlas（星图）—— 深色全景仪表盘，把满天种子收进一张图；新 UI 定名 Prism（棱镜）—— 一束光分出五色光谱，正对它的五主题工程仪器感。目录 atlas/ 与 prism/ 各自落位，公共逻辑层（app.js 三件套 + vendor + 图标）收进 shared/ 单一来源；此后新增 UI = 新增一个同名目录，零结构成本。

01

现状盘点

AS-IS

全部前端资产在 src/auto_qb/web_ui/static/，由 web.py:277 的 StaticFiles(html=True) 以根路径全量托管 —— 目录结构即 URL 结构，这是迁移方案的基础事实。

资产角色被引用方式
index.html · style.css · icon.png旧 UI（视觉层，单文件深色主题，八轮视觉打磨）/ 与 /style.css、/icon.png（绝对路径）
app.js · config_editor.js · config_rules.js共享逻辑层（两套 UI 单一来源，不复制分叉）两套 index.html 均引 /app.js 等绝对路径
vendor/vue.global.prod.js共享依赖（Vue 3 本地托管）两套 index.html 均引 /vendor/…
newui/新 UI（tokens/themes×5 + base/components/views + theme.js）/newui/ 及 /newui/css/… /newui/js/theme.js

关键事实（决定方案的四个约束）

事实含义
目录即路由StaticFiles 挂根，无逐文件路由 —— 挪目录 = 改 URL，后端几乎零改动；唯一例外是根路径 /：旧 index.html 挪走后根目录无 index.html，需补一条重定向。
共享逻辑层单一来源app.js 三件套被两套 UI 引用且无路径硬编码（JS 内部不引用自身路径）—— 可整体挪入 shared/，只改两处 HTML 引用。
非 /api 全量 no-cache（web.py:289）升级后浏览器不会拿旧 HTML/JS 打新 URL —— 路径切换后缓存风险低。
测试有路径触点test_web.py::test_static_assets_disable_heuristic_cache 直接请求 /app.js /style.css /config_editor.js，且 / 将从 200 变为重定向 —— 测试必须同步改写。

命名原则（本次沉淀，后续加 UI 沿用）

#原则理由
1取身份名，不取代际名classic / old / new / v2 会随第三套 UI 出现而失效；身份名（星图、棱镜）与时间无关
2目录 = 英文小写单词，与 URL 一致/atlas/ 好打好听好收藏；目录名即路由名，零映射成本
3中文名两字，与视觉气质同源顶栏切换器与 title 里显示，短名不挤布局
4成对（或成组）不撞车多 UI 并存时名字要像同一柜子里的仪器，避免一个具象一个抽象的错位

# 静态前端：UI 目录化（atlas=星图 / prism=棱镜），根路径进默认 UI
# 挂在 app.mount("/") 之前
@app.get("/", include_in_schema=False)
async def _ui_root() -> RedirectResponse:
    return RedirectResponse("/atlas/", status_code=307)

@app.get("/newui/{rest:path}", include_in_schema=False)   # 可选：旧书签兼容
async def _newui_legacy(rest: str) -> RedirectResponse:
    return RedirectResponse(f"/prism/{rest}", status_code=307)

默认 UI 取星图 = 维持"根路径是老入口"的现状习惯；将来若棱镜转正，改一行即可。新增 config 键则需同步 validate_config + schema（黄金法则 4），默认先不做配置化，避免为一次性决定加键。

07

风险与回退

RISKS
风险评估对策
浏览器缓存旧 HTML/JS 引用旧路径低非 /api 已全量 no-cache（带 ETag 重校验），路径切换后天然失效
外部收藏 /newui/ 失效中307 兼容重定向覆盖；重定向属可观测残留，后续可撤
共享逻辑层被误复制进某 UI 目录中shared/ 单一来源写入 modules.md 与 pitfalls；冒烟契约（JS→DOM 约定）不变
JS→DOM 契约在改 HTML 时被碰坏低P2 只动 <head> 资源行、切换链接、title 三类行，不触模板结构；P4 全量测试兜底
rename 检测失真低git mv 原子移动；审阅用 git log --follow、git diff -M
回退单提交 revert 即完全还原 —— 无数据迁移、无配置迁移、无外部依赖
