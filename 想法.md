# 想法

自动管理qbittorrent的PT种子

## 功能

利用`qbittorrent-api`实现以下功能

* [x] 每60秒检查一次
* [x] 自动给对应的tracker添加tag, 自动删除(替换)不想要的tag, 自动删除类似(单词相同大小写不同)的tag
* [x] 自动给对应的种子添加HR tag, 如tracker1 HR为3D(3天), 80%触发, 则将满足条件的种子添加HR tag: !!HR3D!!
* [x] 根据已有种子的tracker导出yaml配置模板, 尽量保留已有配置
* [x] 自动暂停正在上传但文件不存在或文件大小不正确的种子(可能是辅种, 原种子带文件被删除了), 并添加标签: MISSING. 或者要求重新校验?
* [x] 辅种任务跳过检查并自动开始, __下载量/完成量/进度为0__ 且 __状态为暂停stop的种子__ 视为辅种任务
* [ ] 自定义跳检规则: 可以对不同路径, 不同大小, 不同tracker, 不同分类或tag进行配置, 跳检基础检查: 对比文件列表与文件大小(宽松) 或 对比piece hashes(严格)
* [ ] 自定义规则: 筛选条件+动作. 筛选条件: 路径, 大小, 标签, 分类, trackers, 状态. 动作: 跳检, 校验, 限速, 暂停, 开始, 添加标签, 添加分类, 强制汇报tracker, 添加HR标签, 添加HR分类 等
* [ ] 自动给已满足HR条件(做种时间长于要求的时间+12小时)的种子添加分类: HR-DONE, 并强制汇报tracker
* [ ] 根据tracker自动限速
* [ ] (待完善) 复杂的限速规则, 比如指定某tracker某段时间段限速, 或者根据每天流量自动限速

## 配置文件

```YAML
---
config:
    interval: 60S # 检查间隔, 支持时间单位: S秒, M分, H时, D天
    remove_similar_tags: true # 删除类似(单词相同大小写不同)的tag

    add_hr_tags: false # 添加HR标签
    hr_tag_format: "!!HR${time}!!" # HR标签格式, 支持${time}变量

    add_hr_categories: true # 添加HR分类
    hr_category_format: "!!HR${time}!!" # HR分类格式, 支持${time}变量
    overwrite_category_for_hr: false # 添加HR分类时强制覆盖已有分类(分类只能有一个)

    skip_checking_for_cross_seeding: true # 跳过辅种检查
    skip_checking_auto_start: true # 跳过辅种检查时自动启动种子
    add_skip_checking_tags: true # 添加跳过辅种标签
    skip_checking_tag_format: "SKIP_CHECKING" # 跳过辅种标签格式

    # qBittorrent客户端
    qbittorrent:
        host: 127.0.0.1
        port: 8080
        username: <USERNAME>
        password: <PASSWORD>

    example_rules: # 规则集名称, 自定义, 以"_rules"结尾
        rule1:
            enabled: true
            conditions: # 筛选条件必须全部满足时才生效
                - path: /path/to/file # 路径, 支持正则, 正则以"regex:"开头
                - size: ">=100MiB" # 文件大小限制, 支持大小单位: B, KiB, MiB, GiB, TiB, 支持比较符: >, <, >=, <=
                - tags: # 标签, 不同标签组之间为或的关系, 支持正则和${hr-time}变量
                    - tag1,tag2
                    - tag3,tag4
                - category: # 分类, 支持正则和${hr-time}变量
                    - category
                - trackers: # tracker的自定义名称, 不同tracker组之间为或的关系, 支持正则
                    - tracker1
                    - tracker2
                - state:  # 不同state组之间为或的关系, 种子状态, 可选: checking, complete, downloading, errored, stopped, uploading
                    - complete&uploading # 状态为完成且正在上传, 用&连接符连接
                    - stopped
                - hr: condition-met # HR筛选, 可选: condition-met(满足HR触发条件), condition-not-met(不满足触发条件), satisfied(满足要求+额外做种时长)
                - date_time:
                    day_of_month: 1-31
                    day_of_week: 1-7
                    time: 10:00-23:00
                - seedtime: <24H # 做种时长
                - upload_ratio: ">1.5" # 上传比率
                - upload_size: ">10GiB" # 总上传大小
                - upload_size_today: ">10GiB" # 今日上传大小, 只统计当日程序起始运行至当前时间段内上传的数据, 同一天多次运行有效
                - upload_size_this_week: ">10GiB" # 本周上传大小, 类上
                - upload_size_this_month: ">10GiB" # 本月上传大小, 类上
                - freespace:
                    path: "R:\\"
                    amount: <100GiB # 可用空间大小
            actions: # 筛选条件满足后执行的动作, 动作顺序执行
                - basic_check: filelist # 可选: filelist(对比文件列表和文件大小, 宽松), piecehashes(对比每个块的hash, 相对严格), custom(自定义)
                - custom_basic_check_program_path: "/path/to/program" # 可选: 运行自定义的basic_check程序, 参数: 暂未定
                - check: full-checking # 校验, 可选: skip-checking, full-checking
                - always_check_first_one: true # 对相同路径下的第一个种子强制校验
                - start: true
                - ignore_next_action_error: true # 忽略下一个动作的错误继续执行后续动作, 仅对下一个动作起效, 默认不忽略错误
                - add_tags: # 添加标签
                    - tag-format1 # 标签格式, 支持${hr-time}变量
                    - tag-format2
                - ignore_next_action_error: true
                - remove_tags: # 自动删除站点标签, 可以有多个, 支持正则和${hr-time}变量
                    - tag-format3
                - ignore_next_action_error: true
                - add_category: # 添加分类
                    format: category-format
                    overwrite: true # 添加分类时强制覆盖已有分类(分类只能有一个)
                - remove_category: true # 自动删除站点分类
                - move_to:
                    path: /path/to/move/to
                    overwrite: true
                - upload_speed_limit: 1000KiB/s
                - download_speed_limit: 1000KiB/s
            stop_following_rules_if: conditions-met # 可选: conditions-met, conditions-not-met, action-failed, all-actions-succeed, always, never
        rule2:
            # ...

    # tracker站点配置
    trackers:
        tracker1: # 自定义tracker站点名称
            domains: # 站点域名, 可以有多个, 也可单独配置
                - domain1
                - domain2
            tags: # 自动添加站点标签, 可以有多个
                - tag1
                - tag2
            remove_tags: # 自动删除站点标签, 可以有多个
                - tag3
            U: 1000KiB/s  # 单种上传限速, 0指无限制, 支持速度单位: B/s, KiB/s, MiB/s, GiB/s
            D: 10MiB/s  # 单种下载限速, 同上
            HR: 3D@100%+12H # HR配置, 格式为"做种时间@触发条件+额外做种时间", 额外做种时间防止意外,
                            # 支持时间单位: S秒, M分, H时, D天.
                            # `@100%` 表示触发HR的百分比, 默认80%. 也可设置触发HR的大小, 如`10MiB`,
                            # `+12H`表示做种满3天+12H, 自动添加HR-DONE分类
            rules:
                - ignore_next_rule_error: true # 忽略错误, 覆盖规则指定的"stop_following_rules_if"
                - @example_rules # 引用规则集
                - @example_rules.rule1 # 引用具体规则
        tracker2:
            domains:
                - domain1
                - domain2
            tags:
                - tag1
                - tag2
            U: 1000KiB/s
            D: 10MiB/s
            HR: 20H@30%

        tracker3:
            domains:
                - domain1
                - domain2
            tags:
                - tag1
                - tag2
            U: 1000KiB/s
            D: 10MiB/s
            HR: 20H@10MiB
...
```

### 例子1: 简单配置

```YAML
---
config:
    interval: 60S
    remove_similar_tags: true

    add_hr_tags: false
    hr_tag_format: "!!HR${time}!!"

    add_hr_categories: true
    hr_category_format: "!!HR${time}!!"
    overwrite_category_for_hr: false

    skip_checking_for_cross_seeding: true
    skip_checking_auto_start: true
    add_skip_checking_tags: true
    skip_checking_tag_format: "SKIP_CHECKING"

    qbittorrent:
        host: 127.0.0.1
        port: 18080
        username: admin
        password: pwd12345

    trackers:
        hdfans_org: # 红豆饭
            domains:
                - hdfans.org
            tags:
                - HDFans
            U: 0KiB/s
            D: 0KiB/s
            HR: "3D@80%+12H"
...
```

### 例子2: 自动添加盘符标签规则

```YAML
---
config:
    # ...

    add_tag_rules:
        add_r_tag: # 为R盘的两个目录添加"R"标签
            enabled: true
            conditions:
                - path:
                    - "regex:^R:\\Download\\PTing\\"
                    - "regex:^R:\\Download\\ing\\"
            actions:
                - add_tags:
                    - "R" # 添加"R"标签
            stop_following_rules_if: never
        add_i_tag: # 为I盘的目录添加"I"标签
            enabled: true
            conditions:
                - path:
                    - "regex:^I:\\PT\\LongSeeding\\"
            actions:
                - add_tags:
                    - "I"
            stop_following_rules_if: never

    trackers:
        hdfans_org: # 红豆饭
            domains:
                - hdfans.org
            tags:
                - HDFans
            U: 0KiB/s
            D: 0KiB/s
            HR: "3D@80%+12H"
            rules:
                - @add_tag_rules.add_r_tag
                - @add_tag_rules.add_i_tag
...
```

### 例子3: 自动校验并开始指定盘的IYUU辅种规则

```YAML
---
config:
    # ...

    iyuu_rules:
        # 自动校验R盘的IYUU辅种并开始
        auto_start_iyuu_on_r:
            enabled: true
            conditions:
                - path:
                    - "regex:^R:\\Download\\PTing\\"
                    - "regex:^R:\\Download\\ing\\"
                - category:
                    - "IYUU自动辅种"
            actions:
                - check: full-checking
                - start: true
            stop_following_rules_if: action-failed

        # 自动跳检I盘的IYUU辅种并开始, 添加"跳检"标签
        auto_start_iyuu_on_i_skip_checking:
            enabled: true
            conditions:
                - path:
                    - "regex:^I:\\PT\\LongSeeding\\"
                - category:
                    - "IYUU自动辅种"
            actions:
                - basic_check: filelist # 仅检查文件列表
                - check: skip-checking
                - add_tags:
                    - "跳检"
                - start: true
            stop_following_rules_if: action-failed

    trackers:
        hdfans_org: # 红豆饭
            domains:
                - hdfans.org
            tags:
                - HDFans
            U: 0KiB/s
            D: 0KiB/s
            HR: "3D@80%+12H"
            rules:
                - @add_tag_rules.add_r_tag
                - @add_tag_rules.add_i_tag
                - @iyuu_rules
...
```
